这版怎么做的、哪里不是烘焙器本体
  1. 轨迹：载入烘焙器 tool/src/js/20_sim.js，按「金曜菊-B」存档里两条引菊层的参数逐星记录点火后的真实位置；延时点火的金锦层，星点火前不画。
  2. 尾巴亮度随年龄的曲线，按烘焙器火花的冷却、淡出公式（温度按年龄 ÷ 中值寿命，最后 30 % 寿命淡出）算，颜色走各层自己的 Ramp。这是整条火花云的平均，没有「火花起势」「寿命随发射阶段变长」这两项随位置的变化。
  3. 单片 + 锁 Z 在预览里绕竖直轴转到正面朝相机；UE 的 Camera Facing + Locked Axis : Z Axis Facing 已经在本机实播验证过能立着播放、随方位转（详见 UE_v2_verify/结论与云端交接.md）。
  4. 颗粒的 UE 公式（本机读回）：A = Noise.r + 2·(Param2 + Progress)，mask = smoothstep(h, 1−h, A)。预览直接用同一条公式。
