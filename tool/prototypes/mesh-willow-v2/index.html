尾迹长度（白热段 + 余烬长尾）

从你的烘焙器截图量的（白热段弧长 ÷ 星头速度 ≈ 2 s；约 6 s 时余烬还连到爆点），要用烘焙器「火花 / 余烬」页的数核对。粗细也随年龄变：星头带一点晕、白热段粗、余烬细。

导入烘焙器轨迹（替换近似模拟）

JSON：{"format":"fwl.star-tracks/1","dt":0.016667,"stars":[{"p":[x,y,z, x,y,z, …],"be":7.21}]}。单位米，y 朝上，爆点为原点；p 从 t = 0 起每 dt 一个点，到星头熄灭；be 可省。

数据
和 v1 的差别
  1. 轨迹换成截图里的配方（初速 345、终端 34、重力 ×1、燃烧 7.3 s）。v1 用的是「我的 · 大小与造型 · 我的」（900、×4、8 s），星头 1 s 内刹住、之后以约 68 m/s 直落。
  2. 关掉时间扭曲：v1 让每束各按 0.85–1.15 倍速播放、45 % 的束提前截断；现在每束都按真实时间流动，错落只来自每颗星自己的初速和燃烧离散。
  3. 十字带按每颗星的运动平面建，宽度方向整根不变，不会翻转。
  4. 条带贴图不用 mip、顶 / 底两行严格为 0，细线消失（勾「旧做法」可复现）。
  5. 尾迹拉长到白热段约 2 s、余烬 7 s；加了溶解噪声颗粒和随年龄的粗细。
  6. 去掉「余烬下坠」：静态网格只能做匀速下坠，值一大，越老的尾巴沉得越多，上半圈的弧会翻到星头下面；负值就往上飘。等拿到烘焙器余烬的受力再说。
