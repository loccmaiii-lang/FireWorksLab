颗粒什么时候出来由 Param2 曲线管（整个粒子一个值）：物理预设按 HK10-1 存活率，年龄 7–9.5 s 以后才断成点，所以 7.5 s 才开始渐出。「白热段保护」就是 ColorIntensity：大于 1 时白热段透明度顶满、颗粒打不进去，颗粒提早出来时（加强预设）用。「尾巴延长亮度」是 A 淡完之后接的那段暗光的倍数，溶解阶段的亮点靠它。改这两项会重算 B 的条带。

这页模拟了什么、没模拟什么

  • A 的网格、条带、动态参数、颜色倍数、寿命、缩放都按正式资产读回复刻（`B09主角读数.md`、`COLOR_BASELINE_20261019/标定.json`）；400 束 ε 0.78 = 10,988 顶点、手游 130 束 ε 3 = 1,998，和 UE 读数一致。
  • 材质按 UE 采集的 Soft 母材质节点算：透明度 = saturate(主图 A × ColorIntensity × 粒子 Alpha × 溶解遮罩)，溶解 = smoothstep(h, 1−h, 噪声 + 2·Param2)，噪声 UV 固定在轨迹上、可横移；混合是 Translucent（母材质 BlendMode 读回）。
  • 做 A/B 时发现：研究文档里「靠 ColorIntensity 顶满透明度、按年龄断点」只对亮的白热段成立。暗的段要么被提亮好几倍，要么得把亮度挪进颜色、透明度留高——Translucent 下这会变成挡住后面烟花的暗纱。所以 B 的亮度仍放在透明度里，颗粒出现的时间改由 Param2 曲线按时间管。
  • B 的噪声图是程序生成的替身（256²，暗底 + 亮点）。UE 里候选的 `T_EFX_FireWorks_GoldSpark_2x2_01D` 长什么样没看过，不合适就要新做一张小图（算新增）。
  • 没模拟：TAA、UE 的曝光 / 泛光 / 色调映射（这里两边用同一套近似，只能比 A 和 B 的差别）、半透明排序、真机。竖向视角 60° 是推断，要用实机截图量。
  • 断点时间按 HK10-1 配方的火花寿命估（普通 55 % · 2.03 s · σ 0.45；余烬 45 % · 6.48 s · σ 0.2）。正式网格的轨迹来自 v2 近似模拟，不是烘焙器。正式资产寿命 14.25 s、DP0 按 16.1 s 设计，所以整朵播放比轨迹快约 13 %，A、B 都照这个复刻。
