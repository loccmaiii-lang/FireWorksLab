使用前了解

每次开机后双击「启动全部工具.cmd」。重复启动会复用服务；关闭这个网页不会关闭本机服务。

HTTP 和原 file 页面的浏览器草稿各自保存。日常继续使用原离线文件；偶尔转到 HTTP 测试时，用节目文件导入副本，两个入口不自动同步个人节目。

离线 HTML 包仍可发给别人。本页地址仅在这台电脑生效；UE 沿用本机 17780 服务，实际导入仍由你点击确认执行。
