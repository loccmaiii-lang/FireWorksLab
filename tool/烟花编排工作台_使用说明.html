烟花编排工作台 · v15 使用说明

8025 是主开发入口，离线 HTML 从同一套正式源码生成。v15 区分当前调用与全部调用预览、明确复制范围，并修正替换花型继承旧片段偏移；保留模板先保存、片段固定引用、双向定位和显式更新；保留导演选择、齐发随机错开和固定路径覆盖更新；保留真实 UE 状态、自动导入与原 DF 色值。旧公开网页 v1 本轮没有更新。

发给别人什么

发送「烟花编排工作台.html」即可，约 2.4 MiB；也可发送附带本说明的 ZIP。脚本、样式、六份目录数据和完整测试节目已内嵌，不需要源码、8025 服务、CDN或公网。使用现代 Chrome / Edge 打开原文件；GitHub 源码预览页不是应用入口。

初次打开含《汪洋与浩渺 · 融合编排05》的 252 个片段、1689 个事件、18 个固定花型版本、段落、三档和节奏参考。已有离线版个人草稿时优先恢复草稿，它与 8025 分开存储。新建节目仍是真空白，不附默认音乐、段落或片段。

轻量 HTML 不附音乐字节。试听时，在「节目 → 节目音乐 → 导入或替换音乐」选择音频。导入相同原曲会保留音乐锚点、段落和片段时刻；换曲时保留片段绝对时刻，解除旧音乐锚点和标记，段落需重新核对。参考波形不是音频已加载的标志。已授权上传的原节目、备份、原曲保持原归档。

从头制作节目

  1. 「节目 → 新建节目」，填写名称和时长，点「创建空白节目」。模板库和舞台保留，原节目可撤销恢复。
  2. 可先导入音乐。音乐起播时刻是节目秒数，如倒计时结束后 10 秒起播。移动音乐起点只带动已关联音乐的片段与标记；按节目秒数放置的片段保持原位。
  3. 左栏模板库默认花型模板，分类依次为基础模板、花型模板、编排模板。基础模板来自 ResourceFXTable，是只读原始形态与规格参考；未知尺寸保留为待标定。
  4. 选花型，底部「编辑花型」进入统一编辑页。中文名供预览、英文 ID 供引擎；球花层、尾缀层、扇形束可关联基础模板，展开延迟、高度偏移、位置、角度、缩放及随机范围。保存新版本前核对直接引用范围；编排模板中的固定引用不会默默改绑。
  5. 「设置发射」创建编排片段，在右栏选坝顶或小平台、具体发射点、开始时刻、点间间隔。顺序支持同放、左到右、右到左、中心向外、外向中心。画布点位与下方点位条联动，当前 ID 从 P0/B0/F0 开始。
  6. 创建后片段进入时间轴和编排片段栏。选中可修改、复制、删除、撤销和重做；双击片段定位播放，拖播放头定位。空格播放/暂停，重播图标重播当前范围。
  7. 用时间线「建立段落」或拖选区间建立编排段落，自己填写名称、范围。段落是组织编排的区间，不是自动曲式结论；点段落定位，需要音乐联动时设置关联。
  8. 打开「模板库 → 编排模板 → 新建编排模板」，填写模板名，添加调用，给每次调用选择花型固定版本、实际发射口、顺序、相对时间和三档参演点。新增调用会直接选中，可继续编辑。
  9. 「仅保存编排模板」让它立即入库；「保存模板并创建片段」可一次完成保存和放入节目。每个调用生成一个片段，同次放置组成一组，全部引用真实保存的模板版本。保存模板不会改变已选的节目发射时刻。新建按钮是紧凑 DF 主色动作。
  10. 片段右栏「来源编排模板」显示固定版本和同组片段数，「查看引用模板」打开确切版本。模板右栏「节目中的引用」列出每次放置的位置，点「定位」回到时间轴和检查器。版本选择器可以查看旧版。
  11. 编辑模板保存新版后，旧片段继续引用旧版。需要应用时，在片段来源卡点「更新此组到 vN」，只更新这一组，可撤销；节目时刻、段落、音乐关联保留。同 ID 的调用保留片段身份。已经单独改过节奏、点位、三档，或删除/单独复制出的不完整组，不会被整组更新覆盖；先将现有编排存为新模板，再重新设置发射。
  12. 已有独立片段可以「将当前编排存为模板」，保存相对时序到库，然后复用；这个动作不自动改绑原片段。初始的3个条目是预置框架，需点「配置编排模板」后绑定花型和发射点，再保存；它们不是库数量上限，也不是252个独立节目片段的映射。自己的模板保存后条目数增加。

画布默认完整全景 100%，近景、倍率和复位在画布工具中。坝顶总长 800 m，五段 150/150/200/150/150 m，坝顶高 150 m，小平台高 50 m；比例尺是设计参考。网页模拟不等于 UE 真实资源尺度、轨迹和外观。

复制编排模板与播放范围

复制的是整套编排模板。比如8次调用，只修改右栏当前第1条，另外7条仍保留；它们不是原节目残留。调用列表显示实际花型、固定版本及点位，原自定义调用名称另行保留，不用旧名称猜花型。

  1. 画布上方「全部调用」查看整套；「当前调用」只试听右栏所选一条。换调用、换档位或修改参数会暂停并回到局部起点。预览只读取这个模板，不混入节目。局部预览不影响保存和创建片段的范围。
  2. 右栏「当前调用 · N / M」可切换，也可点下方调用行，选择与字段联动。每次保存和创建片段仍包含全部M条，按钮明确数量。
  3. 若复制后只想要所选花型：点「仅保留当前调用 · 移除其它N次」，再点「仅保存编排模板」。这一步先改草稿；保存前可「恢复刚移除的调用」或「放弃修改」。恢复保留当前调用后续微调。
  4. 切换到不同花型会重置旧片段捕获的缩放、高度和角度偏移，改用该花型固定版本自身参数；时序、随机错开及其它调用保持。现有旧版不自动改动。同花型保留原固定版本及源微调；旧包复制的偏移可显式点「重置源片段微调」再保存新版。
  5. 中低档只过滤相同发射时序。未选本档参演点显示「本档无参演点」，不会回退播放全套。当前预览通过不代表其它调用已配置：整套保存仍严格检查全部调用。
  6. 放弃修改恢复保存的花型、点位和发射区域；切换版本也清除未保存的区域状态。已有节目引用仍固定旧版，需要更新时用既有显式组更新操作。

齐发里的随机错开

「设置发射」右栏，以及已创建片段的「时间与节奏」，都有「随机错开」。填0.2表示每次完整花型在名义时刻后增加0–0.2秒延迟；填0关闭，范围0–60秒。球花、尾缀与内部扇形束保持自己的相对时序，一起平移，不拆散花型。内部原生随机大小等参数仍在花型层里单独设置。

齐发可选择多个实际发射点。每点、每次花型得到独立错开，随机组随节目保存；刷新、重播、三档切换与交付不会重新抽取。想换节奏点「换一组」，可撤销。名义编排时刻保持0.1秒网格，随机实际时刻保留更细精度；实际首发显示在预览和时间轴。超过节目结束会报错，不能静默截掉。

「将当前编排存为模板」提取当前实际相对时序，下次复用保持已经做好的错落；不会再次随机叠加。若希望重设随机，可在新片段中配置。

三档、保存和交换文件

高、中、低档沿用正式 8025 的规则；当前档位同时决定预览、时间线有效事件和导演交付。切档后核对右栏实际事件摘要。

「保存」和「保存节目」写入当前浏览器；改名后保存更新节目，不会下载文件。等已保存状态再关闭；它不改写 HTML 原文件。

「下载节目版本文件」生成完整 .dfshow，含节目、固定花型/编排版本、点位、三档、段落、音乐标记和已导入音频。未导入时仅含节奏参考和音乐身份。转移电脑、浏览器或 HTML 位置前先下载文件，不依赖 file 来源的浏览器草稿跨位置共享。

「打开节目」先校验再替换，成功可撤销，错误时保持当前内容；恢复切换前节目、恢复初始方案也可撤销。「另存为」建立独立节目身份。工具版本、节目文件版本和花型固定版本分别管理。

分享新版 HTML 不会同步后来编辑的个人节目，请另附 .dfshow；音乐未随文件保存时另附原曲。云端应回传新版本完整 .dfshow、修改清单和检查结果，本机备份后再导入核对。三张 TXT 表不能恢复整场。

连接 UE 与自动导入

机制与原 HTML 导入器一致：离线 HTML → POST/text/plain → http://127.0.0.1:17780/gpcli → 已运行的 UE 工程。HTML 不含工程粒子、材质、贴图；接收方要打开对应工程并启动既有 GPUECli 服务。只编排、保存、导入音乐不要求连接 UE。

  1. 打开自动只读探测，顶栏显示连接中、已连接或未连接。服务重启后点「重新连接」。接口固定，无需输入；默认识别 BP_Failed_NewYearFireworks_ShowDirector_2。默认目标不存在时读取候选，多目标不猜选，右栏会要求选择。
  2. 想换目标：点「交付 → 选择导演 → 读取 UE 导演列表」，选择已加载的蓝图或关卡实例。列表不代表磁盘所有未加载资产；其他蓝图在UE内容浏览器右键「复制引用」，粘贴到「导演蓝图引用路径」，点「检查并使用此导演」。目标必须是有效导演；错误不会偷偷换回默认目标。打开选择、换目标、节目/档位变化都会清除旧确认。
  3. 点「交付」，右栏「导演三表」首屏有「自动导入 UE」。进入交付、改变节目/档位/目标时自动只读核对导演和关联发射点，显示实际事件数。
  4. 核对目标，等检查通过，勾选「确认替换当前档位三表与节目时长」，再点「自动导入 UE」才写入。打开页面、重连、检查不写入。
  5. 导入前下载导演完整配置备份，执行前重读基线；写三个烟花数组与节目时长，随后读回。保留其他导演设置。播放中、现场绑定错误或检查后配置变化会阻止写入。
  6. Blueprint 读回一致后仅保存选定资产；关卡 Actor 修改需在 UE 手动保存关卡。写入、读回、保存分别报告，实播另行验收。

按钮灰色时先看检查结果和确认框。连接失败先启动服务再重连。超时不重复写入，不猜测回退，先核对 UE 和导入前备份；只有本次已知局部变更可确认时才恢复并读回。复制、下载三表仍保留用于手动交接。

「交付资源」实时目录查询是另一项既有本机目录服务；内嵌基础/花型/编排模板和节目不依赖它。

覆盖更新与本机历史

固定发送「烟花编排工作台-离线包.zip」，内含同名HTML、使用说明和README。每次解压到接收者原来的文件夹，覆盖「烟花编排工作台.html」，继续打开这个原路径。同一浏览器、同一配置档、正常模式且不清除网站数据时，沿用v1本机存储标识；已保存的个人节目优先于内置测试节目，恢复备份、已有节目记录和固定模板版本不被新包替换。原来下载的.dfshow也留在用户自己的位置，更新包不带同名个人节目文件。

本机发布路径继续使用你已打开的2026-10-10-v12文件夹；名称是历史目录名，里面的工具已经是v15，以后仍在此覆盖，不新建版本交付目录。维护者回滚材料另存到源码工作目录，分享包不包含它们。

撤销/重做是当前打开会话的操作记录，不等于永久版本文件。长期历史请「下载节目版本文件」留存；重开后可「打开节目」导入。同一路径覆盖无需每次重新导入已保存草稿；换电脑、浏览器或移动路径时用.dfshow转移。不要在仍打开旧页面时覆盖后继续编辑；先等“已保存”，关闭工作台，再覆盖并重开。

后续更新方式（维护者）

先改正式 8025，在源码目录运行 npm run build。生产构建、108 项核心回归和包装检查通过后，自动生成一次轻量 HTML 到固定交付路径（沿用当前文件夹）；检查失败保留上次成功文件。npm run release:offline 可执行同一完整流程。普通节目保存不触发工具打包，也不发布旧 Site。

包装默认排除音乐；低层构建参数 --music include 供明确需要的大包。配色唯一来源为 tool/design-system/tokens.json v0.1.1，原 DF 主色 #00d49b、底色 #111d21。烘焙器、编排工作台、特效工作台（原导入器）消费同一颜色角色，不各自另建色板。
