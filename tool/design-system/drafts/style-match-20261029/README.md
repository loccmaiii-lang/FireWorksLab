统一规则：

- 保留蓝灰/薄荷、1px边界、4px控件小圆角；用表面角色区分结构与表单，禁用整行透明度与装饰渐变。
- 交互边界与装饰分隔分角色：输入边界辅助色`#617985`，分隔线仍为`#2b4149`；主色`#00d49b`不变。仅纯色配对检查中交互边界对输入底为3.67:1，不据此声称整页无障碍通过。
- 结构节点有同族类型图标和细导线；选中只用柔和底与左指示，显隐/只看仍各自独立。
- 标签、数值、单位、辅助信息采用不同字阶，数字等宽；值与单位不断行。
- 普通动作40px、数值框32px、参数行40px、树行32px；只定义角色，不根据附图缩放反推源码像素。
- 爆后扰动固定32×18px矩形开关、12px方形把手，普通复选框不被改造成开关；禁用轨道为中性灰且文字可读。
- 警告按风险摘要/原事实/原动作排列，保留“约”、原值和“清除出点”。不把视图重排当作修复时长或导出结果。
- 不增加独立身份区、页签或确认步骤；图2可编辑层不能继承图1只读参考的业务状态。

`tokens.json` 是本候选唯一数值来源，运行 `python -X utf8 tool/design-system/drafts/style-match-20261029/build_tokens.py` 生成CSS。未修改 `tool/design-system/tokens.json/css`。
