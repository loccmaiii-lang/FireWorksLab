## 独立边界

- 以独立副本 `drafts/v1/demo.html` 为冻结来源，原文件不改。来源 SHA256 和六个基线文件哈希在 `source-manifest.json`；交付时六项复核一致。
- `preview.html` 已内嵌原图像、图标、样式和完整控制器，只追加独立CSS与视觉元信息。运行只需要本目录，不依赖旧稿文件。
- `build_preview.py` 用于在来源副本重新生成快照，需该副本的 `../v1/`；日常打开和审阅无需运行它。重新生成后必须重新核验。
- 原Demo的存储键保持；本稿另用 `fwl.ui-demo.visual-exploration.20261029`。A/B/C共用此独立演示存档，方便相同状态比较。
- 烟花图像、画布中性背景、曝光与模拟保持；时间轴只演示播放状态，静态参考不随参数重算。下载是带 `demoOnly` 标记的JSON，不能用作素材包，不连接UE。
- 仅作视觉草稿，未改生产、原组件库、共享tokens或正式配方；不表示用户认可或生产接入。
