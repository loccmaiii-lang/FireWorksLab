## 操作

左边为原B，右边是保留128真实物理层级的129组合。点左侧组件目录，或右上「检查当前组件」，可以在右侧打开该类控件并操作；内部选择器可以切换全部14类。底色、类型图标、数字框、绿色滑杆等同时映射到实际128样本，不只显示选型标签。

「原B/128」保留不启用组合样式的对照；「组件对照」保留参考方向的样板。顶部区分「已选择14/14」与「组合样式已载入14/14」，后者来自子页面样式启用及实例存在回执，不代表烘焙器业务验收。

可导出129 JSON或下载含选择的单HTML。下载HTML优先恢复文件内选择；普通预览使用专属 `fwl.component-choice.20261029.v8.129` 存储键。恢复按钮载入用户已确认的原始14类决定，不会改旧v7或其他存档。

右侧保留真实字段和数值，接的是独立控件样本。点树不会加载另一套业务参数，状态栏会说明；眼睛、只看、还原只影响此页。烟花为原静态参考，没有真实保存、烘焙、素材导出或UE操作。旧B、128、v7、共享tokens及配方未改。file页双击/第二浏览器/全读屏未自动化验收；已验证实际下载HTML在HTTP字节副本中的恢复，资源均内嵌。
