# 统一组件候选稿 · 取舍说明

这是供用户验收的设计候选，尚非正式组件库或生产迁移。Material与WAI用于参考规则，当前没有引入它们的运行库。主题色、直角感、细边框及既有业务语义保持；124不再是每一处控件差异的规范依据。

本轮29类组件分为：Material参考8类、桌面适配14类、领域自定义7类；另保留14组合模式和8模板规格。分类表示参考来源和适配责任，不表示完成程度。

## 保留

- 蓝灰/青绿、深色表面、细边框、小圆角和原工作区气质。画布、Ramp及效果本身的颜色不参与界面主题归并。
- V5左库/中预览/右侧上结构下参数。继承用户已选的类型图标与父子导线方向，保护原树序、缩进、行高、操作列和分隔行为；本轮不再次探索结构布局。
- 参数名—滑杆—数值—单位的对齐，搜索、仅改动、英文名、修改标记、还原、锁定与帮助。眼睛影响配方/输出，靶心只影响观察；输出节点没有眼睛时不补一个灰控件凑统一。
- 保存、撤销、确认指纹、真实导入及UE执行仍由原业务控制器负责；候选Demo只演示隔离状态，静态参考图不重算。

## 合并

- 同用途基础按钮、字段、选择框使用4px控件小圆角；菜单容器7px、项4px、方形开关2px。形状差异由用途解释，取消“同为控件但因页面来源不同而不同”的默认规则。
- 将共享73变量和草稿60条局部定义整理为候选角色关系，不相加当成133种独立设计值。本轮只在隔离目录使用`--u-*`，不写回正式`--fw-*`来源。
- 正常、悬停、选中、焦点、错误使用同一套角色规则；必要输入边界、模块分隔线、主动作各有用途，不把所有边框画成同一种强调。
- 两档密度统一叫regular/compact。常规控件40px、正文14/22、字段13/20；紧凑32px、正文13/20、字段12/18；树行32/28保留。上述数值是项目候选，不是Material官方强制标准。是否可读、可点以实页测量和操作验证为准。
- 标签、帮助、错误和单位拥有固定位置；长文字只在允许处换行，数值+单位保持原子组。菜单不再用固定行高压住长命令。

## 领域专用

结构树、参数事务、版本引用、产物摘要、导入核对和时间轴保留领域模型。Ramp、曲线、粒子图和Timeline的四类规格主要统一外框、标签和反馈，不由此宣称领域内核实现完整。

## 状态怎么统一

不再给29类机械套九态。每类按交互、值/视图、可用性、校验四个轴列适用状态，记录不适用原因，并检验真实组合：

1. **选中＋焦点**：当前值/对象仍明确，键盘焦点另有可见反馈。
2. **错误＋已修改**：保留非法输入与就地原因，同时保留未保存事实。
3. **勾选／半选／未知**：半选只表示真实部分选择，未知不画成关或半选。
4. **禁用／只读／进行中**：禁用阻止动作并给原因；只读可查看/复制；进行中说明作用范围、阻止重复提交，不编进度。
5. **失败＋旧结果**：保留有效旧内容且标旧，不把旧内容改写成当前成功。

原生HTML语义优先；Material负责通用层级与组件原则，WAI补树、页签、滑杆、模态等网页键盘语义。APG tooltip和window splitter页面仍有工作中说明，本稿将它们作为补充模式，不当作已经认证的实现。

## 简化了什么

取消页面来源决定的同用途样式分叉、重复身份卡和完成徽章、为树/模块/工作区重排专门增加的动画。保留必要动作，不把常用动作塞进新多级菜单；保留真实父子层级，不为画面整齐改数据。无装饰滑入、缩放、弹跳或默认涟漪。

## 本轮验收

本轮重点审：组件适用状态样板，以及编辑、交付、导入核对三个代表页面和可操作Demo。交付页预览优先；进出恢复原编辑上下文。导入核对使用明确标注的内置示例，不读取或写入真实资产。

同视口对照需保持对象、状态、密度与内容一致；核对长中文名称、长错误、菜单边界、数字单位、焦点可见、窗口缩窄与短高场景。截图、自动检查、人工审看、读屏和用户认可分别记录，不能用一个“通过”覆盖未测项目。正式库登记与三工具迁移在用户审定之后。
