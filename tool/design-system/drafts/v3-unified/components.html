规则

本轮统一了什么

同用途默认外观
按钮、字段、下拉统一4px小圆角与1px细边；主要、安静、危险变体保留各自职责。
同一密度接口
常规40px、紧凑32px，同时继承字阶、行高、间距。数值为本项目候选，不是Material强制值。
边界角色
输入的必要边界用已有轮廓色，模块分隔用较弱分隔色；不再混用成同一种灰线。
适用状态
按交互、值、可用性及校验分别定义；混选属于复选，拖动属于滑杆，错误不强加给所有组件。
实现边界
此页和三个代表页共用候选样式。正式注册、生产迁移与真实业务验收，在用户审稿后另行进行。

可尝试：Tab走完整页 → 选中分段后继续用方向键 → 越界输入并按Esc → 改变子勾选 → 打开菜单与对话框再关闭。屏幕截图和静态检查不能代替完整读屏验收。
