这轮请验收四件事

  1. 同类控件一致

    按钮、字段、选择控件、滑杆的默认规则清楚；主动作、次动作与危险动作可区分。

  2. 信息主次清楚

    结构表达对象与父子关系，参数表达可编辑值；交付页优先给预览空间。

  3. 阅读与密度合适

    比较常规和紧凑，检查长名称、数值、单位、说明和错误是否容易读。

  4. 操作反馈可理解

    试选中加焦点、混选、错误与修改、禁用原因；明确保存、观察、准备和确认各自影响什么。
