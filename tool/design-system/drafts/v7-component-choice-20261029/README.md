# B / 128 单文件组件选型台

打开 `index.html`，或下载浏览器中「下载含选择的 HTML」生成的文件。所有样式、脚本、图标和静态参考均已内嵌；选型本身不依赖 8034 服务。直接打开下载文件尚未通过本机 file:// 自动化测试，已通过相同单文件的 HTTP 入口测试及无外部资源静态检查。

1. **B / 128 左右对照**：左为原分组聚焦 B，右为完整 4.9.128 实页 DOM 与 CSS 的组件样本。可选「结构与参数」或「原稿上下文」，两边可分别放大。
2. **逐组件挑选**：点左侧 14 类目录，看 Material / Adobe 候选对照，试用控件后选择一种，也可以「保留 128 当前」。上方始终说明该类在 128 当前采用了什么；「规格与来源」展开具体文件和尺寸。
3. **查看我的组合**：右边预览已经选择且可适配的外观，左边 B 保留原样。输入框和滑杆可分别选型；未提供场景适配的方向只记录，不假装已应用。
4. 添加备注，再用「下载含选择的 HTML」带走整份对照稿；用「导出选择 JSON」保存轻量决定，也能重新导入。重新打开包含选择的 HTML 时，优先载入文件中保存的选择。

初次交付为 **0 / 14 尚未决定**；没有替用户预选。浏览器只使用独立的 `fwl.component-choice.20261029.v7` 键。选择 JSON 格式为 `fwl.component-choice/1`，包含当前128来源、所选方向、备注与是否已决定。

Material / Adobe 指本项目既有候选的参考方向，不表示安装或完整使用官方框架。树、颜色/Ramp/曲线、进度反馈为项目领域组件，本轮没有完整独立的两套品牌皮肤，页面已经标明「待细化」。菜单和对话框提供可操作样板，在当前右侧场景中不投影替换。

## 交互边界

- 左侧保留原 B 的 40 个真实字段、分组、搜索、条件、折叠等参数交互。烟花为原有静态参考，不随参数重新计算；存档为此页内存样本。
- 右侧保留真实128层级、原值、文字、图标与组件样式，接通输入/滑杆同步、样本修改标记、还原与锁定；其他业务动作提示未接通，不运行生产控制器。
- 不执行真实保存、烘焙、素材导出、UE 导入。原B、128正式文件、共享tokens、配方和他方文件均不修改。能力说明中另有原始完整入口，需本机服务。

## 重建与来源

在仓库根目录运行：

```powershell
python -X utf8 tool/design-system/drafts/v7-component-choice-20261029/build.py
```

`shell.html`、`picker.css`、`picker.js` 为外壳；`catalog.json` 为14族来源备注；`bundle_sources.py` 包装原B与128快照；`catalog_samples.py` 包装既有候选样板。构建只输出本目录 `index.html` 和 `source-manifest.json`。

128快照来自实际 `/baker?ui=material-b` 的 GLB-S1 金锦层，在序列化前保留当前输入值/选择/勾选；不把运行状态当作本选型文件的烘焙或验证结果。来源哈希及 Tabler MIT 许可在 `source-manifest.json` 和单HTML内保留。

核验及截图见 `design-qa.md`、仓库 `analysis/results/20261029_组件风格选择/`。正式应用留待用户选定方向。
