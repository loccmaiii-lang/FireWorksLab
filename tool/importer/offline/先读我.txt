烟花工坊 FireWorksLab 5.0 · 先读我
=====================================

这一个文件就是全部：做烟花效果（烘焙器）、导出素材包、把素材包导入 UE，都在「烟花工坊.html」里。
不用装 Python，不用开任何本地服务，不用联网。


一、怎么打开
------------
1. 把「烟花工坊.html」放在自己电脑上一个固定的地方，例如 D:\FXTools\烟花工坊\。
   以后发新版，替换同一个文件就行。
2. 用 Chrome 或 Edge 打开（右键 → 打开方式 → Chrome）。
   别的浏览器不能读写文件夹，导出和导入用不了。
3. 打开后默认是「制作」画面。右上角：UE 连接状态 ｜ 显卡；左下角：导出文件夹、备份文件夹。


二、第一次要选的文件夹
----------------------
1. 导出文件夹：点左下角「导出　未选」，选一个空文件夹。例如 D:\ProjectTextures\FireWorksLab\，
   或者自己建一个 D:\FWL_Export\。
   - 导出和导入用的都是这个文件夹，不用选两次。
   - 不要选 UE 工程里面的目录（…\Content\ 下面）。
   - 以前用旧烘焙器导出过的文件夹也可以直接选，里面的旧包照样能导入。
2. 备份文件夹：只有要覆盖 UE 里已有的资产时才用。用哪个：
   - 左下角「备份」选过的，优先用它（建议第一次就选好，例如 D:\FWL_Backup\）；
   - 没选过、但烘焙器里选过仓库文件夹（FireWorksLab 根目录，一般只有做效果的人有），就用仓库文件夹；
   - 都没有时，导入前会弹出来让你选。
   同样不要选 UE 工程里面的目录。备份文件是 .uasset.bak，放错地方 UE 也不会把它当资产读进来。


三、Chrome 会弹什么、点什么
---------------------------
1. 选文件夹时：先出系统的「选择文件夹」窗口，选好点「选择文件夹」；
   接着 Chrome 问「允许此网站修改文件？」→ 点「允许」。
   注意：这个框里默认选中的是「不允许」，别直接按回车，用鼠标点「允许」。
   （有的 Chrome 版本分两步问：「查看文件」→「保存更改」，都点同意的那个。）
2. 每次重新打开浏览器，第一次导出或导入时，左下角可能显示「需允许访问」：点一下，再点「允许」。
3. 新版 Chrome 第一次连 UE 时，可能问「允许访问本地网络上的设备吗？」→ 点「允许」（这是连本机 UE 用的）。
   不小心点了拒绝：点地址栏最左边的图标 → 网站设置 → 把这一项改回「允许」，再刷新页面。


四、UE 要开什么
---------------
1. 打开 DF 项目的 UE 编辑器就行（GPUECli 插件随工程启用，不用另装）。
   右上角显示「● UE 已连接」才可以导入。断开时显示「UE 未连接 · 重新连接」，它也会每十几秒自动重试。
2. 导入前先把 P4 连上：新资产要「添加」，更新要「迁出」。P4 没连上时导入会在保存后停下并说明原因。
3. UE 里有自己没保存的东西，导入前先保存（导入只保存它自己写的资产，但万一编辑器崩了，没保存的会丢）。
4. 没开 UE 也能制作、导出；只是「导入」会变灰，并写明原因。


五、导出 → 导入
---------------
1. 在制作画面调好效果，点右上角「导出」（或「导出 ▾」里的「导出素材包」）。
   选了导出文件夹时，素材包直接写进去，不会再另外下载一个 ZIP；没选时浏览器照旧下载 ZIP。
   写完自动打开「资源交付」并选中刚导出的包。
   也可以从「导出 ▾」第一项「资源交付」进去，看所有导出过的包。
2. 资源交付页：选一个包 → 看检查结果和资产表（每项写着「新建 / 覆盖 / 复用」和 UE 路径）。
   - 检查没过时「导入」是灰的，鼠标放上去写着原因（例如手机发射器超过上限、贴图超过 1024）。
3. 点「导入」。第一次复制材质会编译 shader，可能要几分钟；这时不要关页面，也不要关 UE。
4. 导入完成只代表资产已写进 UE 并保存。ResourceFX 配表这一版还没有；UE 里有没有播对，要自己在 UE 里看。
5. 贴图规范是自动的，不用手动改：永不勾 NeverStream；贴图组 DistantVFX；Ramp 用 Clamp + NoMip；
   PC 主序列 NoMip；手游主序列按贴图组、最大 1024。


六、注意
--------
- 同一时间只开一个烟花工坊页面去导入。
- 「我的效果」存在这个浏览器里。换电脑、换浏览器，它不会跟过去：先在旧的里「我的效果 → 导出全部」，再到新的里导入。
- 「编排节目」这一版还没接（右上角入口是灰的，悬停写「编排节目下一版接入」）。
- 版本号「FireWorksLab 5.0.0」点开是 5.0 更新说明：画面、播放、导出范围、检查器、结构树怎么用，都写在那里。
