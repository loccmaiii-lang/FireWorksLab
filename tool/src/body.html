烘焙中…

点参数名看说明（固定在右栏底部，Esc 关；F1 = 光标所在参数的说明）；双击参数名恢复默认值；鼠标移到参数名左边出现锁，锁定的参数切换号数、随机微调时不变。开启自动烘焙后，调参停手会更新贴图；关闭时按 B 烘焙。贴图规格在「输出」里设置。「实时模拟」是物理原始效果；「引擎回放」按项目材质的方式播放：Dynamic Parameter 帧号取整、不做帧间混合、灰度查渐变图上色。

本机交付服务没连上

「指定目录」导出要靠本机交付服务（127.0.0.1:8034）把素材写进资源目录。这次的素材还没开始烘焙，按下面三步重连后接着导出：

  1. 打开仓库里的 tool 文件夹，双击 启动烘焙器.cmd。
  2. 看弹出的命令行窗口：一闪就关、并自动打开了一个新的烘焙器页面 = 服务已经起来了（新页面可以关掉，回到这一页）；窗口停住、写着错误 = 没起来，照窗口里的提示处理（常见：没装 Python 3.10 以上、本机启动配置里的路径不对）。
  3. 回到这一页点「重试连接」，连上后这次导出接着做。

不想等：点「先导出 ZIP」，这次的素材包下载到浏览器的下载文件夹（内容和指定目录导出的一样）。
