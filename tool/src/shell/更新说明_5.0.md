## 5.0.01 · 烟花工坊（2026-11-06）

照审阅意见把界面里还是旧样子的地方改掉了。参数、烘焙、导出的结果都没变。

- **结构树**：层下面只列星、火花、余烬这些发射器。点层那一行，右边是这一层的全部设置：时间与缩放、出生方式、规格、环境、颜色、输出。单层效果也有「1 层」这一行。
- **多层效果**：点效果名，右边是「整体」：总时长，和每层的开始、时长；点哪一层就到哪一层。
- **输出**：一个模块。常用的（产物、英文名、PC / 手机导出、贴图、格子、单格、张数、固定曝光）露在外面，其余点标题旁的「+N」展开。
- **颜色**：只在层里出现一次。一条色带，点一段改这一段的颜色和时刻；「焰色」下拉给这一段上色；渐变图四个色块。
- **参数行**：开 / 关的参数是开关；有随机的参数，范围画在滑杆上，悬停这一行出现「分布」；能自动算的参数，名字旁边一个「自动」图标；倍数写「倍」。
- **序列贴图**：一屏看完——当前格、整张贴图、帧号曲线在左，右边是交付表（每层 PC / 手机出什么）；几张贴图时左下翻页。原来的「交付清单」模式去掉了：导出尺寸在「规格」，英文名在「输出」，导入范围在「导出 ▾」。
- **去掉的**：实拍对照（连同 V 键）、右栏的「审阅」「工具」、播放条上的时间滑杆（拖刻度尺）、时间轴层行的眼睛和「S」（在结构树上）。
- **画面**：画出贴图范围的四个角；升空尾缀的「只看某一段」在画面右键菜单里。
- **效果库**：上面一排筛选（全部、待验收、球花、尾缀……），下面一个列表，右边写状态。
- **导出 ▾**：写着要不要重新导出、为什么、导出到哪个文件夹；「导出全部」；「导入范围」。状态栏右边写「已保存 / 未保存」。

## 5.0.0 · 烟花工坊（2026-11-06）

一个离线文件：做烟花效果、导出素材包、导入 UE，都在这一页。

- **打开**：用 Chrome 或 Edge 双击「烟花工坊.html」。不用装 Python，不用开本地服务，不用联网。
- **制作**：左边结构树选层、发射器；右边检查器调参数；中间画面切「实时模拟 / 引擎回放 / 序列贴图」。
- **导出**：右上「导出 ▾」。第一次先在左下「导出」选一个导出文件夹，之后导出直接写进去。
- **导入 UE**：「导出 ▾」第一项「资源交付」→ 选包 → 看检查结果 → 点「导入」。导入前先打开 UE 编辑器、连上 P4。
- **备份**：要覆盖 UE 里已有的资产时，会先让你选一个备份文件夹（不要选 UE 工程里的目录）。左下「备份」也能选。
- **贴图规范**自动处理，不用手改：永不勾 NeverStream；贴图组 DistantVFX；Ramp 用 Clamp + NoMip；PC 主序列 NoMip；手游主序列按贴图组、最大 1024。
- **编排节目**下一版接入（右上入口是灰的）。

## 用法要点

- **画面**：右下的「距离」「预览曝光」左右拖动就改，单击可输入；在画面上点右键：贴图最新（B）、自动烘焙、按导出分辨率、预览泛光（升空尾缀还有「只看」）。
- **播放**：空格播放 / 暂停，R 重播；拖时间轴上面的刻度尺换时刻；播放条右边是生成缩略图、时间工具。
- **导出范围**：播放条下面一行，设为入点、设为出点、恢复；「一并移动」「同刻联动」管拖时间点时别的点跟不跟着动。
- **检查器**：搜索参数名；「筛选 ▾」只看改过的、显示英文名；「全部折叠」；「⋯」里是恢复发射器、恢复本层、随机微调、导入参数。悬停模块标题出现「恢复本模块」，悬停参数行出现单项恢复。
- **结构树**：点层那一行看层的设置；层行悬停有「显示」「只看」「⋯」（时间与缩放、排序、改名、复制、删除；排序以下只对「我的效果」）。
- **快捷键**：右下「快捷键」或按 ?。
- **我的效果**存在这台电脑的浏览器里。换电脑或换浏览器前，在效果库「我的效果 → 导出全部」，到新的地方再导入。
