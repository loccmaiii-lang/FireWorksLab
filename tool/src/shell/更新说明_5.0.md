## 5.0.0 · 烟花工坊（2026-11-06）

一个离线文件：做烟花效果、导出素材包、导入 UE，都在这一页。

- **打开**：用 Chrome 或 Edge 双击「烟花工坊.html」。不用装 Python，不用开本地服务，不用联网。
- **制作**：左边结构树选层、发射器；右边检查器调参数；中间画面切「实时模拟 / 引擎回放 / 序列贴图 / 交付清单」。
- **导出**：右上「导出 ▾」。第一次先在左下「导出」选一个导出文件夹，之后导出直接写进去。
- **导入 UE**：「导出 ▾」第一项「资源交付」→ 选包 → 看检查结果 → 点「导入」。导入前先打开 UE 编辑器、连上 P4。
- **备份**：要覆盖 UE 里已有的资产时，会先让你选一个备份文件夹（不要选 UE 工程里的目录）。左下「备份」也能选。
- **贴图规范**自动处理，不用手改：永不勾 NeverStream；贴图组 DistantVFX；Ramp 用 Clamp + NoMip；PC 主序列 NoMip；手游主序列按贴图组、最大 1024。
- **编排节目**下一版接入（右上入口是灰的）。

## 用法要点

- **画面**：右下的「距离」「预览曝光」左右拖动就改，单击可输入；在画面上点右键：贴图最新（B）、自动烘焙、按导出分辨率、预览泛光。
- **播放**：空格播放 / 暂停，R 重播；播放条右边是生成缩略图、时间工具。
- **导出范围**：播放条下面一行，设为入点、设为出点、恢复；「一并移动」「同刻联动」管拖时间点时别的点跟不跟着动。
- **检查器**：搜索参数名；「筛选 ▾」只看改过的、显示英文名、全部参数；「全部折叠」；「⋯」里是恢复发射器、恢复本层、随机微调、导入参数。悬停模块标题出现「恢复本模块」，悬停参数行出现单项恢复。
- **结构树**：层行悬停有「显示」「只看」「⋯」（时间与缩放、排序、改名、复制、删除；排序以下只对「我的效果」）。
- **快捷键**：右下「快捷键」或按 ?。
- **我的效果**存在这台电脑的浏览器里。换电脑或换浏览器前，在效果库「我的效果 → 导出全部」，到新的地方再导入。
