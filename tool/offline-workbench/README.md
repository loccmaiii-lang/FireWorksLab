## 保存与交换节目

「保存」和右栏「保存节目」写入当前浏览器，等待顶部显示“已保存本机草稿”后再关闭页面。它不会改写HTML原文件。

「节目 → 备份与恢复 → 下载节目版本文件」得到完整dfshow，包含固定花型/编排版本、三档、段落和嵌入音乐；换浏览器、换电脑或移动HTML文件位置时，先下载此文件，再在新位置「节目 → 打开节目」导入。不要依赖file来源的浏览器草稿跨文件位置自动共享。把新版HTML发给别人，不会同步你的个人最新编排，另附dfshow。

## 如何连接UE

沿用原`df-fx-workbench_v2_locmai.html`导入器的机制：

`离线HTML → POST/text/plain → http://127.0.0.1:17780/gpcli → 已运行的UE项目`

HTML不是UE插件，也不包含工程中的粒子/材质/贴图。接收方要打开相同工程，并运行原导入器所需的既有GPUECli服务。只编排、试听和存文件可以不连接UE。模板库的“交付资源”目录查询仍是既有可选本机目录功能，需要对应目录服务；内嵌的基础/花型/编排模板与原节目不依赖它。

1. 点击右上「交付」，右栏选择「导演三表」及交付档位。
2. 粘贴**导演**Blueprint或关卡Actor路径。原用户提到的Bloom_A1子模板不是导演目标；从内容浏览器复制实际导演路径。
3. 点「检查导演与发射点（只读）」。它读导演配置及DirectorId相同的真实点位，并检查P/B/F槽位绑定，未通过时不可导入。
4. 核对目标和当前档位，勾选替换确认，再点「备份并导入 UE」。此动作替换所选导演的三个烟花数组和节目时长，先下载导入前完整配置备份，执行前再次读取配置，写后读回核对。改节目/档位/连接目标会使确认失效；播放中或检查后配置改变会阻止写入。
5. Blueprint读回一致后，仅保存选定资产；关卡Actor只写当前编辑器会话，需在UE自行保存关卡。写入、读回、保存和实播是分别列出的状态。保存失败不会显示已全部完成。

网络/超时的结果不自动重试，也不猜测回退；先核对UE及导入前备份。只有能确认是本次已知字段变化、其他配置未变的失败，才恢复这些字段并再次读回。当前工具只沿用原服务能力，没有新引擎代码或全关卡自动保存。
