# 四尺玉 V4：发光机理与视频色彩重新校准

目标：在独立目录 `studies/radiometry` 重做 V14、V13 的发色与动态复现，保留 V3 和生产烘焙器。用户授权继续执行，不另设审批步骤。

1. 审计旧代码：温度只驱动亮度、灰度 Ramp 丢失温度信息、逐通道色调映射漂白、红点手选粉色等问题。
2. 重新读取两段原视频。记录逐阶段非饱和线芯/线边/彩芯样本、饱和比例、取样位置和时间；排除字幕、地景、烟背景和前一发干扰。不从压缩 RGB 视频反推唯一化学配方。
3. 保存 CIE 官方色匹配数据及来源校验。实现 Planck 光谱积分到 XYZ/线性 RGB；保留温度降低导致的亮度下降，不把每个温度归一到相同亮度。
4. 独立 V4 渲染器：沿 V3 的运动历史计算颗粒年龄，分别模拟持续发光与冷却；彩芯用视频观测色度代理选择性发光，不伪造元素鉴定。线性 HDR 相加、小亮芯和弱带色晕、明确显示变换。
5. 先渲染诊断静帧，逐阶段与原视频、V3 对照，修正后再烘焙原生 1024 像素帧和动态视频。提供可调参数、同步原片、逐帧查看的独立预览。
6. 验证温度/色度/亮度关联、随机访问一致性、线段与分辨率稳定性、颜色导出与预览一致性、完整序列解码和原生产文件哈希。说明 RGB 高精度母版与旧 RGBA 灰度接力材质的兼容边界，不把视频精度冒称为实时运行性能。
7. 交付可复查的分析报告、原片样本、V3/V4 对比和两套新素材。报告观察事实、物理解释、拟合参数、未验证内容，并报告尚未还原的差异。
