【贴图】
T_V13_pink_2048.png（星头、闪光、拖尾合并）
尺寸 2048×2048，灰度（线性），RGBA 接力：先填满 R 的 64 格（第 0–63 帧），再接 G（64–127）、B（128–191）、A（192–255）
格子 8 列 × 8 行，行优先，左上为第 0 帧；单格 256×256 像素；共 256 帧；格子四周留空 2 像素
导入：sRGB 关闭，压缩 BC7；1K 版本在引擎里复制一张，把最大尺寸设为 1024 即可
T_V13_pink_2048_帧号测试.png：排查用。格子、接力、取景与正式贴图完全相同，内容是帧号 + 以爆点为中心的固定大小圆和网格。
  把材质实例的贴图临时换成它播放：帧号应连续递增不倒退，圆应不动、不胀缩、不变扁。
  帧号乱跳 / 倒退 → 帧号曲线或材质的接力解码不对；圆胀缩、晃动 → Size By Life / 位置曲线不对；圆变扁 → 对齐方式或 Initial Size 不对
T_V13_pink_2048_Ramp.png：渐变图 256×8（sRGB），灰度从暗到亮依次取：拖尾冷却色 → 拖尾高温色 → 星头高温色

【Cascade 发射器】
Required：Screen Alignment = Rectangle（面向相机，X、Y 尺寸分开生效；不要用 Square——Square 只认 X，Y 方向会按错的比例缩放，画面变形、抖动）；Emitter Duration = 7.50 s；Emitter Loops = 1
所有曲线（Size By Life、Dynamic Parameter 帧号、Color Over Life、Location / Velocity 等）：每个关键点的 Interp Mode = Linear。CurveAuto 会在关键点之间冲过头：尺寸来回抖、帧号倒退一抖一抖。Size By Life 勾选 Multiply X、Multiply Y。
Spawn：Rate = 0；Burst：Count = 1，Time = 0
Lifetime：7.50 s（常量）
Initial Size：X = 84870 cm，Y = 84870 cm（常量）
Initial Location：Z = -8437 cm（精灵中心相对爆点的高度，这样爆点正好在发射器原点）
Dynamic Parameter：第三通道 = 帧号；Use Emitter Time 不勾选；曲线插值 Linear

【帧与流畅度】
平均 34.1 fps，最低 34.1 fps，每帧最大位移 1.8 像素（建议 ≤ 3）
平均面片面积为最大尺寸的 100%（overdraw 按此折算）

【自检】
  画面占比：平均 16%，最差 10% 的帧 ≥ 5%；面片取景改「紧凑」可提高到 90% 以上
  过曝：第 66、81、82、83、84、93、94、95… 帧超过 2% 像素顶到 255，可降低星头亮度或改 Gamma 2.2
  边缘渗色：无（留边 2 像素）
  通道布局：R 有内容，G 有内容，B 有内容，A 有内容
  近似帧：48 对相邻帧几乎相同，可把「取帧」改成「按画面变化」自动合并
  末尾 56 帧接近全黑，可把序列时长缩短到约 5.87 s

【烟（开花烟，用项目现有烟雾贴图）】
Spawn：Burst Count = 8；Lifetime 4.90–9.90 s
Location → Sphere：Velocity 勾选，速度约 42435 cm/s；Drag = 2.22（烟团很快停在星走过的地方）
Initial Size 5092 cm，Size By Life 1 → 3（扩散）
Alpha Over Life：0 → 0.3（在 0.13）→ 0
颜色：前 0.90 s 被火光照亮，乘本母版 Color Over Life 与 Light 曲线；之后转为场景夜空灰

【LOD 建议（1080p、竖直视角 60°）】
LOD 0：0–3,101 m，全部层，2K 贴图

【说明】
面向相机的精灵用 Initial Location 的 Z 偏移对齐爆点；从很陡的仰角看时会有轻微偏差。
