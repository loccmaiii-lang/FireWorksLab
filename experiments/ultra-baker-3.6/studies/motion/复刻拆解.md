# 四尺玉视频拆解与第二版复刻

这次从原视频重新校准两种四尺玉，并保留上一版进行同步比较。改动覆盖结构、时间、尾迹密度和颜色交接；不是只提高输出分辨率。

所有改动在 `experiments/ultra-baker-3.6` 内，原始烘焙器未覆盖。第二版依然是可调的程序复刻，尚未达到逐星、逐像素还原。

同步视频左右两版都来自实际 **4K 灰度 RGBA 图集**，单帧 512×512。双方关闭附加辉光。每版只做一次固定的等比例缩放与平移：鸿巢在开花后 3.2 秒对齐宽度，片贝在 6.5 秒对齐宽度，并对齐爆心位置；之后不逐帧改变大小，不拉伸时间。这个对齐会消除一个时刻的整体大小差异，不能拿该时刻的宽度一致来证明还原准确。

视频为 H.264、30 fps；半速版本重复已有帧，没有生成中间细节。原片阶段标注保留完整升空与结尾，对照视频从开花开始，均只含画面。原片仍保存在项目 `vidio` 目录。

## 鸿巢 V14：看清白尾如何变成红色余烬

原片 720×1280、30 fps，共 445 帧。逐帧检查后，开花起点从第一版的 4.13 秒修正为 **4.20 秒，第 126 帧**。视觉起点误差按约一帧（0.033 秒）理解。

| 开花后 | 画面证据 | 对复刻的要求 |
|---|---|---|
| 0–1.2 秒 | 强烈白亮爆心，球面快速展开，中心部分饱和 | 不能从过曝白团推断准确星数；要保留快速展开 |
| 1.2–3.6 秒 | 白色亮芯与暖色细尾逐渐分离，外缘增长减速 | 同时调整运动、亮芯厚度和尾迹，不能只增加亮度 |
| 3.6–7.5 秒 | 上部转弯、下部拉长，形成伞形 | 星头和尾迹需要连续运动，不能套一个整体缩放曲线 |
| 约 7.5–8.5 秒 | 白尾逐渐衰退，红色闪点接替 | 需要一段交接，而非全体在同一帧变色 |
| 8.5 秒后 | 红色余烬闪烁、下落；仍有零星暖色细尾 | 红点要沿主花轨迹出现；原片结束时尚未完全熄灭 |

第二版提高尾缀密度和白芯宽度，按展开曲线调整初速与阻力；白尾后段逐渐转暖变暗，红色点火分散在约 8.3 秒附近。红色层与主花使用相同初始方向和速度，再选择约四分之一星体发光，解决第一版红点与主花不对应的问题。数值是视觉配方，不是烟花药剂的实测物理参数。

横向亮像素包络使用 0.5%–99.5% 分位数，排除文字和地面。在开花后约 0.4–6.6 秒采样，简化的二次阻力投影模型对该曲线的平均绝对误差约 **1.58 个原片像素**。这是“简化曲线对测量数据”的误差，**不是第二版图像与实拍的误差，更不是还原相似度**。中央橙色团块更符合受光烟团的外观，当前没有把它伪装成一朵持续燃烧的内芯。

单靠 RGB 阈值识别红色余烬会把白尾色边和受光烟雾一起算进去，因此这项自动点火指标已判为不可靠，保留原始记录但不用于成绩评价。交接区间以连续画面判读为准。

## 片贝 V13：暗载体、彩芯和外圈金花是三件事

原片同为 720×1280、30 fps，共 547 帧。开花起点取 **5.70 秒，第 171 帧**，按约一帧不确定性理解。开花前后右上角还有上一朵烟花的残留，不能把这些亮点计入本朵的星数和早期外径。

| 开花后 | 画面证据 | 对复刻的要求 |
|---|---|---|
| 0–1.5 秒 | 较小的金色主花展开 | 前段不能直接铺满后来的巨大外圈 |
| 1.5–3.3 秒 | 金色尾迹减速、弯曲 | 保留金芯连续尾迹，外圈载体维持暗态 |
| 约 3.3–4.3 秒 | 粉紫、蓝、绿小花分批出现 | 用局部彩色子花，而不是整球换色 |
| 4.3–5.6 秒 | 外圈从亮点变成金花，年龄和尺寸不同 | 点火时刻分散、各朵大小离散 |
| 5.6–7.5 秒 | 金花互相叠加，产生密集金色花雨 | 子花要继承部分父级速度，并有独立阻力和下坠 |
| 7.5–12.5 秒 | 暖橙色细尾下落、变暗、稀疏 | 保留长尾，不让所有子花整齐消失 |

第二版把外圈载体的头部与尾迹隐藏；彩芯平均点火由 2.6 秒改为 3.65 秒，外圈金花由 4.35 秒改为 4.8 秒，并分别设置离散。外圈配方从 **66×42＝2772 颗子星**提高到 **72×100＝7200 颗子星**，约 2.6 倍；这是模拟配方数量，不能当作真实视频中的粒子计数。各朵大小离散为 18%，子花的阻力、重力、速度继承可独立编辑。金芯尾迹延长，后段保留到 12.5 秒。

按同一套颜色阈值检查连续四帧，实拍彩芯首次明显检出约在 3.23 秒，第一版约 2.07 秒，第二版约 3.47 秒：从约提前 1.2 秒，改善为约延后 0.2 秒。这是依赖曝光、压缩和阈值的“画面检出时刻”，不是药剂真正点燃的时刻，也不代表全部彩芯同时出现。

## 为什么没有对参考视频逐帧追着烟花做稳定

补做了地面、建筑区域的光流追踪，并排除烟花与字幕。鸿巢 444 对相邻帧都有足够特征；片贝 546 对中 502 对满足最低要求。这个平移模型未支持片贝存在明显的全画面大幅抖动，因此撤回第一版“明显相机移动”的笼统描述。

夜景、视差、低纹理和原视频可能存在的处理仍限制这项判断。对照最终保留原片运动，只做上文说明的一次固定对齐，避免把真实运动当作相机运动消掉。

## 精度提高在哪里，仍卡在哪里

| 维度 | 已实现 | 实际限制 |
|---|---|---|
| 空间采样 | 2K／4K／8K 图集；4 倍线性空间超采样后再缩小 | 8K 图集是每帧 1024×1024，不是每帧 8K |
| 时间采样 | 最高 960 Hz 快门采样；长主花分成两段，共 512 帧 | 原片只有 30 fps；输出仍按整数帧播放，未插帧 |
| 粒子结构 | 子花独立运动参数、分散点火、同轨迹余烬 | 真实三维星位和逐朵空间关系仍是程序近似 |
| 可调与导出 | 参数、灰度贴图、色带、时间曲线和 Cascade 说明同步更新 | PNG 灰度 RGBA 仍为 8 位，并非 16 位 HDR 母版 |
| 预览 | 实际贴图播放、局部放大、独立高精度预览 | 视频有编码损失；看极细颗粒要回实时预览 |
| 光学真实感 | 白芯、颜色与衰减重新校准 | 镜头光晕、受光烟雾、散射与相机曝光响应未完整模拟 |

因此不能说所有维度都已超越实拍或达到“百分之多少相似”。目前最确定的改善是片贝的阶段顺序与花雨密度、鸿巢的白尾质感和余烬交接。仍明显欠缺的是实拍的烟雾光照、局部不均匀分布、颗粒长短层次与部分下坠形态。
