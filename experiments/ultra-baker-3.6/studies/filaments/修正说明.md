# 四尺玉连续尾丝第三版

上一版的主要错误，是把“白亮段”和“整条可见轨迹”当成同一个对象，用点火花寿命、密度和亮度一起调。它能做出明亮短划，却丢掉了后面更长、更细的暖色部分。增加分辨率不能修正这个形态错误。

## 从视频重新观察到什么

鸿巢原片 7.40 秒，即开花后 3.20 秒，选取顶部一根较容易辨认的亮线：白亮部分约 49 px，能保守追到的全长约 210 px；此帧花体水平半径约 258 px。全长约为半径的 0.81 倍。这是一个人工选取样本，边界判断约有 ±8 px 误差，不是全体尾迹的平均值，也不是实际燃烧时间。

[查看原片标注](线条拆解.png)；[坐标、计算与限制](source-line-measurement.json)。标线放在轨迹旁边，原片未锐化或 AI 补细节。

到开花后约 7 秒，上部的白亮部分转成钩形，但它后面还接着更早形成的细轨迹。不能把每根尾迹都当成相同长度的直线，也不能把整段全部加亮。

暖色长轨迹可能包含残粒发光和被照亮的细烟。仅凭这段视频不能唯一分辨二者。第三版用长历史曲线、随主星熄灭衰减的余辉层近似其可见形态；“8 秒历史窗口”是拟合参数，不是测得了 8 秒的单颗火星寿命。

片贝则是多朵子花叠加。第二版 100 个子星配上独立点火花，容易变成密集碎点。本次改为每朵 58 个子星的连续弧线，保留分批点燃，同时调整下垂与粗细。58 是视觉配方选择，不是实拍计数。子花的空间位置仍未逐朵对应原片。

## 改动到哪一层

- 新增 `tool/src/js/41_filaments.js`，沿每颗星的运动历史生成连续三角带；相邻段共享端点和切线，横向做像素覆盖积分。拖尾不再依赖随机散点凑成线。
- 白亮段和弱余辉有独立时间响应，每根线的长短、粗细变化固定在该星上，不随每次绘制乱跳。
- 鸿巢导出四个实际图层：白亮主花、暖色长尾、红色余烬、短促金芯。白亮主花和暖尾复用相同轨迹，颜色不再挤在同一个灰度渐变里。
- 片贝外圈子花与先行金芯使用连续尾丝。原有彩芯的独立点火保留。
- 渲染开关默认关闭；已有金芒菊和其他配方仍走原来的点火花流程。实验编辑器中可以调整新增尾丝参数。

这是渲染模型与素材分层的改动；三维星体运动仍沿用现有模拟器，并非重新反求了每颗真实星体的三维轨迹。

## 查看结果

- [实拍 / 第二版 / 第三版同步视频](index.html)：建议先看鸿巢 +3.2 s、+7.0 s，再看片贝 +6.5 s。三栏的两份程序结果都使用 4K 图集、单帧 512 px，避免把分辨率差当作形态改善。
- [原生贴图分层预览](preview.html)：选择 8K，单帧 1024 px。关闭鸿巢“白金长尾主花”，单独检查暖色长尾；点击画面并切换 4× 查看已有像素。
- [鸿巢 8K 素材](V14-fine-8k.zip) / [片贝 8K 素材](V13-fine-8k.zip)。另有 2K、4K 档。

每套 8K 素材均有 6 张 RGBA 贴图，未压缩基础纹理约 1.5 GiB，不含 mip、工作缓冲或引擎额外开销。8K 是图集尺寸；不是单帧 8K。RGBA 各通道存动画帧，A 不能当透明度。

## 验证与仍存在的差距

独立尾迹测试检查：曲线无内部断口；细分数翻倍时总亮度变化低于 0.03%；重复请求同一时间得到相同结果；未点燃的载体不发光；跟随主星的弱余辉在主星熄灭后结束。这些只证明实现稳定，不是还原度评分。详见 `renderer-verification.json`。

完整素材包检查 PNG 尺寸、RGBA 数据、分段及原始工具文件哈希；视频检查解码帧数、拖动与播放；原生预览检查图层开关、缩放及与烘焙器定帧输出一致性。检查记录和脚本均保留在实验目录。最终检查：6 份 ZIP、36 张图集和 12 段视频通过检查；4K / 8K 原生预览在两套抽检时刻与烘焙器输出逐像素一致（最大 8 位误差为 0）；原始工具 29 个文件哈希未变。编辑器启动、取消、原有上升尾缀及矩形素材读取回归通过。

形态仍有明显差距：鸿巢的白线长度和粗细分布仍较整齐，部分钩形与下坠未对应实拍；片贝子花局部密度、大小层次、明暗和颜色仍偏程序化。中心烟团、局部受光亮团、镜头散射和相机响应尚未完整实现。第三版修正了尾迹的结构表达，不能称为已经高精度复刻完成。

原始项目 `tool/` 未改。第二版配方及必要贴图保存在本目录 `before/`，第二版完整结果仍在 `studies/motion/`。本轮新结果全部位于 `studies/filaments/`。

## 复现

在项目根目录依次运行：

```powershell
python experiments/ultra-baker-3.6/tool/build.py
node experiments/ultra-baker-3.6/tests/filament_verify.cjs
node experiments/ultra-baker-3.6/tests/study_bake.cjs --only=V14 --filaments --rebuild
node experiments/ultra-baker-3.6/tests/study_bake.cjs --only=V13 --filaments --rebuild
node experiments/ultra-baker-3.6/tests/motion_capture.cjs --filaments
python experiments/ultra-baker-3.6/tests/motion_video.py --filaments
python experiments/ultra-baker-3.6/tests/study_package.py --filaments
python experiments/ultra-baker-3.6/tests/motion_decode.py --filaments
node experiments/ultra-baker-3.6/tests/motion_verify.cjs --filaments
node experiments/ultra-baker-3.6/tests/filament_preview_verify.cjs
```

脚本使用项目根目录的 `127.0.0.1:18766` 本地静态服务。需要 Chrome、当前配置的 Playwright 路径、Python OpenCV，以及实验目录 `.deps` 中的 imageio-ffmpeg。
