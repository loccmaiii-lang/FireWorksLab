# 烟花烘培器参数交互稿

本地预览：http://127.0.0.1:4177/ 。由 Product Design 模板启动，React 页面嵌入隔离的真实烘焙器，复用当前效果、素材和模拟。

## 使用路径

1. 选效果 → 点图层 → 用右上「分组定位」找模块。
2. 类别是固定段落标题，模块是主要折叠入口；常用参数直接可见。
3. 「展开更多参数（N 项）」展开后变成「收起更多参数」。随机按钮同样明确显示展开 / 收起及当前随机量。
4. 点参数旁 `?`（或在参数上按 F1）才显示说明；说明固定在右栏底部，占据独立空间，不盖住参数。继续调参不会自动换说明；关闭 / Esc 收起。
5. 说明区「恢复默认」调用原有双击参数名的恢复动作；模板默认值与「恢复到打开时」仍是两个原有概念。
6. 多层效果的图层管理默认展开，保留整体、各层、独看、静音、开始时间等原功能。

## 边界与维护

- 生产版本是 4.3.7。这个目录是交互稿，并非发布 4.3.8。
- `scripts/generate-baker.py` 从当前生产生成文件读取，只替换 UI 展示 / 触发方式；不会写生产文件。
- `src/baker-panel.css` 和 `src/baker-interactions.js` 是隔离 UI。原引擎、取帧、渲染、模拟、产物输出和命名数据整段原样复用。
- 浏览器数据使用 `fwb.draftUI1.` 命名空间，避免改到正式页面的保存版本、草稿与面板习惯。
- `npm run dev` / `npm run build` 自动生成克隆。开发服务通过 `/tool`、`/analysis` 代理本机仓库 HTTP 服务（4185）。不依赖外网，不上传配方。
- 本地副本仍有真实调参、模拟、导出行为；完整效果验收和引擎回放验收按仓库标准另做，本次只验交互。
- 全量参数逻辑盘点及源码完整性证据见 `analysis/results/UI16/参数交互审查/`；交互和视觉验收见本目录 `design-qa.md`。
