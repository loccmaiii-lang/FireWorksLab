用户 09-29 23:10 通过 JM3。只提取方法，**不照搬参数、不拿它的拟合分数当标准**（金芒菊是单层、结构简单，差距 0.026；多层效果的分数没有可比性）。

## 提取出的做法（所有效果都用）

1. **先选对模板、结构一次对**：层数、每层轨迹关系、头尾关系、颜色时间线在起点里定死；拟合只调连续量（大小、亮度、星数、时间），不指望拟合补结构。
2. **对照看同一时刻**：实拍 / 模拟在 10–90% 燃烧的同一时刻并排，外加连续播放；整体和局部（放大）都看。
3. **相机效果单独建模**：实拍的模糊、过曝、曝光只在对照时加（`fit.camera`），素材本身保持清晰；不能靠模糊画面、改取景、调暗某层来降低差距。
4. **导出后回放检查**：在烘焙器里播实际导出的贴图（导出效果 / 贴图页），查格子、帧号、取景（Fixed / Zoom）、曝光、清晰度；引擎相关问题（抖动、裁切）在这一步暴露。
5. **一个效果收成一个条目**：用户看到的是一个完整候选，不是几个半成品。
6. **通过后只改形式、不改效果**：取景、格子、导出命名可以换，艺术效果保持用户通过的那一版。

## 对多层效果的补充（金芒菊没遇到、之前出过错的）

- 各层自动曝光会互相抵消：次要层要按原理固定亮度，不进拟合（QA5 / QC4 / QD4 教训）。
- 次要层要单独渲染确认「看得见」：芯太稀、星点太小、离散太小会变成空心环（QC5 / QD5 教训）。
- 同一批星的不同阶段（尾巴层 / 星头层、主段 / 第二段）必须共用同一模拟（同种子、同初速、同星数），不能拼几个互不相关的球。
