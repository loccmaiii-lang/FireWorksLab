# 烘焙器 3.0 验收清单

打开 `tool/FireworkBaker.html`（先 `git pull`）。标题栏应显示 v3.0，右上角显示你的显卡。每一项写了「怎么做」和「应该看到什么」，有问题直接在对应条目后面记下，下次一起发我。

建议顺序：先做第 0 项测速，再按板块往下。

## 0. 显卡测速

1. 「迭代」页 → 显卡测速 → 开始测速（约 20 秒）。
2. 应该看到：同屏 3 万 / 10 万 / 30 万 / 100 万 / 300 万颗火花各自的毫秒数，以及当前母版 2K 完整烘焙耗时。
3. 把整段结果复制给我，用来定四尺玉的粒子预算。

## 3. 产物

| # | 怎么做 | 应该看到 |
| --- | --- | --- |
| 3.1 | 锦冠 → 产物选「分段母版」 | 统计显示「×2 段」和分段时刻；贴图视图出现「段 A / 段 B」；导出 ZIP 里有 `_A`、`_B` 两张贴图，参数表两个发射器，段 B 带 Emitter Delay |
| 3.2 | 菊 → 产物选「单元序列」 | 导出效果里是 150 个沿速度方向的粒子；贴图是一颗星的星头 + 直拖尾；参数表有 Sphere 速度、Drag、Const Acceleration、Size By Life X/Y、Pivot Offset、overdraw 对比 |
| 3.3 | 在引擎里按 3.2 的参数表搭一个发射器 | 重点确认两件事：Pivot Offset 用哪一个值时星头落在粒子上；速度对齐后星头在前还是在后（反了就勾「星头朝下」重导） |
| 3.4 | 菊 → 导出种子变体 V1–V3 | ZIP 里三张贴图 + 一份参数表 |
| 3.5 | 取帧改「按画面变化（合并近似帧）」 | 多一遍低分辨率烘焙；帧号曲线在变化小的时段更平 |
| 3.6 | 看统计栏最后一行和参数表【自检】；贴图视图里的红色像素 | 过曝、边缘渗色、通道布局、近似帧、末尾全黑都有提示；把「格子留边」调成 0 且面片取景为「紧凑」时应报边缘渗色（「随开花放大」本身留了空，内容碰不到格边，报「无」是对的） |
| 3.7 | 参数表【LOD 建议】【烟】【声音节点】 | 有距离分档、烟的发射器参数、带时刻的声音事件 |

## 5. 地面 · 循环

逐个切换喷泉、瀑布、转轮、扇形、连发、仕掛け：

- 统计里「接缝」≈ 1（1.3 以内都算无缝）。
- 导出效果连续播放不跳。
- 仕掛け：图案改成文字并填字。
- 参数表：Emitter Loops = 0、Lifetime = 循环周期、帧号 0 → 帧数。
- 「自动选格子」按内容长宽比挑列 × 行；3.1 起循环类横竖分开铺满，画面占比应 ≥ 90%，格子方向只影响像素是否接近正方形。

## 6. 迭代

| # | 怎么做 | 应该看到 |
| --- | --- | --- |
| 6.1 | 迭代 → 当前存为 B，回母版页改几个参数 | 画面左 A 右 B，中间金线；A/B 区列出参数差异；「A ↔ B」可交换 |
| 6.2 | 载入 `vidio/` 里的视频，填「开花时刻」，选叠加 / 卷帘 / 差值 | 视频随时间轴同步；缩放、偏移可对齐 |
| 6.3 | 载入一张实机截图 | 同上，静态叠加 |
| 6.4 | 数值测量对比，参考选 V05、V14、V06 | 表格列出 t50、t80、t90、下坠、下/上、燃烧、花径、消え口，差距在 20% 内打 ✓ |
| 6.5 | 存版本（带批注）→ 改参数 → 再存 → 点旧版本「回滚」或点缩略图 | 参数回到旧版本；列表显示改了几项，悬停可看具体差异 |
| 6.6 | 存为配方「A」→ 点「派生」→ 改两项 → 存为配方「B」 | B 显示「派生自 A · 2 项差异」；改 A 后载入 B 会跟着变 |
| 6.7 | 导出配方库 JSON，命令行：`node tool/batch_bake.mjs 配方库.json out` | out 文件夹里每个配方一个 ZIP |
