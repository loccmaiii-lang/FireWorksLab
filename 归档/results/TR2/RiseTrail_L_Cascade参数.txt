工具：烟花母版烘焙器 3.2（模拟内核：GPU；产物：升空尾缀序列（循环 + 消散））

【贴图】
T_RiseTrail_L_Loop.png（上升循环）、T_RiseTrail_L_Fade30.png（消散，30 fps）、T_RiseTrail_L_Fade20.png（消散，20 fps）；另有 _4K 母版（4096×4096，单格 256×4096）
尺寸 2048×2048，灰度线性，RGBA 接力：先填满 R 的 16 格（第 0–15 帧），再接 G、B、A，共 64 帧
格子 16 列 × 1 行，单格 128×2048（1:16，贴合细长的尾迹）；格子四周留空 2 像素
导入：sRGB 关闭，压缩 BC7
T_RiseTrail_L_Ramp.png：渐变图 256×8（sRGB），暗 → 亮 = 冷却的橙红火星 → 金色火星 → 白热段与星头

【材质实例】
项目现有的 RGBA 序列帧材质；列 = 16，行 = 1；Ramp = T_RiseTrail_L_Ramp；循环、消散各一个材质实例（只换贴图）

【Cutout：裁掉面片上的空白，减少 overdraw】
上升循环：Required → Cutout Texture = T_RiseTrail_L_Loop_Cutout（512×512，所有帧叠在一起的轮廓）；
  Sub Images Horizontal = 1，Vertical = 1；Bounding Mode = Eight Vertices；Opacity Source Mode = Alpha；Alpha Threshold = 0.1；不加 SubUV 模块。

【升空尾缀：两个发射器接力】
弹道（真实二次阻力）：162.9 m/s 出膛，9.77 s 到达 600 m
Cascade 线性阻力拟合：Initial Velocity Z = 14930 cm/s；Drag = 0.097；Const Acceleration Z = −981 cm/s²（误差 0.7%）

1）上升循环（T_RiseTrail_L_Loop）
Required：Screen Alignment = Velocity；Emitter Duration = 9.767 s；Emitter Loops = 1
所有曲线（Size By Life、Dynamic Parameter 帧号、Color Over Life、Location / Velocity 等）：每个关键点的 Interp Mode = Linear。CurveAuto 会在关键点之间冲过头：尺寸来回抖、帧号倒退一抖一抖。Size By Life 勾选 Multiply X、Multiply Y。

【自检】
  画面占比：平均 96%，最差 10% 的帧 ≥ 96%
  过曝：无
  边缘渗色：无（留边 2 像素）
  通道布局：R 有内容，G 有内容，B 有内容，A 有内容
  近似帧：0 对相邻帧几乎相同
  循环接缝：1.15（≈1 无缝）

【烟（上升尾烟）】
挂在弹体上：Location → Emitter InitLoc；Spawn Rate 25 /s；Lifetime 3–5 s；Initial Size 150 cm，Size By Life 1 → 4；Drag 1.5；Alpha 0.25 → 0

  0.000  发射

  玩家听到的时刻 = 事件时刻 + 距离 ÷ 343 m/s（800 m 约晚 2.3 s）

【LOD 建议（1080p、竖直视角 60°）】
LOD 0：0–53 m，全部层，2K 贴图
LOD 1：53–106 m，屏幕上已小于单格像素：1K 贴图即可；粒子数/火花发射率减半；关闭 Light
LOD 2：106 m 以外：只留本层；去掉芯（小缩放的牡丹层）和烟
（Cascade：粒子系统的 LOD Distances 依次填 0、5300、10600，单位 cm）
