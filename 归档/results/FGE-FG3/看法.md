# FGE-FG3 看法（对话框FanGold，2026-10-07 18:30）

- 审看版本：条目 FG3（4 层 = 4 簇，每簇 22 条细金线；每条 = 细火星 + 白热火花 + 闪烁火花 + 星头光晕；火花寿命 3.0 s、燃烧 1.7 s、顶上爆裂 64 个 / 3.4 m），烘焙器 4.9.31 导出（指纹 dff4da08·master4.9.31，4.9.32 只改升空尾缀，导出仍是当前版本）。
- 回放检查全过：4 层各 59–60 帧、4×4×4、单格 512，过曝 ≤ 1.47 %，没有空帧、切边、回跳。标准检查 FGS2 ✅。
- 烘焙回放：实时模拟和导出效果在 0.59 / 1.77 / 2.95 / 4.13 / 5.31 s 一致。看了出膛（左 → 右四簇先后出来）、到顶爆裂（约 1.8–2.2 s，冠带成弧）、尾巴老化熄灭（整条线留到 3 s 以后，从下往上慢慢暗）。
- 对照实拍（FGV3 一览，出膛后同一秒、同比例）：一簇一簇、每簇是一撮细线；上升节奏（冲上去再吊住）、到顶时刻、尾巴留存都对上。
- 剩下的差异（不影响主要目标）：冠带仍比实拍小一些、没有实拍那么白（实拍手机过曝 + 前一排的冠带叠在一起）；线头在顶上略往外勾（外侧簇明显些）；簇之间比实拍空（按你要的「一簇一簇」留的）。「冠带再亮」「簇稍宽」两个变体在 FGV3 里，要的话直接换。
- 未经 UE 验证：Pivot、自发光倍数；4 层 = 4 张序列贴图。
- 结论：进待我验收，推荐 FG3。
