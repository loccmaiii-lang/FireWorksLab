# RT5SE1 / RT5ME1 / RT5LE1 看法（对话框15，2026-10-05）

审看：烘焙器 4.4.5 导出（本机 RTX 5080，10-05 13:33 发布），RT5L 指纹 `78078c43·emitset4.4`。三个包一起看，这份写在 RT5LE1。

- **回放检查**：循环层 RiseLoop 都过（过曝 1.2% / 0.6% / 1.0%，帧号不回跳、无空帧）；**消散 RiseFade 都没过：过曝 7.0% / 5.3% / 5.0%**（上限 2%）。原因：消散按开花前的末速度（大档 23.5 m/s）单独取景，尾迹里的火花挤在 76 m 的面片里叠亮；循环层用的 H4 口径没管到消散的亮度。
- **烘焙回放**（实时 vs 导出，RT5L 0.66–5.96 s）一致：起步从弹体后面长出来、前段长、越往上越短，开花点接上消散。
- **尺寸**（用户 10-05 14:02 问「是不是过大」）：对比 RT4L——亮段长度 RT4L 全程约 110 m 不变；RT5L 从 0 长到 ~90 m（约 1.9 s）再缩到开花时 ~24 m，最长不比 RT4 长。**宽度大了**：循环面片 11.3 m（RT4L 6.9 m），亮芯约 9 m（RT4L 约 6 m），因为中火花进了贴图（散得宽），面片宽度按 99.5% 能量量出来；星头光晕 14 m。
- **粒子**：GPU 只剩粗火花等 ≤ 683 颗（RT4L 约 7300），细 / 中火花在贴图里——这是 4.4.5 按当时理解做的，和用户 10-05 01:28「合并渲染 + 800 个 Cascade 粒子」不一致。

结论：**不进就绪，STD10 继续 hold**。下一版 RT6 按方案 6.4：近段循环（火焰主体）+ 远段 + GPU ≤ 800 分粗 / 细 / 闪烁 / 落火，远看清楚；宽度回到 RT4 的量级并做成可调；消散的过曝一起改。
