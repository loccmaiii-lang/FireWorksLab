# NFJV5 看法（对话框新花型，2026-10-08）

候选对比 5（卯 / 辰 / 未 / 申 / 酉 / 戌，4.9.39 模板上改参数）。总差距：卯 0.318、辰 0.453、未 0.373、**申 0.370**、酉 0.437、戌 0.473。
审看：差距.md + 对照_1.80 / 2.30（实时渲染 mtRenderLayers，不是导出包、不是 UE）。

- **柠点星：申最好（0.20，卯 0.24）**。星晕色相 +1.2 / 2.0 / 3.0 s = 59 / 68 / 73°（实拍 49 / 69 / 69°），核心饱和 0.26 / 0.35（实拍 0.33 / 0.37），晕饱和 0.41 / 0.60 / 0.73（实拍 0.56 / 0.64 / 0.68），FWHM 5.9 / 5.3 / 4.2（实拍 5.5 / 5.1 / 4.3）。看 对照_1.80：柠黄绿的干净小点，不再是辰的绿雾、也不像卯那样发闷。渐变图暗端亮一点（#5a6e0c）比未（#4a5008）通透。
- 青绿细线：申 3.2–3.3（实拍 4.2–5.5，走势平）；放大图里是很淡的细线，不是一团团。比卯（1.7–2.6）近。
- 酉 / 戌（星头大、亮）分数变差：FWHM 偏大、晕和核心饱和都掉（变白）。眼睛看光感好一点，但量出来是「糊大」不是「通透」，不取。
- 金菊蕊：未–戌（丝 0.3 / 1100、+1.4 s 停、寿命 1.3）**+2.3 s 断成碎点（成串 0.6，实拍 0.15）**、+1.2 s 对比度 0.78。原因：+1.4 s 停火花、寿命又短，+2.3 s 只剩稀的老火花。实拍 +2.3 s 丝还连着、但已经很淡（看 对照_2.30）——要「早出的火花寿命长、晚出的短」+ 颜色末段压暗，而不是早停。烘焙器有 `sparkLifeEnd`（末段出生火花寿命 ×），用它：寿命 1.7、末段 × 0.6、+1.7 s 停。
- 红点蕊：未（光晕 0.3 / 半径 2.5 / 大小 1.0）+2.0 s FWHM 4.86、光晕 0.28（实拍 4.86 / 0.27）。

定稿（写进模板 4.9.40）：申的柠点星（晕 0.35 / 半径 3、快门 0.5、渐变 #5a6e0c / #e8f048、颜色曲线早暖后柠绿、细线 400 / 0.2 / +2.0 s 停）+ 星头末段亮度略抬（+3.0 s 核心偏饱和）+ 显示强度 1.7 + 细线亮度 0.08；未的红点蕊、橙引尾；金菊蕊按上面改（卯的颗粒 0.35 / 900、底光 0.03、寿命 1.7 × 末段 0.6、+1.7 s 停、颜色 +2.3 s 压暗红橙）。下一步本机 NFJL5：条目曝光 + 时刻对照 + 模板（亥）对申同尺比，确认没退步再导出。
