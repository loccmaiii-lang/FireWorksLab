# 烘焙器 4.2 走查（对话框2，2026-10-02 20:04 用户要求：动手前以使用者 + 设计师身份完整走一遍）

方法：云端真开页面，按使用者路径点（首页 → 新建配方 → 菊模板参数 → 工具 → 组合编辑器 → 预设 / 添加图层 / 选层 / 查看交付 / 保存 / 我的版本 → 引菊手机回放），截图在会话临时目录；另起一个只读代码审查查状态切换（28 条，下面合并去重）。没改任何文件。

## A. 会做错东西（批量生产前必须先修）

1. 组合编辑器继承上一个打开的效果的身份：资产栏名字 / 阶段、「保存」进的版本、交付页命名全是上一个效果的（实测：先开鸿巢，再在编辑器里搭「菊 + 牡丹」，导出名是 YonshakuKamuro_Main / Red / L3）。`79_library.js` 工具项只设 lib.key='combo'，没清 lib.effect；`wbKey()` 仍返回 ef:<上一个>。
2. 编辑器里存的版本打不开（key = combo，`openMine` 不认）；非条目层（存入组合库的母版、默认层）快照只记花型，恢复时变回「默认」；组合库不持久化，刷新就没了。
3. 默认层是共享对象：同一预设里两层都是「牡丹 · 默认」时，改一层两层一起变。
4. 改完一层马上点别的层（或拖别的层的点）：`selectComboLayer` 设 dirty=false、gen++，这次重烘被丢掉，参数是新的、贴图是旧的，导出包和参数不一致。4.2.0 的轨道拖动会自动切层，更容易踩到。
5. 切换条目（左栏 / ↑↓）不提醒未保存，改动全丢。
6. 层改动没保存、切走再回来时，带改动的状态被当成「AI 版」基准：「参数已变」不亮，「通过」门槛放行。

## B. 同一件事两处管 / 说法不一致

7. 右栏底部旧规格框（贴图尺寸、列 × 行、通道、输出、编码、取帧、内核、面片取景）和新「输出」一节各管一半；设了单格 / 按帧数后底部显示的不是实际；`70_ui.js` 烘完把夹过的列数写回 P.cols，原来的 4×4 丢了。
8. 三套版本：资产栏版本、工具页「版本与回滚」（每次导出自动存）、派生配方；回滚会把别的花型参数塞进当前条目。
9. 单束两条路、产物不同：资产栏「单束」只出 PC、没有 cascade.json；把产物改成单束后切回大面片，不恢复原格子。
10. 拖动和滑杆效果不同：只有在轨道上拖才带动序列时长和接力；用滑杆改燃烧，星被截掉、接力悄悄断开。
11. 入点 / 出点是绝对时间：改燃烧 / 点火后不跟着内容走，前面可能出现全黑帧；可见范围停在第一次设入点时。
12. 「恢复本花型默认」回到模板默认值，不是 AI 版；之后「复制我的改动」对不上。
13. 合并输出时「拖尾亮度」滑杆无效；颜色一节提示改「分开」，但分开时 cascade.json 只写星头；「Gamma 2.2」「单通道」和引擎（材质不改）对不上。
14. 4.0 里「分段母版」和「大面片母版」实际完全一样，说明还写两张。
15. 联动每次把所有不同的轨迹参数从当前层拷到联动层，会抹掉「暂时不联动」期间做的差异；联动判断只比 4 项，编辑器里两个默认菊会被当成同一批星；「暂时不联动」是全局的、切效果不复位。

## C. 不直觉 / 看着累

16. 右栏约 6 屏：参数前先是花型卡、母版名称、产物、一段说明、建议曝光按钮和一段说明；很多名字被截断成「…」；最底下还有一套导出按钮（导出 2K 母版、种子变体、存入组合库、导入参数、恢复默认、随机微调）和旧规格框。
17. 花型模板也显示「AI 版 · kiku」；「新建配方」里选实拍复刻卡片会直接替换当前条目的参数（资产栏、审阅、通过都还是原条目）。
18. 组合编辑器藏在「工具」最后；预设只有「菊 + 芯」；母版库 / 存入组合库是老流程，和资产栏、版本、交付、命名都不通；文案还写「母版页」「1024 版本」。多层右栏「观察图层」和「各层在整朵里的位置和颜色」是同一批层列两遍，延迟两处能改。
19. 时间轴帧刻度里「换张」的刻度显示成一块黑色，像缺帧。
20. 手机预览：接力带动重烘的层不补手机版，引擎回放可能整片显示「手机版还未烘焙」。

## D. 平台与导出

21. 组合包不能混产物：`libP` 强制大面片，单束 / 循环层 + 粒子不能和大面片进同一个包。
22. 手机没有「纯序列」路径：循环层 + 粒子的手机版仍是 CPU 粒子；手机比例填 0 会变成 0.3。
23. 命名不统一：尾缀 V5 的文件名是一串下划线；单束是 T_x_Unit；种子变体没有手机贴图。
