## 结论：变色菊（外层亲星）+ 三层芯（蓝 / 金黄 / 橙），外层四段变色「橙红尾 → 洋红 → 青绿 → 白闪」

名字就是配方：**三重蕊** = 三层芯（「蕊」= 日式的「芯」），**洋红、青绿、闪** = 外层亲星的变色顺序。之前组合页的旧预设「五段变色三重芯（V11）」颜色顺序和层数都不对（用了「蓝 → 红 → 紫 → 银」的变色菊模板和两层芯），要按下面改。

- 「光丝」= 外层星后面长时间不散的细亮线（火花寿命长、几乎不减速，所以整条弹道都亮着）。它的颜色跟着星头变（橙红 → 粉 → 白），正好符合引擎里「一张序列 + Color Over Life 整体染色」的做法，不用分开做。
- ③ 芯 2 的判断最没把握：金黄小点很小、混在光丝里，也可能是外层变色时的过渡色。**请你重点看 t8.80、t9.60。**

## 进引擎的拆法（PC / 手机）

按你在球形B 给的方向（光丝用序列、光点用粒子）：

| 层 | PC | 手机 |
| --- | --- | --- |
| ① 外层（光丝 + 变色星头） | 大面片母版序列（灰度 RGBA 2K + Ramp），Color Over Life：橙红 → 洋红 → 青绿 → 白 | 同一张序列，帧数减半或单帧 + 缩放 |
| ① 末段白闪 | GPU 粒子（点灭，10 Hz 烘进序列要 40 帧 / 秒，太贵） | CPU 粒子，数量减半 |
| ② 芯 1 蓝 | GPU 粒子 + 小序列（无尾牡丹，粒子最省） | 单帧 + 缩放 |
| ③ 芯 2 金黄小点 | GPU 粒子 | CPU 粒子 / 可省 |
| ④ 芯 3 橙 + 银丝 | 小面片序列（银丝要形状） | 单帧 |

## 烘焙器现状

- ✅ 已有：菊 + 分段变色（最多 5 段）、火花只在前几秒（`sparkStop`）、点灭从某时刻开始（`strobeStart`）、牡丹、延时点火。四层都能用现有模板表达，**不缺结构**。
