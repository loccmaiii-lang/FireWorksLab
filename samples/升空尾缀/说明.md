# 升空尾缀（第三版 · 烘焙器生成）

在烘焙器里选 花型 → 上升 → 「升空尾缀 · 小 / 中 / 大」，产物「尾缀序列（循环 + 消散，速度朝向）」。这里的文件就是这三个配方直接导出的结果；改参数后在烘焙器里重新导出即可。

| 档 | 用于 | 造型参考 | 引擎亮度 |
| --- | --- | --- | --- |
| `RiseTrail_S` | 简单礼花（青柠星级，约 120 m 开花） | 尾缀C | ×1 |
| `RiseTrail_M` | 中等礼花（金芒菊级，约 200 m） | 尾缀B | ×1.6 |
| `RiseTrail_L` | 大型礼花（四尺玉级，约 600 m） | 尾缀A + 鸿巢四尺玉 | ×2.5 |

每档：
- `T_*_Loop.png`：上升循环，64 帧，30 fps（2.13 s），**真循环**（火花按周期性编号生成，第 64 帧 = 第 0 帧，没有交叉淡化）。
- `T_*_Fade30.png` / `T_*_Fade20.png`：开花后消散，都是 64 帧；30 fps 播约 2.1 s，20 fps 播约 3.2 s。第 0 帧就是上升结束那一刻循环播到的那一帧（接力差值 0）。
- 以上都是 2048×2048、RGBA 接力（四个通道都用满）、灰度线性；`_4K` 是 4096×4096 母版。格子按内容长宽比自动选（细长的用 16 列 × 1 行，较宽的用 8 × 2）。
- `T_*_Ramp.png`：渐变图，颜色按实拍统计拟合。
- `*_Cascade参数.txt`：两个发射器（上升循环 + 消散）的完整设置、弹道拟合、Size By Life、帧号曲线、Pivot。
- `*.json`：全部参数，可在烘焙器「导入参数 JSON」继续修改。

视频（每档）：
- `升空尾缀_<档>_预览_消散2.1s.mp4` / `_消散3.2s.mp4`：① 随体特写（贴图原样，循环 3 圈后接消散）；② 引擎播放（面片沿弹道上升，到顶接消散）。
- `升空尾缀_<档>_实拍对照.mp4`：左实拍、右贴图。
- `升空尾缀_三档对比.jpg`：同一世界比例、各自亮度的三档并排；下排拉到同样高度看造型。

与实拍的逐项对照（沿尾迹长度的亮度、宽度、颗粒、亮点、颜色、摆动）在 `analysis/replica/尾缀_<档>_对照.jpg` 与 `_数值.json`。
