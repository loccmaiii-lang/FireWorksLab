# RT6 分层与末段气流 Implementation Plan

> 按用户明确执行授权，在本会话逐步实现和检查，不另派代理。

**Goal:** 在正式烘焙器补齐RT6合并输出的曲线、独立余烬及燃尽后气流，提供Comet/Silver副本，完成后交回导出（23）。
**Architecture:** 复用RT6确定性粒子编号、原弹道及发射器参数；统一火花外观曲线求值。新增气流仅作用于燃尽后仍存活尾粒，默认0；余烬是内部模拟组，输出仍合并。固定认可原件，新候选可按燃尽阶段启用分层曲线，完整输出用同一个内核测量、预览、烘焙。
**Tech Stack:** JavaScript/WebGL、既有参数表及构建器、Playwright/Edge、Python检查。

## Global Constraints
- Cascade既有材质，无引擎代码。PC/手机灰度RGBA，帧号取整；Comet红头单独，尾部合并；Silver合并。
- 原CS3C/CS3S参数和认可状态不变；新候选头部与前段不改。已存在非空曲线的修复影响单列。
- 不扩大到其他花型物理重构。功能不支持的输出分支必须明确阻止或提示，不能静默丢失。
