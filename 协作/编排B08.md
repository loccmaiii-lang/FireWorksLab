## 1. 低配限峰（性能，必须做）

**960 曲线对到演出时刻**：

- PerfDog 远距离段大约就是一整场（0–215 s）。两个峰：
  - 约 65 s（0.95 ms）：B05 低配在 64.3 s 同时开了银彩菊大 ×5 + 金芒菊中 ×4；
  - 约 182.6 s（1.04 ms）：B05 低配在 181 s 开金蕊青柠大 ×3 + 中 ×2，184.6 s 又是金芒菊大 ×9 一整排。
- 189 s 的 0.95 ms 是同一段的尾巴。
- 曲线是从截图读的，时刻有 ±2 s 误差。
- 规律（推断）：
  - 贵的是一下子开很多朵浓密金菊（金曜菊、金蕊青柠、金芒菊）。
  - 银彩菊白墙（点灭类）一次 18 朵也只有约 0.6 ms。
  - 所以按种类加权，不能只数朵数。

**做法**：

- 定一个「开花负担」：t 之前 2 s 内开花的花，按种类权重 × (直径 / 230 m)² 求和。
  - 权重：金曜菊 / 金蕊青柠 1.0，金锦菊 0.6，金芒菊 0.5，银彩菊 / 点灭 / 爆裂 / 金垂柳 0.3，其他 0.5。
- 用 B05 的实测点粗标：负担 ≤ 1.6 的时刻都在 0.76 ms 以下，≥ 2.3 的到 0.95 以上。所以 **PC 低配上限取 1.8**。
- 超了就把那一刻负担最大的一排在低配里再隔一次，规则依次是：
  - 两端留；
  - 3 朵留两端；
  - 只剩两端两朵时，换成中间一朵；中间没有点就低配不放。
- 墙 / 入口在低配也允许隔（性能优先），倒计时、主角不动。全场共隔了 29 次。

**结果**（一张表上的模型值，不是实测）：

| 开花负担最大值 | B05（测的那版） | B07 修订1 | **B08** |
|---|---|---|---|
| PC 低配 | 4.32 | 3.96 | **1.78** |
| PC 中配 | 5.02 | 4.94 | 4.97 |
| PC 高配 | 7.13 | 6.89 | 6.95 |

- B05 那两个峰的位置：
  - 64–65 s：B05 2.86 → B08 1.78（金芒菊 / 银彩菊大低配留 3 朵）；
  - 184.6 s：金芒菊大 ×9 → 低配 P0 / P4 / P8 三朵。
- PC 低配 360 发（B07 修订1 414、B05 304）；低配同屏面积峰值 8.1（B05 15.2）。
- **有没有风险**：
  - 低配按模型比 B05 低一半多，960 再到 1 ms 的可能性小。这是推断，模型是从一张截图粗标的。
  - 中 / 高配和 B05 持平（±2 %），B05 在 3060 / 3080 上没问题。
  - 1060 高配那张表里 SmallJank 374.8 / 10 min、1%Low 21，比旧包（19.6 / 39.3）差很多，你没提。要是这两个新包里有烟花，可能也和开花峰有关，**请看一眼卡顿时刻对不对得上烟花**。
- 低配为性能减了两端的排（「中低配留两端」的例外），共 3 排：122.8 s 多重菊、164.9 s 多重菊、169.5 s 金蕊青柠，都只剩中间 P4 一朵。

## 2. 小平台：不出新尾缀，降到约 40 m，花放大

- Tiny 尾缀条目 EffectScale ×0.65，到顶约 40 m，升空时间不变（1.69 s）。
  - 依据：UE-14 实测，尾缀条目缩放只改长度、不改时间。
  - Tiny 是「合成一张」：1 个发射器、本地坐标，没有近段 / 远段。所以不会出现 10-11 说的「近段远段会错位」（推断，Tiny 本身没量过）。
- 花 22–28 → 36–44 m：小金花 44、小银菊 40 / 38、短爆裂 36。手游分裂星同尺寸，原生 30 m，≤ ×1.47。
- 对称一对角度 ±8–11° → ±15–22°。40 m 高、40 m 大的两朵半叠，不糊成一团。
- 没有新资源。XS（80 m）从 B06 起没用，可以从 ResourceFX 退掉（不删资产，要你点头）。
- 代价：线细到 ×0.65；升得慢一点（平均 24 m/s，原 37 m/s）。

## 3. 同时同高：上下两层

- 全场 P 排小号和 B 排小号 1 s 内同时开、同一根小尾缀的有 2 处：23.65 s 小银菊 + 点灭星、48.85 s 小银菊 + 小青柠。
- 现在 P 排挂**现有中尾缀**开到 +210 m，B 排 ×0.8 留在 +150 m（原 ×0.6）。
- 手游那份照旧，手游没有 B 排。
- 23.65 s 那一刻，前一排（21.15 s 金裂星）还在褪，B 排点灭星和它有一点交叠；按「开花到寿命 75 %」算它已经不亮了。

## 4. 按种类定大小（90–100），中 / 大号不放大

- 小号基准：爆裂星 / 金裂星 100、点灭星 / 小银菊 95、橙辉星 / 小青柠 90 m，再叠每点 ×0.92 / 1 / 1.08。
- **放大会不会叠得更厉害（你问的）：会。**
  - 先试了小号 90–110、中号 150–160：重叠体检从 8 处升到 12 处，多出来的是「中号和下面 B 排小号同高叠」，就是图 4 那种。
  - 所以改成：
    - 小号 90–100；
    - B 排小号同一刻上面有中 / 大号的，不放大；
    - 中、大号不放大。
  - 现在重叠 10 处（B07 修订1 8 处），多的 2 处都是后一排压前一排快熄的花（126.4 s、171.6 s）。
- 结果真正放大的只有单独开的小号排：小银菊 18 发、金裂星 5 发。大部分小号是 B 排，在中 / 大号下面。
- 名义直径没在 UE 量过（10-11 本机估计有的资源差 1.6–3 倍），实机测量回来再校这张表。

## 5. 同种类更随机：两种交替、时间错开

- 两种交替：8 排的奇数位换成不同色系、寿命不更长的花。
  - 小银菊 / 点灭 / 金裂星 / 小青柠 → 橙辉星；
  - 金芒菊 → 绿牡丹，金曜菊 → 彩千轮，金锦菊 / 金蕊青柠 → 多重菊。
- 银金占比 65 % → 61 %。
- 换上去的花寿命不能更长：一开始用了小青柠（6.6 s），会把后面同高的排盖住，所以换掉了。
- 时间：
  - 9 排齐发，每点随机错开 0 / 0.1 / 0.2 s；
  - 3 排里→外的步距 0.1 → 0.15 s。
- 起音命中（±0.1 s）84 %（B07 修订1 同口径见体检）。
