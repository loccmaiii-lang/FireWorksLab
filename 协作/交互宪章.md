## 1. 每块屏幕管什么

| 区域 | 管什么 | 不放 | 状态 |
| --- | --- | --- | --- |
| 左栏 = 库 | 找、建、搜索、收藏、隐藏；行内改名 / 删除 / 隐藏；「＋ 新建效果」 | 参数、烘焙设置、重复的导出按钮 | 4.5.3 精简过 |
| 中栏 = 画布 + 一行时间 | 实时模拟 / 引擎回放 / 贴图 / 流转；PC / 手机；播放、入出点、每层一条细轨；烘焙状态 | 版本管理、完整参数、长说明 | 4.5.0 |
| 右栏 = 发射器 → 模块 → 参数 | **第一屏就是发射器标签**；选中的发射器 9 个模块；这一层的颜色在发射器下面；审阅 | 资产改名 / 删除、第二套版本系统、和顶栏同名的导出 | **4.6.0** |
| 顶栏 = 当前资产 + 主动作 | 名字、来源、版本、没保存标记；保存、另存、还原、撤销 / 重做、导出素材包；⋯ 只放低频的 | 删除、隐藏（在左栏行内） | 4.5.0 |

一件事只有一个主入口。快捷入口调用同一个命令，名字、确认、撤销、出错提示都一样。

## 2. 发射器和模块（5.0 的核心）

- **每个发射器同一套 9 个模块**：生成 / 形状 / 初速 / 受力 / 寿命 / 大小 / 颜色 / 亮度 / 闪烁。模块按这个顺序排；特有的（点灭、辉星、子花的闪光……）排在后面。（4.6.0）
- **没有参数的模块照样列出**，灰字写明「跟谁」或「为什么没有」。例：「爆裂 › 受力：小闪只亮零点几秒，原地不动」。（4.6.0）
- **每个值三种填法**：数值、随机（收在本体参数的「随机」下面）、按寿命曲线（几行「时刻:值」，拖点编辑器以后做）。（4.6.0，自定义发射器先有；其它发射器在第 3 步补齐）
- **「＋ 加发射器」** 在发射器标签行最后。去掉的入口在那个发射器的「颜色」模块里。（4.6.0）
- **联动看得见、能断开**：
  - 算出来的值用灰字，「用默认」勾选能断开（4.6.0：开花闪光半径、子星大小 / 亮度、子花闪光半径）；
  - 链条图标和「物理给默认、每个值都能改」在第 3 步做。
- **颜色**：一层输出只有一条颜色。同一层的发射器颜色跟这一层走；要不同颜色就拆层（加发射器的颜色模块里写着）。

## 3. 状态、撤销、出错

1. **删除都能撤销**：每删一个叠一条撤销提示，各自 8 秒（4.5.10）。撤销会把版本、草稿一起找回。删层、加层、挪层进 Ctrl+Z（4.5.10）。
2. **不丢改动**：
   - 切走、刷新、换版本以前，没保存的改动先存成草稿（4.2.3 + 4.5.10）；
   - 浏览器存不进去时红字常驻提示，不说「已保存」（4.5.10）。
3. **导出不拿旧贴图**：某层按新参数烘焙失败或没烘完，导出拦住并说是哪层（4.5.10）。
4. **系统替你做的事要写出来**：例如结尾全黑的帧没烘，「火花灭完」那行会写明（4.5.10）。以后每个自动值都按这条做。
5. **说明**：悬停 1.5 秒出现，点名字钉住，Esc 或 × 关掉（4.5.0）。

## 4. 词汇（一个概念一个词）

| 概念 | 用这个词 | 不用 |
| --- | --- | --- |
| 调参用的实时画面 | 实时模拟 | 渲染模式 |
| 导出贴图按引擎方式播 | 引擎回放 | 导出效果、回放模式 |
| 你自己的效果 | 我的效果 | 配方（只指文件） |
| 存档 | 版本（自动的叫「导出时版本」、没保存的叫「草稿」） | 恢复点 |
| PC / 手机交付的 ZIP | 素材包 | 导出效果 |
| 你加的发射器 | 自定义发射器 | 子效果、事件层 |
| 物理上本来就是 0 的模块 | 「这个发射器没有这一项」 | 留空不写 |
