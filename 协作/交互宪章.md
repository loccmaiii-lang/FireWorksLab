## 1. 每块屏幕管什么

| 区域 | 管什么 | 不放 | 状态 |
| --- | --- | --- | --- |
| 左栏 = 库 | 找、建、搜索、收藏、隐藏；行内改名 / 删除 / 隐藏；「＋ 新建效果」 | 参数、烘焙设置、重复的导出按钮 | 4.5.3 精简过 |
| 中栏 = 画布 + 一行时间 | 实时模拟 / 引擎回放 / 贴图 / 流转；PC / 手机；播放、入出点、每层一条细轨；烘焙状态 | 版本管理、完整参数、长说明 | 4.5.0 |
| 右栏 = 发射器 → 模块 → 参数 | **顶上固定一块**：「现在改的是：层 › 发射器」、一个「搜索」入口、一行发射器标签（4.9.8）；选中的发射器 9 个模块；这一层的颜色在发射器下面；审阅 | 资产改名 / 删除、第二套版本系统、和顶栏同名的导出 | 4.6.0；**4.9.8** |

**右栏换页只换显示**（4.9.7，对话框23；GPT 方案 C08）：「参数 / 审阅 / 工具」三页切换不动打开的效果、播放时间、选中的层 / 发射器、模块开合；各页的滚动位置各记各的。多层效果里也有「工具」页。

## 2. 发射器和模块（5.0 的核心）

- **每个发射器同一套 9 个模块**：生成 / 形状 / 初速 / 受力 / 寿命 / 大小 / 颜色 / 亮度 / 闪烁。模块按这个顺序排；特有的（点灭、辉星、子花的闪光……）排在后面。（4.6.0）
- **没有参数的模块照样都在**，不再一个个占位：在发射器末尾合成一块灰字，原因相同的合一行，措辞书面、精简。例：「形状 · 初速 · 受力：开花点单次闪光，无位移」。（4.6.0；4.9.8 用户 10-06 12:30「尽量精简描述，描述用词专业点……书面化精简些」）
- **每个值三种填法**：数值、随机（收在本体参数的「随机」下面）、按寿命曲线（几行「时刻:值」，拖点编辑器以后做）。（4.6.0 自定义发射器；4.8.0 / 4.9.4 所有发射器的大小、亮度）
- **「＋ 加发射器」** 在发射器标签行最后。（4.6.0）
- **去掉发射器**：发射器框右上角的 ×，鼠标在框里停 1.5 秒出现（用 Tab 键进框马上出现），点了就去掉，Ctrl+Z 撤回。只有自定义发射器能去掉；颜色模块里不再放这个入口。（4.9.8，用户 10-06 12:30「放到发射器的框右上角，鼠标停留1.5s出现一个x，我点就删除，不要放在颜色模块中」）
- **联动看得见、能断开**（4.9.0 链条；4.9.8 换成带字的按钮，用户 11:18「不知道看怎么断开怎么接回去」）：
  - 接着：状态列的按钮写「跟着算」，数值用灰色斜体，下面一行用话写跟谁、怎么算（不写公式）；滑杆照样能拖；点「跟着算」= 断开，固定在现在算出来的数。
  - 直接改就断开，存你填的数，按钮变成「接回」，下面写「已断开：用你填的 ×；跟着算是 ×」；点「接回」回到跟着算。
  - 现在有链条的：开花闪光半径、子花 7 项、子星终端速度、尾缀终端速度、消散帧率。以后加的联动（例：粒径 → 火花寿命 / 阻力）都用这一套。
- **旧（待删）参数**（4.9.0）：参数表里要删的，这个效果用着就照常显示、名字前标「旧」、说明写用什么代替；没用上就收进模块底下的「旧（待删）▸ N 项」。真删要等 UE 实测和你看过。
- **颜色**：一层输出只有一条颜色。同一层的发射器颜色跟这一层走；要不同颜色就拆层（加发射器的颜色模块里写着）。每个发射器的「颜色」模块有一行「颜色随本层 · 去改」，点了滚到下面的「本层颜色」，那里有「← 回到 ×× › 颜色」回到原来的位置。（4.9.8）
- **参数行一种网格**（4.9.8）：名字 | 滑杆 | 数值 | 状态。状态用字写，一行写一个最要紧的：跟着算 / 接回（链条）、超范围、改过、旧、锁定、不起作用；悬停写全。锁在名字左边，鼠标移上去或锁着时才出现。
- **常用 / 更多**（4.9.8）：每个模块先显示常用的（命名表 tier = core）和改过的；别的收进模块标题右边的「更多 N 项」（写出其中几项不是模板默认值），点开记住；常用的不到 1 项、别的不到 3 项就全显示。搜索、只看改过的时不收。模块收起时标题后面写前两个参数的值。旧（待删）一个发射器一个开关，在发射器末尾。
- **放在哪个标签里**（4.9.8）：花型、英文名、产物在「效果」标签；多层里这一层的导出方案在「输出」顶上，「这一层在整朵里」（开始时间、缩放、时间倍率、镜像）和轨迹联动在「效果」顶上。图层管理在发射器上面：屏幕高 ≥ 860 px 默认展开，矮的屏幕默认收成一行「图层 [1 ××] [2 ××] … 整体」；你开合过就按你的。
- **输出栏收口**（4.9.5，宪章遗漏 1；汇总第 2 节 #4，用户 10-05 19:40 全按推荐）：序列效果的「输出」发射器先展开两个模块，其它输出模块默认折起。
  - **直接调**（9 项）：PC 怎么出、手机怎么出、入点、出点、贴图宽、贴图高、格子（列 × 行）、曝光、留边。
  - **算出来的**：帧率（每帧停几个 tick）、贴图张数、单格大小。灰字写「现在算出来是多少」，带链条；直接改就断开，存你填的数。
  - 旧帧数模式（开花段、淡出起点……）和 Zoom 取景在「旧（待删）」里。效果用着才显示。

## 3. 状态、撤销、出错

1. **删除都能撤销**：每删一个叠一条撤销提示，各自 8 秒（4.5.10）。撤销会把版本、草稿一起找回。删层、加层、挪层进 Ctrl+Z（4.5.10）。
   - **一次操作算一步**（4.9.7，对话框23；GPT 方案 C09）：一次拖动（按下到松开，中途停多久都算一次）、一次输入提交（回车 / 离开输入框）、一次选择或点击；按住方向键调滑杆，松开算一步；拾色器关掉算一步。两个参数紧挨着改是两步。还是同一个撤销栈。
2. **不丢改动**：
   - 切走、刷新、换版本以前，没保存的改动先存成草稿（4.2.3 + 4.5.10）；
   - 浏览器存不进去时红字常驻提示，不说「已保存」（4.5.10）。
3. **导出不拿旧贴图**：某层按新参数烘焙失败或没烘完，导出拦住并说是哪层（4.5.10）。
4. **系统替你做的事要写出来**：例如结尾全黑的帧没烘，「火花灭完」那行会写明（4.5.10）。以后每个自动值都按这条做；细则见第 6 节。
5. **说明**：点参数名（或模块标题旁的 ？）才打开，固定在右栏底部；再点同一个名字、点 ×、按 Esc 关掉；F1 = 打开 / 关掉光标所在参数的说明（4.9.8，登记在 KEYMAP）。鼠标移过去不弹。依据：用户 10-04 偏好「频繁移动鼠标时不得自动弹参数说明；主动点 ? / F1 后打开固定说明区，关闭 / Esc 收起」（`experiments/参数交互稿/AGENTS.md`）。以前（4.5.0）是悬停 1.5 秒出现。
6. **身份条**（4.9.1）：顶栏写名字、来源、版本、改了没保存、素材包和现在一不一样；旁边写贴图是旧的 / 烘焙中 / 失败。

## 6. 不静默（4.9.5，宪章遗漏 5；方案 6.5 ③）

系统替你改了什么，都要让你看得到：

1. **打开旧存档时**，系统按现在的规则改写了某个值，或者不再用某个参数，画面上方出一条常驻提示，写明改了哪几项、为什么。提示要点「知道了」才收。（4.9.5）
   - 适用于打开我的效果、AI 效果、正式库、多层组合，以及导入配方文件。
   - 值写中文（4.9.7）：选项写选项名（例：「结尾」原来是「最后 0.3 s 整体淡出」），数值带单位；不写内部值（fade、0）。
   - 例：空中类的「结尾：淡出」「冷却方式：0」现在不再用；旧的「紧凑取景」改成 Zoom。打开时都会列出来。
2. **滑杆只是常用范围**：数值框能填范围以外的值，滑杆停在头上，数值照存；说明里写常用范围。（4.9.2）
3. **自动值写实际值**：链条、灰字「现在算出来是多少」，见第 2 节。系统替你夹值、跳帧、自动加张数时，那一行或烘焙状态里写出实际用的值。例：「火花灭完」、贴图张数「放不下自动加」、每帧停几个 tick。

## 8. 新功能准入（4.9.5，宪章遗漏 4；对话框20 草案第 6 节）

加一个对象、动作或入口以前，先在这份宪章里写清下面几项，写不出就先改宪章、再做：

| --- | --- |

| 首屏 | 1366×768 和 1920×1080 下，主入口不用滚动就看得到 |
