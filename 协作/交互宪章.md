## 0. 共用基础与三个工具的职责

### 0.1 产品边界与迁移顺序

| 工具 | 唯一职责 | 资源来源与交付 | 当前迁移约束 |
| --- | --- | --- | --- |
| 烟花烘焙器 | 效果制作、实时模拟、烘焙、检查、资源输出、资源导入 | 输出完整 PC/手机包、资源元数据和同版本缩略图；通过本机适配器交给现有 UE 导入模块 | 新增独立导入工作区；原参数、物理、材质角色、版本与检查口径保持 |
| 烟花编排工作台 | 消费烟花资源，安排发射/开花、时间节奏、点位与演出引用 | 识别烘焙器资源目录中的名称、缩略图、时长、尺度、平台与固定版本；演出编辑不回写烟花制作参数 | 资源库/资产引用保留，烟花参数制作迁回烘焙器；纯编排模板、相对时序与音乐编辑仍属编排 |
| 特效工作台 | 常规其他资产、材质与配置处理 | 沿用现有非烟花工具的数据与执行规则 | 烘焙器和编排台完整迁移且验收前，原烟花素材导入与烟花编排功能继续可用；验收后再移除入口与重复代码 |

先完成共用基础与样板，再按真实任务逐块翻新。制作/交付/导入可处于同一烘焙器应用内，但工作区职责、对象和状态分清；不把导入队列插入发射器参数栏。公共协议与设计基础可入仓库，本机执行配置与凭据不随设计迁移公开；工程命名和用户明确授权的节目/素材按现行授权与资料清单共享，已有授权不因本宪章撤销。

### 0.2 共用视觉规则及可执行来源

- 依据 Material 3 / Material 3 Expressive 与已核对的 2026 更新适配专业桌面工作区；记录规范查询日期和平台支持，不将设计规范等同于安装组件库。
- `tool/design-system/tokens.json` 是颜色、字阶、间距、形状、密度与动效值的唯一来源，生成 `tokens.css`。基础组件使用 `fw-` 前缀，避免覆盖旧工具。样板直接消费这些文件，不另抄一套样式。
- 深色中性灰表面、薄荷主色为第一版共同基础。主色表达当前主动作与选中；成功、警告、错误、未验证有独立语义与文字。新建/更新/复用/跳过是操作计划，不能预先涂成完成状态。
- 界面主题与烟花画布、Ramp、曝光、粒子颜色、贴图完全分离。画布背景保持判断产物所需的中性背景。
- 字阶角色统一：页面标题 24/32、区域标题 18/26、正文 14/22、字段/状态 13/20、辅助 12/18 px；数字使用等宽数字，单位独立且可读。按需采用本机中文字体，不依赖在线字体加载。
- 间距采用 4/8 px 基础级次；相同层级使用相同间距。紧凑/舒适使用同一字阶与语义，普通控件高 32/40 px；现有参数行 30 px 规则保持。粗指针操作目标至少 48 px，不能靠缩小点击区凑首屏。
- 统一图标按语义名称消费，第一版复用项目现有 Tabler 离线 SVG 及许可；不同旧工具在分区迁移时做语义映射，不混用图标字体字符。
- 基础动效表达状态和层级，使用统一时长/缓动；用户操作立即生效、重复操作可打断。尊重减少动态效果；不把烟花模拟的物理动画套入 UI 动效限制。

上述像素值与第一版深色主题是本项目适配值，不是官方强制值。规范核对：2026-10-10，[Material I/O 2026 更新](https://m3.material.io/blog/whats-new-at-io26)、[间距](https://m3.material.io/styles/spacing/overview)、[动效](https://m3.material.io/styles/motion/overview/how-it-works)；基础实现版本 v0.1.0。当前原生基础已实现按钮/字段/滑杆/复选/分段选择/折叠/提示/对话框/进度/状态/表格，菜单与复杂领域组件按真实任务补齐，不据此宣称全部规范已覆盖。

### 0.3 基础组件与独立状态样板

共享按钮、图标按钮、输入/数值/滑杆、复选、分段导航、模块折叠、菜单、对话框、提示条、进度、列表行和状态标签。默认、悬停、焦点、按下、选中、禁用、只读、加载、错误按组件适用性定义；禁用写原因，状态不能只靠颜色。

`tool/design-system/index.html` 为独立组件与状态样板，不是生产业务页，也不永久占据三个工具的侧栏。样板可切密度、验证键盘/焦点/错误/对话框/提示；业务示例明确标“状态演示”，不能把演示进度或素材包当作已写入/已检查/已导入。

模块参数、层轨道、编排时间轴、导入产物表分别保留业务模型，只共享视觉、标签、键盘和反馈规则。HTML 与 React 可通过适配使用共同基础，不因共用规范强行迁移全部技术栈。

### 0.4 工作区、焦点与可访问性

- 工具名称、当前对象与版本、主要动作清楚常驻；三工具的视图切换不改变对象、草稿或确认范围。
- 区域局部滚动，常驻栏占真实空间；切回恢复该区域滚动、筛选、选择及入口焦点。窄屏只切呈现窗格，不能等同切选对象或授权执行。
- 主入口在 1366×768、1920×1080 可见；按第 8 节 W14 保持参数首屏要求。真实中文长名可换行/展开，实际值与单位完整可达；200% 缩放与窄屏检查不丢动作。
- 以 WCAG 2.2 AA 为验证目标：普通文本对比度 ≥4.5:1，必要控件/焦点 ≥3:1；Tab 顺序、可见焦点、标签、错误关联、读屏反馈与对话框焦点恢复一起实现。声明通过需对应实际验证证据。
- 全局快捷键仍登记 KEYMAP；组件只使用其本地键盘行为，不能截获浏览器与无障碍快捷键。

### 0.5 业务状态与保存/撤销

| 对象 | 必须区分的状态 | “完成”的证据 |
| --- | --- | --- |
| 配方/演出草稿 | 未保存、保存中、已保存、保存失败 | 真实持久化成功；失败保留当前编辑内容 |
| 烘焙结果 | 参数已改/旧贴图、烘焙中、取消、失败、最新 | 完整结果指纹对应当前候选；失败保留上次成功且标旧 |
| 资源目录 | 未配置、写入中、失败/部分写入、已导出、旧版本 | 文件完整写入、读回/指纹核对后发布完成标记 |
| 导入计划 | 等待连接、检查中、检查失败、待核对、确认失效、可执行 | 当前包、配置、选择、命名/目标及依赖与确认指纹一致 |
| UE 导入 | 执行中、包间停止、部分完成、失败、UE 已保存、版本管理失败/完成 | 逐资产真实回执；写入成功不等于版本管理或实播通过 |
| 效果认可 | 未实播、已实播待认可、用户认可 | 与候选版本绑定的实际播放及用户决定 |

一次拖动/输入提交算一步参数撤销。删除本地对象沿用可恢复提示；UE 写入、覆盖、停止和恢复按导入器执行机制处理，不能声称被烘焙器 Ctrl+Z 回退。短结果可关闭，持续错误就地显示、可定位/重试；日志阅读不被新记录抢滚动。

### 0.6 指定目录导出 → 自动检查 → 用户导入

这是用户已确立的目标流程；4.9.60已接入目录发布与原导入检查，完整实机/迁移/统一表现仍按文末实现状态核对：

1. 用户指定并保存本机资源导出根目录。主动作“导出到资源目录”直接输出展开的资源文件；该流程无需下载 ZIP、解压、复制路径。ZIP 可保留为独立便携交付动作，不作为指定目录流程的静默回退。
2. 烘焙器先完成当前 PC/手机产物、正式命名、尺寸标定和现有整理，再交给本机目录适配器。每个效果目录及文件名保持固定，参数/帧曲线/格式契约不改变。
3. 全部文件写入并核验后才发布完成回执与资源索引。写入中、失败、取消、缺文件和指纹不符均不可进入可执行导入列表；新导出不得静默替换正在执行任务绑定的旧快照。
   资源按稳定效果目录组织，每个修订使用不可变子目录，最新索引指向完成修订；导入/演出使用固定修订。保留原生文件名，避免用同一绝对路径覆盖历史后仍声称版本可追踪。
4. 回执包含本机实际目录、效果/英文名、完整文件清单、来源与产物指纹及 PC/手机配置。导入模块自动接收、识别、新建或更新候选，执行既有名称/重名/类型/依赖/指纹检查，展示当前包与逐资产清单。未知/冲突/需要命名决定的项停在原导入器的核对环节，不按名称猜测合入。
5. 保留导入器现有队列/设置/逐资产预览、确认、导入/同名更新、复用/跳过、日志、停止与部分失败恢复交互。只有用户明确点击“导入”才触发 UE 写入；自动识别、检查、完成导出均不等于授权写入。
6. 修改源包、平台配置、命名、目录或资产选择作废对应旧确认。执行前重读来源并复核；恢复任务使用真实已完成/失败回执。同名更新重建粒子发射器的覆盖范围必须展示，手改值按现有行为处理。
7. 浏览器目录句柄没有可供现有导入器直接使用的绝对路径。正式联动由本机适配器提供目录与文件交接；网页端不能假定内存 Blob 或句柄自动成为 UE 路径。适配器与现有 UE 服务分开处理可用性，UE 离线时仍可制作/导出，导入显示等待连接。

### 0.7 编排消费与版本可追踪资源

- 素材包保留 `fwl.cascade/1`；新增独立 `workspace-resource.json` 资源索引和 `workspace-thumbnail.png` 缩略图，不把展示字段塞入原生材质/粒子字段。索引至少含稳定资源 ID、资源修订指纹、制作者版本、配方来源、中文/英文名、时长、尺度及标定状态、PC/手机配置、完整文件/内容指纹和缩略图时间/来源。
- 缩略图由同版本产物按引擎回放口径生成，不能用不同版本旧图或任意符号冒充效果；未生成显示明确占位与原因。示意、未 UE 标定和已实播分别标识。
- 编排工作台通过资源目录/索引识别库条目，选择固定资源版本用于演出。节奏、点位、片段、音乐锚点及编排模板属于演出；烟花模拟/材质/烘焙字段在烘焙器制作。
- 配方版本 → 导出修订 → UE 资产回执 → 演出资源引用形成可追踪关系。更新索引提示“有新版本”，用户应用前已有演出继续引用原版本；删除/丢失资源给缺失引用提示，不静默跳过或换成其他效果。
- 共享版本按授权范围交换资源索引/缩略图与演出文件，未授权数据不默认上传；本机连接配置与账户凭据保持本机。工程命名、路径与原件使用现行用户授权及资料清单，不统一强制脱敏。虚拟编排可用未导入资源，但真实交付必须区分导入完成/未实播/缺失映射。

### 0.8 迁移门槛与变更治理

现有工具在每阶段可运行并留备份。新烘焙器导出/导入和编排资源消费完成后，核对旧功能清单、草稿/批次/资源映射/演出引用迁移、刷新恢复、错误恢复、实际任务与用户认可，再移除特效工作台原烟花两项功能。旧浏览器来源与存储显式迁移，不推定自动共用；“只做节奏编排”不授权直接删除旧花型草稿。

公共基础版本独立于烘焙器渲染版本；tokens 更新不改变默认烟花效果。共享基础由同一认领方修改，例外写明工具/组件/理由/验收；各工具不得再定义同名但不同含义的颜色或状态。更新本宪章、tokens、样板与覆盖清单须可对应同一版本。

每阶段核对：打开 → 选择 → 改 → 切换 → 保存 → 刷新 → 导出 → 自动检查 → 用户导入 → 回执/失败恢复 → 编排引用。执行结束、AI 自检与用户认可保持区分。生产尚未接入的目标必须明确写“待接入”，不能用样板或静态检查冒充上线。

## 3. 状态、撤销、出错

1. **删除都能撤销**：每删一个叠一条撤销提示，各自 8 秒（4.5.10）。撤销会把版本、草稿一起找回。删层、加层、挪层进 Ctrl+Z（4.5.10）。
   - **一次操作算一步**（4.9.7，对话框23；GPT 方案 C09）：一次拖动（按下到松开，中途停多久都算一次）、一次输入提交（回车 / 离开输入框）、一次选择或点击；按住方向键调滑杆，松开算一步；拾色器关掉算一步。两个参数紧挨着改是两步。还是同一个撤销栈。
2. **不丢改动**：
   - 切走、刷新、换版本以前，没保存的改动先存成草稿（4.2.3 + 4.5.10）；
   - 浏览器存不进去时红字常驻提示，不说「已保存」（4.5.10）。
3. **导出不拿旧贴图**：某层按新参数烘焙失败或没烘完，导出拦住并说是哪层（4.5.10）。
4. **系统替你做的事要写出来**：例如结尾全黑的帧没烘，「火花灭完」那行会写明（4.5.10）。以后每个自动值都按这条做；细则见第 6 节。
