## 2. 发射器和模块（5.0 的核心）

- **每个发射器同一套 9 个模块**：生成 / 形状 / 初速 / 受力 / 寿命 / 大小 / 颜色 / 亮度 / 闪烁。模块按这个顺序排；特有的（点灭、辉星、子花的闪光……）排在后面。（4.6.0）
- **没有参数的模块照样都在**，不再一个个占位：在发射器末尾合成一块灰字，原因相同的合一行，措辞书面、精简。例：「形状 · 初速 · 受力：开花点单次闪光，无位移」。（4.6.0；4.9.8 用户 10-06 12:30「尽量精简描述，描述用词专业点……书面化精简些」）
- **每个值三种填法**：数值、随机（收在本体参数的「随机」下面）、按寿命曲线（输入「时刻:值」，4.9.12 增加对应数据的只读折线图；拖点编辑器以后做）。（4.6.0 自定义发射器；4.8.0 / 4.9.4 所有发射器的大小、亮度）
- **模块默认收起，标题右边写摘要**（4.9.14）：一眼看完一个发射器有哪些模块、各是多少（例：「生成  300 个/秒 · 起势 0.80 s」「受力  阻力 4.00 1/s · 重力倍率 0.05×」「闪烁  未启用」「颜色  随本层颜色 · 定位 ↗」）；有改过的前面一个琥珀点、右边 ↺。每个发射器第一个有参数的模块默认展开；你开合过的按你的。序列效果的「输出」照旧先展开「直接调」「算出来的」。搜索 / 仅改动时有结果的模块自动展开，清掉回到你的开合。
- **「＋ 加发射器」** 在发射器标签行最后。（4.6.0）
- **去掉发射器**：发射器框右上角的 ×，鼠标在框里停 1.5 秒出现（用 Tab 键进框马上出现），点了就去掉，Ctrl+Z 撤回。只有自定义发射器能去掉；颜色模块里不再放这个入口。（4.9.8，用户 10-06 12:30「放到发射器的框右上角，鼠标停留1.5s出现一个x，我点就删除，不要放在颜色模块中」）
- **联动看得见、能断开**（4.9.0 链条；4.9.8 换成带字的按钮，用户 11:18「不知道看怎么断开怎么接回去」）：
  - 接着：参数下方状态行的按钮写「跟着算」，数值用灰色斜体，下面一行用话写跟谁、怎么算（不写公式）；滑杆照样能拖；点「跟着算」= 断开，固定在现在算出来的数。
  - 直接改就断开，存你填的数，按钮变成「接回」，下面写「已断开：用你填的 ×；跟着算是 ×」；点「接回」回到跟着算。
  - 现在有链条的：开花闪光半径、子花 7 项、子星终端速度、尾缀终端速度、消散帧率。以后加的联动（例：粒径 → 火花寿命 / 阻力）都用这一套。
- **旧（待删）参数**（4.9.0）：参数表里要删的，这个效果用着就照常显示、名字前标「旧」、说明写用什么代替；没用上就收进发射器末尾的「旧（待删）▸ N 项」（4.9.8 起一个发射器一个开关）。真删要等 UE 实测和你看过。4.9.11：空中花型 14 项（尾迹粗细、两头收尖、星头前段亮度……）你 10-06 14:24 定留下，不再是旧；现在 65 项（物理尾缀、RT / V5 尾缀旧旋钮、旧输出；4.9.13 开花段时长、淡出起点不再是旧；4.9.21 删了「放大的中心」）。
- **颜色**：一层输出只有一条颜色。同一层的发射器颜色跟这一层走；要不同颜色就拆层（加发射器的颜色模块里写着）。每个发射器的「颜色」模块有一行「颜色随本层 · 去改」，点了滚到下面的「本层颜色」，那里有「← 回到 ×× › 颜色」回到原来的位置。（4.9.8）4.9.12 保持连续布局，颜色分段先于强度，开始秒数直接输入；首段固定 0 s、最多 5 段不变；色值与渐变条只读，仍用原拾色器改颜色。

## 3. 状态、撤销、出错

1. **删除都能撤销**：每删一个叠一条撤销提示，各自 8 秒（4.5.10）。撤销会把版本、草稿一起找回。删层、加层、挪层进 Ctrl+Z（4.5.10）。
   - **一次操作算一步**（4.9.7，对话框23；GPT 方案 C09）：一次拖动（按下到松开，中途停多久都算一次）、一次输入提交（回车 / 离开输入框）、一次选择或点击；按住方向键调滑杆，松开算一步；拾色器关掉算一步。两个参数紧挨着改是两步。还是同一个撤销栈。
2. **不丢改动**：
   - 切走、刷新、换版本以前，没保存的改动先存成草稿（4.2.3 + 4.5.10）；
   - 浏览器存不进去时红字常驻提示，不说「已保存」（4.5.10）。
3. **导出不拿旧贴图**：某层按新参数烘焙失败或没烘完，导出拦住并说是哪层（4.5.10）。
4. **系统替你做的事要写出来**：例如结尾全黑的帧没烘，「火花灭完」那行会写明（4.5.10）。以后每个自动值都按这条做；细则见第 6 节。
5. **说明**：点参数名（或模块标题旁的 ？）才打开，固定在右栏底部；再点同一个名字、点 ×、按 Esc 关掉；F1 = 打开 / 关掉光标所在参数的说明（4.9.8，登记在 KEYMAP）。鼠标移过去不弹。依据：用户 10-04 偏好「频繁移动鼠标时不得自动弹参数说明；主动点 ? / F1 后打开固定说明区，关闭 / Esc 收起」（`experiments/参数交互稿/AGENTS.md`）。以前（4.5.0）是悬停 1.5 秒出现。
6. **身份条**（4.9.1）：顶栏写名字、来源、版本、改了没保存、素材包和现在一不一样；旁边写贴图是旧的 / 烘焙中 / 失败。
