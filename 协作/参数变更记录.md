> 规矩见 `协作/参数宪章.md`。每条记五样：日期、版本、改了什么、理由、用户原话。

## 2026-10-05 · 烘焙器 4.6.0（5.0 第 1 步，对话框15）

- **用户原话**：
  - 20:22「我就是希望每一个子发射器拥有的参数都是全的，以及交互可以做的更好一些」；
  - 21:40 Q1「物理给默认，每个值都能改」、Q2「按真实米数」；
  - 21:55「直接开始吧……随后直接开 5.0」。
- **加了 89 个参数，全部是以前写死在代码里的数，默认值等于原来的数**。基准回归逐像素相同，画面不变。

  | 发射器 | 加了什么 |
  | --- | --- |
  | 爆裂 | 延迟随机、最近距离（× 范围）、跟随星、寿命、衰减、亮度、亮度随机、大小、大小随机 |
  | 开花闪光 | 半径（用默认 = 跟初速）、衰减、寿命 |
  | 子花 | 子星大小（用默认 = 同星）、子星亮度（用默认 = 同星）、闪光半径（用默认 = 跟子花初速） |
  | 星 · 点灭 | 亮相亮度、暗相亮度、频率随机 |
  | 火花 | 跟随随机、温度随机 |
  | 火花 · 辉星 | 延迟随机、闪光宽度、闪光亮度、闪前压暗 |
  | 余烬 | 寿命随机、变暗快慢、淡出开始 |
  | 分叉火花（新发射器） | 寿命、寿命随机、甩出速度、速度随机、继承速度、阻力倍数、温度倍数、亮度、变暗指数、大小倍数。「分叉数」「分叉时刻」从「火花 › 松叶分叉」搬过来 |

- **自定义发射器 1 / 2**（「＋ 加发射器」，默认关）：
  - 事件：星熄灭时 / 开花时 / 开花后某个时刻 / 星燃烧时沿路；
  - 生成什么：光点或星；
  - 9 个模块全有，包括大小随寿命、亮度随寿命（几行 时刻:值）。
- **名称表 +89 行，发射器表 +89 行**。新增发射器「分叉火花」「自定义 1」「自定义 2」。所有子发射器的模块列表补成 9 个标准模块。
- **「游戏内大小」改成真实米数**（`协作/标准.md` 2.1，Q2 用户批）。

## 2026-10-05 · 烘焙器 4.7.0（5.0 第 2 步，对话框15）

- **用户原话**：
  - 10-04 16:17「老的先灭」；
  - 10-05 01:28 #11「新旧两套逻辑……宁可旧效果重导」；
  - 19:40「全按推荐」（汇总 §3「删：冷却方式、结尾两个旧 / 新开关」，#4「五种帧数模式 + Zoom 进旧（待删）」）；
  - 21:55「直接开 5.0」。
- **删**：`coolMode`（冷却方式）、`endMode`（结尾）从面板、名称表、发射器表删掉。键留在 BASE 里，旧存档能读，空中类不再看它们。
- **改缺省**：`frameBudget` → `fixed`（固定机位 + 匀速帧，新选项），`zoom` → `off`。其余五种帧数模式和 Zoom 选项标「旧（待删）」，UE 实测第 1 项过了再删。
- **改默认值**：15 个花型模板的序列时长加长到盖住最后一批火花（结尾不再整体淡出，不加长就会被切掉）。
- **改数据**：待验收 JM4-40、QN11、HK10、HN2 的序列时长、帧数、Zoom（见 `tool/CHANGELOG.md` 4.7.0）。

## 2026-10-06 · 烘焙器 4.9.0（5.0 第 3 步，对话框15）

- **用户原话**：10-05 21:40 Q1「物理给默认，每个值都能改」；19:40「全按推荐」；20:22「交互可以做的更好一些」。
- **没加、没删参数，没改含义**。只改面板：
  - 联动的 11 项换成链条（存的值照旧是 -1 / 0 = 跟着算）。`subVt`、`rtVt`、`rtFadeFps` 以前写「0 = 同主层 / 按弹径算 / 自动」，现在同样是链条。
  - 参数表「删」「改成常量」的项，面板上标「旧」；这个效果没用上就收起。代码、存档、导出不变。暂不标：`shellNo`（号数）、`frameBudget`（固定机位是它的一个选项）、`coreProfile`（要看过画面再定常量）。
