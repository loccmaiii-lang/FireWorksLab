## 2026-10-07 · 烘焙器 4.9.29（对话框23）：产物表加「低端」列 + 单帧的 6 个设置

- **用户原话**：09:41「我还希望有一个单帧导出功能，与单帧溶解图功能……单帧图可以输出带颜色的太阳，溶解图和别的层譬如cut图，如果有多种这种功能图就合并成一张，命名后缀我来填」；09:54（经对话框21）「有现成材质；默认某一帧，长曝光做成可选，两种要能并排对比看；产物表加低端列；要出现顺序图」；12:40「单独一份低端包，贴图名尾巴加_MB;其它按推荐的一样」「先做能做的（推荐）」。
- **加了什么**（导出方案；单层存在效果参数里、多层存在层上，和光点大小一样；改了不重烘大面片）：
  - `outLow` 低端导出（单帧 / 序列 / 不出，缺省不出）：多层存在 `L.out.low`。序列 = 和手机同一张贴图。
  - `lowPick` 单帧取哪一刻（某一帧 / 长曝光，缺省某一帧）：长曝光 = 入点到出点之间每个像素取最亮。
  - `lowAt` 单帧时刻（s，0 = 自动：花开得最大的那一刻）：右栏一行「用时间轴现在的时刻」。
  - `lowSize` 单帧贴图大小（512 / 1024 / 2048 px，缺省 1024）。
  - `lowJit` 溶解错落（0–1，缺省 0.3）：按像素小块给熄灭时刻加随机，0 = 完全按模拟。
  - `lowMaps` 功能图（D 溶解 / C 轮廓 / A 出现顺序，缺省三种都要）+ `lowSuffix` 功能图后缀（缺省空 = 按勾的 D / C / A 顺序，你可以改）。
- **类别**：引擎字段（导出方案）。不改模拟；只影响低端包 `cascade_low.json` 和它的贴图。缺省「不出」：以前的素材包逐字不变（不多文件）。

## 2026-10-07 · 烘焙器 4.9.28（对话框23）：单束加「变体数」「随机感」2 个参数

- **用户原话**（09:20）：「3.Ribbon的段数不知道怎么控制，而且段数多性能扛不住，还是用断尾快星或者没有什么下坠直线星用，同时这些效果要对粗细、长短或多个不同种子一起组合，提升随机感，降低随机感」；11:45 问「单束的随机感按哪种做」，用户选「变体数 + 随机感（推荐）」。
- **加了什么**（导出方案；单层在右栏「输出」、多层在层页头「导出方案」，只在 PC 出单束时出现；多层存在层上，和光点大小 / 亮度一样）：
  - `unitVariants` 单束变体数（张，1–4，缺省 1）：这一层烘几张单束贴图，每张换一个种子（火花纹路不同），星数平分，每张一个发射器（贴图、材质、发射器各 × 张数；粒子总数不变）。
  - `unitRandom` 单束随机感（0–1，缺省 0）：① 几张之间粗细（火花大小、星头大小 × 1 ± 0.4 × 随机感）和长短（尾长 × 1 ± 0.35 × 随机感，和粗细错开排）拉开多少；② Cascade 里每颗星的大小随机（Initial Size 均匀分布：宽 ± 25 % × 随机感、长 ± 20 % × 随机感），一张贴图也有用。
- **类别**：引擎字段（导出方案），不改模拟；只影响 PC 单束的贴图和 cascade.json。缺省 1 / 0 和以前逐字相同（OUTPUT_VER 不升）。
- 单层：`unitVariants` / `unitRandom` 算导出方案的键（改了不重烘大面片，只重烘单束）。名称表 / 发射器表 +2 行（`analysis/scripts/加参数_单束变体.py`）。

## 2026-10-06 · 烘焙器 4.9.21（对话框23）：加「效果 › 整体调整」6 个倍数；删「放大的中心」（入点前放大一律绕爆点）

- **用户原话**（21:51）：「1.就按照之前的全局风格帮我加回去，放在效果层里，类似一个最后的全局调整;2.为什么有些效果我调了入点，引擎回放与UE中会先从下往上生长这样跳一下，是你没自动设置好Piovt吗？」；问了两件事，回答：整体调整「每层一份（推荐）」、入点前放大「一律绕爆点（推荐）」。
- **加了什么**（效果 › 整体调整，空中花型每层一份，缺省都是 1 = 原样）：照 4.1.1 全局风格层（62_style.js，4.1.2 拆掉）的 6 个倍数——
  - `adjTailLen` 尾长（×，0.3–3）：火花寿命、余烬寿命一起乘。
  - `adjSparkSize` 尾缀粗细（×，0.3–3）：火花大小乘；余烬（× 余烬大小）、分叉火花（× 分叉火花大小）跟着变。
  - `adjSpread` 尾缀散布（×，0.3–3）：火花速度随机乘（尾迹更宽、更松）。
  - `adjHeadSize` 星头大小（×，0.3–3）：星头大小乘。
  - `adjSparkBright` 火花亮度（×，0.3–3）：火花亮度乘（含余烬）。
  - `adjTwinkle` 闪烁（×，0–3）：火花闪烁乘，乘完最多到 1（再大亮度会出负数）。
  - 叠在最后：存的还是原来的火花寿命等，模拟 / 烘焙 / 导出前才乘（`fxP`，10_types.js）；烘焙结果里记的是乘完的数（导出说明和贴图对得上）。不管自定义发射器。
  - 旧风格层另外 3 项（粗细随机、亮肩、泪滴星头）现在就是 `tailJit` / `tailShoulder` / `headTear`，含义不变，面板位置从「火花 › 大小 / 亮度」「星 › 大小」挪到「效果 › 整体调整」，和旧风格层一样 9 项排在一起。
- **类别**：6 个都是物理量（× 倍数）。参数宪章第 3 条加例外：只给你手调，AI 拟合 / 配方不动它们（保持 1）。
- **删了什么**：`prePivot` 放大的中心（0 面片中心 / 1 爆点，缺省 0）。入点前放大一律绕爆点：cascade.json 写 Pivot Offset（和没设入点时同一个）、Initial Location Z = 0；引擎回放同口径。
  - 原因：缺省「面片中心」时，入点前那一帧绕面片中心放大，面片中心在爆点下面（菊 −14.4 m、牡丹 −14.5 m、冠 −31.7 m），花小的时候整朵偏到下面、跟着放大往上走，就是你看到的「先从下往上生长」。没设入点的效果一直用 Pivot Offset 绕爆点，所以没这个问题。
  - 存过的效果：入点 > 0、从小放大、存的是「面片中心」的，打开时上方提示一条（不静默）；重导会变。AI 条目、模板都没设入点，素材包不变，所以 OUTPUT_VER 不升（升了会让所有大面片素材包显示过期）。
  - Pivot Offset 的导入换算对话框5 导入器 v2.8 已核（`spec/UE实测.md` 10-04），烟花实播对齐还没在 UE 里验。
- 名称表 / 发射器表 +6 行、−1 行、3 行挪位置（`analysis/scripts/加参数_整体调整.py`）。

## 2026-10-06 · 烘焙器 4.9.13（对话框23）：帧数分配默认改回「按运动分」
