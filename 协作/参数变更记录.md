## 2026-10-06 · 私有导入工作台v2.15（对话框5）

- 用户原话：「手游资产不能超过1024」；核准「不带 _HD 的贴图按手游处理」。
- 改动：仅私有导入器的引擎设置策略。移动贴图MaxTextureSize=1024、HD=2048；三个平台强制像素格式、实例单面/无溶解显式设置并读回，替代照抄示例。目标目录只能现存，禁止隐式新建。
- 理由：平台目录混用、示例未完整继承/过度继承造成错误；用户已直接授权修改。烘焙器参数/导出尺寸和全局标准不修改，源PNG不缩小；写入手机上限不等于修改贴图帧布局。
- 验证：隔离回归及原生语法compile通过；真实导入/播放未验，本轮零UE资产写入。

## 2026-10-06 · 烘焙器 4.9.11（对话框23）：空中花型 14 项不删了

- **用户原话**（14:24）：「参数栏，你一共要删多少项旧的东西？因为我看有些功能还挺好用的，你都标注了要删掉……以及整体调粗细，头部这些，这些都是归一化操作，我认为是可以保留的，而且很有用」；问「14 项怎么处理」时选「全部留下，不再标旧」。
- **改了什么**：下面 14 项从「旧（待删）」改回正式参数（类别物理量），面板照常显示、名字前不再有「旧」。没有加 / 删参数，含义、默认值、算法都没变，画面不变。

  | 发射器 › 模块 | 参数 |
  | --- | --- |
  | 星 › 大小 | 泪滴形 headTear |
  | 星 › 亮度 | 前段亮度 headDim、前段结束 headDimUntil |
  | 火花 › 寿命 | 末段寿命 sparkLifeEnd |
  | 火花 › 大小 | 大小随机 tailJit、粗细 tailWidth、星头端收尖 tailPinchHead、尾端收尖 tailPinchTail、最粗处位置 tailBellyAt |
  | 火花 › 亮度 | 亮肩 tailShoulder、线间底光 tailHaze、底光半径 tailHazeR |
  | 余烬 › 寿命 / 亮度 | 熄灭时刻 emberEnd、随星淡出 emberFollow |

- **理由**：
  - 尾迹形状旋钮按尾迹长度归一化（星头端收尖按火花出生点离星头的距离算，不按年龄），和「大小随寿命」曲线（按单颗粒子寿命）不是同一个量，二者相乘；整体调比写曲线关键点顺手。
  - 末段寿命、线间底光在你的金曜菊-A 和引菊 → 锦里用着；前段亮度在球形 A 里用着；随星淡出在鸿巢锦冠里用着。
- **仍是旧（待删）的 68 项**（照旧收着，你 14:24 选「以后再说」）：物理尾缀 43、升空尾缀 RT 旧旋钮 13、V5 尾缀 5、输出 7（入点前放大 3、最低帧率、开花段时长、淡出起点、裁掉开头空白）。另有「帧数」里 5 种旧模式和面片取景的 Zoom。
- **帧节奏**：你 14:24 选「维持现状」——默认还是固定机位 + 匀速帧，「按运动分」等照旧标旧。
  - 对比数字（一张贴图）：菊开花后 0.5 s 内，匀速 10 fps、用 44 格；按运动分 30 fps、用 64 格。
  - 要开花段更顺，可以在「输出 › 算出来的 › 每帧停几 tick」填 1（30 fps，贴图张数会变多）。
- 表：`analysis/命名/发射器表.json` 14 行类别 → 物理量（单位见表）；`协作/筛查/参数清单_分类结果.csv` 14 行建议 → 保留；`71_panel43.js` LEGACY 去掉这 14 项。
