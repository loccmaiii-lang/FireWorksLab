# 协作/提示词/

放**给别的 AI 的提示词**：用户新开对话框时贴的那一段、给本机 Codex / 夜班 / 其他工具的执行说明（`CLAUDE.md` 第 9 节）。以前散在 `协作/` 顶层的（`提示词_2026-10-16_…`、`看板巡检提示词.md`、`统一工作区_翻新评估与提示词.md`）原地不动。

- 命名：`<任务>_<YYYY-MM-DD>.md`（如 `目录整理第2阶段_2026-10-22.md`）。
- 开头写：谁写的、给谁用、用户原话；正文写全范围、只许改、禁止、做完标准，接手的 AI 不用再问。
- 派给本机 Codex 的活写进 `协作/派活队列.json`，这里只放长提示词，队列里链过来。
