# 本地看板与反馈 Implementation Plan

> **For agentic workers:** 本轮用户已授权实施，在当前会话逐项执行并自检，不另建对话或派活。

**Goal:** 本机打开同一份 HTML 即可看到在线快照叠加待同步变更，并离线反馈、导出和幂等接回 Git，云端再按行合并。

**Architecture:** 保留在线快照作为基线；Python 生成本地视图与 HTML，未应用条目只投影不改 appliedAt。浏览器仅保存用户字段到 localStorage，导出反馈 JSON 后由本机巡检收集到追加清单；云端使用稳定新行 ID 和字段基线合并，不导入整页 HTML。

**Tech Stack:** Python 标准库、现有单文件 HTML、纯 JavaScript、Python unittest / Node vm 隔离检查。

## Global Constraints

- 本轮新授权覆盖旧“离线不改 HTML”：可生成 HTML 和本地视图，不伪改在线快照、appliedAt、用户验收或 UE/P4。
- 既有 P001–P038 保持原样，新发现与反馈只追加。
- 反馈标明“保存在本机 / 已导出 / 已进 Git / 云端已应用”，不混淆。
- 无监听服务、无新自动化、不读取浏览器私有资料、不改 tool/src。
- file:// 浏览器自动化被安全策略阻止；使用源文件和隔离执行检查，真实浏览器点击不声称已验。
