## 关于「在球花粒子里做高度 / 大小随机」：不建议

- **尾缀接不上花**：
  - 子模板里尾缀和花是两个条目。花在粒子里随机抬高或降低，尾缀不知道。
  - 结果尾缀头和开花点差出这个随机量：线要么够不着花，要么穿过去。这正是「线从地上接到花」要避免的。
- **种子对不上**（你担心的情况大概率会发生）：
  - Cascade 的 Random Seed Info 每个模块一份。勾了「Randomly Select Seed Array」，每个模块在初始化时各自从数组里挑一个。这是 UE4 源码的行为，没在你们引擎里测。
  - 星头、火花、延迟星头分在不同发射器上，两两挑到同一个种子的概率只有 1/3。
  - 要对上只能用「Get Seed from Instance」，那得用代码或蓝图给实例设参数，违反「引擎里不写代码」。导演表也没有这一项（推断）。
- **编排侧看不见结果**：重叠体检和动画都预测不了随机高度，可能随机撞在一起。
- **范围大**：要改资源本体，PC 和 _M 两套都得改。

**大小随机这次的做法**：

- 不放进粒子。用子模板里花条目的 EffectScale：整朵花所有发射器一起缩放，没有种子问题（UE-14 实测等比）。
- 小 / 中号每个点 ×0.92 / 1.0 / 1.08，大号 ×0.92 / 1.0。编排时按种子定好，所以能体检。

**高低错落这一版先不要**，尾缀从地上出来优先。以后想要，正确做法是「不同高度的尾缀资源」：

- 导出（23）按 RT6 每档再出高低两根；
- 线粗不变，花正好接在尾缀顶；
- 你在 ResourceFX 加几行。

## B07 改了什么（这次必须做的）

底稿同 B06：B03 修订2 → B04 小平台（不换 Tiny）→ 收窄 3 改 P2 / P4 / P6。最后照旧接 B06 的扇和 B05 的名字 / 手游 6 种。

1. **尾缀从地上出来**：高差全部归 0（B06 有 68 % 的球花尾缀从坝顶上方 10–70 m 才出现）。原来靠高差错开的地方改用构图：

2. **中低配隔点（你的想法，加了一条）**：

     - 9 点：中配 P0 / P2 / P4 / P6 / P8，低配 P0 / P4 / P8；

   - 低 ⊂ 中 ⊂ 高 照旧嵌套。
3. **小平台加密**：
   - 18 → 71 组，最长空档 34 s → 4.9 s（只有倒计时没有）。
   - 按段每 1–2 小节一组，开花踩这一小节前半里最强的起音。
   - 10 种排法轮换：隔点左→右、三点里→外、两端一对、7 点右→左、中间两朵、外→里、V 形、7 点左→右、隔点里→外、中间一朵。

   - **高度还是 62 m**：不拉伸尾缀就只能换一根更短的尾缀资源（见「可后做」）。
4. **张力**：

5. **方向**：主排「里→外」70 % → 47 %，按段轮换左→右 / 右→左 / 外→里 / 齐发，相邻两波不重样。后面 3.8 s 内还有一排中 / 大号的，只用齐发或里→外：两端晚开会压在下一排同一点还亮着的花上，现在没有高差能错开。

## 可后做（要你点头的）

1. **段落配色**（色彩 6.5 → 8）：给每段一个主色、在转场放对比色。我的建议：
   - 开场金白；
   - 往返扫射 / 抬升金银；
   - 低位密奏冷白（点灭星）；
   - 第二次递进青柠绿；
   - 转场彩（彩千轮紫 / 绿牡丹）；
   - 终章金；
   - 白色收束白 → 主角金。
   - 这是换主排的花（选角），要你同意方向。
2. **手游大位加第二种**（手游 6.5 → 8）：现在大位只能放大号金芒菊，所以一半都是它。大位能不能加银冠菊 / 辉星放大到 230 m？要超过 ×1.6，你定。
3. **小平台降到约 40 m**：导出（23）按 RT6SE8 出一根 40 m 的前台尾缀，你导入一行；我改 `新尾缀.json` 一处，重编。
4. **高低错落要回来**：S / M / L 各出高低两根尾缀资源，见上面。
5. **大小随机交给引擎**：子模板条目 RandomScaleRatio，整朵一起缩放、每次放都不同；要 UE 测一次。
6. **Day 也去掉高差**：Day 小号还有 +10–30 m，10 分钟能改。
