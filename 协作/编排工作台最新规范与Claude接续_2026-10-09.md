## 时间量化、错开与倒计时（用户 2026-10-09 17:14 补充）

**编排层时间只用 0.1 s 的整数倍。** 组调度时间、音乐锚点、点间隔、点位偏移、错开量一律是 0.1 s 的整数倍，最小非零值 0.1 s，不再使用 0.05 / 0.03 这类 0.0x 秒。理由是用户说 tick 带 0.0x 秒小数会给性能增加新的开销。范围只限编排层；固定子模板里用户编辑的内部延迟（例如金扇每筒约 0.035 s）不受此限，编排者也不能改它。数据里检查：所有时间字段 ×10 后是整数；非零点位偏移 ≥ 0.1。

落实检查（2026-10-10用户再次指出遗漏）：不能只检查输入框和名义时间。随机错开的**实际取样结果**、三档有效调用时间、三表的 `EffectScheduleGroups.Slots.StartTime` 与父模板 `EffectTemplates.Entries.LocalTimeOffset` 也须在0.1秒网格；预览与三表展开一致。子模板 `EffectSubTemplates.Entries.LocalTimeOffset` 保持固定版本原值，音频采样/资源寿命也不属编排调度网格。每次节目交付附上述检查，未检查不能声称遵守。

多点齐发限制按用户2026-10-10新增“同时发射+可配置随机错开”更新：允许主动关闭错开；不再全局强制“同刻最多一个镜像对”。本机R04候选将R03中31个超过两点的齐发片段配置为0–0.3秒离散错开，种子固定、至少保留一点在原拍点；该候选待试听验收，不等于强制所有节目使用0.3秒。性能收益仍须UE实测；编排刻度与引擎实际Tick间隔分别记录，不能仅凭小数位数声称已降低Tick开销。

**错开放在编排模板（原称片段模板，用户 10-09 起统一叫「编排模板」），不放在固定子模板。** 固定子模板（`ST_…@版本`）保持不变；原来的「齐发」（同一时刻所有点）可配置点间顺序与间隔或上述随机错开。10-09候选曾要求同刻最多一个镜像对，该限制已由上段10-10用户要求更新；非零错开仍 ≥ 0.1 s。高低、大小的错落用固定子模板的不同版本表达，不再逐发加 dz / scale / dt。

**倒计时。** 倒计时 10 秒。音乐在倒计时约 5 秒时缓缓升起，0 点绽放第一轮烟花。这与前面「`showTime = musicTime + 10`」的写法不一致：按 10 算，音乐在 0 点才开始，倒计时段没有音乐。候选 A 暂按 `musicOffsetS = 5`（倒计时 5 进入，0 点落在音乐 5.0 s），由用户确认；生成器 `--offset` 可一键改回 10，所有锚点同时给 musicS 与 showS。

**倒计时用烟花做**（用户 2026-10-09 18:33）：不是只显示数字。从坝顶 P0 + P8 起每秒一对、向里放到 P4，再用扇形 + 前台向里走一轮，0 点从 P4 向外绽放。倒计时第一发的开花时刻 H 不能早于它的 D（升空时间）：调用时间 H − D 不能为负，所以第一发放在 2.0 s 是建立在小银菊 D ≤ 2 s 的占位假设上，D 要等固定子模板。

**升空尾缀**：球花、前台花的固定子模板里含升空尾缀（前台彗星只有尾缀），扇形即发。编排 cue 写开花时刻 H；调用时间 = H − D 待绑定。预览页画尾缀只是示意，升空时长取 `spec/尺寸标定.json` 的设计值，不是实测。不要因为方案里只写 H 就认为没有尾缀。

**叠层构图与 17 点连扫**（候选 A2）：高潮不是单排。一个构图由几层叠在一起，各层按各自的 lead 先后开：高排（中号九点，A / B 高低版本相邻点交错）、压顶（大号 P0 / P4 / P8，比高排晚 0.5 s）、中排（中号垫在大号下）、低排（小号 4–5 点，低位）、扇形、前台、连波（大号九点一小节一波，用分道版本 @1…@5 躲单资源限额）。**17 点连扫**：把 P 排和 B 排看成一条线（x 从左到右 P0 B0 P1 … B7 P8），同向同槽位，P 排每 gap 一格、B 排晚 gap / 2，整条线每 0.1 s 一发（gap = 0.2）；依赖「P 点能放扇形」。

**扇形扫向写法。** 每个扇形 cue 写明 `order`，含义如下，扇形本身的束数和角度不动（只引用用户固定好的 A / B / C）：

| 写法 | 含义 |
|---|---|
| `LR` / `RL` | 沿坝顶从左端到右端 / 右端到左端逐点放 |
| `CO` | 里→外：从中心向两侧，镜像点同刻（至多一对） |
| `OC` | 外→里：从两端向中心，两头相向 |
| `ALT_IN` | 两头交替向中心（先左后右，最后落在中心），用于鼓点连击 |
| 对扫 | 同一扇形槽位、同一锚点，P 排与 B 排反向同扫，写成两条 cue（`macro.name = X`，`leg` 标哪一排向哪边） |

规则：相距小于 1 s 的扇形 cue 必须是同一槽位家族（同一颜色），不在一次扫射里换色；扇形 cue 的点间隔常用 0.2 s（原模板 10 槽 0、0.2…1.8 s），快扫 0.1 s，慢扫 0.3 s。P 点能否放扇形尚待本机确认；若不能，对扫改成 B 排来回两程。
