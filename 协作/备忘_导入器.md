## 2026-10-05 · 本机已跟进（对话框5）

用户本轮直接指定读取本备忘并处理模块支持，覆盖此前撤回排队；源码和项目配置仍只留本机。本机实际工具同路径更新到 **v2.13**，包内 `VelocityOverLife` 对应 UE 面板的 **Velocity/Life**，原生类为 `ParticleModuleVelocityOverLifetime`；两种标识对应同一个模块，挂接位置由包决定。

- 18 个隔离脚本共 413 组通过，其中新模块 72 组，含 RT5 小 / 中 / 大的 PC + 手机六份实际导出以及本机最新 RT6L 包；核对模块挂接、完整曲线、轴开关、CPU/GPU 分布默认、独立 Pivot、帧号、时间、保存目标及命名/同名更新/缓存兼容。
- 独立未保存系统的三个 CPU 发射器另有 11 组原生写入/读回通过：Velocity/Life 的常量 / 随机 / 曲线、Absolute true / false / 默认，以及 Size By Life 只改 Y 和独立 Pivot。测试对象移到 Transient，未产生测试资产文件、未修改既有用户资源；未打开 Cascade 或实际播放。
- 新向量/曲线/布尔检查在预览和执行入口挡住错误；未知模块仍阻止执行，真正错误的原生字段不会统一跳过。正式命名、历史任务、独立呈现及原备份/替换/缓存/保存保持。
- 第 5 项仅确认密集 101 点方波原样保留且 GPU 默认开启查找表；最终采样是否抹平仍 ⚪，不能把参数写入/模拟或 CPU 读回当成 GPU 画面通过。第 6 项无需改；第 7 项元数据过滤继续回归通过。

过程只记 `对话记录/对话框5.md`；完整私有源码、样本、路径、原生记录和失败尝试不上传。共享离线 UI 标准原有 `store is not defined` 仍 6/7，不冒称全部通过；共享烘焙器和效果/显卡队列没有被这次工作接手。
