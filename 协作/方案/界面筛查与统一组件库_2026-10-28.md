## 0. 一句话

先把「有哪些界面、每个控件是哪段代码生成的」列成能跑的清单；在你的真实环境里用固定规则全量筛；问题按**根因**归到组件，每一类出设计规格进组件库；再按组件**整类替换**（带计数）；最后让构建和合入门禁拦住库外控件。以后新功能只能用库里的组件拼，缺的先进库。

## 4. 第二步：筛查规则

「自动」= 脚本直接判；「半自动」= 脚本标出候选，人看截图确认；「人看」= 只能看截图判断。例子都是你今天截图里的。

**A 控件是不是库里的组件**

| 编号 | 怎么判 | 方式 | 例子 |
| --- | --- | --- | --- |
| A1 | 库外控件：button / select / input / summary / 能点的 div，没有组件类 | 自动 | 整体调整的 ×0.8 … ×2、「用这个」「试算几档节奏的帧数」 |
| A2 | 浏览器默认样子：计算样式等于浏览器默认（灰底按钮、白底或灰底输入框、系统下拉） | 自动 | 「整段想要」输入框 |
| A3 | 同一种组件有多种样子：按（高、圆角、底色、边框、字号）分组，组数多于库里定义的变体数 | 自动 | |
| A4 | 浏览器原生弹框 confirm / alert / prompt | 自动（静态） | |
| A5 | 内联样式、裸颜色、裸字号 | 自动（静态） | |

**B 尺寸与几何**

| 编号 | 怎么判 | 方式 | 例子 |
| --- | --- | --- | --- |
| B1 | 被裁：元素（含焦点框）超出最近的裁剪或滚动容器 | 自动 | 树的列头「显示 / 只看」、轨迹联动的绿框、「场景」行右侧 |
| B2 | 文字被截断，又没有悬停提示或展开 | 自动 | |
| B3 | 不该折行的折了：按钮、标签、标题、短选项超过一行；说明句断在数字或单位中间 | 半自动 | 「这一层 / 5 张」 |
| B4 | 点击区小于 24 × 24，主要操作小于 32 | 自动 | |
| B5 | 同一行的控件高度不一，或基线不齐 | 自动 | |
| B6 | 出现横向滚动条；内容被吸顶栏盖住 | 自动 | |

**H 视觉质量（规则抓不到的，看截图打分）**

| 维度 | 看什么 |
| --- | --- |

**5.2 严重度**

| 级 | 含义 |
| --- | --- |
| 严重 | 挡操作或误导：点不到、值被截掉、被盖住、键盘到不了、状态显示错 |

**5.3 两个维度分类**

例：轨迹联动那段 = 根因「没有勾选列表这个模式，长说明也没有固定位置」；整体调整那一块 = 根因「`12_tempo.js` 手写按钮」，应换成「预设按钮组」组件。

**6.2 四层产出**

1. **基础规范**：字阶（20 多种收到 5–6 档）、间距刻度、控件高度档（紧凑 / 常规）、缩进规则、栏宽、图标尺寸、动效。
2. **组件**，每个一张规格卡：结构图、尺寸、变体、状态矩阵（默认、悬停、焦点、按下、选中、禁用、只读、加载、错误）、键盘、文案规则、什么时候用 / 不用、Chrome 和 Edge 的差异怎么处理。
3. **模式**（几个组件怎么拼）：参数行（名称 | 滑杆 | 数值 | 单位）；模块（折叠标题 + 内容 + 短说明 + 长说明）；子分组；预设按钮组；勾选列表（如「关联图层」）；计算结果行；搜索 + 筛选工具行；树行（名字 + 眼睛 + 独看 + ⋯）；顶行操作；提示条 / 撤销条；空状态；烘焙进度。
4. **页面模板**：右栏（树 + 参数）、中栏视图条、左栏库、交付清单、资源交付、审阅、粒子图编辑、弹窗。

**6.3 组件初步清单**（Codex 按实际清单增删）

- 基础：按钮（主 / 次 / 幽灵 / 危险 / 图标）、预设按钮组、分段、输入（文本 / 数值 / 搜索）、滑杆 + 数值、下拉、勾选、单选、开关、折叠（模块 / 子组）、标签页（发射器标签）、菜单、弹窗、悬停提示 / F1 说明、提示条 / 撤销条、身份 / 状态标签、进度、滚动条、分隔条。
- 复合：参数行、树行、效果库列表行 / 缩略图卡、产物表、版本列表。
- 领域组件（只统一外框和状态，里面按业务）：颜色段 / Ramp 编辑、曲线编辑、粒子图画布、时间轴。

**6.4 设计稿交付格式（为了能精确还原）**

- HTML 原型，直接引用 `tool/design-system/tokens.css`，不只给图；另出 PNG 给你审。
- 数值写 token 名，不写裸值；需要新 token 的列出来。
- 每个页面稿注明由哪些组件拼成，不出现一次性样式。
- 关键页面三档屏幕加 150% 各一套；Chrome 和 Edge 各截一张。
- 每张新稿配一张「现在 vs 设计稿」对比图。
- 带版本号（设计稿 v1 对应组件库 v1.0）。

**6.5 V5 新加的部分要重新设计，不只是摆放（18:49）**

你说「树这些都要重新设置，之前只有布局，设计的太丑了」。所以 4.9.125 新加的部分全部当作设计对象，不算保留项：

范围：布局、字、图标、间距、结构都可以重新设计；颜色、圆角、高亮仍按冻结表。设计稿认为高亮样子在树上不好看，单列成「画风变更提议」给你定。

## 7. 第五、六步：组件库和还原

**7.1 组件库**（`tool/design-system`，现 v0.2.1 → v1.0）

- tokens 分两层：**冻结层**（画风）和**可调层**（布局）。`build.py --check` 校验冻结层没被改；要改，得有你批过的记录。
- 组件 = CSS 类 + JS 工厂函数（如 `FWUI.button({...})`、`FWUI.paramRow(...)`）。业务代码不再手写 `<button>`、`<select>`。**【补】这是「默认统一」真正落地的关键**：只有 CSS 类的话，手写模板漏套一次就又散了。
- 组件登记表 `components.json`：编号、中文名、用途、变体、状态、版本、负责人、样板截图、在哪儿用（使用计数）、状态（草稿 / 已批 / 弃用）。
- 样板页 `index.html`：所有组件 × 所有状态，同时是截图回归的基线。
- 每个组件一页说明。
- 版本：加组件 = 升小版本；改已批组件的外观 = 先出对比图给你批；弃用 = 标弃用 → 迁完 → 删掉。
- 宪章 §0 定的是三个工具（烘焙器、导入器、编排工作台）共用这个库；18:49 定了三个一起做（第 3.5、7.3 节）。

**7.2 还原（迁移）**

- 按组件**整类替换**，不按页面零碎改。比如「按钮」：一次把所有生成点都换成工厂函数。完成 = 迁移计数 N / N，规则 A1 为 0。
- 顺序：基础规范（字阶、间距）→ 高频组件（参数行生成器、按钮、下拉、勾选 / 单选、开关）→ 模式 → 页面模板 → 领域组件外框。
- 每一类一个提交，附：前后对比图（同一组页面、你的环境）、规则复跑结果、合入门禁、界面状态检查。功能、参数、导出不变。
- 每一步做完更新「界面健康表」：库外控件数、各条规则的问题数、覆盖率。

**7.3 三个工具怎么接同一个库，和 4.9.125 什么时候合入**

- 烘焙器：直接用 CSS 类 + JS 工厂函数。
- 编排工作台：每个组件包一层很薄的 React 组件，用同一套 CSS 类（宪章 §0.3 本来就允许「HTML 与 React 通过适配共用」）；去掉 `material-theme.css` 里和库重复的部分。
- 导入器：把 `sync_importer_colors.py` 扩成同步整套 tokens + 组件 CSS，私有源码由本机改。
- 4.9.125（18:49）：筛查、设计、还原都在 `v5-4.9.125` 分支上做，处理好再合入 main。分支会开得比较久，main 上别人还在提交：每个阶段开始前 rebase 一次 origin/main，冲突保留对方内容再合；`style.css`、`tool/design-system`、`92_v5shell.js` 等在状态清单「共享文件」登记认领。

## 8. 第七步：守门（以后不再退化）

- 构建（`tool/build.py` 静态核对）：源码里出现库外控件、新颜色、新圆角、新字号、内联样式 → 报错。确实要例外的写进允许名单，每条写理由和期限。
- 合入门禁加「界面规则」：在 10 个左右的代表页面跑 A–G 自动规则，新增问题大于 0 就不让推。
- 截图回归：样板页 + 代表页面截图比对，有变化要写原因。
- 新功能准入（宪章 §8）加一行「用了哪些组件」。缺组件就先进库（规格卡 + 样板 + 外观你批）再用。
- 每个版本自动出一份界面健康表；每月全量筛一次。

## 9. 自审循环（吸收 18:25 提示词的 LOOP，加上停止条件）

原提示词：做完后对照检查表看页面 → 和对标作品比 → 有差距就补 → 再循环，直到「没有可见的改进」。

改成：

- 审的人和做的人分开（Codex 筛和设计 → 对话框9 实现 → Codex 复筛；也可以反过来），不自审自过。
- 每一轮跑：全部自动规则 + H 维度打分 + 校准集。
- 出循环的条件（都能数出来）：严重和明显问题为 0；细节问题有清单，你同意留下；维度分全部 ≥ 4；校准集全部抓到。
- 最多 3 轮。3 轮还过不了，说明是规范或组件设计本身的问题，回到第四步重新设计，不在页面上硬补。
- 不用「没有可见的改进才停」做完成标准：永远能再改，会变成停不下来的循环。
- 不用「优先级压倒一切」（OVERRIDE_ALL）。顺序是：约束（画风冻结、功能不变、Chrome / Edge 一致）> 一致性 > 美观。

## 14. 宪章怎么同步（18:49「以上筛完，后面就会变成宪章并且是统一的风格对嘛？我们库里的宪章会同步更新对嘛？」）
