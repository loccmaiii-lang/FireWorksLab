# 组件与交互清单（三工具共用 · E 样板范围）

> 对话框9，2026-11-04。用户 20:04「现在的E方案第一版没有包含所有的组件，我担心后面会来回返工」；20:17 同意新流程：一套共用样式同时生成「关键屏」和「可操作的组件全表」，评审分外观评委、盲比、交互走查三路。
> 本清单 = E 样板的范围与验收清单：清单里每一项都要在组件全表里出现、每种状态都画出来、交互能操作；关键屏只能用清单里的组件拼。
> 依据：129 完整烘焙器实际渲染的控件（af556aa1 `FireworkBaker_129.html`）；三个工具的界面生成点统计（烘焙器 1379、编排工作台 891、导入器 99 个非样式生成点）；样板 v4.1；层数最多的真实效果（仙女棒、窜天猴尾焰各 13 个发射器，嵌套 3 级）。

## 1. 烘焙器主屏布局（用户 20:17 定）

| 区域 | 内容 | 说明 |

| 分隔条 | 可上下拖，双击恢复；结构与效果库各自可折叠成一行标题 | 层多时把效果库收起 |

| 中：视图条 | 适应窗口 / 1:1 / 游戏内大小、距离、显示曝光、构图网格、写进意见、精简布局、左右栏、预览设置 | |

## 2. 基础控件（8 类，覆盖三工具 76–91 % 的控件）

每个控件都要画出：默认、悬停、焦点（键盘）、按下、选中 / 开启、停用、错误、只读；需要时加「加载中」。

| 控件 | 变体 |
| --- | --- |
| 按钮 | 主按钮（实心，一屏一个）、次按钮、文字按钮、危险按钮、图标按钮（附悬停提示）、分裂按钮（导出 ▾）、异步按钮（加载 / 失败） |

| 下拉 | 原生下拉（固定选项、选项少：速度、显示方式）；自定义菜单（带动作：⋯、导出 ▾、加层）；两种在 Chrome / Edge 外观一致 |
| 开关与勾选 | 开关（即时生效）、勾选（多选）、单选 |
| 分段选择 | 2–4 项；选中样式只有一种 |
| 标签页 | 工作模式（实时模拟 / 引擎回放 / 贴图与交付）、效果库 / 模板 |

## 5. 交互（样板中能实际操作）

- 数值：拖动改值、Shift 精调、单击输入、越界报错、双击参数名恢复默认；一次拖动只记一步撤销。
- 键盘：Ctrl+Z / Ctrl+Y、空格播放、R 重播、← → 1 tick、F 精简布局、L / P 左右栏、结构树方向键。
- 结构：选中联动（结构树 ↔ 时间轴 ↔ 检查器）、展开折叠、显示 / 只看、加层、加发射器、⋯ 菜单。
- 布局：拖动左栏分隔条、折叠结构 / 效果库、精简布局。
- 时间：拖播放头、拖区间条、设入点 / 出点、生成缩略图。
- 参数：搜索、仅显示已改、锁定、展开随机、依赖关闭时隐藏。
