# 循环火焰模板 Implementation Plan

> **For agentic workers:** 按勾选步骤在当前任务执行；采用 writing-plans。当前环境未提供 executing-plans，按仓库既有实现、检查和交付流程完成，不另开任务。

**Goal:** 一个可编辑、可控场、可无缝循环烘焙的落地燃烧模板。

**Architecture:** 在 SparkGraph 中新增通用 flame 形态。有限寿命的周期燃烧源沿现有三维轨迹构造连续管状密度，用 GPU 射线积分生成灰度辐亮度，复用 Ramp、循环取帧、PC/手机导出。共享气流控制轨迹，程序噪声控制火舌细节；两者以周期粒子的年龄为时间，避免全局时间取模造成纹理跳变。属于艺术可控的体积重建，不是真实流体压力/燃烧求解。

**Tech Stack:** 现有原生 JavaScript / WebGL2 / Python 构建与校验。

## Global Constraints

- 保留旧模板、随机序列、默认渲染路径；新能力默认关闭或单位变换。
- 只增加一个燃烧模板；不自动加入烟、冲击爆炸或飞行尾焰，不改 UE 材质。
- 同一渲染核覆盖实时、烘焙和导出；灰度 RGBA 接力 + 现有 Ramp。
- 尺寸倍率改变物理尺寸与取景，不改变时间；调火焰高度用初速、寿命、加速度、气流。风和密度取景仍需用户可见可调；导出检查拦截裁切。
- 旧粒子图缺新参数读回默认值，不改原存档；新参数参与配方指纹、撤销及保存。
- 火焰暂不支持粒子镜头散焦/运动曝光积分，相关设置明确变灰；导入的冲突参数报错，不能悄悄丢失效果。
- 连续燃烧不包含点燃和熄灭一次性段。引擎淡入淡出由已有 Color Over Life 控制，循环纹理本身不含首尾黑帧。
- 审看版本与导出版本一致，内部检查、AI 审看、用户通过分开记。

## 参数契约

新增图级 `spaceScale`（最终整体尺寸，×，默认1）。源 `sourceScale[3]`（三个轴的出生范围比例，默认全1）与 `sourceOffset[3]`（中心偏移，m，默认全0），适用于全部根发射器，子粒继承母粒位置所以变灰。

新增火焰：`flameDensity`（消光系数，1/m，默认8）；`flameDepth`（纵深/横向厚度，×，默认1）；`flameNoise`（粗尺度侵蚀比例，0–1）；`flameDetail`（细尺度侵蚀比例，0–1）；`flameScale`（噪声空间尺度，m，默认0.16）；`flameWarp`（密度管横向卷曲位移，m，默认0.07）；`flameRise`（细节上移速度，m/s）；`flameTip`（末端/根部半径，0–1）；`flameFloorEnabled`/`flameFloor`（截断平面开关与高度，m）；`flameSteps`（每射线积分样本数，8–64整数，烘焙质量字段）。侵蚀与卷曲全部关闭时细节尺度与上移速度变灰；关闭地面平面时高度变灰。温度未求解，不提供虚假的 Kelvin 控件；颜色仍由真实生效的 Ramp / Color Over Life 编辑。模板经GPU审看采用48样本、0.16m卷曲、密度6、亮度0.9；新增形态缺省与模板调参分别保留。

复用：粒子数、源半径、种子、寿命/大小/亮度随机和曲线、喷射方向/初速、重力/阻力/位移扰动、全局风/涡流/收束/随风倍率、循环周期、取景四边、曝光与输出规格。所有参数范围是可编辑约束；过小尺度、过高数量/步数需给明确错误，不能静默降档。
