# 协作/方案/

放**方案、研究、计划、复盘**（给用户定的、给接手 AI 看的长文）。10-22 起新写的放这里（`CLAUDE.md` 第 9 节）；以前的 `协作/方案_*.md`、`研究_*`、`计划_*`、`复盘_*` 原地不动，分类见 `仓库梳理.md`「协作/ 顶层旧文件分类」。

- 命名：`<主题>_<YYYY-MM-DD>.md`，主题用中文短语（如 `导出排查_2026-10-14.md`）；同一主题再写一版就换日期，旧版不覆盖。
- 开头写：谁写的（对话框名 + 编号）、用户原话、状态（待定 / 已批 / 已做 / 被取代）。用户批了、做完了，在文末加「执行记录」，不另开文件。
- 只写方案本身和复现命令；做了什么的明细写对话记录，状态写 `协作/状态清单.json`（一事只记一处，`CLAUDE.md` 第 6 节）。
