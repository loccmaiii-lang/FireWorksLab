## 1 底稿和改了什么

- **底稿**：16.0.18 当前节目「B01节奏D-高低大小-尾缀v2」。
  - 时间、点位、密度、扇、PC 三档点集都不动。
  - 已逐条核对：除新加的小平台片段，PC 高 / 中 / 低的（花种、点、起飞时刻）和底稿完全相同，900 / 756 / 324 次。
- **① 高度按尾缀 v2 重挑**：
  - 起因：引擎尾缀按尺寸档重导后，开花约 150 / 210 / 330 m（你今晚重导 PC 尾缀）。
  - 旧的高低随机是按 190 / 265 / 410 m 挑的，换成新高度后层间距变小，深度重叠从 1465 次取样涨到 2062。
  - 做法：用同一套规则（`--vary`）在新几何下重挑组高度和种子（种子 3），重叠降到 1976、主角被压 168 → 121。
  - 主角设计偏移不变：66 小节 P4 +20；105 小节 P4 +20 / P2 −20 / P6 −45；余韵 +5。
- **② 手游三档**：
  - 规则：
    - 只用 P 点；
    - 只放手游编排执行方案 §2.1 的周三白名单——小银菊、橙辉星、金芒菊（含大号）、银彩菊、主角，加可选的爆裂星、金锦菊；
    - M / L 一排只放偶数点 P0 / 2 / 4 / 6 / 8，奇数点只上 PC，免得手机上花叠花；
    - 二排、托底扇、扇组、小平台都不上手游。
  - 做法：
    - 把 13 条 M / L 整排拆成「偶数点（PC + 手游）」和「奇数点（只 PC）」两个片段；
    - PC 三档点集原样保留；
    - 片段写 `mobile:false` → 一张表里写 PlatformFlags 12。
  - 结果（高配手游 149 次）：
    - 银彩菊 72（终章白墙为主）、小银菊 36、大号金芒菊 16、金芒菊 10、金锦菊 10、主角 5；
    - 中配 135，低配 119。
- **③ 小平台小花束尾**（你要的「小花 + 不同尾缀」）：
  - 用现成资源拼了 7 个固定子模板（`协作/编排B01/小花束尾.json`）：

## 2 纰漏（我自己找的，按风险排）

1. **没在 UE 里放过。**
   - UE 里的导演还是修订1（旧高度）。
   - B02 开花点按你今晚重导的尾缀 v2 高度算；尾缀没导好之前，花和尾缀会错位。
2. **小花束尾的几何是估的。**
   - 束长取基础资源库的预览值：银扇 65 m、红彗星 75 m。
   - 挂花时刻取出束 1.0 s、0.85 倍长。
   - UE 里花可能不在束顶；左右方向按「Roll 正 → 局部 Y 负」推（和大号花型同一约定）。
   - 量到后改 `小花束尾.json` 的 `estimate` 三个数重编即可。
3. **手游有长空档。** 白名单外的花不放，手游上没有花的时段超过 8 s 的有：
   - 21–33 s（连续展开）
   - 33–46 s（密集问答）
   - 69–104 s（35 s，第一次抬升 → 蓄势收窄）
   - 104–112 s（蓄势收窄）
   - 137–156 s（高潮 II → 转场铺色 B）
   - 179–188 s（终章）

   这些空档在 PC 上放的是金蕊青柠星（含大号）、金曜菊、绿牡丹、彩千轮、多重菊（大号），都不在白名单里。

   你定白名单时有三条路：
   - **补金曜菊、绿牡丹**：要各做一个 ≤ 3 发射器、不带 GPU 的手游版，能补上 33–46、69–104、137–156、179–188 的大部分空档。
   - **其余三种不上手机**：金蕊青柠星、彩千轮、多重菊是多层花，你之前定过手机不用，那几段就接受手游上空着。
   - **白名单花替补**：等工作台支持「只上手游」的片段（PlatformFlags 2），在空档里放白名单花顶上。
4. **手游中低配只能是 P2 / P4 / P6，不是宪章写的 P0 / P4 / P8。**
   - 一张表里手游和 PC 共用同一条事件的画质，P0 / P8 在 PC 中配就去掉了。
   - 要 P0 / P4 / P8 得有「只上手游」的片段（PlatformFlags 2），工作台现在只有片段级 14 / 12。
5. **手游资源还没有。** 手游表里没有这些花的手游行，B02 只定「哪几发放」，画面要等手游资产（执行方案周二、周三）。
6. **主角和大号花一样高（约 330 m）**，等 Hero 行。
7. **GPU 预算**：仍按暂定 ≤ 200 / 秒排（实测上限 250），PC 高档峰值 200；小平台每秒最多加十来个。
8. **工作台没升号**：16.0.19 自动载入排给本机同步（8）发布，现在请手动打开。
9. **像不像、乱不乱要你看**；体检只能证明规则被遵守。
