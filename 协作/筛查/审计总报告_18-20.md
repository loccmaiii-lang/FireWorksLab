**固定基线**：`9b8fbdb3516823c907fb79b85e9887b178a4ce20`（`9b8fbdb`）。**范围**：参数大筛查（18）、隐性耦合与自动行为（19）、4.5.0 界面走查（20）。三项均使用独立副本，只读审计；未改产品、效果、核心代码或共享认领文件，未占用 GPU，未提交或推送。4.5.0 快改、HK10E7/STD9 和已恢复的 GPU 队列作为背景，不重复验收。

## 结论与证据边界

- **应先处理的静态确认缺陷**集中在删除/撤销的数据完整性、组合导出的烘焙版本、零值材质强度、层间同步与对象状态。这里的“确认”指固定基线的代码路径和触发条件成立；没有声称本轮在浏览器、GPU 或 UE 中复现。
- **18 号是 5.0 迁移建议，不是 80 个当前缺陷**：输入 CSV 398 行（369 面板、21 个标为“隐藏”的行、8 个材质行），作用链 JSONL 398 条，387 个不同 key。建议动作是删 80、合并 170、留 93、改名 22、拆分 20、改常量 13；这些是待讨论的目标方案，未获实施批准，也未做迁移后的画面对照。输入中 197 个效果的使用频次未由 18 号独立复算。所谓 21 个“隐藏”键有部分已在独立输出控件出现，不能整组视为死参数。
- **19 号列出 40 条跨参数/层/输出行为**，有意依赖和缺陷逐项分开；六个 C 项是代码确认的条件路径，一个 R01 异步打开竞态仍是推测。HN2 的橙层 `ign=.08 + sparkStop=1.2` 与锦层 `ign=1.28` 得到 1.28 秒交接，是有意接力条件，并非默认的错误联动。4.5.0 已有跟随/粘连开关，不能沿用旧提示词称其不可关闭。
- **20 号的七条问题全部没有真实页面动作验证**：直接打开隔离副本 `file://` 被浏览器安全策略拒绝，且明确禁止绕行；截图目录为空。44 个 JS 文件 `node --check` 为 0 个语法错误，只能证明语法。20-01～04 的代码控制流可确认；20-05 是静态功能缺口，20-06 是 CSS 路径，20-07 是文案不一致。不可宣称界面走查或导出通过。

## 建议顺序

1. **4.5.x 数据与导出正确性**：先处理 20-01～03、19-C01～04；接着处理 19-C05、20-04。所有修复需在隔离配方中验证撤销后版本、每层 revision、零值材质、保存/重开联动层；当前仅有静态证据。
2. **4.5.x 可见性与可恢复性**：核对 19-C06、20-05～07，显示烘焙失败/待同步/当前对象身份，并在可用的隔离浏览器中检查 19-R01。不要用旧 `SMOKE27 undefined.then` 计作三处产品缺陷：`openEffect` 在非组合路径可返回 `undefined`，而旧脚本直接调用 `.then`（`79_library.js:169-175,372-395`，`analysis/scripts/界面冒烟.py:43,100`）。
3. **5.0 方案与 UE 门槛**：再决定 18 的删/合/拆、实际年龄冷却、物理粒径与可见亮核拆分、RT5 安全路径、固定取景及输出控件收口。保留旧模式与视觉快照，经过 WebGL/素材包/UE 实测后才迁移。
