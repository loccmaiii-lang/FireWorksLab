## 判定口径与摘要

- **代码确认**：触发到结果的赋值或调用链在固定基线可追溯；指代码条件成立时的行为，**不等于本轮已运行复现**。
- **推测／未验证**：代码存在竞态窗口或依赖运行环境，但本轮没有交互、GPU、UE 证据来证明用户已遇到。
- **有意依赖**：按现有说明或明确设计实现，仍可提出可见性改进；不计为产品缺陷。

代码确认的条件缺陷主要是：**组合新参数烘焙失败后仍可导出旧 `e.bake`**（C01）；**显示强度设 0，部分 Cascade 导出以 `|| 1` 改成 1**（C02）；**关自动烘焙时，联动层的 21 个键要等源层烘焙成功才同步，保存可持久化不一致值**（C03）；**内置组合的全局 `linkOff` 可带入“我的效果”，勾选关系仍显示但同步被挡住**（C04）；**组合说明 JSON 在导出前读取旧烘焙元数据**（C05）。打开时的异步交叉写入是代码可见的竞态风险，尚未交互验证（R01）。

## 引菊 → 锦专题：从操作到落地

固定基线数据在 `analysis/原理/条目_引菊转锦.json:5-86,86-165,168-180`：橙层 `HN2-O` 的 `ignDelay=0.08`、`sparkStop=1.2`、`burn=1.3`；锦层 `HN2-G` 的 `ignDelay=1.28`；两层 `delay=0`、默认 `rate=1`。轨迹识别的 `seed=7,stars=293,v0=250,vt=20` 相同（同文件 `:15-29,:95-111`）。所以橙层“火花停”的组合绝对时刻为 `0+(.08+1.2)/1=1.28s`，恰与锦层“点火” `0+1.28/1=1.28s` 重合。这是现有规则检测出的接力关系，**不是在 HN2 专用代码里写死 1.28**。

```text
右栏改橙层 sparkStop / 拖橙层火花停（或反向改锦层 ignDelay）
  → setTimingParam / trackDrag
  → timingEdit 先用 layerSpans.at(t)=L.delay+t/L.rate 记录旧重合点
  → phasesOf(...).set() 写本层 P.sparkStop；超出寿命时也可能写 P.burn
  → 若 follow 开：layerEndOf 差值 → P.duration、显式 cutOut、visTo；
                  ignDelay 有变化时 → cutIn、preFrom
  → 若同批星且 linkOff/glueOff 均关：gluePartners 找绝对时刻差 <0.02s 的非默认点
  → phasesOf(伙伴).set() 写锦层 P.ignDelay（反向操作则写橙层 P.sparkStop，可能再推 burn）
  → 若 follow 开：伙伴 P.duration/cutIn/preFrom 等也跟移
  → onParam + rebakeLayers/queueLayerBake → 预览／烘焙／导出
```

对应代码：`tool/src/js/79_workbench.js:385-420,423-479,555-572,623-641`。入／出点另经 `setCut/applyCut` 写 `P.cutIn/cutOut`，首次设点捕获 `preFrom/visTo`，量化到引擎 tick；烘焙从 `tool/src/js/50_bake.js:436-476,612` 读这些字段。组合时间由 `L.delay+本层时刻/L.rate` 决定，右栏点火数字和轨道位置不处于同一时间原点（L03）。

**当前最小可控操作**：在组合时间轴关“同一时刻的点一起动”，可单独改锦层 `ignDelay` 或橙层 `sparkStop`；若还要防止入点／时长随时间参数移动，再关“时长／入点跟着走”（`tool/src/js/79_workbench.js:525-538`）。入出点可选中层后拖白把手或点“设为入点／出点”（`:643-666`）。这两开关是 4.5.0 已有功能；原提示词关于“入出点跟随不能关”“候选默认切回放”在本基线已过时。**仍未完全可控**的是 T01 的时序不变量、`preFrom/visTo` 不可直改、两套时间原点未并排显示；建议先让这些关系可见，再按需给 T01 独立解锁。不开新专用 HN2 参数，也不应破坏同批星有意共享的 21 键。

## 核对与未解决限制

`SMOKE27` 的 `undefined.then` **不能按“三处产品缺陷”计**：`tool/src/js/79_library.js:169-175` 的 `openEffect` 仅在 `openReview` 返回值存在时转发；`openReview` 对组合返回 `openComboEntry` 的 Promise，但普通单层、asset、queued 路径返回 `undefined`（`:372-395`）。`analysis/scripts/界面冒烟.py:43,100` 直接对返回值调用 `.then`，与该契约不符。要验证产品打开是否有真实问题，应使用 `Promise.resolve(openEffect(...))` 后检查 UI 状态，而不是把调用端异常当三项独立缺陷。
