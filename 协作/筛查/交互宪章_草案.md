# 对话框 20｜FireWorksLab 交互宪章草案（供对话框 15 汇总，未定稿）

依据 4.5.0 固定提交 `9b8fbdb3516823c907fb79b85e9887b178a4ce20` 和 `协作/方案_底层统一与参数宪章_2026-10.md` §6.5–6.9。它是设计建议，**未改变产品或标准**；浏览器未能打开隔离页面，布局数值仍需实测。

## 1. 空间语义与动作归属

| 区域 | 固定职责 | 应放的主要入口 | 不放的东西 |
| --- | --- | --- | --- |
| 左栏＝**库** | 找、建、搜索、收藏、显示/隐藏、资产列表、最近使用 | 花型模板、AI 效果、正式库、我的效果、我的模板、我的版本；每行身份/状态/收藏和本对象的改名、隐藏或删除；“＋新建效果” | 参数滑杆、烘焙策略、重复的导出按钮 |
| 中栏＝**画布 + 一行时间** | 观察与操纵当前效果 | 实时模拟/引擎回放/贴图/流转、PC/手机、播放/时间/入出点、层细轨、烘焙状态及可取消/重试 | 版本管理、完整参数、长文档式说明；多余的发射器行/曲线图 |
| 右栏＝**发射器→模块→参数** | 编辑当前效果或层 | 图层管理、发射器标签、模块、参数、局部↺、联动链条/自动值、审阅 | 顶层资产改名/删除、第二套版本系统、与顶栏同名的主导出 |
| 顶栏＝**当前资产身份及主动作** | 让用户随时知道“我在改谁、哪一版、是否未保存” | 名字、来源/版本、保存、另存、还原、撤销/重做、导出素材包；`⋯` 仅收低频文件/协作动作 | 主要的删除、隐藏、改名、存模板若左栏/右栏已承载；不明来源的状态词 |

**一件事一个主要入口。** 旁路快捷方式可存在，但应调用同一个命令，并在两个入口上用相同名字、确认/撤销和错误提示。顶栏“保存”的目标必须随当前对象显示清楚：AI/正式/模板为“存成我的效果”，我的效果为“保存此效果”，我的模板为“更新模板”或“存成新效果”，不能同一按钮无提示地换语义。

## 2. 对象动作的固定位置

| 对象 | 打开/查找 | 编辑与保存 | 改名/复制/排序 | 删除/隐藏/恢复 | 导入/导出/分享 |
| --- | --- | --- | --- | --- | --- |
| 花型模板、空白发射器 | 左栏库；选择器可作新效果首层 | 右栏调；顶栏明确“存成我的效果” | 内置名不可改；复制成我的模板或我的效果 | 内置项不删；顶栏↺回默认/打开时 | 顶栏导出；`⋯`配方文件/复制改动 |
| AI 条目单层/多层、正式库 | 左栏按状态；层在时间细轨/右栏 | 右栏调；保存派生为我的效果 | 不能改源名；层复制到我的效果 | 左栏行直接“隐藏”，隐藏组可找回；不删源 | 顶栏导出；交付清单列 PC/手机和版本；`⋯`复制改动 |
| 我的效果 | 左栏我的效果 | 右栏调；顶栏保存/另存 | 左栏行或顶栏名字处改名；层在右栏排序/复制 | 左栏行和顶栏删除调用同一可撤销命令；撤销恢复**版本与草稿** | 顶栏导出；`⋯`配方文件、复制改动、仓库连接 |
| 我的效果的版本、草稿、导出恢复点 | 同一版本面板；统一显示来源、时间与是否自动 | 打开后顶栏能区分“覆盖当前效果”与“另存为新版本” | 版本行改名；自动恢复点若不支持改名就别显示改名 | 每行删、连续删除仍可逐笔撤销；删除当前版后切到明示的目标版 | 版本快照导出配方；历史在同一面板，不分散到底栏/工具页 |
| 层 | 右栏图层管理 + 中栏细轨 | 右栏完整参数；父效果顶栏保存 | 右栏行内改名、复制、上下移；单层存为模板在层行或页头 | 删层可 Ctrl+Z、顶栏撤销；静音/独看明示“仅观察” | 导出方案在层页头，整包导出在顶栏；差异随父效果分享 |
| 我的模板 | 左栏我的模板；选择器作来源 | 打开后顶栏主动作“更新模板”，另有“存成我的效果” | 左栏行改名/复制 | 左栏行删、撤销；删当前模板后离开或显示已删除状态 | `⋯`导出配方；收藏在左栏行及选择器同一状态 |
| 收藏 | 左栏收藏视图和对象行星标 | 切换即时持久化 | 不另设对象级复制/排序，若要手工排序需先定义顺序语义 | 再点星标即取消；明确“取消收藏≠删除对象” | 不作为独立导出对象 |
| 配方文件 `.json` | 顶栏`⋯→导入配方` | 导入前显示目标对象、层数/类型冲突与后果；导入后生成可撤销快照 | 文件本身由系统文件管理 | 应用不删用户磁盘文件 | 顶栏`⋯→导出配方`，复制改动为文本，说明两者用途 |
| 素材包 `.zip` | 交付清单显示将导出的文件与名称 | 不是可编辑配方；参数改动后标“旧包” | 英文文件名在交付清单设、导出前校验 | 应用不删磁盘包 | 顶栏一个“导出素材包”；进度可取消、失败可重试、重复点击幂等 |
| 本机任务结果文件夹 | 左栏工具/结果区，明确是“打开结果” | 仅预览及开关发射器 | 不在烘焙器内管理文件夹 | 不从 UI 删除结果 | 结果预览与当前效果区分身份；不伪称导入可编辑配方 |

## 3. 同一套状态、确认、撤销与错误恢复

1. **身份条**总显示：对象类型、名字、来源、当前版本、未保存标记、贴图是否按当前参数烘好、导出包是否对应当前参数。查看旧版本或草稿时不要把它叫“AI 版”。
2. **破坏性动作**：删除效果、版本、草稿、模板、层都采用同一方式。可以先做后给可撤销提示，但必须为每次删除保留独立恢复记录；多次删除不能覆盖较早的回调。恢复范围包括版本历史、层参数和未保存改动。若某项无法完整恢复，则确认前说清损失范围。
3. **烘焙与导出**：只有一个当前作业状态，显示阶段、进度、参数版本、目标平台；用户主动的长作业有“取消”，取消后释放资源并保留上次成功结果。改参使旧预览作废应显示“旧作业已作废，正在按新参数烘焙”；重复点击导出要禁用或只排一次。失败保持错误条、可重试，不用会自行消失的 3.5 秒 toast 承载唯一错误信息。
4. **提示模式**：参数说明统一为悬停 1.5 秒淡入、离开淡出、点名称钉住；已钉住用 × 或 Esc 关闭。`Esc` 的优先级：最上层对话框/选择器 → 打开菜单/提示 → 抽屉 → 精简布局，不能一次 Esc 连关几层。原生 `prompt/confirm` 尽量换成可复用的应用内对话框，标题说清对象与后果。
5. **自动动作可见**（与方案 §6.5 对齐）：自动计算值显示灰字与单位，旁边可解锁；联动用链条图标且可断开；夹值要说明原因与实际值；层开始时间与点火延迟并排显示两个时间原点及绝对时刻。参数改动记录应包含代码替用户改的字段。

## 4. 词汇表（一概念一词）

| 概念 | 统一用词 | 避免混用 | 说明 |
| --- | --- | --- | --- |
| 实时调参视图 | 实时模拟 | 渲染模式、模拟模式 | 源参数实时画面，调参用 |
| 导出贴图的引擎式播放 | 引擎回放 | 导出效果、回放模式、烘焙回放 | 浏览器预览；不称 UE 实测 |
| 全图贴图视图 | 贴图 | 纹理、整张（若指视图） | 流转中的“整张”仅为子选项 |
| 格子播放视图 | 流转动画 | 流转、动画（单独） | 与贴图视图相邻 |
| 用户创建的完整资产 | 我的效果 | 配方、条目（作为 UI 主名） | “配方”只用于文件/参数快照 |
| 一个效果的存档 | 版本 | 恢复点（泛称） | 自动导出快照写“导出时版本”，草稿写“未保存草稿” |
| 参数交换文件 | 配方文件 | 素材包、母版 JSON | `.json`，可导入到兼容对象 |
| PC/手机交付 ZIP | 素材包 | 导出效果、结果 | 完整导出；交付清单列内容 |
| GPU 计算结果目录 | 本机任务结果 | 迭代区（旧） | 只预览，不等于可编辑效果 |
| 来源对象 | 派生自 | 复制、另存（含义不明时） | AI/正式/模板→我的效果时明确保留来源 |

## 5. 快捷键：单一登记表

所有快捷键由一个配置表供事件绑定、按钮 title、帮助面板共用；不能各文件硬写各自说明。基线目前分散在 `79_undo.js:60-70`、`79_library.js:576-588`、`79_workbench.js:822-827`、`72_picker.js:101-107` 和 `body.html` 标题中，需统一核对。

| 键 | 唯一动作 | 焦点规则 |
| --- | --- | --- |
| Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y） | 撤销/重做一项资产编辑；结构变化也要入栈 | 在文字/数字输入里留给字段原生撤销；删除 toast 另显示可点入口 |
| B | 按当前参数烘焙 | 输入框内不触发；烘焙中显示同一作业而非另开 |
| R | 重播 | 输入框内不触发 |
| F | 精简布局开/关 | 输入框内不触发；状态持久化 |
| L / P | 左库/右参数显示开关 | 输入框内不触发 |
| V | 实拍对照开/关 | 仅有实拍时有效 |
| ← / → | 按 30 fps 退/进 1 tick | 时间滑杆聚焦时遵守滑杆原生键盘语义 |
| Esc | 按上层优先级关闭 | 不导致未保存数据静默丢失 |

## 6. 新功能准入

新增对象或动作前，在此宪章补：对象类型、固定入口、所需状态、保存范围、撤销范围、错误与取消、快捷键、1366×768 和 1920×1080 首屏目标。若找不到归属，先修改宪章并由负责人确认，再实现。检查至少包含“打开→修改→切换→保存→刷新→导出→取消/重试→重复操作”，并以**真实浏览器截图/产物**核验；静态检查只作辅助。用户验收状态继续按 `协作/标准.md`，此草案不能替代其标准。
