**最重要的 3 个问题**

1. **119.4 s 换点之后，低配宽度变窄了，不是「不变」。** 换点前是 P0 / P4 / P8，换点后是 P2 / P4 / P6。两边 P0 / P8 的银彩菊大 116.6 s 开，按寿命 75 % 算在 120.0 s 熄灭（按整寿命算是 121.1 s）。所以 120.0–122.6 s 低配只剩 P2 / P4 / P6 三朵：圆心最左到最右 393 m，含半径 605 m。16.0.37 和 B07 修订1 这时是 750 / 970 m，窄了大约 40 %，持续约 1.5–2.6 s，到 122.7 s 银彩菊大 P0 / P4 / P8 开花才恢复。另外 P4 没换走，122.67 s 银彩菊大开在 120.17 s 多重菊大还亮着的同一个点上，同心叠还在。`编排B08.md`「两边 P0 / P8 银彩菊还亮着，宽度不变」和更新记录「宽度不变」都要改；也可以换一种组合，比如留 P0 / P8。
2. **同心叠只少了地方，花对反而多了，还新冒出一处。** 严格口径：PC 低配，同点、同档、高度差 ≤ 5 m、两朵都亮着并重叠 > 0.5 s。
   - 16.0.38：6 处、16 对；16.0.37：8 处、13 对；B07 修订1：7 处、15 对。
   - 165.0 s P4 是这次放宽加回来的金芒菊大，压在 162.4 s 多重菊大上，是新出的叠。
   - 194 s 多了 4 对：加回的银彩菊 P1 / P3 / P5 / P7 和自己 1.6 s 前那一发叠。这是同一排连发，推断是有意的。
   - 剩下跨排的叠：122.5 s P4、132.5 s P0 / P8（重叠刚过 0.5 s）、165.0 s P4 / P8、171.5 s P0 / P8。
   - 更新记录写的「低配里两排叠在同一个点上的换开了」说多了，实际只换了 119.4 s 一排。
3. **A 最高的那几刻，B05 读数里正好没有校准点（推断，影响「约 0.8 ms」的可信度）。**
   - 16.0.38 低配 A 的前三个峰：129.7 s 3.97、43.9 s 3.83、168.0 s 3.69。
   - B05 在 129.3 s 是 6.02、168.2 s 是 6.7、43.9 s 是 3.83，比 182.6 s（1.04 ms 那处，A 5.06）还高或差不多，可是这三处 ±2 s 内都没有读数（最近的是 125 / 140、164.8 / 173、40 / 50 s）。
   - 两种可能：曲线在这几处真的不高，说明 A 高估了，这样 B08 更安全，但 A 这个口径就更弱；读数漏掉了峰，那 A ≈ 4 也可能接近 1 ms。
   - 更新记录让用户「特别看 64、130、183–190 s」是对的，建议加上 44 s 和 168 s。

## 逐条

### 1. 低配放宽了没有、有没有超

- PC 低配 A（亮着的浓密金菊面积，开花到寿命 75 %，Σ(直径 / 230)²）：
  - 全场最大 **3.97 @ 129.7 s**，> 4.0 的格子 **0 个**。
  - 16.0.37 是 3.24 @ 16.6 s，B07 修订1 是 6.03 @ 187.5 s，B05 是 8.70 @ 187.6 s。
  - 中 / 高配 6.68 / 10.10，和 16.0.37、B07 修订1 一样。
- B05 实测峰附近（±2 s 闭区间最大值）。S 含小平台花，括号里是 B05 的百分比：

| 时刻 | B05 A / S | 16.0.38 A | 16.0.38 S | 16.0.37 A / S |
|---|---|---|---|---|
| 64.3 s（0.95 ms） | 1.98 / 6.22 | 1.98（**100 %**） | 4.58（**74 %**） | 0.99（50 %）/ 3.59（58 %） |
| 182.6 s（1.04 ms） | 5.08 / 5.08 | 3.62（**71 %**，181.1 s 金蕊青柠大加回 1 朵） | 2.64（**52 %**） | 2.77（55 %）/ 1.79（35 %） |
| 189 s（0.95 ms） | 8.70 / 1.80 | 2.90（**33 %**） | 1.39（**77 %**） | 同 16.0.38 |

- **插值估 ms（推断）**：
  - 方法：对 25 个 B05 读数，按读数时刻取 B05 低配 A，做保序回归（PAV，ms 对 A 单调不减），块之间线性插值。A 的取法有两种：
    - [t − 2, t] 最大：B08 低配 A 3.97 → **0.71 ms**；
    - ±2 s 最大：→ **0.67 ms**。
  - 文档用三个点（3.24 → 0.76、3.85 → 0.6、5.06 → 1.04）本身就不单调，直接两点连线会得到 0.66–0.88。
  - 所以「约 0.8 ms」算偏高的说法，保序估计约 0.7 ms。两种口径都低于 1 ms，按用户 23:48 的要求「别超过 1ms……0.8 左右」看，**还有余量，没有放过头**。
  - 排序一致性：ms 差 > 0.1 的读数对，[t − 2, t] 口径同向 139、反向 16，和文档一致。
  - 64.3 s 那个峰 A 解释不了（A 和 B05 一样）。如果按 S 成比例粗推，0.95 × 0.74 ≈ 0.70 ms（推断）。
- **比 16.0.37 低配多放**：球花 220 → 247，**大 +9、中 +18、小 0**；扇 0；小平台不变；发数 379 → 406。
  - 多的分布：41.8–43.6 s 金芒菊中 ×4、54.6 s 银彩菊大 ×2、64.3 s 金芒菊中 ×2、116.3 / 116.5 s 银彩菊中 ×4、129.1 s 金芒菊大 ×1、132.5 s 银彩菊大 ×2、158.4 s 银彩菊大 ×2、165.0 s 金芒菊大 ×1、181.1 s 金蕊青柠大 ×1、192.5–194.3 s 银彩菊中 ×8。
  - 119.4 s 多重菊大是换点，不算多放。
- 隔点核对：和 B07 修订1 低配比，B08 修订3 低配只少 8 朵。
  - 64.37 s 银彩菊大 P2 / P6；
  - 184.38–184.58 s 金芒菊 P1 / P2 / P3 / P5 / P6 / P7（大 2 中 4）。
  - 和文档「64 s 5 → 3、184 s 9 → 3」一致；64.3 s 金芒菊中 4 朵（P1 / P3 / P5 / P7）没动，属实。
