# UE 实测包（4.0-d）

这几个包不是效果素材，只是用来在 UE 4.24 里确认烘焙器的几条假设。用本机导入工具导入，**跑一次就行**，结果填进 [`../UE实测.md`](../UE实测.md)（直接写，或者把截图 / 录屏发给 AI，由 AI 填）。

重新生成：`python3 analysis/scripts/UE实测包.py`（文件名固定，覆盖）。

| 目录 | 测什么 | 怎么看 | 对应问题 |
| --- | --- | --- | --- |
| `1_帧号/` | 帧号曲线在引擎里取帧准不准 | 三个面片循环播放：左「Uniform30」每 tick 一帧，中「Held3Tier」4.0 的三档持帧，右「Steep37」3.7 式开头陡峭。**30 fps 录屏**，逐帧读格子里的大号帧号，和 `预期帧号.csv` 对。看有没有跳帧、回跳、开头被抹平 | D6（曲线查找表） |
| `2_串扰/` | RGBA 接力压缩后会不会串通道 | 四个面片分别显示 R / G / B / A 第 0 格（横条、竖条、斜条、同心圆 + 字母）。格子里出现别的通道的条纹 = 串扰。PC 看 BC7；手机在编辑器里切 ETC2 / ASTC 预览再看 | D4 |
| `3_曝光/` | 材质亮度和色调是不是烘焙器假设的（自发光 ×4） | 一个面片 10 块灰阶。关自动曝光，用游戏常用的后期，截图，和 `预期_曝光卡.png` / `预期显示值.csv` 对 | C3 |
| `4_Ramp/` | Ramp 导入设置会不会让星芯变黑 | 左边 Ramp 按项目默认导入，右边改成 Clamp + NoMipmaps（`cascade.json` 里 `import_hint` 写了）。左边星芯出现黑圈 = Ramp 必须 Clamp | D5 |

- 每个包都有 `cascade.json`（PC）和 `cascade_mobile.json`（手机），全部 CPU 发射器，一个粒子系统里几个面片横着排开（间隔 60 m，面片 40–60 m）。
- 循环播放（`loops: 0`），面片一直在，方便看。
- 材质角色都是 `flipbook_rgba`（项目已有的模板），不新增材质。
