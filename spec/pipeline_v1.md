# 烘焙器 → 引擎 导入方案 v1（2026-09-29 定稿）

烘焙器的产物怎样变成引擎里可用的 Cascade 粒子。**本文件只写通用流程和约定**，项目自己的目录、命名、材质模板、导入工具都留在本机，不进本仓库。

参数格式见 [`cascade_params_v1.md`](cascade_params_v1.md)，示例见 [`examples/`](examples/)。

---

## 1. 分工

| 谁 | 做什么 |
| --- | --- |
| 云端（烘焙器） | 导出素材包：贴图 + **一个 `cascade.json`**（格式 `fwl.cascade/1`）。只写通用引擎参数，材质、动态参数写「角色」，不写项目资产路径和材质名 |
| 本地导入工具（本机私有） | 读素材包 + 本机的项目配置 → 导入贴图、复制材质实例模板并改参数、从空白建粒子系统、保存。先预览，再执行；同名资产一律不覆盖 |
| 用户 | 在引擎里看效果、微调、提交 |

## 2. 素材包约定（云端必须遵守）

- 一个效果一个目录：`<导出根目录>/<效果名>/`，里面有 `cascade.json` 和它引用的贴图。
- **目录和贴图文件名固定**：同一个效果重新烘焙时，覆盖到同一个目录、用同一个文件名，不带日期或版本号。
- 效果名用英文。引擎里的正式名字（英文名 + 两位序号）在导入时由用户指定，写进本地记录后不再变。
- **贴图命名（2026-10-02 用户定，烘焙器 4.1.1 起大面片素材包按这个出）**：`T_EFX_FireWorks_<名称>[_<层>]_<列>x<行>_<序号>_HD.png`（PC）、手机版去掉 `_HD`；Cut `…_<序号>_C.png`、溶解图 `…_<序号>_D.png`（需要才生成）PC / 手机共用，最大 512；Ramp `T_EFX_FireWorks_<名称>[_<层>]_R.png` 共用。`<名称>` = 礼花英文名（状态清单「英文名」，交付页可改），`<层>` = 多层时每层英文名，`<序号>` = 第几张贴图。帧号测试图放 `_检查/`，不导入。包里附 `命名对照.txt`。
- 轮廓图（cutout）由烘焙器直接导出，不要让本地再生成。
- 大面片母版的取景**只用「固定」或「随开花放大（Zoom）」**。紧凑取景已禁用：引擎里实测会抖。

## 3. 首次导入与之后的更新

**首次导入（有新增时）**：由本地导入工具来做。
1. 预览：列出将新建的贴图、材质实例、粒子，以及它们的目录；已存在的标红，禁止执行；
2. 执行：单个效果约 30 秒，纯粒子效果约 3 秒；
3. 导入完成后，在内容浏览器刷新就能打开。CPU、GPU 发射器都**不需要重启编辑器**（已实测）。

**之后改了参数、重新烘焙（没有新增）**：用户自己处理。
- 贴图：素材包目录和文件名固定，引擎里的贴图记得自己的源文件路径，**右键「重新导入」就会更新**；
- 粒子数值（尺寸、曲线等）：用户在 Cascade 里自己调。云端每次导出的 `cascade.json` 是本次的完整数值，可以直接对照。

**只有这些情况需要本地导入工具再跑一次**：
- 新增了效果、发射器或贴图；
- 贴图格子数（行 × 列）变了：材质实例的 Rows / Cols 要跟着改；
- 本地做「合入对比」：把新的 `cascade.json` 和引擎里的现状逐项比较，列出差异，由用户决定改哪些。

## 4. 引擎规则（实测结论）

| 规则 | 原因 |
| --- | --- |
| PC 版小粒子能用 GPU 就用 GPU；手机版一律用 CPU | 平台约定 |
| GPU 发射器的分布**必须烘查找表** | GPU 粒子的颜色、尺寸、寿命是从查找表采样的，不烘就全是 0，粒子在但看不见 |
| CPU 发射器的分布**不烘查找表** | 引擎直接按曲线计算，精确；而且脚本新建后在同一会话里打开也不会出问题 |
| 用脚本从空白新建的粒子系统，要补上 LOD 距离和 LOD 设置各一项 | 空着打开 Cascade 会越界崩溃 |
| 对齐方式用 Rectangle；曲线关键点一律 Linear；帧号最后一个值 = 总帧数 − 0.01 | 见参数格式第 8 节 |
| 材质实例 = 复制项目给的模板，只改贴图和行列参数 | 不从母材质新建 |

## 6. 给云端的下一步（2026-09-30 状态）

1. ✅ 烘焙器导出时直接生成 `cascade.json`（PC）和 `cascade_mobile.json`（手机），和贴图在同一个 ZIP / 目录；贴图名按第 2 节固定为 `T_<效果名>…`。已支持：大面片母版（固定 / Zoom / 分段）、升空尾缀 V5。单元序列、地面循环、上升星头循环还只有参数表。本地导出任务把素材包放在本机固定目录 `analysis/local/输出/素材包/<效果名>/`，重新导出覆盖。
2. ✅ 取景选项里去掉了「紧凑」，默认 Zoom；旧配方里的紧凑自动按 Zoom 处理。
3. ⏳ 纯粒子层（点灭星、火花等）也按同一格式输出，发射器写 `"gpu"`：PC 写 true，手机写 false。等第一个纯粒子层（球形B 的光点层）做出来时实现。
