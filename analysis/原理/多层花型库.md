## 2. 现实依据

### 2.1 芯物是什么、几层叫什么 ✅

- **芯**：大圆里面看到的小圆；**亲星**（最外层）不算进芯数；做芯的星叫芯星（[Walkerplus](https://www.walkerplus.com/article/150280/)）。
- 层数和名字（圈数 = 芯数 + 1）：

| 名字 | 芯数 | 圈数 | 说明 |
| --- | --- | --- | --- |
| 芯入（芯入菊 / 芯入牡丹） | 1 | 2 | 最基本的芯物 |
| 八重芯 | 2 | 3 | 「八重」不是 8 层：当年做出两层芯被认为到顶了，取「多重、极致」的意思（[All About](https://allabout.co.jp/gm/gc/417308/)） |
| 三重芯 | 3 | 4 | 大曲「芯入割物の部」要求 10 号玉、三重芯以上（[about-fireworks](https://about-fireworks.com/oomagari-shiniri-warimono/)） |
| 四重芯 | 4 | 5 | 主要在竞技大会出现 |
| 五重芯 | 5 | 6 | 约 2017 年起出现在大曲参赛玉里（同上）；土浦 10 号玉有「昇り曲導付五重芯変化菊」「昇曲付五重芯銀点滅」「昇曲導付三重芯変化菊」（[土浦市 PDF](https://www.city.tsuchiura.lg.jp/data/doc/1764056874_doc_159_0.pdf)） |

- 实例配色：三重芯「银、红、青」，四重芯「红、绿、紫、粉」（All About）。玉名的写法 = 升空效果 + 芯数 + 主体效果（土浦玉名）。中式叫「蕊」，名字就是配方：规格 + 颜色 + 主体 + 蕊 + 附加（配方总表 2.3）。

### 2.2 构造：为什么同心、同时开、同时灭

- 玉从里到外：割药 → 芯 → 八重芯 / 三重芯的各层 → 最外面的亲星；外面糊很多层牛皮纸，纸糊得匀，割药的力才匀，花才开得圆 ✅（[横滨市金泽区 PDF](https://www.city.yokohama.lg.jp/kanazawa/kurashi/kyodo_manabi/kyodo_shien/chiiki/kanazawamaturi/kanazawamaturi46/matsuriprevent.files/0006_20201021.pdf)）。
- 每层芯星和割药交替、在纸半球里均匀排好再合起来 ✅（Walkerplus）。
- 推到模拟上 〇：
  - 同一根导火、同一个爆心 → **各层同时开**（层之间没有延迟）。
  - 越往里层空间越小，芯星做得小、排得密 → 初速低、终端速度低（vt ∝ √星径）→ 半径小。
  - 设计目标是**各层同时熄灭**：评判里「一齐开、一齐灭」是硬指标。
- 评判（大曲芯入割物）✅（about-fireworks）：同心、正圆、一齐开一齐灭；星放射状、均匀、笔直；颜色变化鲜明；**消え口**（熄灭）整齐。→ 第 3 节的硬规则。

### 2.3 变色（変化）〇

- 星是在转动的容器里一层层裹出来的 ✅（横滨 PDF）；星从外往里烧，所以颜色按裹的顺序变。和仓库里青柠星、引菊 → 锦的分层星是同一个机制 ✅（项目实测）。
- 「変化菊」：先「引」（炭火尾、星头暗），再转色光；每颗星的层厚一样 → 整朵同时变色。多层模板里**各层共用同一组变色时刻**。

### 2.4 发色：为什么是这些颜色 ✅

颜色来自火焰里特定分子 / 原子的发光，金银来自高温颗粒的白炽（[Wikipedia: Pyrotechnic colorant](https://en.wikipedia.org/wiki/Pyrotechnic_colorant)、[Brock University](https://brocku.ca/cmt/upload/1094491599.5293/colours.htm)）：

| 颜色 | 发光物种（发色剂元素） | 主要谱带 | 模板用色（sRGB 起点） |
| --- | --- | --- | --- |
| 红 | SrCl（锶；SrOH 也有一点） | 617–646 nm（SrOH 600–613） | `#ff3b2a` |
| 橙 | CaCl（钙） | 591–608 nm | `#ff8a2e`（「引」段） |
| 黄 | Na（钠） | 589 nm，极强，容易压掉别的颜色 | `#ffc53a` |
| 绿 | BaCl（钡，要有氯；没有氯只剩偏黄的 BaOH / BaO） | 511–533 nm | `#5cff66` / 柠檬绿 `#b4ff4a` |
| 青 | CuCl（铜） | 403–456 nm；温度一高 CuCl 分解、发绿黄 / 橙红，最难做亮 | `#4f7bff` |
| 紫 / 洋红 / 桃 | Sr + Cu（锶多偏洋红） | 红 + 青两组谱带 | `#b35cff` / `#ff66c4` / `#ff7ac4` |
| 银白 | Mg / Al / Ti 颗粒白炽 | 连续谱 | `#eef2ff` |
| 金 | 木炭 / 铁颗粒白炽（约 2000 K，配方总表 1.3） | 连续谱 | `#ffd29a` |

- 「青最难做亮」→ 模板里青、红、紫这些亮度低的芯自动给高一点的显示强度（`mtHeadInt`，按颜色的相对亮度补）。
- **不写装药 / 星药的具体配比**：模拟和引擎只用得到「颜色 + 燃烧时间 + 尾的种类 + 速度」，配比对素材没有用。

### 2.5 物理：速度、阻力、大小

- 星的初速 50–130 m/s 量级，空气阻力近似和速度平方成正比 ✅（清水武夫 1957，[STEM Vol.18 No.2](https://www.jes.or.jp/mag/stem/Vol.18/No.2.03.html)）。
- 终端速度 vt = √(4 ρ_s g d / (3 ρ_a C_d))：星密度约 1.6–1.8 g/cm³、C_d ≈ 0.5 → 星径 10 mm 约 19 m/s、20 mm 约 27 m/s 〇（和号数表 17–40 m/s 一致）。
- 二次阻力下 t 时刻的横向距离 R = ln(1 + c·v0·t) / c，c = g / vt²；芯的初速按目标半径反推（`v0For`，和号数表 `applyShellNo` 同一个公式）✅。

    - **平级的几组**（彩色千轮）：没有亲星，显示强度每组都按颜色亮度补（`peers`）。小玉比星重（终端速度 30）、飞得开，小花小（子星初速 24），一朵一色；花型模板「千轮」的小花大、四组叠在一起每朵都混色。

11. **曝光**（`多层模板.py --expo`）：芯物要看的是全开的同心球，所以每层按燃烧中段（45 / 60 / 75%）最亮那帧的 99.8% 分位 → 0.93 定，再按回放检查的过曝口径（每帧顶到 250/255 的像素 ≤ 格子 2%）在全程 10 个时刻核一遍、留在 1.5% 以内。花型库的 `autoExposure40` 按「最亮一刻」定，多层里开花头几帧星挤在中间最亮，按它定后段太暗（花型库的菊也是人工调到 ×3）。

## 6. 烘焙器还缺的能力（给底层负责人；按标准第 3 节做成通用、默认关）

1. **环的方位角**（交叉环、立体多环）：现在 `ring` 只绕水平轴倾斜，两个环换倾角投影出来是同一个椭圆。要「每层（或每环）倾角 + 方位角」。
2. **层的爆点位置偏移**（段咲き、多节礼花弹）：多层效果里每层一个 InitialLocation 偏移 + 延迟。
3. **齐闪**（白闪蕊）：点灭相位统一（现在每颗星随机相位）。
4. **色分け**：4.9.16 起两半能做（分簇一簇 + 张角 90° + 整套簇转角，见 1d 染分）；四色扇区（每层四分之一）还缺「按方位角切扇区」——圆锥簇拼不严。
5. （不是缺能力，记一下）**同一批星的两段火花**：一层只有一个火花时间窗（`sparkStart` / `sparkStop`）。球形 D 末段 +3 s 起的银色细短线要拆成同一模拟的第二层（球形 D 的 YD1 / YD2 就是这样拆的）；第二批模板没拆，等球形 D 的「是不是相机拖影」定了再说。
6. **光露**：4.9.16 用现有的「星头亮度 / 大小随寿命」做了（见 1d）；有参考视频再对闪光时刻和亮度。

## 7. 检查和没验证的

- 标准检查（云端，`analysis/probe/多层模板/标准检查.md`，烘焙器 4.9 上重跑）：13 个模板全 ✅（按多层组合每层都过：单格 ≥ 512、屏幕放大 ≤ 1、30 fps 显示帧、燃烧段 / 淡出段帧率、尺寸有效）。
- 每层曝光按第 3 节第 10 条定，全程过曝（顶到 250/255 的像素占格子）最大 0.6%（上限 2%）。
- 定帧总表 / 参考对照：`analysis/probe/多层模板/`。

- 都是云端软件渲染下看的（实时模拟口径的定帧 + 标准检查）；本机没导出、没做回放检查；**没经过 UE 验证**（多发射器同爆点叠加的 overdraw、GPU 光点点灭层）。
- 层数多的模板（五重芯 6 层、四色牡丹 5 层）在游戏里是 5–6 个发射器；内层面片小，但同一爆点叠加，手机上要看 overdraw。
