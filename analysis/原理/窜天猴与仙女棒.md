# 窜天猴尾焰与仙女棒：本轮实现依据

目标是可调、可烘焙的快速多形态喷射。用户明确要求持续主体、很多长火星、多层参数、拉伸感、仙女棒全部形态，并补充「不必完全无缝、短平快、偶尔爆发、节奏不要平均」。

## 依据与边界

- 只读参考：`D:/Blender/Firework_FX_Lab/assets/Sparkler/V05/parameters.json`，来源 SHA256 见结果 `来源.json`。读过配方、版本说明与 cluster 模型，并看过仓库留存的 V05 审稿帧。V05 未完成正式循环/引擎验收，本轮不继承其通过结论。
- [Photron / 九州大学高速摄影说明](https://www.photron.co.jp/mitaiken/sparkler/)描述燃烧小滴连续分裂。用于判断「母粒上发生多级分叉」，不据此推定本项目粒径、亮度或窜天猴燃料。没有声称观看网页内完整高速视频。
- [真实火箭尾焰素材目录](https://upload.filmsupply.com/clips/sparks-glow-as-they-spray-from-a-fireworks-rocket-as-it-takes-off-out-of-a-bottle-and-flies-into-the-night-sky-celebrating-a-happy-new-year/605657)只用于确认观察对象为喷口后方的定向火星；未把目录文字当逐帧测量证据。
- 20 m 左右尾焰取景、0.72 m 仙女棒取景、64 帧 / 30 fps 周期均为制作候选，不是用户已确认的世界尺寸。

## 最小实现与关键取舍

一套通用粒子图支持线、点、不规则碎片，配方作为 `P.sparkGraph` 保存。旧配方没有该字段就保持原模拟。13 层来自原工坊，不按两个效果复制两套物理。

| 层 | 作用与关系 |
|---|---|
| 01 | 燃烧核心 |
| 02 / 03 | 细长暗丝 / 中等金丝 |
| 04 | 粗亮短火星 |
| 05 | 分裂母粒 |
| 06 / 07 | 母粒寿命 65% / 90% 触发首次与延迟分叉 |
| 08 | 首次分叉再产生二级碎火星 |
| 09 | 不规则粗碎片，自转与翻转 |
| 10 / 11 | 暗红余烬 / 圆形余烬 |
| 12 | 不同尺寸的粗短火星 |
| 13 | 燃烧头的炽热碎点 |

线条沿解析运动的历史路径画，速度、阻力、寿命及历史时间共同决定长短；不靠整屏模糊。子粒继承事件瞬间的母粒位置和部分速度，不另放一组悬空星形贴图。粒子宽度、亮度和随机分布独立，改亮度不扰乱轨迹。

窜天猴把根层改成朝喷口后方的锥形喷射，保留子粒局部散射。连续底量上叠加不等间隔的短爆发；成簇只重新分配已有粒子的出生时刻与方向，不额外堆一层长期残影。

亮度不是 Blender Emission 数字照搬：本工具使用灰度 RGBA + Ramp，细丝按亚像素覆盖率编码。仙女棒粗亮粒、圆点及分叉经过独立校准；分叉速度放大 1.5 倍以保证低分辨率可辨认，不宣称逐像素复刻 V05。

输出是每个平台一张序列、一个 CPU 面片发射器。Local Space 跟随喷口，弹体弹道由场景驱动。这个简单方案适用于局部快速尾焰；若要求长尾粒脱离弹体保留在世界坐标中，需要另外明确弹道及尾迹时长，不能仅移动本序列假装实现。当前未扩展这部分。

## 验收

看正式烘焙器的引擎回放及 `analysis/results/SparkGraph/实包回放.html`。原速判断喷射节奏，¼速检查分叉与形态；对比 PC / 手机。标准检查量尺寸响应、64 帧可见性及分辨率；实际素材包量切边、空帧、曝光及接缝。UI 验证打开、改参、保存、刷新恢复、烘焙与连续三周期。基准回归检查旧画面不变。

素材灰度未使用整屏模糊；UI 的显示曝光、Bloom 和 UE 压缩不是已验证物理。手机细丝细节少于 PC，世界米数、UE 朝向锁及跟随、Bloom/压缩仍待实机确认。

## 4.9.84 镜头修订
用户否定固定头亮尾暗，明确批准按资源开关的快门、景深与散焦。当前1/30s END来自工坊V05 globals；新版以真实生存区间裁剪曝光，逐粒瞬时形态积分，快慢自然拉长缩短。默认关闭仍走原核。景深用原三维Y深度、正交有限光圈，散焦半径=光圈直径/2×abs((镜头距离+Y−焦距)/焦距)；焦距此处指对焦距离，不是镜头焦长。核为保能量的圆/六边形软边近似，非全屏模糊。能力通用，不按rocket/sparkler名写分支；其他二维模拟不编造深度。源图作为质感和结构参考，非像素匹配承诺；结果和限制统一见SparkGraph/看法.md。
