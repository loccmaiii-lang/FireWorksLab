# 引菊 → 锦（橙色直线菊转金锦）· 效果原理

参考：`vidio/3.0/尾缀3.0_A.mp4`（4K 竖拍，从发射点附近仰拍、手持跟拍）。开花 = 视频 4.63 s（白闪第一帧 4.634，30 fps ±17 ms）。
同类效果：青柠星开头 0.5 s 的橙色放射线、球形A 的金线、球形C / D 开头的橙红短放射——都是「星在运动中烧出的连续尾线」，以前一直用随机火花去凑，所以碎、成团（见文末「以前为什么做不对」）。

## 1. 是什么

一发大玉的主层：**分层星**。外层药烧出平滑的橙色尾线（引き），烧穿后换内层锦药（金色、带延迟闪光的火星）。整发还有升空尾缀（另一件素材）、开花后约 3 s 的彩色小割（浮模様）、后段下垂成冠，这里只做主层。

| 时刻（开花后） | 看到什么 |
| --- | --- |
| 0–1.2 s | 橙色直线菊：每颗星后面一条连续、平滑、几乎没有颗粒的橙线，线从中心附近一直到星头；线的内段（开花初期烧出的）比中外段暗 |
| 1.2–1.4 s | 线的**最外端**（星头）先出现金色闪点——星换药了，不是曝光变化（内段同一时刻还是橙） |
| 1.4–2.1 s | 金色闪点从橙线外端开始，**随星继续往外扩散**（花径 +1.4 → +2.4 s 还在变大约 40%）；橙色内段变暗但还在（2026-10-01 22:17 用户在 UE 里看后改正：之前写的「从外往里变长」是错的，做出来金色往中心长） |
| 2.1 s 以后 | 以金色颗粒线为主，星减速、下坠（实拍此后手机晃动、出画，不能定量） |

## 2. 现实的化学和物理

- **橙线**：富木炭的引药（和火类）。细碳粒在约 1700–1900 K 发橙光；火花细、密、寿命短，远看是一条实线。
  - 线上每一段的亮度 = 那一刻每秒烧出的火花 ÷ 星的速度 × 火花还剩多亮。开花初期星最快（约 250 m/s），火花铺得稀；星在空气阻力下很快慢下来，后烧出的段铺得密。
  - **尾是有限长的一段**：火花离开星后只烧零点几秒（约 0.5–1 s，星飞得快时气流强、烧得更快）。所以亮着的只是最近烧出的那截，尾巴内端离中心越来越远；星速有快有慢（约 ±12%），各条尾的内端落在不同半径 → **中间有空隙**，边缘参差（用户 2026-10-01 17:24 指出，模型补上后与实拍一致）。以前所有版本都把尾画成「爆点 → 星头」整条轨迹，中间被几百条老尾段填实。
  - 星刚点着时引药发射率有一个爬升（实测约 0.3 s），所以开花瞬间的线段更暗。
- **锦**：内层含木炭 + 金属燃料 / 辉星成分，火花颗粒大、温度高、带钠的黄光，所以更金更白，而且一颗颗看得见；辉星的熔滴先飞一段、延迟零点几秒再闪亮。
  - ~~火星是向后喷出的（约 70 m/s，比星快，所以往中心飘）~~ —— **错，已撤回（用户 2026-10-01 22:17 在 UE 里看：金色从外往里长，和实拍相反）**。改正：锦火星主要**继承星的速度**往外走，被阻力慢慢停住、闪亮、下落；金色段是星换药后在身后留下的一段，前端就是星头，随星往外扩散。实拍 +1.4 → +2.4 s 花径还在变大约 40%，金色区域跟着往外推，内侧的橙线变暗。
- **星的运动**：二次空气阻力 + 重力。按实拍展开节奏拟合：初速 250 m/s、终端速度 20 m/s → +1.0 s 半径约 80 m、+4 s 约 130 m（约尺玉大小）。侧面看后段下垂。

## 3. 分层（同一个模拟，两层）

| 层 | 画什么 | 颜色 | 引擎 |
| --- | --- | --- | --- |
| O 引线 | 每颗星在「引药点着 → 换药」之间、且火花还没烧完的那段轨迹，画成**连续的线**；加一层很淡的暗红底光（受光烟） | 橙（Ramp：暗端深红、亮端橙黄） | 一组大面片发射器（分段接力） |
| G 锦 | 换药以后：一颗颗离散火星（继承星速往外走、阻力停住、慢慢下落、延迟后短闪）+ 很淡的金线 | 金（Ramp：暗端琥珀、亮端金白） | 一组大面片发射器（分段接力） |

两层的星位置完全相同（同一个三维模拟、同一个随机种子），只是画法和颜色不同——满足「一个发射器一条颜色曲线：头尾异色拆成同一模拟的两层」。

### 3.1 引线的亮度从哪来（每一项都是现实里的一个原因）

| 原因 | 参数 | 定稿值 | 看到的效果 |
| --- | --- | --- | --- |
| 点火药先烧、引药晚点着 | `oIgnDelay` / `oIgnDelayJit` | 约 0.12 s，离散约 37% | **中间空隙**：尾巴开始时星已在半径 30–40% 处；早晚不一 → 空隙边缘参差 |
| 尾火花只烧一会儿，星越快烧得越快 | `oLife`、`oLifeSpeedExp` | 30 m/s 时 2.5 s，∝ 1/星速 | 开花初期烧出的（靠中心）早灭，后段的橙线一直留到 +2 s |
| 火花离开星后要一会儿才烧旺 | `oRise` | 约 0.33 s | 线尖比中段暗 |
| 星速有快有慢 | `speedJit` | ±8% | 尾巴有长有短 |
| 受光烟 / 细火花 | `oHaze`、`oHazeM` | 0.018、6 m | 线间暗红底光（「纯净的橙」） |
| 星飞得快烧得快（每秒火花数随速度） | `oSpeedExp` | 约 0.4 | 早期线不至于太暗 |

完整参数见 `experiments/引线/考卷/候选C.json`（定稿后改为 `定稿参数.json`）。

## 4. 烘焙器缺什么（给 4.0 负责人）

> 2026-10-01 22:2x：先用 4.0 现有参数在烘焙器里搭（两层同一批星：橙层 = 高发射率、不继承星速、不闪烁的火花铺成连续线；金层 = 每颗星延迟到换药时刻才点着、火花继承星速往外走 + 延迟闪光），看引擎回放够不够；不够再补下面的通用能力。

1. **轨迹线图元（引线）**：沿星的历史轨迹画连续线（按屏幕 ≤ 0.3 px 加密采样）；权重 = 发射时间 × (星速/50)^β × 亮度（点火延迟 + 爬升、火花寿命 ∝ 星速^−γ 的截断、烧旺爬升、短燃 + 余烬两段衰减、换药后衰减）；线的像素亮度按每米像素数归一（与分辨率无关）；可选暗红底光（大半径模糊 × 强度）。现有「尾 = 离散 GPU 火花」做不到连续，也做不出中间空隙。
2. **换药时刻（tSwitch ± 离散）**：一颗星前后两种尾，前段画 O 层、后段画 G 层，共用同一模拟。
3. ~~火星向后喷出速度（sparkBack）~~：不需要（见第 2 节改正）；用现有的 `sparkInherit`（火花继承星速）即可。
4. **分层贴图增益 + Color Over Life 补偿**：闪点多的层在贴图里压低增益，引擎里用 Color Over Life 补回，避免顶到 255。
5. 都做成通用能力（默认关）：青柠星开头、球形A 金线、球形C / D 橙红短放射、鸿巢锦冠的长尾都能用。

## 5. 考卷（先定及格线，再调）

`experiments/引线/考卷.py`：把实拍和模拟都按爆点展开成极坐标（放射线变竖条），在交付分辨率（512 格、Zoom）、开花后同一秒量：

| 编号 | 量什么 | 防的是哪种失败 |
| --- | --- | --- |
| H1 / H2 | 相邻半径角向剖面相关（连续性）、沿线断点率 | 线碎、断成虚线（QA15–QA18） |
| H3 / H4 / H4b | 0.6R 处的线数、线的角宽（两边都限） | 成团（QN6）、线太细 |
| H5c / H5d | 0.3R 与 0.6R 的线数比、单条线内端亮度（各线中位） | 中间被填实、没有空隙 |
| H10 / H11 | 线亮度中位、线饱和度 | 线发暗、发棕、发灰（靠压曝光凑数） |
| H6 | R(t)/R(1.0)，0.3–1.2 s | 展开节奏不对 |
| H7a–d | 内 / 中 / 外三带的 G/R、B/R、金像素占比（减天空底色后） | 颜色不对、转金太早 / 太快 / 发白 |
| H8a / b | 沿线高频能量（闪点）：橙段只要求不比实拍更碎（实拍的细颗粒主要是视频噪点，不去凑）；锦段要有颗粒 | 橙段碎、锦段没颗粒、橙段星头冒亮点（QA13） |
| H9 | 线亮度中位 ÷ +1.0 s 的值，0.3–1.4 s | 开花初期太暗 |

参考指标（受实拍机位影响，只报告不调）：全部像素平均的内 / 中段亮度比（含线条汇聚）、外缘 / 中段亮度比、+1.5 s 以后的亮度（手机自动曝光在变）、+1.3 s 以后的半径增长（手机在发射点附近仰拍，下落的星朝镜头靠近）。

考卷的有效性：故意做坏的四个版本（旧做法的离散火花线、断线、成团、橙段点头）必须判不及格，见 `experiments/引线/考卷/反例判定.json`。

## 6. 以前为什么做不对（球形A QA4–QA18、青柠星 QN4–QN10）

1. 线是几千颗随机火花自己凑出来的：长短、断不断、末端亮不亮由发射率、寿命、末段寿命、寿命离散、继承、冷却、温度 7 个参数一起决定，互相牵连；QA18 单改寿命 −25%，线短了，断点还在。
2. 单格 256 px：一根线 1 像素宽，导出后必然断续。标准已定 PC 单格 ≥ 512。
3. 没有事先量好的及格线：每轮靠拟合分数 + 用户看，用户成了质检。
