# 球形A · 效果原理解析（2026-09-30 22:56 修正）

## QA13 失败后的因果重查

用户确认过的金尾 → 粉头 → 银白点方向继续有效，但此前把前段写成“金白、亮的星头”是不准确的。原片 +1.133 s 是连续金线，尖端没有独立亮球；+1.633 s 才开始出现细小点头，+1.867 s 粉点明显。母星从开花起就在运动、发射火花，**不等于母星从开花起就呈现独立点头**。不能为延后点头把母星点火、运动或金尾发射一起延后。

证据：`analysis/迭代/QA14/原片逐阶段.jpg`、原尺寸 PNG 与 `原片采样.json`。30 fps 的视频把请求 +1.12 s 对应到第 43 帧，即 +1.133 s；不是精确到毫秒的实拍。整段使用同一裁切，没有逐帧放大。+1.4 s 仍主要是金线，+2.2 s 金线缩短、变暗，+2.633 s 主要是小光点，仍有少量细残迹。

因果链：母星速度与阻力决定展开半径 → 火花沿母星历史轨迹出生 → 火花继承速度、阻力与重力决定其离开出生点的距离 → 自身温度、寿命和冷却决定哪些旧火花仍可见 → 可见旧火花与当前母星的距离形成尾长与中心空隙 → 母星发光阶段决定独立点头何时出现 → 材质、采样、曝光和序列帧决定最终可见结果。尾长不能仅用一个火花寿命数解释。

旧模型的具体问题：QA13 的 `headDim=1`，从开花起就显示高亮点头；统一的火花寿命与 45% 对数离散把许多旧火花冷却掉，留下短而碎的中段尾，寿命分布的长尾又让末段残金持续。单纯增加统一寿命会同时延长后期残迹。展开速度也偏快：同一固定裁切下，实拍 +0.367/+1.133/+3.367 s 半径约 67/124/190 px，早期增长比例必须单独检查。

QA14 是待验证的模型假设：母星保持同轨迹；用已有的发光阶段参数让独立头在 +1.60–1.85 s 渐显；新火花寿命随发射进程从较长逐渐变短，并减少寿命离散。**火花寿命在出生时确定，之后按自身年龄冷却；没有按全局时刻抹掉已经存在的尾迹。** 新能力默认末段倍数 1、离散 45%，四个时刻的旧版 GPU PNG 哈希逐张一致。它是否足够解释参考仍以实际导出图为准，预演有改善不算通过。

药剂只能作解释假设。单凭 RGB 参考不能确认木炭、锶或镁铝的具体配方，也不能证明真实星体有严格的三个药层。已确认的是三段可见颜色与尾迹行为，下文旧化学描述不能当作实测事实。

核验必须先能拒绝 QA13：+1.133 s 的独立点头、尾迹连续性与中心过亮都不通过；+1.867 s 短碎尾也不通过。旧 `refkit.heads` 数的是局部亮峰，参考金线上也能计出 600 多个，**不能用于判定独立星头是否出现**。结构张量连续性可作辅助，不能代替点头形态、同一秒局部与实际导出检查。

## 结论：三层变色菊，星头和尾巴颜色不同

花型库模板：**菊**（带尾星）。星是**三层**：金色木炭尾 → 粉红 → 银白。

之前 QA1–QA4 没做对的地方：变粉的时候，**只有星头是粉的，尾巴还是金色**（下面 t2.10 / t2.30 两张最清楚）。烘焙器一个图层只有一条 Color Over Life，星头和尾巴只能同色，所以 QA4 在 50% 时整颗都变粉了。

## 药剂假设（未通过实拍确认，不能当作确定配方）

- 外层：木炭 + 硝石 → 金色长尾（木炭火花），星头金白。
- 中层：锶系红加白光成分 → 粉红；**这一层里还有木炭**，所以变粉以后还在出金色火花（尾巴金色一直连到星头）。
- 内层：镁铝白光 → 银白，不含木炭，所以没有尾。
- 开头 0.2 s 的橙红：星外面包的点火药。

## 烘焙器里怎么做：同一个模拟，拆成两个图层

同一个随机种子、同样的初速和星数，两个图层的星**位置完全重合**，只是一个画尾巴、一个画星头：

1. **尾巴层**（菊）：只画火花尾，星头亮度压到几乎为 0；颜色 橙红（0–0.25 s）→ 金；火花 0–2.2 s。
2. **星头层**（牡丹，无尾）：只画星头；颜色 橙红 → 金白 → **粉红（+1.75 s）→ 银白（+2.35 s）**；约 +3.3 s 熄灭。

## 进引擎（你 23:10 提的两种，都能做）

| 方案 | 尾巴 | 星头 | 说明 |
| --- | --- | --- | --- |
| **序列 + 单帧**（手游合适） | 大面片序列（金，Color Over Life 只管尾巴） | **一张单帧光点图** + Size By Life 随开花放大 + Color Over Life 变色 + Const Acceleration 下坠 | 星沿半径匀速张开，光点图按同一条放大曲线缩放就能对上尾巴的尖端；+2.4 s 以后没有尾巴，对齐也不重要了 |
