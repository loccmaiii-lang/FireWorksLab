# 火花从哪里出来：发射器概念审查（对话框FanGold，2026-10-09）

> 用户 10-09 20:44（截图：橙扇 FC6O 实时模拟，箭头指一条线的星头和尾巴根部）：「你现在这个效果的火花前面细，后面扩散是怎么做出来的？我们现在的烘培器，火花是从什么地方播放出来的？是星头吗？星头如果变大，那火花离星头近的位置为什么不会跟着变大？火花会有一个发射器概念吗？……按照niagara的概念，应该就是星头就是作为发射器，发射器越大，火花出生范围也会更大，也就会变得更粗，请你帮我看看还有没有类似的问题没有发现或者忽略的」
> 依据：烘焙器 4.9.53 源码（`tool/src/js/20_sim.js` 星模拟、`40_gl.js` VS_SPK 火花着色器、`41_particles40.js` 光点核）。只读，没改代码。

## 1. 现在火花是怎么出来的

- **发射器 = 每颗星**（有一半 Niagara 的概念）：生成率 `sparkRate`（个 / 秒）、继承速度 `sparkInherit`、速度随机 `sparkSpread`、阻力 `sparkDrag`、下坠 `sparkGrav`、寿命 `sparkLife`，都挂在星上。
- **出生点 = 星心的一个点**：`40_gl.js` 191 行 `sp` = 星轨迹在出生时刻的插值位置（CPU 版 `20_sim.js` 462 行同样是 `s.x − s.vx·h·u`），**没有出生范围**。
- **初速 = 星速 × 继承（0.3–1.7 倍随机）+ 三个方向同一个 σ 的高斯散布**（194 行），和星的运动方向无关。
- **星头大小 `headSize` 只是画星头那块圆片的直径**（光点核：size = 实心亮核直径、I = 面亮度），模拟里的星没有大小；火花的出生点、初速都不读它。

所以刚出生的火花横向宽度永远是 0，往后按 σ(年龄) = 散布 ×（1 − e^(−阻力·年龄)）/ 阻力 变宽 →「前细后粗」本来就是点发射 + 随机速度的结果。FC6O 又加了三样把它推到极致：

| 手段 | FC6O 的值 | 作用 |
| --- | --- | --- |
| 点发射 + 散布、低阻力 | 散布 2.2 m/s、阻力 1.2/s、跟随 0.05 | 宽度 σ：0.1 s 0.2 m → 0.5 s 0.8 m → 1.3 s 1.3 m |
| 星头端收尖 / 最粗处 | 0.9 / 0.85 | 着色器里按「离星头的距离 ÷ 尾长」把横向位移再 × 0.1 → 1，火花大小 × 0.55 → 1 |
| 亮肩（负） | −0.3 | 新火花小而暗、老火花大而亮 |
| 泪滴星头、星头小 | 0.85、0.25 m | 星头本身是尖的 |

## 3. 建议（加参数要先记参数变更记录、用户批）

- **火花 › 形状：出生半径**（m，默认 0 = 现在）+「跟星头大小」倍数（0 = 不跟；1 = 出生在星头圆片里）。在球里均匀取点（或球面）。对应 Niagara Shape Location / Cascade 的 Sphere 位置模块；火花烘进序列，引擎不受影响。
- **火花 › 初速：向后喷速度 + 锥角**（默认 0 = 各向同性，同现在），和 RT6 的 rtJet / rtCone 同一个意思。
- **星头 › 光晕单独一份**（星头光晕占比 / 半径，默认 = 层的光晕），火花仍用层的。
- **火花 › 生成：按每秒 / 每米**（默认每秒）。
- 扇面 N 簇加「筒距」（m，默认 0）。
- 默认值全是「现在的行为」，基准回归逐像素相同。
