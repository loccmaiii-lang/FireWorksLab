### 0.1 一排是怎么放出来的（用户的原理 + 补充）

| 环节 | 用户的描述 | 补充（实拍量的 / 物理上的） |
| --- | --- | --- |
| 发射筒 | 一个扇形有 N 个发射筒 | 实拍新射线的方位峰：−33 / −25 / −15 / −7 / −1 / 5–9 / 11 / 21 / 29°（8.3、10.0、12.0 s 三排都一样），**筒距约 8–9°**；画面只拍到 ±36°，扇面实际约 ±45° → **约 11 根筒**，均匀排开、筒口在同一处（筒排宽 < 1 m，远看是一点） |
| 出膛 | — | 筒与筒引线串联：一排从一侧到另一侧**逐筒出膛**，0.35–0.4 s 扫完（相邻两筒约 0.035 s）；排与排方向交替（Z 字引线）。每根筒出膛时筒口一团橙白火舌（约扇面高 15 %、0.1–0.2 s）+ 发射烟 |
| 星头 | 每一个同时扩散 N 个星头 | 一根筒一次打出 **4–5 颗星**，同时出筒，在筒轴周围一个小锥里散开（半角约 4–6°）；相邻筒的锥互相重叠 → 整面扇看起来是**连续的**，只在方位上有轻微疏密（筒的峰），不是几簇分开。每排约 50 颗星 |
| 弹道 | — | 星小、二次阻力：出膛约 105 m/s、终端速度约 11 m/s → 0.3 s 到顶高 55 %、0.8 s 86 %、约 1.65 s 到顶（约 28 m）；外侧筒仰角低，顶点低 → 爆点连成弧 |
| 尾缀火花 | 星头拖出尾缀火花 | 金色辉星火花（木炭 + 金属，熔滴延迟一会儿才闪）：细、密、几乎不继承星速，留在走过的路上慢慢下落 → **整条射线从底到顶都亮、会闪**；刚出的橙金，老的变淡金 / 银白，约 3 s 后灭完。星头本身不亮，白热段不明显（这一点和升空尾缀不同） |
| 爆裂 | 最后星头爆裂出现爆裂星 | 星按时间烧完（约 1.7 s，刚到顶）才点着芯，**每颗星**碎成几十粒微星，0.1–0.5 s 内各自炸开、离星 2–3.5 m；50 颗星的团连成一条白色冠带，而且冠带也是**从一侧到另一侧**先后炸开（跟着出膛顺序） |

### 0.4 要补的通用能力（用户 18:40 批，烘焙器 4.9.34 已加）

现有分簇排法只有立方 / 6 轴 / 8 角 / 二十面体 / 一圈 N 簇（360° 均分）/ 球面，星也是同一时刻全部出发，所以「N 根筒排成扇面、逐筒出膛」现在做不出来。补两项（默认关，现有效果逐像素不变）：

1. **簇的排法 + 「扇面 N 簇」** + 参数「扇面总张角」（°）：N 簇在画面平面里均分这个张角、居中朝上，整套簇转角 / 倾斜 / 偏转照旧能转（外左 / 外右变体 = 整套簇转角 ±15° 之类）。
2. **簇依次出膛**（s，正 = 从左到右、负 = 从右到左；0 = 同时）：第 k 簇的星晚 k / (N − 1) × 这个时间才出筒（之前不动、不亮、不生火花），开花闪光、「开花时」自定义发射器跟着各自出筒时刻。任何分簇花型都能用（例：万華鏡依次开）。

按参数宪章先在 `协作/参数变更记录.md` 写一条、你批了才改；`tool/src` 现在由对话框23 临时认领，要先在状态清单「共享文件」排队、和对话框23 错开。

不补的退路：11 根筒 = 11 层（每层一圈 1 簇 + 转角 + 层延迟），现有能力能做出一样的画面，但导出是 11 张贴图、11 个发射器，只适合看效果，不适合进游戏。

## 1. 是什么

地面扇形组合（Fan Cake）打出的一排：几簇金尾彗星从同一处呈扇面射上去，减速到顶后每颗星炸成一团白色噼啪，连成一条冠带。视频里连打 9 排。

| 时刻（这一排出膛后） | 看到什么 |
| --- | --- |
| 0–0.4 s | 各簇从一侧到另一侧先后出膛（实拍每排 0.35–0.4 s 扫完，方向一排一换：7.8 s 左 → 右、9.5 s 右 → 左、11.6 s 左 → 右）；筒口橙白火舌约扇面高的 15 %，底部发射烟被照黄 |
| 0–1.4 s | 金尾彗星很快冲上去再吊住：0.3 s 约到顶高的 60 %、0.8 s 约 80 %、1.4 s 基本到顶；射线是直的 |
| 1.4–1.9 s | 星在顶上吊着、尾巴继续烧：整条射线从底到顶都亮，新尾橙金、老尾变淡金 / 银白 |
| 约 1.9 s | 星烧完，每颗星炸成一团白色噼啪（0.1–0.5 s 内炸完、离星约 2 m），相邻的团连成冠带，约 0.6 s |
| 1.9–3.5 s | 尾巴继续老化变银白、慢慢落下变暗；下一排已经出膛（实拍排间隔 1.6–2.1 s，下一排出膛 ≈ 上一排爆裂） |

量到的颜色（视频曝光偏高，只看色相）：新尾中位 (186, 144, 91)、亮端 (239, 197, 137)；冠带爆裂中位 (218, 207, 191)、亮端 (249, 240, 229)；筒口火 (217, 173, 99)。

比例：出膛点 (390, 1080) px，中间几簇顶上在约 227 px（853 px）。按冠带高约 28 m 算，实拍 30.5 px/m（参考人高约 60 px ≈ 2 m，人比发射点离镜头近，只作量级参考）。

## 2. 现实的结构和物理

- **扇形组合**：一排筒按角度排开、引线串联，所以一排是先后出膛的「扫」；排与排之间引线走 Z 字，方向逐排交替。每个出膛口装几颗星（同一方向一个小锥），开出来是**一撮几乎平行的金线**，不是一根一根均匀铺开的射线——这就是用户说的「一簇一簇」（上一版 demo 每发一束、40 束均匀铺开，错）。
- **星 = 锦冠金尾彗星**：木炭 + 金属燃料的金色火花，加辉星成分（熔滴延迟一会儿再闪），所以尾巴又长又密、会闪。火花几乎不继承星速，留在走过的路上慢慢下落，整条路径都亮。
- **弹道**：星小、阻力大（二次阻力）。出膛 105 m/s、终端速度 11 m/s → 0.3 s 约 15.5 m（55 %）、0.8 s 约 24 m（86 %）、1.65 s 到顶约 28 m，和实拍「冲上去再吊住」一致（解析式：y = vt²/g · ln(cos(φ − g t / vt) / cos φ)，φ = atan(v0 / vt)）。外侧簇（±30°）竖直分速度小，顶点低一些，冠带是一条弧。
- **爆裂**：星芯是噼啪药。外层按时间烧完（≈ 1.7 s，刚到顶点）才点着芯，碎成几十粒微星各自延迟炸开。按时间、不是按高度，所以爆点连成弧，不是一条水平线。

## 3. 第 1 版分层（FG3：4 层 = 4 簇，被第 0 节取代）

| 右内簇 ClusterR1 | −10° | 0.20 s | 37 |

- 每层：锦冠（kamuro）· 星的排布 = 分簇 · 一圈 1 簇（默认朝正上）、张角（半角）9°、簇方向随机 2°；整套簇转角定这一簇朝哪边。和「染分牡丹」同一个做法（每半一层：一圈 1 簇 + 转角 ±90°）。
- **一簇 = 很多条细线**（用户 16:53「一簇（组）里面有多个束（条）细的组合而成」）：每簇 22 条，火花横向散开只有 0.15 m/s，每条只有一根细线粗。
- **每一条线像升空尾缀那样组成**（用户 16:53「细火星 + 白热火花 / 闪烁火花 / 星头光晕」；照 RT6 的组成，`升空尾缀.md` 7k）：
  | 组成 | 怎么做（同一层） | 看到的 |
  | --- | --- | --- |
  | 细火星 | 主火花：小（0.12 m）、寿命 3.0 s ± 40 %、几乎不继承星速；出生 2350 K 冷却到金；四分之一延迟闪光 | 金色细线，有亮有暗、错落熄灭 |
  | 白热火花 | 自定义发射器 1（星燃烧时沿路）：每颗星 140 个/s、寿命 0.22 s、很亮 | 星头后面一段白热：出膛时星快、白热段长，到顶时短 |
  | 闪烁火花 | 自定义发射器 2（沿路）：30 个/s、寿命 0.9 s、闪烁 6 Hz（≤ 0.4 × 帧率） | 金线两边零星闪的亮点 |
  | 星头光晕 | 星头亮核 + 光晕 | 每条线顶端一个亮点 |
  一层只有一条颜色：都是灰度 + 同一条 Ramp，靠亮度落在 Ramp 的不同段（白热最亮 → 白端，细火星 → 金，冷了 → 暗琥珀）。
- 4 簇覆盖约 ±40°（实拍扇面 ±40–48°）；层延迟 0 / 0.1 / 0.2 / 0.3 s = 左 → 右扫射（实拍 0.38 s）。反方向（右 → 左）是同一组层把延迟倒过来。
- 颜色：一层一条颜色曲线。金尾和顶上的白色爆裂在同一层：Ramp 暗端琥珀、中段金、亮端暖白，爆裂小闪很亮，自然落在白端。
- 有尾：金尾火花（锦 + 一半辉星）。熄灭：烧完在顶上爆裂，尾巴自然冷却灭完。
