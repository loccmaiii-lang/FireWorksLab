# 仙女棒：快抛慢落、气流与分叉

本轮首选沿用当前向四周喷发的仙女棒，保留13类火星、短促爆发和可选镜头成像。下述研究支撑运动机制，不把线香花火的材料、尺寸、速度直接当作普通手持金属仙女棒的实测需求。

## 原理与证据

1. Inoue等《Direct Self-Sustained Fragmentation Cascade of Reactive Droplets》，PRL 118,074502(2017)，观察到反应液滴逐级碎裂；母火球喷出粒子，粒子在飞行中继续碎裂。支持多级亲子轨迹，不支持用全局涡流制造分叉。该研究针对日式线香花火，不能据此声称所有铁粉仙女棒化学机理相同。
   https://pubmed.ncbi.nlm.nih.gov/28256875/
   https://gfm.aps.org/meetings/dfd-2015/55f6240269702d060dd50300
2. 《Heat balance of senko-hanabi and iron sparks》(2019)比较了线香花火与铁火星的温度及热平衡，明确两者不同，且手持混合金属/氧化剂体系还需进一步分析。视觉发光大小不能当作真实质量/粒径直接驱动全部阻力。
   https://www.jes.or.jp/mag/stem/Vol.80/documents/Vol.80%2CNo.4%2Cp.136-141.pdf
3. NASA阻力方程：阻力与相对气流、面积、阻力系数有关；固定系数形式随相对速度平方增长。当前烘焙器的线性阻力是便于控制的近似。先调初速分布、减速时标与重力，足以解决本轮视觉问题；不为了物理名词新增CFD或把平方阻力当作唯一答案。
   https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/

4. NASA对燃烧的说明：热的低密度气体因浮力上升。用于解释弱上升空气流；并不能直接证明致密金属颗粒都向上飞，颗粒运动仍需重力和相对气流阻力。
   https://www.nasa.gov/missions/station/iss-research/studying-combustion-and-fire-safety/

## 当前速度为何显得均匀

SGS1不是没有随机初速；主层大多同用1.7/s阻力，0.05–0.2s短寿命使抛射动量通常只下降少量。多层速度区间高度重叠；重力仅0.184m/s²。曝光不变时，一组相近的短线更容易呈现匀速感。以上是基于配方和模型的诊断，不是实拍拟合结论。

首选：大多数低/中速火星 + 少量高速尾部；细丝阻力较强、粗粒惯性较强；可自由飞行层用地球重力形成下坠，燃烧核心作为附着发光区保留原状态。每颗粒子的随机值固定，不逐帧抽随机速度。不靠改播放速率或曝光假装速度变化。

## 场的取舍

- 本轮首选：燃烧点上方渐入的弱热羽流近似 + 微弱侧风与连续涡动，轴向收束=0。复用现有气流，不求解温度/流体。细丝随流较强、粗碎片较弱；这只是分层惯性近似，未用发光直径冒充物理质量。
- 可后做：移动仙女棒的摆动风、独立局部涡环，前提是用户确实需要这些运动。
- 暂不建议：强向心收束、大旋涡、每帧随机力、全部火星向上浮。它们容易改变仙女棒的放射与下坠特征。烟和热气会上升，并不意味着密度高的金属火星也必然上升。

## 新全局控制的具体含义

现有半锥角/数量/直径/寿命/亮度五项已对SGS1可用，继续复用。

| 拟新增项 | 作用与边界 |
|---|---|
| 整体初速倍率 | 只乘各层自身初速分布；子粒继承取有效母粒速度；不是播放速度 |
| 整体重力倍率 | 乘各层加速度向量，不改初速和气流 |
| 分叉延展（寿命倍率） | 只乘子粒寿命，影响实际可飞行距离；飞行距离仍由速度、阻力、重力共同决定，不承诺等比距离 |
| 分叉张角倍率 | 调分叉相对母粒行进方向的角度；球形分叉也需生效；1保留原图，不强迫所有分叉改成单锥 |
| 分叉数量倍率 | 优先通过第一代子粒数调整，后续代数随第一代数量变化，不逐级复乘 |
| 分叉尺寸倍率 | 只乘子粒宽度；面积会影响光量，不自动补亮度 |
| 分叉初速倍率 | 只乘子粒自身散射速度，速度继承另按各层原参数 |
| 分叉重力倍率 | 只乘子粒加速度，叠加在整体重力倍率上 |

用户已经确认“飞行距离”和“张角”两者分别控制。距离采用明确可解释的寿命/延展，不把范围做成后期缩放贴图或硬裁切半径。所有倍率默认1，各层原值保留；无子粒时分叉组变灰写原因；实际导出和实时共用一套有效参数。

## 本轮验收

同取景、同曝光对照；13类形态与爆发时刻保留；快慢火星共存且能看见减速/下坠；一级/二级分叉从母粒轨迹接续；五项已有倍率可用；新增八项需完成默认回归、独立生效、保存撤销与PC/手机真实输出后才能称上线。新控件当前排在共享源码4.9.113之后，数据候选不代表新控件已实现。
