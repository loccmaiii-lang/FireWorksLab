# 窜天猴柔光暗底 · 2026-10-18

目标是主体背后的柔散发光层，适合原主体+柔层+粒子细节的层次关系。本轮只制作柔层；主体和用户粒子版保留，UE三层实际合成及GPU扰动未经本轮验证。

原理依据：

- [Epic Bloom](https://dev.epicgames.com/documentation/en-us/unreal-engine/bloom-in-unreal-engine)：光晕可用不同半径高斯模糊近似。这里借用空间低频光晕的美术分工，不改全场后处理，更不采用文档里卷积核NeverStream设置（本项目禁止）。
- [Blender Glare](https://docs.blender.org/manual/en/4.4/compositing/types/filter/glare.html)：可以单独输出glare再合成，说明柔光与原锐利图像分工可分离。
- [Epic UE4.27混合模式](https://dev.epicgames.com/documentation/en-us/unreal-engine/material-blend-modes?application_version=4.27)：Additive=源色+背景色，黑色透明，没有遮光；暗底不能被当成黑烟或压暗底板。

首选：保留原13层的运动、事件、数量与相位，把副本作为更宽的暖色软核，以原width²/新width²补偿峰值面积，再降低至原能量的一小部分；不拉长曝光伪造空间柔光。核宽按平方相加是高斯卷积的方差关系；原尺寸随机/寿命曲线仍保留，所以是可控近似，不声称是完整相机PSF或真实体积散射。

副本形状改为圆对称软核；原快门轨迹继续贡献方向性。原不规则碎片等锐利轮廓由主体和粒子层承担，柔层只保留其发光事件。初始σ增量0.16m（PC512的20m取景约4像素）、能量比例0.12、暖橙Ramp都属于首轮美术候选，不是用户确认值或物理标定。

关键取舍：同一光路的主体+散射若不减主体就不严格守恒，因此本层是弱叠加近似；控制其贡献，避免与UE Bloom叠加过强。假定相同起播时间、播放速率、绑定位置和轴锁；若UE独立随机循环相位，贴图相同也会错位。共用取景和pivot，不把底层随意放大/下移。

验收：单独看柔而弱、无硬碎片；和主体相加只补宽光晕、保留主体细丝。对比黑底与中灰背景，检查过曝、裁切与质心；PC/手机实际RGBA回放与统一入口均通过。暂不增加黑烟遮挡、热折射材质、第三层GPU实现或全局Bloom调参。
