# 粒子图全局气流 · 2026-10-15

用户目标：喷口附近锥形向外喷，随后向内收、向下吹并有连续扰动；多个全局控制。图1红线视作期望轮廓，图2–4提供尾焰/粒子流形态参考；静态图不能反推出速度场、压力、真实尺度或随时间演化。

## 原理与关键区别
- 射流卷吸（entrainment）：高速射流与环境流体通过剪切层混合，带入周围空气。自由湍流射流的整体宽度通常随下游扩展；不能据“卷吸”推导出所有火星都向轴心收紧。[van Reeuwijk 等，2016，DNS研究](https://arxiv.org/abs/1603.09078)。
- 粒子随流与惯性：气流通过阻力改变粒子速度，颗粒惯性越大越不容易跟随小尺度涡动。采用有限响应率表达，不从发光贴图的像素直径推断真实质量。[Yuu 等，1978，圆射流颗粒实验](https://aiche.onlinelibrary.wiley.com/doi/abs/10.1002/aic.690240316)。
- 火箭喷焰受喷口/环境压差影响，可出现膨胀、压缩和激波结构；这和低速火星受气流弯曲不是同一个机制。[NASA喷焰研究，2011](https://ntrs.nasa.gov/api/citations/20110014613/downloads/20110014613.pdf)。没有压力、马赫数等信息，不把附件识别为马赫环，更不据此做CFD。
- 亮焰收尖也可由燃烧/冷却和可见阈值造成，发光包络不等于流线。本次明确改变轨迹，不通过调暗外层、缩窄取景或隐藏粒子制造收束。

## 首选近似与范围
在当前图的喷口局部坐标中叠加三项气流：定向风 U、轴向收束 -k×径向偏移、空间连续的涡流扰动。轴通过喷口原点；沿轴超过开始距离后，用smoothstep在渐入长度内引入场。

粒子加速度 = 既有重力/阻力/层扰动 + 全局响应率×本层随流倍率×渐入权重×(气流速度−粒子速度)。先保留初始锥形及惯性，再受气流影响。收束是美术可控近似，未求解质量守恒的气体密度/轴向压强；不能称真实火箭流场。涡流分量自身使用散度为零的三角基，渐入遮罩和收束场整体不保证散度为零。

固定RK4步长（至多1/240s，按强度/尺度继续细分）+ Hermite位置/速度采样；轨迹缓存只在开启时生成。所有渲染和子粒继承共用同一sample。时间演化是共享绝对时刻且整周期重复；粒子出生节奏仍按原爆发事件，不为了循环平均化。没有逐粒每帧重新摇随机数。

当前必做：全局开关、三场分量、轴向与渐入、逐层响应、统一参数栏保存/撤销、镜头成像同轨迹、PC/手机真实导出。仅SGR1推荐候选开启；SGS1具备同样控制但配方不改。旧配方默认关闭。可后做空间操纵柄和更多局部场；暂不建议CFD、马赫环、燃烧模拟、世界坐标尾迹。

## 验收
1. 在同一随机种子/亮度/粒子数下比较开关：近喷口方向保留，中后段出现连续向内弯；不能直接缩放最终图片。
2. 风速、收束率、扰动速度分别置零，各自作用消失；逐层倍率0时回原轨迹。
3. 分叉发生位置和继承速度取改变后的母轨迹；快门采样位置/速度一致，无随机时间跳变。
4. 统一右栏修改→撤销/重做→保存我的效果→刷新恢复；真实输出按64帧/30fps播放，PC512和手机256单格，通过标准和回放检查。
5. 关闭回归两效果×镜头开关×三时刻=12帧与4.9.103相同；恒风解析解、步长减半、周期场及乱序查询检查。

后续调参建议：先关涡流，只调风/收束确定包络；再开弱涡流。收束率增大更紧，响应率增大转弯更快；空间尺度增大是更宽的弯折。粗火星低随流倍率，细丝稍高。推荐数值为首版调参，未认作用户审美通过。实际UE姿态、Bloom、压缩尚未实测。
