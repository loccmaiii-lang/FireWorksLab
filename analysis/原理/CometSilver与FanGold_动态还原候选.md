# Comet/Silver 与 FanGold：动态还原候选（2026-10-13）

状态：只读源码核查与候选建议；未批准实施，未改生产代码、现有配方或认可素材。目标是保留现有输出约束，让动态更接近参考，不以增加功能数量为目标。依据为烘焙器 4.9.79 / 817e934e、CS3_RT6 完整参数、Blender FanPair R12 认可造型基线及 R14/R15 后续记录、FanGold V04。R15 未被当作整版用户通过。

## 推荐结论

优先做两件小事：一是用 RT6 已有自转/甩出/三档粒子参数做近似，二是核对并补齐现有参数在“整段合并输出”中的有效性。只有实际回放证明这条路线不足，才补“火花持续受随时间变化的气流影响”。FanGold 的主星减速/寿命问题单独修，不用风场掩盖。

不建议搬入 Blender 的全部八层、完整节点平台、流体系统，或直接叠一套 FanGold 专用几何摆动。原版值得借鉴的是分工与时间关系：头稳定、尾渐活；近邻运动有联系；粗细粒子各自燃尽；停止喷射以后旧粒子继续运动。这些不要求增加 UE 发射器。

## 1. 查到的事实

### 原版不是同一种“扭动”

**FanGold V04**：线性主轨迹及原生脱落粒子之上，额外叠加按 root_id 连贯、按尾龄渐强的几何波形。0.11 m 是位移幅度；不是空气速度，也不是流体模拟。见既有 [物理诊断](../results/FC6O_Blender/扰动与物理对照.md)。

**Comet/Silver R12**：由 `fan_stationary_r12_build.py` 明确使用 `fan_stationary_r10` 原生模块。火花在 RK2 积分的当前位置与中点持续采样四维噪声风场；风场随时间变化，有逐粒归一化年龄强度曲线及退出燃烧阶段的包络。头部不启用同样的扰流。各分量依赖其他坐标，保持无散度的构造；这不是 CFD，也不是简单“每粒出生时抽一个方向”。其基础火花求解器为平方阻力，与 FanGold 的线性解析路径不同。

来源：`D:/Blender/Firework_FX_Lab/production/fan_stationary_r10/nodes.py:7`、`:102`；`src/fxlab/nodes/simulation.py:166`；`assets/{FanSilver,FanComet}/Stationary_SingleAtlas_R12/A/extensions.json`。R12 Silver 前两火花层幅度为 0.55 / 7 m/s，Comet 为 3.5 / 4.5 m/s，不能只抽某一个值代表整束。R14 又降低 Silver 扰动，R15 将独立余烬寿命/明暗进一步拉开；后续版本并不意味着更强扰动更好。

还要防止单位误读：原版 `frequency` 虽有“次/秒”标签，代码中实际参与四维噪声的时间坐标幅度；周期还由 `cycle_s` 决定。它不是 RT6 的自转转速，不能数值照抄。

### RT6 的自转在合并输出里有效，但本次配方关掉了

当前 CS3C 金尾及 CS3S：`rtSpin=0`、`rtSpinPh=0`、`rtFling=0.5`。代码用出生时刻 tb 计算 `phi=2π(rtSpin·tb+rtSpinPh)`，横向初速含 `−rtFling·sin(phi)`。所以当前切向甩出项恰为零。

| 控制 | 真正作用 | 能不能替代旧尾继续扭动 |
|---|---|---|
| RT6 `rtSpin`，转/秒 | 连续出生的火花沿不同相位喷出，形成整体螺旋投影 | 可近似弯曲尾迹；不能令同一老火花反复摆动 |
| `rtFling`，m/s | 给火花切向初速；名义位移尺度约 F/k | 可控制螺旋幅度；过大可能撑宽尾束 |
| `rtSpinPh`，圈 | 改变起始相位 | 非零自转时改变起始波形；零自转时可能只有单侧偏移 |
| `rtLean`，度 | 改变整体弹道方向 | 不产生内部扰动，还会改变整体轨迹 |
| Cascade 整张面片的旋转 | 转动已经烘好的图像 | 不产生内部运动；整面 FanGold 已烘重力方向也会一起转 |
| 普通星 `shellSpin`，rad/s | 出生时加入玉体自旋切向速度 | 不是持续尾流作用 |
| 普通星 `flutter` | 直接改星头速度，还联动发光 | 容易破坏头稳定，不推荐用来补旧尾 |
| `spin`，rad/s | 蜂类专用的飞行转向 | 不能与 RT6 的 `rtSpin` 混用 |

代码：`tool/src/js/47_risetail.js:170`、`:179`、`:274`、`:314`；`20_sim.js:311`、`:389`、`:486`。整段合并渲染最终调用 `rtWorldDraw`，自转确实进入贴图，不是只给 Cascade 粒子字段使用。

RT6 火花出生后，相位固定；速度按阻力衰减并趋向该粒抽到的恒定小气流。**不同出生时刻组成的弯曲，不等于同一批老粒子持续来回摆动。** 这是自转近似的主要边界。

### 当前输出路径还有遗漏，不宜先增加新旋钮

- `rtTurbS` 在白热段与三档贴图火花中有效，当前为 0.35 m/s；按每粒稳定随机数取气流，缺少空间相关、时间演化。
- `rtTurb` / `rtTurbL` 的大涡用于原粒子发射器加速度曲线；当前合并贴图路径没有调用它。当前值 0.65 / 20 不能证明合并素材有这种大涡；`rtGpuSafe=1` 对原 GPU 分支另有禁用，但本次原因更直接：合并图的 `rtWorldDraw` 没有读大涡。
- 三档大小/亮度寿命曲线在 `rtEmitters` 路径接入，而 `rtTexClasses` / `rtWorldDraw` 使用自己的冷却、缩小规则，没有接入这些用户曲线。不能直接推荐用户调这些曲线并声称合并输出会改变。静态代码与数据探针均支持这个结论；尚未重新做像素开关实验。
- V5 旧尾缀已有 `trTwist/trTwistLag` 的波形与年龄渐入代码（`42_trail.js:33,52`），但不在 RT6 合并路径。说明仓库有可参考算法，并非完全没有；直接切回 V5 会改变输出和运动组织，不推荐。

只读探针：`analysis/scripts/cs3_motion_parameter_probe.mjs`；结果 `analysis/results/CS3_RT6/动态参数核对.json`。两款改变大涡参数后贴图火花抽样完全相同；改变小涡则不同；改变细火花两条寿命曲线后贴图粒子类数据相同。该证据是实际函数/源码核对，不冒充 GPU、UE 或美术验收。

## 2. 最小路线与取舍

| 顺序 / 候选 | 做什么 | 好处 | 缺点、影响与停止条件 |
|---|---|---|---|
| A：现有参数近似，优先 | CS 在试验副本启用低频 RT6 自转，适度增加甩出，保持头/弹道/时长；只用已经接入的三档寿命、阻力、数量、亮度及粗细随机 | 最小改动；不改底层、不添参数或引擎模块；合并输出已有支持 | 偏规则螺旋，旧尾不会持续回摆；幅度可能被随机散布淹没。若要求“停止喷射后仍有缓慢扭动”则本方案天然不够，不继续堆自转 |
| B：补齐既有参数的合并路径 | 三档寿命大小/亮度曲线与原粒子路径共用求值；明确大涡适用性，消除“界面可调但产物无响应” | 通常比新增八层更有收益；可先恢复不同粒子组的燃尽层次 | 需要渲染/导出一致性修复；开启曲线的旧配方可能改变，必须列出影响并重验。大涡接入须保持原单位/含义；不能顺手改成另一种风模型 |
| C：持续气流，仅在 A 不足时 | 一个通用空气速度场，按当前位置/当前时刻求值，通过阻力影响粒子；支持按粒子年龄渐强。先用已有少量平滑模式，暂不搬四维噪声/多级细节旋钮 | 可让旧粒子继续运动、近邻成缕，头部可保持不受扰；更接近 CS 原版动态机制 | 确定性积分/轨迹缓存与多渲染路径接线工作明显更多；烘焙成本增加。不是 FanGold 几何波的逐像素复制；需新增/改义参数时另作提案 |
| FanGold：并行但独立的问题 | 少量校准初速、阻力、寿命，核对展开/到顶/可见回落。若常系数平方阻力不能同时匹配早晚段，再复用已有线性阻力内核接主星 | 先解决形态骨架；不会用噪声掩盖轨迹错误 | 精确线性轨迹不能靠任意平方阻力参数保证。补能力时采用统一阻力求值和有单位的系数，避免“FanGold专用/旧版新版”开关；不改所有模板的默认阻力 |

推荐先 A，再只做 B 中有明确使用需求的接线。C 是第二阶段候选，不是必须建设的通用大系统。FanGold 先修减速/寿命，与 CS 的自转试样分开判断；不要因两者都叫“扭动”而强迫用一个假波形解决全部问题。

建议 A 的诊断试点（不是最终配方）：保持种子、出生率、弹道与颜色，转速先看约 0.5 与 1 转/秒两个低频档，甩出速度在当前 0.5 的基础上试 1 m/s，再看是否需要更多；不同时改随机散布，先判断连贯分量是否可见。精确保持现有 64 帧循环周期的测试值可用 0.46875 / 0.9375 转/秒；界面步进可能需直接数字输入，不能把这两个数包装成通用美术推荐。

细火花 k=7，甩出0.5的名义幅度只有0.071 m；Comet/Silver当前随机散布名义尺度分别约0.457 / 0.600 m。由此**推断**原本即使开自转，也可能被散布掩盖；尚无新回放证实，不能直接断言必须减散布或增幅度。头保持稳定与尾部成缕优先于“摆得明显”。

## 3. 哪些候选会冲突

保留：Cascade、现有材质、灰度 RGBA 序列、帧号取整、PC/手机、既定取景和检查标准；Comet红头独立、金尾近远段合并；FanGold保持整面扇形合并导出、不拆簇。用户认可的CS3原件和版本继续保留。

烘焙前增加轨迹丰富度本身不要求 UE 新材质/代码或增加发射器。若贴图尺寸、片数、面片覆盖不变，UE 播放的结构成本大体不变；但更宽的轨迹会扩大面片或降低有效像素密度，增加贴图/片数也会增加内存或 overdraw，不能保证“动态更丰富完全零成本”。

**直接新增“美术尾流振幅/波形/滞后”并宣称完全符合现规则，不成立。** `参数宪章.md` 要求物理量、引擎字段或预览设置，且禁止为拟合再加形状旋钮；有米这个单位不自动变成物理力。已有 V5 或 Blender 私有参数不自动授权新增。若真选几何波形，只能作为需要明确讨论规则例外的候选，本方案不优先选它。

通用受力/粒子年龄曲线可以按已有模块方向提案，但仍需核对每个入口、单位与适用范围，遵循参数变更记录和共享源码认领。不新增“旧/新物理”兼容按钮；离线已认可产物锁版本，改后另出候选。新增默认关闭能力的未启用路径应逐像素不变；修正既有非零参数的作用时，有变化的旧配方必须明列重新验收，不能同时承诺所有旧图不变。

同一灰度输出不能逐粒自由保存独立 RGB 冷却历史。借鉴原版各层冷却时先用独立亮度/寿命和既定 Ramp 能力，不以此为由新增颜色层；Comet已有红头/金尾分层保持。也不复制原版光晕、空间拉伸或长余烬取景的历史例外。

## 4. 影响结果的遗漏

1. **当前时间与出生时间是两件事。** 自转波在出生时赋值，连续风场在粒子活着时一直更新；纯相位、散布随机和明暗闪烁都不能互相替代。
2. **随机要有相关性和稳定ID。** 同条尾、邻近粒子共享缓慢变化，粒间另有小差异；每帧重新随机会抖。不能改一个风参数就重抽寿命和颜色。
3. **循环量化有联动。** 真代码测得64帧下，rtSpin从0变0.5会令内部循环周期2.133→4秒，变1则到3秒；出生率取整、随机编号周期和脉动也可能改变。全程合并贴图不是这个循环的直接播放，不能误称其导出fps变成16；应重算实际最终帧号与回放。A/B对照记录这些联动，隔离试验可用保持周期的值。
4. **粒龄与整束阶段不可混用。** 优先逐粒年龄渐强/独立燃尽；如果参考确有末期整束变化，再考虑阶段包络。不要让所有粒子同一秒变暗或共同摇摆，造成整体擦除/摆布片。
5. **停止发射后还要看。** 喷射螺旋最容易在升空时显得像，真正差异在头灭后0.3–1秒。长寿层要有足够采样时间，但不因增加余烬任意延长用户已认可节奏。
6. **空间与时间采样都有限。** 0.1m的摆动在整扇或远景可能不足一个像素。先用实际取景和游戏尺寸测可见位移；不能靠改相机/模糊/加曝光假装有动态。有效源帧率不足时提高频率会跳或倒转，30fps引擎不会补回序列缺掉的时间信息。
7. **坐标与合并边界。** 风应在同一模拟空间中作用，近远段同粒ID、同轨迹；不能先各自扰动再拼接。局部横向与世界重力分开处理；合成面片旋转不等于重算重力。
8. **原版也有取舍。** R15的长余烬曾扩大Silver取景、降低头部像素密度；八层是制作分工，不是本项目必须有八个UE层。优先复用现有三档粒子组，缺什么再补什么。

## 5. 验收方式（建议，不擅改现标准）

- 对照只改一个因素：现版 / 自转近似 / 必要时持续风场；同种子、同物理米制取景、同输出规格、同曝光和颜色。正式只交一个推荐候选，试样不覆盖认可版本。
- **结构**：Comet红头不左右漂，金尾不断；Silver头型与原有宽度/节奏保留；FanGold全扇角度和簇关系保持，外围出现与参考接近的减速与可见回落。
- **动态**：看正常速度、30fps按导出帧号回放，以及头灭前后连续片段；记录横向中心线/宽度随时间、单粒位移、主星竖直速度与存活时间。若只是整张摆动、重抽噪点、规则弹簧或整排同步熄灭，则不算提高还原。
- **有效性**：参数0/非0改变真实导出；细中粗曲线在预览和合并产物一致；近远段交界无断裂。抽3个固定种子避免只挑好看的随机结果。
- **工程**：同配方反复导出确定；未启用新能力的受影响基准逐像素回归；开启旧非零参数而改变的条目明确列出。PC/手机标准检查、实际贴图回放检查、打开→调参→保存→刷新→导出均过。保持现有硬约束和帧率/分辨率下限，不擅降门槛。
- **投入取舍**：记录烘焙耗时、面片覆盖和贴图数量。若在800–1200m、PC/手机实际回放中看不出收益，就停在较简单方案，不继续加噪声层级。
- Blender实际重算、新候选视觉通过及UE实播均未在本轮发生；浏览器回放通过也不能写成UE通过。


## 2026-10-14 · FanGold已授权能力落地（4.9.85）

用户确认补完末段分层/扰动后上传。普通火花/余烬复用原两类粒子，不增加粒群数或UE层数：按各自主星可见燃尽时刻渐入独立亮度/大小曲线、0.6m/s弱时空气流；主星和燃尽前保持，原FanGold1.0基础亮度/寿命/颜色不改。曲线横轴为燃尽后剩余寿命，不再混用停止发射时刻。散布、自旋、原tailDiffuse的全程作用保持；新增气流是后燃阶段的空气速度，经原阻力影响位置/速度，不是每帧随机挪点。

原Blender几何摆动仍不等于这套受力；本次不声称逐层或逐像素复制原Blender。正式候选FC6O整面合并、锚点Zoom；窗口按真实新尾部再测量。验证、耗时和审看见analysis/results/FG_Afterburn/看法.md；未UE实测。
