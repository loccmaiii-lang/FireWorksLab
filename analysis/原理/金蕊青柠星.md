## 结论：芯入り，两个模拟、四层

| | 外层（亲星，青柠星） | 芯（金蕊） |
| --- | --- | --- |
| 花型 | 分层星：先「引」（橙色木炭尾、星头暗）→ 无尾的柠绿光点（牡丹） | 金色木炭尾的小菊（尾很密，从芯心到星头一根根金丝），星头一圈粉红 |
| 点火 | 开花即点 | 开花后约 0.1–0.15 s 才看得到（+0.13 s 中心一团黄） |
| 颜色 | 橙尾 0–0.75 s → 星头 +0.35 s 起从暗亮起（淡暖白）→ +0.8 s 柠绿（黄绿，亮芯发白），亮度一直不减 | 过亮发白 +0.4–1.3 s → 金 +1.4 s → 橙 +1.9 s → 收完 +2.5 s；星头 +1.1 s 起在芯的外缘一圈**粉红点**（A 偏红、B 偏淡紫粉） |
| 尾 | 只有前段的橙引尾（+0.9 s 前后收完） | 金丝尾一直到 +2.0 s，之后越来越稀、+2.5 s 收完 |
| 熄灭 | +3.4 s 起陆续灭，+3.9 s 基本没了（亮点先变小变暗） | 星头 +2.2 s 前后灭，金丝尾 +2.6 s 前没了 |
| 半径 | 基准 | +0.3 s 约外层的 0.55，+1.3 s 起不再张大（约外层最终的 0.38） |

一个发射器只有一条颜色曲线：外层尾（橙）和星头（暖白 → 柠绿）颜色不同，芯的金丝尾和粉红星头颜色也不同，所以两个模拟各拆两层（同种子、同初速、同燃烧，星位重合；和青柠星 QN12、球形D 同一做法）。

## 物理（按实拍花径拟合）

- 外层花径（上半球 98% 分位，A / B 平均）随时间和最终的比：+0.27 / 0.53 / 0.8 / 1.27 / 1.8 / 2.33 / 3.0 / 3.4 s ≈ 0.26 / 0.46 / 0.57 / 0.73 / 0.83 / 0.91 / 0.96 / 0.99。二次阻力 + 重力拟合：初速 120–160 m/s、终端速度 18 m/s、重力 1 倍都在误差内（和青柠星 140 / 18.6 同一量级）→ 取 150 / 18，最终半径约 85 m。
- 芯（星头外缘）：+0.3 / 0.53 / 0.9 / 1.27 / 1.53 / 1.8 s ≈ 外层最终的 0.16 / 0.24 / 0.32 / 0.37 / 0.39 / 0.40 → 初速约 90 m/s、终端速度约 12 m/s。
- 外层光点数：+2.6 s 数到 470–520 个（有重叠）→ 520 颗。

## 药剂（按颜色推测，常见做法）

- 外层：分层星，外面一层木炭橙色引药（橙尾，约 0.6 s 烧完）→ 里面钡 + 钠的柠绿色光药（亮度稳定）。
- 芯：木炭金尾星（金蕊）；星头偏粉红，最可能是外面一层锶系红光药或带锶的点火药（实拍过曝发白，前 1 s 看不出星头颜色）。

## 和以前的记法有什么不同

`协作/花型配方总表.md`「金蕊青柠星」写的是：外层先橙带尾 0–0.6 s、约 3.1 s 一起熄灭，芯约外层 0.5。逐帧看：外层到 +3.4–3.9 s 才陆续灭（比青柠星那一发长 0.5 s），芯 0.5 只是开头，+1.3 s 以后约 0.38；芯是金丝尾 + 粉红星头两种颜色（以前没记）。

## 进引擎（四层，一个素材包）= 多层模板「金蕊柠」（`mt:kinzuiLime`，烘焙器 4.9.37 / 4.9.39）

数值以 `tool/src/js/18_multitypes.js` 为准（待验收条目 JQ5 由 `analysis/scripts/金蕊柠.py` 从模板生成）。两个模拟：外层 520 颗、初速 160 m/s、终端速度 18 m/s、重力 1、燃烧 3.8 s（离散 4%、末段 15% 淡出）；芯 300 颗、初速 130、终端速度 9.5、重力 0.5（很快停住、几乎不坠）、燃烧 2.15 s、+0.06 s 点火。

| 层 | 名字 | 结构 | 做法（现有花型 + 现有参数） |
| --- | --- | --- | --- |
| 1 | **橙引尾** | 外层 · 前段 | 牡丹，只画火花：每颗星每秒 900 粒、寿命 0.32 s、+0.55 s 停；星头压到 0.02；亮橙（偏黄）、暖色渐变图；这一层的星活到 1.0 s 就够 |

| 3 | **金菊蕊** | 芯 · 金丝尾 | 菊：每秒 300 粒、寿命 1.0 s、几乎不跟星走（继承 0.05）→ 芯星停下来以后从芯心到星头一根根金丝；+1.2 s 前白（显示强度 5.5，过亮）→ 金 → 橙；火花 +1.7 s 停、越到后面越稀 |

和实拍同一秒（本机导出 JQ4E1 / JQ5E1 的烘焙回放）：花径模拟 / 实拍 0.98–1.04；芯 / 外层 +2.0 s 0.41（实拍 0.42）；粉红点 +1.2 s 清楚、+2.0 s 淡；外层 +2.8 / 3.6 s 光点亮度、稀疏接近。
还差：+1.2 s 实拍芯是一大团过曝的白（相机），导出里是很亮的淡金丝；实拍光点有相机光晕、看起来更大。没在 UE 4.24 里导入过。

名字的规矩：**颜色 + 造型 + 结构位置**（橙 / 柠 / 金 / 红；引尾 / 点 / 菊 / 点；尾 = 引的尾、星 = 亲星、蕊 = 芯）。整个模板叫 **金蕊柠**（金色的芯 + 柠绿的外层）。

## 烘焙器缺的能力

无。四层都是现有花型（牡丹 / 菊）+ 现有参数（火花停、星头亮度随寿命、延时点火、多段颜色）。
