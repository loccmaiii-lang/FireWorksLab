# 兔子点阵烟花

参考是一张静图。右侧已经给出了灯点落位、遮挡和分色，直接从这一侧取亮峰，比沿左侧线稿重新布点更贴近参考。在金棒和青色装饰上，灯芯接近白，外围颜色更明显。点心、半高宽、三组取色和提取方法保存在本次样例的 shared 目录。

用户本轮指定以烘焙器的「型物 → 心形」为开花基准。烘焙器沿心形轮廓等弧长布星，轮廓点的极角决定速度方向，距中心的半径乘以基准初速 110 m/s。默认加 0.4° 方向离散和 1% 速度离散。所有星从同一点起飞，每 1/480 秒计算二次阻力、重力和新位置。实看默认心形，在 0.10 秒已经能看到小心形，随星距拉开，光点逐渐分离。[心形配方](../../tool/src/js/10_types.js) · [轮廓采样、发射和物理步进](../../tool/src/js/20_sim.js)

兔形使用同一个 `Sim`。为了让两根灯棒和耳尖在 1.60 秒准确落在附件位置，先用同一模拟器试射，校准点火前的 476 个二维发射参数。正式采样从同一个爆心出发，初速只设一次，使用固定正面投影。以各自 1.60 秒的高度为 100%，0.20 秒原心形和兔形分别为 27.4% 与 29.3%，0.60 秒分别为 60.1% 与 61.5%。第 48–67 帧停形，第 68 帧起沿用原散落，第 109 帧余火归零。[原模拟调用与心形对照](../results/20261124_点阵烟花/shared/sample_kata.cjs)

此前本机“兔2开花”导出的同色点心与本次附件高度吻合。沿用那份样例的 200 米兔高统一两条路线，方形取景边长约 236.14 米。按项目标定，1080p、1000 米时兔形约高 92 像素，典型相邻点心相距约 1.78 像素。灯点的间隙、场景抗锯齿、Bloom 与观察距离共同决定辨识度。

序列将三组点的运动采样到固定取景的灰度图集，配色用各层 Ramp。VAT 将同一批点的逐帧位置、大小、颜色和强度写入数据纹理，通过网格查找 UV 还原。制作步骤、真实读回数值及验证边界见 [双路线评估](../results/20261124_点阵烟花/看法.md)。
