# 兔子点阵烟花

参考是一张静图。右侧已经给出了灯点落位、遮挡和分色，直接从这一侧取亮峰，比沿左侧线稿重新布点更贴近参考。在金棒和青色装饰上，灯芯接近白，外围颜色更明显。点心、半高宽、三组取色和提取方法保存在本次样例的 shared 目录。

用户选定先见一簇星点向外绽开，展开途中才读出兔形。476 颗星从同一爆心出发，每颗沿直线朝自己的参考点飞行。起初的飞行距离主要由各星的初速决定，星点自然铺成一簇。随后同一半径上的进度逐渐一致，内圈先走完较大比例的路程，中央点距被撑开，外圈继续向外追上。这种径向映射提供临时的鱼眼放大感，机位和视角固定。第 48–67 帧停在原参考图形，第 68–89 帧逐点散落，第 90–109 帧余火渐灭。

此前本机“兔2开花”导出的同色点心与本次附件高度吻合。沿用那份样例的 200 米兔高统一两条路线，方形取景边长约 236.14 米。按项目标定，1080p、1000 米时兔形约高 92 像素，典型相邻点心相距约 1.78 像素。灯点的间隙、场景抗锯齿、Bloom 与观察距离共同决定辨识度。

序列将三组点的运动采样到固定取景的灰度图集，配色用各层 Ramp。VAT 将同一批点的逐帧位置、大小、颜色和强度写入数据纹理，通过网格查找 UV 还原。制作步骤、真实读回数值及验证边界见 [双路线评估](../results/20261124_点阵烟花/看法.md)。
