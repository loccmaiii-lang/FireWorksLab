## 结论：芯入り变色牡丹，两层（芯 + 外层），外层是延时点火

花型库模板：**牡丹**（芯）+ **牡丹**（外层，带短尾）。之前 QC1–QC3 只做了外层，而且外层的颜色时间线也不对（缺了开头的银白段）。

| | 芯（内层） | 外层 |
| --- | --- | --- |
| 大小 | 最终半径约为外层的 0.45 | 基准 |
| 开头 | +0.07–0.25 s **橙红短放射尾**（点火药），+0.25–0.4 s 整团很亮（过曝发白） | **开花时是暗的**：+0.4 s 才点亮（延时点火） |
| 颜色 | 过亮 → **青柠绿**（+0.4 起）→ 慢慢变暗 | **银白（微带淡紫）+ 短尾**（+0.4–1.1）→ **金 + 短尾**（+1.1–1.7）→ **橙**，尾巴变短（+1.7–2.3）→ **橙色光点，无尾**（+2.4 起） |
| 尾 | 只有开头 0.2 s | +0.4–2.3 s 有短放射尾（银 → 金），之后无尾 |
| 熄灭 | +1.8 开始变暗，+2.2 前后没了（逐渐暗掉） | **陆续熄灭**：+2.4 开始一颗颗灭，到 +4.5 还有零星几颗 |

## 药剂（按颜色推测）

- 芯：钡系绿 + 少量钠 → 青柠；外面包橙红点火药。
- 外层：外面一层黑药（点着了但不发光，所以开花时看不到）→ 银白（镁铝，带出银色短火花）→ 金（木炭）→ 橙（钙 / 钠，无尾）。
- 陆续熄灭：外层星大小不一（燃烧时长离散大）。

## 烘焙器里怎么做

1. **芯**（YC1，牡丹）：颜色 橙红 → 白 → 青柠绿；火花只在前 0.25 s（`sparkStop`）；燃烧约 2.0 s，末段渐暗（`fade`）。
2. **外层**（YC2，牡丹）：**延时点火 0.4 s**（`ignDelay`，离散小）；颜色 银白 → 金（+1.4）→ 橙（+2.3）（比肉眼看到的时刻晚一点：实拍 +1.1–2.2 是暖金白、带高光，云端对照按这个时刻更像）；火花 0–1.9 s（按点火后算），尾长短；燃烧离散大（约 25%）→ 陆续熄灭。
外层的星头和尾巴每个时刻颜色一样，一个图层就够。
