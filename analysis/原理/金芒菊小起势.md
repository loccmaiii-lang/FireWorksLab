# 金芒菊：小起势、快速展开、爆后轻扰动

目标是新的候选，旧金芒菊保持原样。库内 JM4 系列从52m半径开始，因此直接出现大花盘；额外叠加引菊不会自动修掉这个初态。优先降低起始半径并提高初速，依靠既有二次阻力快速减速，让同一批星先形成短引，再成为金芒。花径和完整时长用模拟测量校正，不将初速估算当作定稿。

一层统一轨迹：暖金短引 → 金芒成菊 → 火花冷却淡出；颜色沿用金芒菊的灰度序列与Ramp，星头/火花仍同色。无需新材质，不用第二批无关星遮住第一批的跳变。快速前段需要足够帧密度，贴图张数与真实30fps帧账本须验证，不能只凭平均fps说不卡顿。

爆后轻扰动复用 Comet/Silver 的连续气流：风速随位置与时间平滑变化，粒子在阻力下逐渐跟流；同一空间场让邻近尾迹有相关弯曲，避免逐帧随机抖点。新增一个默认关闭的控制及开始时间/渐入/速度/尺度，作用于当前模拟各束的主星与火花；原有燃尽后气流及曲线含义不变。该场是美术可控速度场，不称流体求解。

实现选择：扰动烘入已有序列，UE继续按原Cascade材质播放，最终运行时不额外计算场。优先保持一张PC主序列及一张手机主序列；导出实际数量和帧率以检查报告为准。此处全局指当前模拟的全部星束；如果用户指UE运行时实时开关，固定序列无法改变内部已烘轨迹，须另评估现有粒子模块的可表达范围。

验收：首个可见星束明显小于旧版、前段连续展开、主体花径/金芒形态及完整消散保留；开关前段不变、后段出现弱且连续的相关扰动；PC/手机回放无暗帧/裁边/过曝，帧密度与游戏尺寸满足标准；最后由用户审美与UE实播确认。
