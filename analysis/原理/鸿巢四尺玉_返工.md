## 2. 首轮为什么像两颗球（找到的具体原因）

1. **红点不在主层星的位置上**：首轮红点层用「延时点火」，而延时点火的离散会多消耗一个随机数，后面每颗星的速度都和主层错开——红点层其实是另一颗独立的球，所以 70% 时在球壳上排成一圈。
2. **尾迹只有一种火花**：同一组参数没法同时做「短而亮的白热段」和「长而暗的褐色线」，拟合只能折中成中等长度的暖色糊。
3. 初速 260 偏小（前 1 s 太小），燃烧、终端速度都被拟合往「圆」拉。

## 3. 补的能力（烘焙器，默认关，旧配方逐像素不变）

| 能力 | 参数 | 用在这里 |
| --- | --- | --- |
| 第二段燃烧：主段烧完后同一颗星接着亮（主段期间不发光、轨迹与主层完全一致） | `afterBurn`、`afterJit` | 红点灭：每颗红点在**它自己那颗锦冠星**烧完的时刻亮起 |
| 只让一部分星发光（按星编号取，不动随机序列） | `keepFrac` | 红点只占约 1/4 |
| 双组分尾：普通火花（白热短段）+ 一部分寿命长、亮度低的余烬，亮度可跟着母星熄灭而淡掉 | `emberFrac`、`emberLife`、`emberBright`、`emberFollow`、`emberSize` | 锦冠的白热段 + 褐色长线 |

验证：红点层和主层用同一个种子时，同一颗星的位置差为 **0 m**（365 颗在飞的星逐一比较）；红点的点亮时刻分布在 6.7–8.4 s，就是各自那颗锦冠星的燃烧结束时刻。

**仍未解决的差异**

1. 顶部轮廓：实拍伞顶更平、钩更宽，顶端回落更慢（+7.6 s 模拟上缘 227 m，实拍 261 像素）；模拟顶部中间略尖（上抛星的速度分布 / 燃烧减质量的细节）。
2. 亮度 / 过曝：实拍相机过曝，白热段更粗更亮；模拟偏细。这是拟合里的亮度、颗粒大小、相机模糊 / 曝光。
3. 红点起始略早（模拟 +7.6 s 就有零星红点，实拍约 +8.0 s）：燃烧时长 ±0.3 s 的量，拟合调。
4. 红点光晕：实拍光晕更大（镜头泛光），引擎里用粒子尺寸 + 材质亮度表现。
5. 中心橙红团没有做（有意）。

## 7. 物理 / 化学印证

- **锦冠 = 负氧平衡的木炭星 + 钛**：木炭烧不完，被甩到星后面在空气里继续烧 → 长而暗的褐金色余烬（持续数秒）；钛粉烧得快、温度高 → 星头后面短而亮的白热段。两种颗粒燃烧时间不同，正对应实拍的两种尾迹组分（白热段约 0.6–1.2 s，暗长线数秒）。
- **燃烧时间是普通菊的 2–3 倍**：锦冠星燃烧约 7.9 s；号数表里 40 号普通菊约 5.2 s、10 号约 2.8 s。
- **伞形不需要额外的「下垂」参数**：二次阻力 + 重力就够。上方的星先减速到零再慢慢加速下落，下方的星一直以终端速度下落，所以下缘拉长、顶部基本不动（实测下缘 35 像素 / 秒 ≈ 终端速度 34 m/s）。
- **红点灭 = 同一颗星的内芯**（分层星：外层锦冠药，内层锶红点灭药）：所以在各自的锦冠段烧完时接着亮、位置接在星头上。点灭是镁在暗反应 / 亮反应之间循环，红色一个周期约 0.3 s（文献），实测 3.3 次 / 秒。只有约 1/4 的星有红芯（装填时混装）。
- **中心橙红团**：不随星运动、边缘发虚，是受光的烟和开花残骸，不是燃烧中的芯。
