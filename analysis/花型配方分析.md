# 花型的「配方分析」：先把实拍拆成化学结构和物理量，再交给拟合（2026-09-29）

> 起因：用户指出青柠星这类简单效果做得一般，没有对参考视频做仔细的配方分析。之前的做法是「给个起点，让自动逼近调十几个参数」，
> 拟合只会在错的结构里找最不坏的数（比如把星数压到实拍的一半、用火花线性减少去凑「后半段没尾巴」、用相机模糊凑光晕）。
> 以后每个效果都先做这一步：结构和能直接量的量由分析定死，拟合只调亮度、大小这些量不准的。

## 方法

1. `analysis/scripts/star_analysis.py <视频> --roi … --t0 … --t1 …`：逐帧检测星头，得到
   星数 N(t)、半径 R(t)（横向跨度，避开升空尾迹）、外圈占比（薄球壳 ≈ 0.6，实心球 ≈ 0.36）、每颗星拖的亮像素（有没有火花尾）、
   星头亮度、星头 / 尾巴颜色随时间、熄灭时刻分布（N 掉到 50% / 10%）、爆点下坠。输出 `analysis/replica/分析/<视频名>/分析.json + 分析.jpg`。
2. `analysis/scripts/star_colors.py`：按时间窗测星的发光颜色——先转线性光再扣天空，只取星头周围一圈没过曝的像素（过曝的芯是白的，不代表颜色）。
3. 看逐帧原图，把时间线翻译成化学结构：分层星（外层 / 内层各是什么火药）、有没有木炭火花尾、什么时候变色、是一起熄灭还是陆续熄灭。
4. 烘焙器缺的结构先补（这次加了 `sparkStop`：分层星的外层带木炭火花尾，烧完火花就停，内层只发光）。
5. 起点按分析定死：初速 / 终端速度（按对照量法的半径曲线拟合）、燃烧时长和离散、颜色分段（线性光测得）、火花停止时刻；
   拟合只放开：星数（有上下限，按检出数 × 0.9–1.6）、星头大小亮度、火花亮度寿命、相机曝光（模糊上限 0.4）。
6. 云端先用 compare.py 跑一次起点，确认结构对了（10% / 50% / 90% 三个时刻一眼能看出来），再下发任务。
