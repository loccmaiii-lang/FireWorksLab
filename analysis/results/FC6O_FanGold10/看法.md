# FanGold1.0：燃尽后扰动测试与首选方案

状态：参数复制、隔离实验和实际贴图回放已执行；视觉收益有限，标准检查未全过，未作为新能力入库、未获用户验收、未经 UE 实播。实验冻结在 4.9.79；已保留云端更新、同步正式烘焙器 4.9.80，没有改 tool/src 或 Comet/Silver。

同步补验：4.9.80重新从真实入口导出FC6O，P/M仍逐字段相同，5张PNG与冻结基线逐字节一致；PC/手机cascade除来源/整理元信息外相同。证据`同步4.9.80核对.json`。这不代表后来仍在制作的带锚点Zoom已经通过验证。

## 结论先说

首选候选是**尾部粒子在各自主星燃尽后，渐入小幅、空间相关的时变气流**。亮头仍走原轨迹；不靠自旋改变喷射形状，不延长寿命，不调亮。它能符合当前 Cascade / 灰度 RGBA / 单条颜色曲线 / 整面合并输出约束。

但这次实测只证明了“可保留前段并令旧尾继续运动”，**没有证明值得立即加入生产**。你保存的 FanGold1.0 退亮很快，0.6 m/s 的候选只带来轻微尾线偏移。全扇正常速度观看收益很小；不建议为了把差异做明显而偷偷加寿命、加曝光或加大散布。本次交一个推荐对照（原参数 / 各自主星燃尽后气流），先不继续堆噪声层或控制项。

打开同目录 `对照回放.html`，可以正常速度、慢放、拖时间，切 PC / 手机。数据来自真实 `__fw.exportFiles` 输出的贴图与 cascade 曲线，按30fps取整；不是另画的烟花动画。48m固定视野用于细节对照，不是1000m游戏大小。上/左是你的原参数，下/右是隔离试验。

## 原版究竟是什么

| 来源 | 代码里实际做的事 | “开始直、后面扰动”的原因 |
|---|---|---|
| Blender FanGold V04 | `production/fan_gold_motion_v04.py` 在原轨迹上叠连续尾流位移，按 root_id 组织相邻粒子，按尾龄保护近头段；不是流体求解 | 新尾偏移小，旧尾波形逐渐显现；属于制作上的几何变形，不能等同于持续受力 |
| Blender Comet/Silver R12，经 `fan_stationary_r10/nodes.py` | 在当前位置/当前时间以及RK2中点重新采样4D噪声气流；有粒龄强度曲线和阶段包络，头部不使用同样的扰流 | 出生速度先占主导，阻力使粒子减速，气流逐渐占主导；代码的年龄/阶段渐入又强化了前直后活 |
| 当前烘焙器 FC6O | GPU普通火花从出生点/出生时刻取空气速度，随后沿解析/平方阻力路径求值；`tailDiffuse`另加随粒龄增长的位置偏移，方向来自出生点场及每粒固定随机 | 可以越来越散，但不等于旧粒子持续穿过时变风场；也没有只等所属主星燃尽后才启用的控制 |
| 当前 RT6 自旋/角偏移 | 自旋改变不同出生时刻的喷射相位和初速；角偏移改变方向/相位 | 能近似螺旋尾形，不能让已经喷出的同一颗旧粒子继续扭动。FC6O不是RT6，不能把RT6旋钮直接套在此条 |

依据沿用已完成的 `../FC6O_Blender/扰动与物理对照.md` 和 `../../原理/CometSilver与FanGold_动态还原候选.md`；本轮再次核对了上述 Blender 源码。参考的“尾龄渐强”并不等于本轮确认的“主星燃尽后才渐入”，二者必须区分。本次是在你的约束下选取其中有用的机制，不声称逐项复制原版。

重力是下落加速度，不会自动制造蛇形横摆。这份保存参数的主星重力为1.4715m/s²，火花为2.4525m/s²；线性阻力5.5/s、平方阻力0.77/m都保留。此前报告对旧FC6O的0.6867m/s²及顶点时间不适用于这份新参数。加末段风不会解决“亮头在燃尽前没有下坠”的问题，本轮也不改主星物理。

## 验证与限制

`验证汇总.json`记录参数、图像和两平台结果；`页面操作核对.json`记录真实FC6O打开、调参、保存副本、刷新及重新打开，另验证对照页播放/暂停/手机切换；测试在空白浏览器资料里完成，未连接用户的配方目录。

- 关闭新增气流：8个关键时刻的图像逐像素相同。
- 全扇延后方案：0.5/1/1.5s逐像素相同。2.0s附近快门窗口跨越2.018s起点，出现63个通道值相差1级，不能谎称这一整帧完全在扰动之前。
- 各自主星起点：0.5s逐像素相同；1s已有少数早燃尽尾巴参与，整帧不再要求相同。主星渲染代码及参数未修改，新增分支仅在`uT > inf.y`时执行。还未做生产级全部条目回归。
- 积分步数64→128：8个时刻RGB最大差1/255，整幅平均差最大0.000232/255；足以支持这个小样的视觉稳定性，不能代替所有配方的精度保证。
- PC和手机各1发射器、1张序列、64帧；PC512格、手机256格。原有回放期约3.167s，未延长。试验ZIP与原基线均约1.96MB，当前输出结构成本没有增加；以后若扰动撑宽取景/增加贴图片数，成本会变。
- **原基线及试验都未全过检查**：标准检查屏幕放大1.07；PC中心跳变3.17px，手机3.44px（均换算512格，上限3）；手机原基线另有末尾空帧1。原样复制与追求正式交付是两回事。本轮不擅自改原参数去过线，也不放宽标准，不列为新增待验收成品。
- 实际回放审看：1–2s末段线条略有偏移，整面差别小，手机更难辨认。2.6s后非常暗。放大或慢放可帮助定位差异，不能算正常游戏观看的收益。
- 以当前默认游戏相机780m四尺玉基准，1080p/1000m约0.462px/m。亚米级末段位移在这个远景条件下通常不足1px，预计收益进一步下降；这是尺度换算推断，未作UE实测。

## 如果以后入库，怎么控制

先按受力模块的通用气流能力讨论，不做FanGold专用摆动分支。生产默认0，未启用路径应逐像素不变；修正现有非零扰动路径时需明列哪些旧配方会变。不能一面改旧模型一面承诺所有旧画面不变。

| 候选控制 | 建议首轮起点 | 调大意味着什么 / 取舍 |
|---|---|---|
| 空气速度强度，m/s | 0关闭；本次试0.6 | 旧尾被带走更多；过大会散开、改变宽度、占用更多像素范围 |
| 燃尽后延迟，s | 0，限定非负 | 更晚才动；代价是剩余可见时间更短 |
| 渐入时间，s | 0.4 | 越长越柔和，但短尾可能在显现前已暗掉 |

空间尺度/变化速度先沿用通用场配置，不新堆一套效果专属旋钮。若正式实现需要暴露之前写死的物理数值，按现有参数宪章统一命名、单位和模块，不把试验常量当正式推荐默认。已有“尾迹扩散”不应与新模型无限叠加成为两个含义重复的滑杆；正式整合方式还需确认，当前没有改它的含义。

**本次必须做**：复制原参数、保留原件、核对机制、燃尽后隔离测试、真实两平台回放、报告不通过项——已做。

**可后做**：先处理FC6O正式交付的取景/空帧问题；若局部扰动值得保留，再认领源码、确定通用参数、补预览/烘焙/RT6合并路径一致性、确定性与未启用回归。要明显增强消散，还可能需要重新讨论可见余尾时长；这不是本轮已确认的要求，不自行实施。

**暂不建议做**：完整流体、多个叠加噪声层、几何波形专属旋钮、通过加曝光或延寿伪造收益、拆簇导出、改UE材质或给每束增加引擎发射器。

最终验收仍看同种子/同取景/同曝光的真实贴图正常30fps回放：前段和亮头不变、燃尽后的尾巴连贯变化、不整排同步摇摆、不出现散点爆开，PC/手机检查通过且目标观看距离能看出值得保留的改善。当前尚不满足最后两项。
