# 复现说明

本次试验基于4ebfd2ea、烘焙器4.9.79及本目录的完整原参数。生产共享源码没有修改。`FC6O_隔离试验.html`是实验用完整烘焙器内核，复用仓库tool/data目录的条目；选择FC6O看同一参数。它不是正式发布入口，新增气流值仅为测试常量，不要覆盖正式HTML。

`对照回放.html`已经自含当时实际导出图像，不依赖后续条目/源码变更。baseline.zip和perstar.zip为当时内部测试包（未通过全部标准，不能当正式素材验收）。

生成器、浏览器渲染、原生Sim探针及回放检查脚本保存在analysis/scripts/fangold10_*。运行浏览器脚本前用仓库ProcessLock/gpu_lock_path占用同一GPU锁，Node需能加载playwright，Edge使用D3D11。脚本中的analysis/local/CS3-FanGold10是临时目录；它们必须在上述构建版本或明确记录的新版本运行。完整复算顺序：probe → trial生成器 → render baseline/trial/perstar（全导出）、fine/zero（stills）→ 标准检查FC6O → check → ui。原参数复制和生成条目的改动已在本提交，不再反复覆盖用户配方。

试验采用固定确定性场与原随机种子；没有拿零参数方案改变前段。浏览器交互验证使用空白资料，不连接用户目录。
