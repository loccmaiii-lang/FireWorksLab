## 3. 推算：整场每 0.1 s 叠了几层（推算.py）

方法：封板导演表 + T22 读回的每个发射器面片大小 / 延迟 / 寿命 + 本次读回的机位（视场角按编辑器默认 90° 推断）；花本体按正方形朝相机面片投到画面，Zoom 取景按最大面片（偏大），尾缀不算。两个量：
- **面积和**：所有面片面积加起来 ÷ 画面面积（≈ 平均叠了几层，最接近半透明开销）；
- **大面片最多叠几层**：只算 ≥ 60 m 的花本体面片，画面上某一格最多被几张盖住。

和实测对照（PC 高配 7 个时刻）：面积和 0 / 0.09 / 0.87 / 1.2 / 1.07 / 1.61 / 3.23 对 AfterDOF 0.08 / 0.09 / 0.13 / 0.16 / 0.20 / 0.26 / 0.50 ms，大致是 **ms ≈ 0.08 + 0.13 × 面积和**（7 个点的粗拟合，推断）。

| 档 | 面积和最高（时刻） | 大面片最多叠层（时刻） | 其它高点（面积和） |
|---|---|---|---|
| PC 高 | **4.70 @ 165.5 s**（叠层：金芒菊·大 + 中号 + 多重菊·大） | 13 @ 126.5 / 132.7 / 165.5 / 187.9 s | 123.2 s 3.98、59.0 s 3.71、132.9 s 3.58、65.2 s 3.56、185.0 s 3.36 |
| PC 中 | **4.18 @ 165.7 s** | 11 @ 59.1 / 166.4 / 184.9 s | 59.0 s 3.46、132.9 s 2.96、185.0 s 2.88 |
| PC 低 | **2.65 @ 58.7 s**（高潮 I） | 10 @ 194.4 s（白墙 9 点） | 165.7 s 2.64、194.7 s 2.51、132.9 s 2.39 |

- 按上面的粗拟合，PC 高配 165.5 s 在这台 5080 上约 0.7 ms（外推，没测到）。
- 多重菊·大（大型_D）每朵两层 301 m 闪光面片 × 1.41 / 1.53，是 162–166 s 这一峰的主要来源（T22 读回的面片尺寸）；要压峰，先看它。
- 低配的叠层最高在收尾白墙（194.4 s，10 层），面积和最高在高潮 I（58.7 s）。
