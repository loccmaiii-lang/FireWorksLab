## 三档共同问题（TR3 相对 TR2）
- **长度修好了**：小 / 中 / 大 = 21.7 / 42.4 / 94.0 m（目标 20 / 40 / 90；TR2 是 32.9 / 57.8 / 129.1）。造型差距 3.70/1.58/3.82 → 1.11/0.88/0.81。
- **颜色仍不像**：渐变图四个色标都接近奶白（例：中档 #ffe59b → #fff8ec）。实拍尾缀C/B/A 下半段是饱和的橙色、一团团的，模拟整条是均匀的米黄。
  - 我的猜测：渐变图同时要对尾缀3.0_A（近景，黄白、过曝）的质感颜色和远景尾缀C/B/A 的颜色，两个目标打架，折中成了奶白。建议颜色只对远景（输出是平视远景），3.0_A 只管颗粒和亮点密度。
- **下半段仍是「均匀的雾」**：实拍下半段是分散的、成团的橙色火星，中间有空隙；模拟是连续的细颗粒带，没有成团、没有空隙。
- **质感对照（尾缀3.0_A）**：实拍上段是很宽的过曝白芯 + 大颗带短拖线的亮火星；模拟是细亮线 + 细碎颗粒。宽白芯部分可能是仰拍透视（近处放大），但「大颗、带拖线、成团」是和透视无关的，模拟没学到。
- 火星确实比 TR2 大了一些（小图里能看出一颗颗的点），但离实拍的颗粒感还差得远。
- 建议：颜色只对远景 + 加「成团程度 / 空隙」测量（和 WC2 计划里的成团测量可以共用）。
