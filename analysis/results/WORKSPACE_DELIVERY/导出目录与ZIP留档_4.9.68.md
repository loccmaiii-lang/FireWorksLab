# 导出目录与 ZIP 留档 · 4.9.68

用户要求：保存路径可选可改，默认 `D:\ProjectTextures\FireWorksLab`；按大中小、平台与尾缀分类；每次导出保存递增 ZIP 版本。

## 当前实现

“资源交付 → 资源目录与版本 → 资源导出目录”可填写绝对路径，或选择目录后保存。Windows 未配置根时默认用户给定的 D 盘路径，已有自定义设置优先。本机当前配置已保存为该 D 盘路径，稳定配置存用户目录，旧联调配置已备份。导出及原导入执行期间禁用改根，结束后恢复。

新目录示例：

```text
D:\ProjectTextures\FireWorksLab\
  尾缀\中\RiseTrail_M\
    revisions\<原生内容修订>\
      PC\cascade.json + 引用贴图
      手机\cascade_mobile.json + 引用贴图
      资料\原配方、命名对照等
      workspace-resource.json
      workspace-thumbnail.png
    ZIP\RiseTrail_M_PC-Mobile_v001.zip
        RiseTrail_M_PC-Mobile_v002.zip
```

类别来自真实类型：纯升空尾缀归尾缀，混合组合归烟花。尺寸来自有效大中小规格；未使用有效规格时，明确的尾缀 S/M/L 档位可作为尺寸来源。普通花型没有明确档位则归未分类，不用名称或任意缩放倍率猜测。平台由实际配置识别，不生成包中没有的平台。

PC/手机各保留独立配置与完整引用贴图；共用贴图在各平台放副本，以保持原导入器禁止跨目录引用的保护。原配置、贴图和原 ZIP 字节不变；序号仅进入留档 ZIP 文件名，不进入 UE 资产名。相同原生内容仍使用同一 revisionId，但每次成功目录导出产生新的 ZIP 序号。序号按同一根内同英文包名递增；已有同序号文件也会避让，不覆盖用户文件。

ZIP 写入后读回 SHA256，使用不覆盖的原子发布。ZIP 记录或资源索引失败时回滚本次新 ZIP/新修订，保留旧资源。便携的“下载 ZIP”保持原出口；本次递增留档属于“指定目录”出口。
