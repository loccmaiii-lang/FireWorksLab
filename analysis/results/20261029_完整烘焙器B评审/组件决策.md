# 完整烘焙器 B 布局 · 组件与交互决策

用户已授权把本轮布局接入完整烘焙器，供真实保存、烘焙与导出测试，并明确保留旧入口。本页记录选用原则与项目适配判断；实现、运行验证和用户认可分别记录，验证结论由本轮主报告补充。

## 1. 截图中的“选框”是什么

- 层名整行高亮是 **Tree view item 的选中状态**；行内眼睛是独立的开关动作。它们不等于复选框。
- “外形／运动／光色／输出”是 **二级 Tabs 标签页**：选择同层级的一组参数内容，语义为 `tablist / tab / tabpanel`，保留方向键、焦点与选中区别。
- “仅改动／英文名”属于参数显示或筛选选项；用 checkbox 或独立按下按钮表达布尔状态，不伪装成互斥页签。

依据：[Material Tabs](https://github.com/material-components/material-web/blob/main/docs/components/tabs.md)、[WAI Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)。Adobe 现行 [Segmented control](https://spectrum.adobe.com/fragments/components/segmented-control/usage-guidelines) 面向同内容的视图切换，不能据其外形把倍率参数、命令和导航全部改为分段控件。

## 2. a／b：结构、类型图标和显示／只看

结构区使用一个文字标题，删除标题前的装饰性图标；节点只有在表示真实对象类型时才使用统一、简洁的类型图标，同级同类型不混用不同装饰。树的展开箭头、缩进与层名承担主要层级表达，眼睛列位置固定。

Adobe 的树视图将上下文、节点名称与行操作分区；类型图标并非每个标题的必选项。Photoshop 的眼睛控制图层可见性，但本项目已定义眼睛影响配方与输出、只看仅改变观察，因此不能复制 Photoshop 快捷操作后混淆这两种语义。“只看”收口到预览区的观察入口；树头不再混排“显示／只看”的无操作说明。“收为路径”若保留，改成明确的结构收起动作，并与参数对象路径分开。

依据：[Spectrum Tree view](https://spectrum.adobe.com/page/tree-view/)、[Photoshop Layers panel](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/get-started-layers/work-with-the-layers-panel.html)。以上为项目适配，不是 Adobe 要求本项目使用眼睛表示导出。

## 3. c：当前编辑、仅改动、英文名

保留一行精简的当前对象上下文，避免树选中、完整身份卡、当前编辑路径重复占高；树滚走或收起时，仍能知道正在修改谁。“仅改动／英文名”移入单层的“参数显示”菜单，启用时保留可清除的短状态；过滤后的范围、结果数及无结果提示不能一起藏掉。

这些具体选项没有必须常驻的品牌规范。收起低频选项是本项目判断，不能以“简洁”为由删除筛选或诊断能力；参数当前无效的原因、输入错误和必要状态继续就地显示。Fluent 明确区分必要帮助与补充说明，并提醒避免堆积大量信息按钮。

依据：[Fluent Info label](https://fluent2.microsoft.design/components/web/react/core/infolabel/usage/)。

## 4. d：参数行中的“× ↺ 锁 ?”

“×”是单位，只有后三项是动作。下一版固定“名称—滑杆—数值＋单位”的阅读顺序，将单位作为不获取焦点的文本，避免视觉上像第4枚按钮。恢复仅在参数已改时明确呈现；不把常用调参藏入菜单，次要动作按实际用途组织。

正式代码的锁用于 **切换号数、随机微调时排除该参数**，不是禁止手动编辑；不得用 `readonly` 或整层锁代替。现有 `tool/src/js/70_ui.js` 的 `state.locks`、行锁提示与随机微调逻辑保留这一含义。参数帮助复用现有 **点击参数名／F1 打开固定说明区、Esc关闭** 的能力；不再为同一个说明每行重复一枚问号。已锁、已改、错误及当前条件无效仍需可辨。

[Spectrum Slider](https://spectrum.adobe.com/web/rsp/components/slider) 将标签、轨道、把手、精确值与单位分开处理，支持与精确输入配合；它没有要求每行并排放恢复、锁定、帮助。行操作的收敛方式是本项目判断。

## 5. e：节奏倍率与高级选项

先按正式功能确认倍率的作用对象。若它是节奏单值快选，使用有名称的“节奏预设”选择器，精确倍率仍可输入；若某项会批量应用参数，则写明动作范围，不伪装成只改一个值。0.8×、1.25×、1.5×等快捷值进入同一选择器，不维持一整排同等强调按钮。高级调整留在明确命名的 details 中，保留摘要及已改提示。

Apple 的 Pop-up button 用于互斥选项，适合无需常驻展示全部选项的场景；“快捷值放入选择器、精确值保留、进阶按需展开”是本项目对该原则的适配，而非品牌规定了这些倍率。

依据：[Apple Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)。

## 6. 主题绿滑杆

保留细轨与清楚的操作热区，使用原主题绿表示有效段和把手，未选段保持中性，焦点使用独立外圈；禁用状态不继续用高强调绿色。该表达可以使用现有 Slider 的填充与 emphasized 能力，但不改变滑杆常用区间、精确输入规则或物理参数含义。

本页不宣称完整烘焙器、全部参数投影、保存、烘焙或导出已通过；对应入口、覆盖范围、截图和实测结论以本轮主报告为准。
