## 门禁 2：盲比结论

- 胜出：v3。主要原因：分组节奏（组间距明显大于行距，折叠模块不再像普通行）；两种状态间搜索框不动；随机幅度去掉虚线框；无停用的「幽灵」按钮；只看图标有含义；输入框更像输入框。
- 退步维度（6 项）：
  1. 边框变多：每个数值框和搜索框常驻一圈细边（约 11 处）。——与第 2 轮「数值框不像输入框」相反。
  2. 选中层时少显示约一行参数（组间距加大所致）。
  3. 「±30%」没写「随机」，含义不如 v2 明确。
  4. 当前对象名与搜索框之间空出一段。
  5. 准星图标比圆圈略繁。
  6. 没有可恢复内容时完全看不到恢复入口。——与第 2 轮「停用按钮几乎看不见」相对。

## 评审给出的前 5 项改动（v3）

1. 随机幅度写成「随机 ±30%」，最好与标签同一行。
2. 去掉数值框、搜索框常驻细边，只在悬停 / 聚焦显示。
3. 组间距从约 51 收到约 42 px（不少于行距 1.4 倍），多显示约一行。
4. 树的显示 / 只看图标在非悬停、非选中行降到约 40–50 % 不透明度；准星刻度缩短 1–2 px。
5. 搜索框左缘对齐滑杆列；「这一层在整朵里」改为简短书面词；「需重新导出」文字改中性色、只留黄点。

## 处理（样板 v4）

两轮评审在两处给出相反意见（数值框边、恢复按钮）。处理原则：按已确认方案（第 3 节 V3「平时无边」）和两轮都能接受的折中，余下交用户在样板上切换决定。

| 项 | 处理 |
| --- | --- |
| 随机幅度 | 标签下方写「随机 ±30%」，界面字体；不放同一行（第 3 轮 v3 试过：「继承速度」「燃烧时间」等标签被截断） |
| 数值框边 | 恢复平时无边（方案 V3）；样板顶部加「输入框边：无 / 淡」切换，由用户定 |
| 组间距 | 20 → 14 px |
| 树图标 | 非悬停、非选中行 50 % 不透明度；已隐藏、已只看的保持全亮；准星刻度缩短 1 px、圆半径 6 → 5.5 |
| 搜索框 | 改为与参数行同一网格，左缘对齐滑杆列（实测 157 / 156 px） |
| 恢复入口 | 没有可恢复内容时显示为停用，停用文字 3.3 : 1（v2 为 2.05 : 1） |
