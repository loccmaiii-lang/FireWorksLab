# XD2 看法（对话框2，4.2.14 光点层再试导）

包和回放检查都对：PC = 主层两张序列 + `L2_Dots`（GPU、soft_dot、没有贴图），回放检查通过（光点发射器按设计跳过）；手机包里没有帧号测试图了。

**时间改对了一半，形状和亮度没对**（烘焙回放.jpg 第三行）：
- 主层烧完以后红点才出现（XD1 是开花就亮）——对；
- 7.25 s：实时模拟、实拍都还没有红点，导出已经有了（早 0.5–1 s）；
- 9.32 s：红点比实时模拟密很多、大、亮，球也偏大。

查下来四个原因（4.2.15 全改）：
1. 红点层 `keepFrac 0.2`：800 颗里只有约 160 颗会亮，光点出了 800 颗 → 太密；
2. 轨迹拟合的是「星的最远半径」，光点全放在外壳上 → 中位距离大 26%；
3. 亮起时刻按「时刻 ÷ 寿命」平均被抹开 → 早亮；
4. 光点直径 × 1.7；亮度按中位数归一（点灭星的亮灭平均被抵掉） → 偏大偏亮。

4.2.15：光点直接按模拟里每颗星定（会亮的星才出、亮起那一刻出生（分 5 批）、亮起时的半径 / 速度分布、之后拟合阻力 + 等效重力、亮度按亮灭平均），层页头选光点时可调光点大小 / 亮度。云端逐时刻比（`combo_pack_check.mjs` 红点层用例）：个数 153 vs 153、距离中位数差 ≤ 7%、平均高度在抽样误差内、总亮度差 ≤ 11%。散点对照见 `云端_4.2.15_模拟vs光点.png`（上 = 模拟里亮着的星，下 = 光点；模拟里点灭星一亮一暗，光点是平均亮度——光点不会闪）。
