## T08 第 3、4 步结论

**第 3 步（母材质 M_EFX_FlipBookSuperPack_FireBase_Unlit，新现场重读 177 个表达式）：可以改（不进透明度 / 溶解分支，不停下来问）。**

- 连线：EmissiveDissolve（缺省 1）、EmissiveDissolvePow（缺省 1）→ Power 得 s → 灰度×s 与 2−s → Power（查色坐标 q = pow(v·s, 2−s)） → Custom「Emissive」节点按 q 采样 Ramp → ComponentMask → Multiply → Add → Multiply_0；Multiply_0 再分三路：① StaticSwitch UseEyeAdaptation → Reroute → EmissiveColor；② Divide → 同一个 StaticSwitch；③ MaterialFunctionCall MF_ThermalImagingFx（武器热成像用的函数）→ Reroute → ClearCoat / ClearCoatRoughness。
- 到不了：Opacity、OpacityMask、WorldPositionOffset、Refraction、BaseColor 等其余输出。透明度那一路吃的是：Alpha、DissolveProgress、TexDissolveOffset / Power / Speed、UseParticleAlpha、UseParticleAlphaDissolve 等（没有 EmissiveDissolve / Pow）。
