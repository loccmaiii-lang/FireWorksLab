# 4.9.82：Comet / Silver 燃尽后分层与气流

已做进正式烘焙器，两款独立候选 **CSLRC / CSLRS** 待用户验收。旧 CS3C / CS3S 原件及认可状态保留。源码认领交回导出（23）。

## 改了什么，怎么调

| 功能 | 正式入口 | 本候选 |
|---|---|---|
| 细/中/粗火花大小与亮度曲线 | 原火花模块的随寿命曲线 | 末段细尾略收、略暗；非空曲线现在会真正进入合并贴图 |
| 独立余烬 | 落火 → 落火进入合并贴图 | 8 颗/秒、寿命 3.2 s、尺寸 0.21 m、亮度 3、阻力 3 /s；仍合在尾图里 |
| 燃尽后气流 | 效果 → 受力 → 燃尽后气流 | 0.6 m/s、尺度 1.5 m、渐入 0.4 s |
| 保留前段 | 同模块 → 燃尽后外观渐入 | 开启；主弹体燃尽后，曲线影响和余烬逐渐出现 |

先调气流强度；0 关闭，强度加大漂移更明显。尺度变大弯得宽，变小变化更碎；渐入时间越长，接入越缓。曲线横轴仍是各颗粒的寿命比例，不是整个效果的播放时间。

新增功能默认关闭，仅适用于 RT6「近段＋远段合并全程」。选回原分段/原生粒子输出会明确提示需要关闭新功能或切回合并，避免预览和导出不一致。曲线修复覆盖原合并/循环贴图路径；个人存档中以前填过却未生效的非空曲线会影响重烘结果。仓库旧配方未发现这类非空曲线。

## 结果和关键取舍

按真实浏览器回放审看 PC/手机整根及末段放大，2.1、3、4.2 s 同秒对照：前段轮廓与亮头保留，末段细尾略收，余烬零星延续，弯散较弱，没有额外团状爆亮。原本较密的 Silver 仍然比 Comet 更饱满。原件和新候选使用同一个世界镜头和曝光，无补帧、无额外提亮。

它是小幅丰富末段的候选，不是原版八层完整复刻。各组仍共用现有冷却/闪烁规则，没有新增每层闪烁频率；不改头肩、不加额外烟、不移植 Blender 四维噪声或二次阻力。气流继续沿用当前重力及尾粒线性阻力，从燃尽时的位置和速度连续接续。

**前段模拟不变，不等于整张新序列的前段采样逐像素不变。** 正式输出让新增尾部参与取景和帧表测量。Comet 的可见时长由 5.9333 s 到 6.1667 s；Silver 仍为 6.9333 s；均 64 帧。相比冻结实验取景，这样能检查全部新尾部是否入框，代价是前段取帧/重采样可能略有不同。
