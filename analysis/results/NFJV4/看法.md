# NFJV4 看法（对话框新花型，2026-10-08）

候选对比 4（卯 / 辰 / 巳 / 午，4.9.39 模板上改参数）。里 / 外改用实拍分界后：总差距 **卯 0.318**、辰 0.453、巳 0.462、午 0.453。
审看：差距.md + 对照_0.47 / 1.20 / 1.80 / 3.00（实时渲染 mtRenderLayers，不是导出包、不是 UE）。

总分是卯好，但**看图辰的芯、粉点、橙引都比卯像**——辰输在柠点星（一项拖了全部）：
- 金菊蕊：辰 +0.47 s 的芯是一根根白丝（卯是过曝白盘），+1.8 s 是琥珀橙的细丝团、边上一颗颗淡紫白小点——**和实拍 +1.8 s 几乎一样**；+3.0 s 只剩很暗的红丝（实拍已经没了，还要再早一点收）。但 +1.2 s 实拍芯还是一大团白，辰已经金了（变色太早）；+2.3 s 丝断得太碎（成串 0.43，实拍 0.15）。
- 红点蕊：辰光晕 0.3 / 半径 2.5 / 大小 1.0 的小点对上了（+2.0 s FWHM 4.9 / 光晕 0.32，实拍 4.86 / 0.27），不再是洋红光环。
- 橙引尾：辰更红（外段色相 18°，实拍 10–20°），线里端 0.50（实拍 0.48，卯 0.58）；线尖星头变小，+0.47 s 外圈那圈黄晕没了。线和线之间对比度偏高（0.57–0.73，实拍 0.30–0.38），这里大半是实拍相机糊（不能靠模糊补），不追。
- 柠点星：辰的渐变图暗端偏绿太多——星头和火花一起发一层**绿雾**，星头白（核心饱和 0.05）、偏大（泪滴 0.25 让 FWHM 5.8 → 6.7）。卯的颜色对，但星头发闷（暗端是深橄榄色）。
- 青绿细线：辰太亮（线带 12–17，实拍 4–5.5），而且是一团团的，不是细线。

下一轮 NFJV5：未 = 辰的芯 / 粉点 / 橙引 + 卯的星色、晕 0.35、快门 0.5 代替泪滴、细线改细密淡（火花 400 / 0.2 / 0.06、+2.0 s 停），芯 +1.2 s 前白、1.55 金、1.85 橙、丝细密（午的 0.3 / 1100）、+1.4 s 停；申 = 未 + 渐变暗端亮一点（通透）；酉 = 未 + 星头大一点亮一点；戌 = 申 + 酉 + 晕 0.25。辰、卯留作对照。
