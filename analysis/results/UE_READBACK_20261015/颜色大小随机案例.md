# 颜色 / 大小随机案例：P_EFX_FireWorks_Strobe_HD（点灭星，派活 T09 第 5 步）

**四条答案**：① **逐朵**——只有 1 个发射器、每朵 1 个粒子（整朵是一张序列面片），逐粒子就是逐朵，一朵里的星颜色大小一样。② 大小靠 **Size = Vector Uniform 9500–10500 cm**（普通随机，连续，面片 95–105 m）；颜色靠 **Color_Seeded**：StartColor Vector Uniform、三通道独立随机，**种子数组 7 个、bRandomlySelectSeedArray = true → 每朵只会是 7 种颜色之一**；另有高度 Uniform ±2 m、寿命 Uniform 2.0–2.4 s（播放快慢 ±9 %）；没有 Instance Parameter / Dynamic Parameter 参与随机。③ 本案例单发射器，没有对不上的问题；**照抄到多层花会对不上**——每个发射器各抽各的种子和尺寸。④ **没用导演能传的参数**，只和导演的 EffectScale / RandomScaleRatio（整朵缩放）叠乘。

> 本机实测（25）· 10-16 02:00 只读（同 `B08资源读数.json`），_M（`/Game/Effects/Props/FireWorks/P_EFX_FireWorks_Strobe_M`）设置相同。原始模块值在 `颜色大小随机案例.json` 的 `raw`。

## 模块（LOD0，L1_Main，CPU、FacingCameraPosition、Translucent）

| 模块 | 设置 | 效果 |
|---|---|---|
| Spawn | Burst 1（Time 0），Rate 0 | 每朵 1 个粒子 |
| Lifetime | Float Uniform 2.0–2.4 s | 每朵寿命不同；帧号曲线按相对寿命 → 播放快慢 ±9 % |
| Color_Seeded | StartColor Vector Uniform Min (1, 0.428, 0)、Max (0.0151, 0, 1)，不锁轴；Alpha 1；RandomSeedInfo：RandomSeeds 7 个 [9512, 576, 8165, 3559, 1243, 569, 1263]，bRandomlySelectSeedArray = true，bGetSeedFromInstance = false，bInstanceSeedIsIndex = false，bResetSeedOnEmitterLooping = true，ParameterName None | R ∈ [0.015, 1]、G ∈ [0, 0.43]、B ∈ [0, 1] 各自独立；每朵挑 1 个种子 → 7 种固定颜色 |
| Size | Vector Uniform X 9500–10500 cm | 面片 95–105 m，连续随机（不走种子） |
| Location | Vector Uniform Z −200…200 cm | 每朵高低 ±2 m |
| Size By Life | 曲线（入点前放大，0.45 → 0.34 → 1） | 不随机 |
| Dynamic Parameter | AnimPase（帧号曲线）、FlipBooxSpeed_Param、DissolveProgress_Param、EmissiveIntensity，都是 UserSet | 不随机 |
| Color Scale Over Life | 常量 (100, 100, 100)、Alpha 1 | 亮度倍数 |

- 颜色真的进画面要材质用粒子颜色（Vertex / Particle Color）乘 Ramp：没读母材质节点，**推断**是乘的（用户做这个案例就是为了颜色随机）。
- 三通道独立随机的颜色范围是一个立方体，不是「橙 ↔ 蓝」一条线：7 个种子抽出来可能有偏暗或偏紫的。要只在两个颜色之间变，Vector Uniform 要锁轴（bLockAxes + LockedAxes XYZ 是同一个随机数）或用 Color Over Life + 种子化的标量。

## 给跨年秀（22）

- 点灭星（Strobe）现在资产里已经自带逐朵随机：大小 ±5 %、颜色 7 选 1、高度 ±2 m、播放快慢 ±9 %。编排里同一排点灭星不用再靠 0.92 / 1.08 制造差别也会不一样；但颜色是**随机**的，同排几朵哪几朵什么颜色每次放都不一样（种子是开播时随机挑），想要「左右对称同色」做不到。
- 这个做法只适合单发射器的花（点灭、橙辉星、金芒菊、小平台花这种一朵一张序列）。多层花（金蕊柠 4 层、金曜菊 3 层、小青柠 4 层……）照抄会星头和尾巴颜色 / 大小对不上，要用固定同一个种子或实例参数（导演得改代码传参，现在没有）。
- 尺寸随机在资产里叠在导演 EffectScale 之上：编排按确定大小核性能时（B08 第 6 节），点灭星实际面片上限要 × 1.05。
