Intended direction: A quiet, dark, instrument-grade DCC workstation in the line of Nuke, Houdini and Niagara. Blue-grey chrome steps back so the firework is the only light on screen. Mint marks only the live or primary thing: the export button, the current tab, the selected item in the tree and the playhead head. Amber is kept for warnings. The square corners and the film-style crop marks with corner readouts (`PC 30 fps tick 60`, `距离 1000 m 预览曝光 1.00 倍`) show an ambition toward a precise, technical "measuring instrument" feel rather than a consumer app. The palette discipline is real and mostly holds: nothing on screen is decorative colour.

Contrast with Pentagram / Apple / Teenage Engineering: Pentagram would start from one typographic system and one grid running across all three columns. There would be two or three sizes, labels in a single dim tone, every number in tabular or monospaced figures, and horizontal datums (toolbar baseline, section rules, timeline top) that line up across the left column, viewport and inspector. Here each column keeps its own vertical rhythm, and nearly everything is set at one 13 px size and weight. Apple (Final Cut Pro / Motion) would keep the roles strictly apart: window-level navigation, document commands and viewer controls would never share one visual treatment. The inspector would hang its controls on a single alignment axis, collapsed-section summaries would sit in a fixed column, and the transport would read as one object under the viewer. Teenage Engineering would commit to the instrument idea this screen only hints at. The layer numbers 1/2/3, the tick ruler, the crop marks and the unit suffixes would become the visual signature, set in a mono face with small units. The single accent would mark state (on, armed, live) with hardware-like certainty, and every control dialect (slider, toggle, segment) would feel like one family of physical parts. This UI is clean and coherent, but it reads as a well-configured dark theme rather than an authored instrument.

Biggest gaps:

Nothing tells you which page you are on or that the two page entries go somewhere. The status items don't share one indicator language: only backup gets a dot, and connected status has none. The boxed numeral badges (`5.0.3 [2]`, `资源交付 [2]`) look like UI form fields, not counts. The inspector toolbar alternates icon, icon, text (`还原`), icon, text, text (`保存 另存`), so it has no rhythm, and the disabled `还原` looks almost the same as the dim undo/redo icons.
2. **No shared horizontal datum across columns.** The left column has no toolbar band. Its root row (`金曜菊-B 稀簇辉闪`) floats about 3 px off the centre line of the viewport and inspector toolbars, and the toolbar rule at y≈79 stops at the left column. Further down, the 效果/模板 tabs, the timeline top edge (y≈790) and the inspector section rules share no common line. The three columns look like three separately composed panels placed side by side.

Values (`0.20 s`, `1.10 倍`, `2400 K`) use proportional figures with units almost as large as the number. The one larger number (`2.00 / 5.24 s`) is not big enough to anchor the timeline. For a tool used all day to tune numbers, figures should be the best-set element on screen, and right now they are the most generic.
