Intended direction: A restrained, dark, instrument-grade production tool in the DCC/NLE idiom (Unreal editor, Nuke, Resolve). It uses a three-column workspace: structure tree and effect library on the left, viewport over timeline in the centre, a sectioned property inspector on the right. The neutrals are quiet blue-grey and the single mint accent is kept for the primary action and current state. The aim is "calm density": everything a technical artist touches all day is visible at once, and typography, not chrome, should carry the structure. Several details show this intent and are done well: dimmed units after tabular numerals ("1024 px", "1.10 倍"), collapsed sections that show a summary value, an inline reason on the disabled row ("强度为 0 时无效"), a bake-progress thumbnail strip above the ruler, and hover-only row actions in the tree.

Contrast with Pentagram / Apple / Teenage Engineering: Pentagram would start from one strict typographic system. There would be two sizes, two weights and two greys. Labels would be clearly dimmer than values, and every collapsed summary, value and icon would sit on a column you could draw with a ruler. They would also treat the 4x4 atlas as the hero: framed, centred on a defined margin, with frame numbers set like a contact sheet. Apple (Final Cut / Reality Composer Pro) would make the page mode the single dominant control. Secondary toggles would be visibly subordinate, the current page would always be marked, and toggles, segmented controls and checkboxes would each have one unmistakable on/off encoding. Apple would also never leave a 500 x 440 px dead zone in the main stage. Teenage Engineering would make the numerals the instrument: a large fixed-width time and frame readout, the atlas as a lit pad matrix where the cell under the playhead glows, and colour used only for meaning, so "passed" and "in progress" would never share a grey. All three would remove the repetition: the layer name appears in five places here, and each studio would show it once with authority and then point to it. This screen has the right ingredients and a clean palette discipline. What it lacks is a governing grid, a second type size and a deliberate composition for the centre stage.
