## 一、控件语法（5 位评委 + 规则 4、6 都提到；扣分最多）

1. **命令和标签要分得开**：
   - 纯信息（顶栏状态、画面读数、「导出范围」这类说明字）降到弱色 #8da3ac。
   - 命令文字按钮（`.tbtn`）用次色 #b4c5cb；悬停加浅底，按下更深一级；全屏统一 28 px 高的点击区。
   - 「保存」改成浅底的次要按钮（介于实心「导出」和文字按钮之间）；其余命令仍是文字按钮。
   - 「查看」「详情」这类就地展开的链接，跟在说明文字后面，用命令色。
2. **两级切换长得不一样**：
   - 工作区（制作 / 导入 / 编排）改成**无框文字标签**：当前项 600 字重，底边 2 px 下划线。
   - 工作模式（实时模拟 / 引擎回放 / 贴图与交付）保留带框分段 `.modeseg`。全屏只有这一组带框。
   - 视图缩放（适应 / 1:1 / 游戏内）、单次 / 循环、筛选块、PC / 手机等：无框，选中项用中性浅底 `.seg`。
3. **开关**：开 = 轨道亮一级，方块在右；关 = 轨道只画细框，方块在左；停用 = 整行弱化，**并且写原因**（悬停提示或行尾小字）。三种状态一眼能分开。
4. **一种图形只有一个意思**：「需重新导出」「恢复默认」「版本记录」「循环」现在都是圆箭头，要各画一个不同的形状。「需重新导出」用琥珀色的小三角或带感叹号的方块，不用圆箭头。

## 五、字体与数字（评委 4、5、8）

20. **字号三级**：
    - 12 px：弱信息、单位；
    - 13 px：正文、参数名、命令；
    - 15 px：当前位置（面包屑末项、当前时间）。
    
    粗体只用在当前位置、模块标题、当前工作区。
21. **数值**：用 tabular-nums、主文字色；单位用弱色、小一号。数字和单位按基线对齐，例如「2.00 / 5.24 s」「1000 m」。
