# E 样板 v2.2 外观改动单

> 对话框9，2026-11-04 23:5x。依据：v2（含 5.0 外壳）的外观评委 5 屏（5.5 / 6 / 6 / 6 / 5.5，v1 为 5–5.5）和新旧盲比 3 对（3 对都是 v2 胜）。评审原文在 `scratchpad/d1/crit_V2s1–5/result.md`、`ab_V12_1–3/result.md`。
> 和 v2.1 交互改动（walk_v2.md）一起做，产出 v2.2。用户已经定的不动：结构树在左栏、显卡在右上角、效果库大号标签 + 薄荷下划线（照编排资源库）、薄荷细框只在结构树当前行、颜色和直角、外壳顶栏的内容。

## 共识（3 位以上评委或盲比都提到）

1. **少一条横带**。现在画面上方叠了四条：外壳顶栏、制作区工具行、视图条、面板标题。工具行中间空出 700–1200 px，工作模式却压在结构树上方。
   - 改成：工具行就是三栏的标题行，内容按列对齐。
     - 左栏那段放「结构」标题（结构树自己那行标题删掉，折叠箭头一起挪上来）。
     - 中栏那段：左端是工作模式（对齐画面左边），后面接视图控件（适应窗口 / 1:1 / 游戏内大小、视图图标、预览设置）。
     - 右栏那段：撤销 / 重做 / 还原 / 版本记录、保存 / 另存、导出 ▾。
   - 原来的视图条整条删掉。「距离」「预览曝光」挪进画面单格的读数里，可以拖动改值、单击输入，和数值框同一套交互。
   - 「需重新导出」放在导出按钮前面：先看原因，再点动作。
   - 1366 下要放得下；放不下的视图控件收进「视图 ▾」。
2. **三级底色，少画分割线**。外壳顶栏一级（chrome），面板一级，画面最深。外壳顶栏和工作区之间靠底色区分，不再只靠一根细线。只从现有中性色阶里取值，不加新颜色。
3. **控件分四种外观，一种意思一种样子**：
   - 工作模式（实时模拟 / 引擎回放 / 贴图与交付；导入区的「烟花导入 / ResourceFX 配表」也算）：等宽分段、细框，选中项实底。全屏只有这一级用这种样子。
   - 选项（视图缩放、筛选块、参数里的枚举值）：中性填充，比工作模式弱一级。
   - 命令（设为入点、保存、预览设置……）：文字按钮，比标签亮一级，悬停有底。
   - 标签和摘要：最暗，永远不能点。
   - 开关圆点改成方块，和竖条滑杆一套。
4. **检查器网格**：
   - 分组标题左缘和参数名对齐，或者比参数名更靠左，不能比子行更缩进。
   - 右侧只留两条边：数值 + 单位一条，恢复 / 查看 / 小按钮一条。
   - 曝光行的「建议曝光」小按钮挪到恢复按钮那一列，滑杆轨道和其他行一样长。
   - 「N 项已隐藏　查看」和参数名同一左缘，「查看」跟在文字后面，不甩到最右边。
5. **字重三级**：分组标题小一号、灰色、中等字重，让数值成为面板里最亮的东西。粗体只用在当前位置：当前工作区标签、面包屑末项、结构树当前行。
6. **少重复**：
   - 「结构」标题后面不再写效果名。
   - 画面读数去掉「（第 2 层）」。
   - 读数从四个角收成两处：左上「PC　单格 1024 px」；左下「75 帧　5 张　30 fps　tick 60　距离　预览曝光」。裁切角标保留。
   - 播放条上的层名保留（走查要求写出入点 / 出点作用在哪一层），但用次要灰字。
7. **时间轴**：
   - 胶片条和时间刻度严格对齐：每格对应它那一帧的时间，未烘焙的部分不画格子。
   - 关键帧菱形只画在「整体」和当前行，其他行只画区间条。
   - 行名一列收窄到够放最长的名字。
   - 「下方还有 N 行」不占一行，改成轨道区底部的渐隐 + 数字；时间轴上沿可以拖高（v2.1 已加分隔条）。
8. **状态栏**：保存状态不放在正中间。左边是「复制我的意见」，右边依次是保存状态和「快捷键」。
9. **效果库状态词**：「待验收」「新」需要处理，用主文字色；「制作中」「已通过」用次要灰。
10. **导出 ▾ 面板**：
    - 摘要收成一行。文件清单（v2.1 加的）收进「详情」，点开才显示。
    - 选项的灰色说明文字换成右侧的数字，例如「只导出需重新导出的层　1」「导出全部　3」。
11. **贴图与交付屏**：
    - 序列贴图画成无缝的一整张，网格做成可以开关的叠加层，显示缩放比例；空格不画框。
    - 交付表按行数定高，不留空白。
    - 同一个数字只出现一次：去掉贴图下面那行说明，层名并进翻页器（「金锦层　2 / 5」）。
12. **图标**：
    - 去掉层行前面的叠层图标（已经有层号）和文件夹标签前面的文件夹图标。
    - 「只看」的方框 S 和眼睛、⋯ 用同一种线框风格。

## 不采纳（和用户的决定冲突，或者评委之间意见相反）

- 去掉薄荷下划线：效果库大号标签是照编排资源库做的（用户 20:33 指定）；工作区标签和它保持一致。
- 把导出 / 备份文件夹挪出外壳顶栏：用户 22:30 指定放在顶栏。
- 删掉状态栏：v1 评审要求有一条全宽状态栏收住底边，本轮盲比也把它算作 v2 的优点；「复制我的意见」是在用的功能。
- 删掉裁切角标：两位评委认为这是画面上最好的设计，另外两位认为像科幻界面。保留，只收拢读数。
