Intended direction: A quiet, dark, instrument-grade production tool in the lineage of Resolve, Houdini and Unreal's own editors. The firework is the only saturated thing on screen; the chrome steps back into blue-grey hairlines, 28 px rows, grey labels and white values. Mint is held for "current / go" (selected layer outline, active tab underline, playhead head, 导出) and amber for exceptions (备份 未选, the layer warning, ⚠ 1 层). Small pieces of craft show what it is aiming for: the L-shaped crop brackets with a quiet HUD tucked inside them, the hairline sliders with a thin bar handle and a default tick, the bake filmstrip locked to the 0.35–2.85 s range on the ruler, the collapsed 输出 section that summarises itself ("1024 px · 5 张"), and the disabled 湍流尺度 row that says why it is disabled ("强度为 0 时无效"). The aim is a calm all-day workbench where the canvas does the talking. It mostly gets there in colour and density. It falls short on typographic hierarchy and control consistency.

Contrast with Pentagram / Apple / Teenage Engineering: Pentagram would start from a type system before any colour: three or four sizes with clear jobs, tabular figures for every number, and one column grid that the inspector values, the timeline label column and the library status column all snap to. Here almost everything is the same 12–13 px. Hierarchy comes only from bold section headers and grey versus white, and the numeric column drifts ("2400" sits about 20 px left of "0.20 / 1.10 / 7.56 / 0.85"). Apple (Final Cut, Motion, Logic) would make the mode switch 实时模拟 / 引擎回放 / 贴图与交付 the clear spine of the window. It would give the current page in the top bar an unmistakable selected state, make the playhead the strongest line in the timeline, and draw every toolbar from one button grammar. Here icon-only, text-only and icon-plus-text buttons sit side by side in all three toolbars. Teenage Engineering is the nearest relative, with its restraint, hairlines and brackets. TE would go further: a custom glyph set instead of stock line icons, a monospaced or tabular readout face for every value (2.00 / 5.24 s, 帧 50 / 75, 1000 m, 2400 K), and tracks that read as distinct coloured instruments rather than near-identical grey hairlines. The bones are TE. The finish is a competent default.

Biggest gaps:
1. Flat typographic hierarchy and no numeric typography. Labels, values, toolbar actions, status text, track names and list metadata all sit at about the same size and weight. The timecode "2.00 / 5.24 s", the frame counter, the inspector values and the HUD readouts get no figure treatment of their own (tabular or mono), so the numbers that a technical artist reads all day don't form a system. The value column also wobbles: 色温 "2400" right-aligns about 20 px short of the other values, and in the collapsed 输出 row "5" and "张" are split by a wide gap that reads like two columns.
2. The top bar is one undifferentiated string. "UE 已连接 | 导出 FWL_Export | ● 备份 未选 | 资源交付 2 | 资源编排 | RTX 4070" uses one weight and one grey throughout, so status, navigation and hardware info are only told apart by thin dividers. The current page has no selected state; 资源交付 and 资源编排 look identical and look like status text. The two boxed-number badges ("5.0.3 [2]", "资源交付 [2]") are ambiguous. "2" next to a version can mean unread log entries, a build number or an update count. Only the backup state gets a dot, while the UE connection, which is just as much a status, gets none.
3. Toolbar grammar is inconsistent, and the most important switch is underweighted. 实时模拟 / 引擎回放 / 贴图与交付 decides what the user is validating, yet it is styled the same as the zoom switch 适应 / 1:1 / 游戏内 a few pixels to its right, so the two read as one six-item strip. The right cluster has five stock line icons (grid, speech bubble, then three near-identical panel-layout glyphs) followed by the text button "预览设置". The inspector toolbar mixes undo/redo icons, disabled text "还原", an unlabeled duplicate icon, then text "保存 / 另存". The transport mixes icons with "1× ⌄", "选项 ⌄" and the icon-plus-text "缩略图". No single rule decides when a command gets an icon, a word or both.
4. The timeline weights its elements in the wrong order. The playhead is a grey hairline with a tiny mint head, and it is visually weaker than the selected layer's bright white bar. The bake filmstrip fills only about 55% of its range box (8 frames, then a dead dark band to 2.85 s), which reads as "still loading". The three emitter sub-rows (星 / 火花 / 余烬) take about 84 px to show near-invisible hairlines. Unselected layer bars are 3 px grey and barely separate from the ruler ticks. The range reset icon crowds the "0 s" label.
5. The effect-library thumbnails break the list's rhythm. Burst effects fill their square, but tail effects (RT6, CS3C, CS3S) show as a 1–2 px vertical speck on black, so a third of the list looks empty or broken. The status words (制作中 / 待验收 / 新 / 已通过) are the same small grey with only 待验收 slightly brighter, so the one state that asks for action barely stands out. "10 个" floats between the filter strip and "+ 新建" with no clear tie to either.
6. The inspector's right gutter and on/off states are ambiguous. One icon column holds a section reset (时间与缩放 ↺), a row reset (缩放 ↺) and a circled "A" (曝光), three meanings at one position with one weight. Default ticks appear on some sliders (开始时间, 缩放) and not others (时间倍率, 序列时长). Changed-from-default rows seem to get a reset icon only some of the time. The "+4" on 环境 has no visible affordance. The toggle and checkbox on-states (发射器共用, 3 点灭星) differ from off only by a brighter grey fill, which is too subtle at 28×16 px. The indented 色温 / 饱和度 group hangs on a left rule that looks heavier than the other separators.
7. Near-miss alignments and disguised actions. The left tree's root title sits a few pixels off the shared toolbar baseline of the centre and right columns, so the three columns don't share a clean top horizon. In the bottom bar, "复制意见" is an action styled exactly like the passive "已保存 20:31". The chevron alone at the right end of the 效果 / 模板 tab bar has no readable purpose.

AI tells:
- Stock line-icon set with generic metaphors (grid, speech bubble, three near-identical panel-layout glyphs, stopwatch). This is the most visible "default library" signal on the screen.
- Boxed number badges ("[2]" twice). This is the square cousin of the pill badge, and its meaning is unclear.
- The "+ verb" text-button pattern repeated in three slightly different forms ("+ 加层 ⌄", "+ 加发射器", "+ 新建").
- Accordion inspector with identical chevron-plus-bold headers and every section expanded by default. This is the generic property-panel template, not one shaped around the common edit path.
- Uniform type size everywhere (the "one font-size app" tell).
- None of the loud tells: no purple gradients, no glassmorphism, no card-within-card, no rounded pill tags, no hero layout. The colour discipline is clearly deliberate.

Top 3 to delete / simplify:
1. Fold the timeline's emitter sub-rows (星 / 火花 / 余烬) under their layer by default, expanded only for the selected layer or on demand. This removes the hierarchy duplicated from the structure tree, gives about 84 px back to the tracks, and lets the playhead and the selected layer bar become the clear focus.
2. Merge the three panel-layout icons in the viewport toolbar into one layout menu, and set one button grammar for all three toolbars (icon-only for universal verbs such as play, undo and redo; text for project verbs such as 保存, 另存, 选项 and 预览设置; never both by accident). Separate the mode switch from the zoom switch with real space and give the mode switch more presence.
3. Turn the top bar into two clusters. The left cluster is status, and only the exception gets colour (备份 未选), so "UE 已连接" and "导出 FWL_Export" can stay muted. The right cluster is page navigation with a true selected state, plus the GPU name. Replace the two boxed "[2]" badges with a single mint dot on the version and on 资源交付. Also show the viewport HUD's "帧 50" only when the timeline is hidden or on hover, since the transport already shows "帧 50 / 75" at all times.

Score: 6.5/10 - Disciplined colour, a real row rhythm and a few genuinely crafted details (crop brackets, hairline sliders, a self-summarising collapsed section) are let down by a flat single-size type system, no numeric typography, an undifferentiated top bar, three toolbars with three button grammars, and a timeline whose playhead is weaker than its bars.
