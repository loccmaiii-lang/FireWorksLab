## A. 用户裁决（必须）

1. **选中样式**：绿色 1 px 细框**只用于当前编辑对象在结构树里的那一行**。效果库的当前效果、时间轴对应行、交付表对应行改用浅底色（中性色，不用薄荷绿）；筛选块选中用中性填充；胶片条当前帧只靠播放头标示。键盘焦点保持 2 px 中性框，与选中区分。
2. **删除不弹确认**：能撤销的操作（删除层 / 发射器等）直接执行，弹出撤销提示条：显示 ≥ 10 秒、鼠标悬停时不消失、出现在操作发生的那一栏附近（左栏底部），文字如「已删除『点灭星』　撤销」；Ctrl+Z 同样撤销。删除确认弹窗只留给不能撤销的操作（组件全表里保留一个这样的例子）。
3. **只看可叠加**：单击「只看」= 只看这一项；Ctrl+单击 = 加入 / 移出只看集合；只看时画面左上角显示「只看：点灭星　Esc 退出」（多项时列名或「只看 2 项」）；Esc 退出只看。只看图标换成一眼能认的形状（不是准星），开启态明显（实心）。快捷键：S 只看当前对象，H 隐藏 / 显示当前对象。

## B. 外观（5 屏评委共识，与用户决定不冲突）

1. **顶栏与工具行合并**：一条顶栏，从左到右：产品名与版本 → 三个工作模式（实时模拟 / 引擎回放 / 贴图与交付，做成全屏最醒目的一组标签）→ 撤销 / 重做 / 还原 / 版本记录 → 保存 / 另存 → 导出 ▾（唯一实心主按钮，旁边是「需重新导出」状态）→ 右端：显卡型号、资源交付、更新记录（显卡仍在右上角，用户决定）。中间列原来的工具行删掉。
2. **全宽底部状态栏**（三栏共用一条）：左：复制我的意见；中：保存状态（「未保存改动 3 项」可点开列表 /「已保存 21:42」）；右：当前画面的技术信息可以留在画面单格的四角（小号灰字，像取景器），不再单独占一条。
3. **时间轴头部从 4 行减到 2 行**：第 1 行 = 播放、重播、速度、循环、时间、时间工具、当前对象区间、设为入点 / 出点 / 清除、选项 ▾（两个时间选项收进这个弹出菜单，带一句说明）、生成缩略图；第 2 行 = 胶片条与刻度合成一条（缩略图在上、秒刻度在下，同一横轴；未烘焙部分是连续的暗色段，不画空格子）。轨道区不被截断，行多时有滚动提示，底部与状态栏对齐。
4. **画面是全屏最暗的区域**（用最深的中性色），面板比它亮一级。
5. **控件统一**：
   - 开关：真正的两态开关，圆点左右移动、开时轨道明显变亮，所有地方同一种。
   - 分段选择、筛选块、视图选项、平台 / 帧率选择：同一种分段控件，选中 = 中性填充。
   - 滑杆圆点改为方形或竖条（配合直角体系）。
6. **效果库头部收紧**：保留大号「效果 / 模板」标签（用户要求）；其下一行搜索；一行筛选块，数量与「＋ 新建」放在同一行右侧；去掉重复的「全部效果 ▾」。「我的模板」作为「模板」下的第三个二级标签。状态文字统一样式（灰字，不加粗）。
7. **检查器**：
   - 一条数值列，单位紧跟数值；区间参数（速度、寿命、大小、亮度）一行放下，分布写成小号次要数字或放进悬停提示；
   - 曲线编辑器宽度对齐「控件 + 数值」两列，不画成卡片框，读数放在曲线下方；
   - 「本层颜色」摘要显示一条色带，不写句子；「建议曝光」做成曝光行上的小按钮；
   - 已改标记放在左侧固定槽位，不推动参数名；恢复箭头在单位列以内；
   - 依赖参数缩进在开关下面（见 C4）。
8. **圆点统一**：「需重新导出」用文字 + 图标挨着导出按钮；更新记录用数字（例「更新记录 2」）；已改参数用左侧槽位标记。不再用三种含义的「•」。
9. **结构树图标**：显示 / 只看图标平时不显示，悬停、选中行、或处于非默认状态（已隐藏、已只看）时才显示。层多时（> 12 行）结构树头部出现一个筛选框。
10. **浮层**：提示和菜单比面板高一级（更亮的底 + 阴影），提示放在不遮挡同组参数的位置（检查器的提示出在左侧、画面上方）；导出 ▾ 菜单第一项写清范围。
11. **命名**：视图条的「显示曝光」改为「预览曝光」，与层参数「曝光」区分。界面上不出现「数字为示例值」这类样板说明（写进说明.md）。

## C. 交互（走查共识）

1. **统一的改动模型**：任何编辑（参数、层、时间轴）都计入改动；状态栏「未保存改动 N 项」可点开列表，每项可单独恢复；Ctrl+S 保存，保存后显示「已保存 + 时间」；需重新导出的层由同一份改动算出，结构树、交付表、导出按钮三处一致。
2. **和打开时比**：参数行区分「非默认」与「本次改过」两种标记；悬停数值显示「打开时 1.10 → 现在 1.30」；行尾恢复按钮是小菜单：恢复到打开时 / 恢复默认。
3. **撤销反馈**：Ctrl+Z / Ctrl+Y 时在操作处显示短提示（「撤销：缩放 1.30 → 1.10」）并短暂高亮该控件；没有实际改变的操作不产生撤销步。
4. **依赖参数**：受开关控制的参数缩进在开关下；开关关闭时这些行收成一行「4 项已隐藏」，其中有改过的写「其中 1 项已改」；因别的值而失效的行置灰，悬停写原因（「湍流强度为 0 时无效」）。
5. **导出说明清楚**：导出 ▾ 菜单顶部一段摘要（几层、哪些平台、格式、保存位置示例）；默认「只导出需重新导出的层」；交付表每行可勾选；「导出设置…」改名为「打开贴图与交付」；导出完成提示写明平台与张数，并有「打开文件夹」。
6. **编辑隐藏的层**：检查器头部提示「这一层当前隐藏」。
7. **时间轴**：「设为入点 / 出点」按钮写出作用对象（悬停提示或按钮后小字）；快捷键 [ ] 设入点 / 出点；拖动数值或播放头时按 Esc 取消；两个时间选项在「选项 ▾」里各带一句说明；胶片条的「烘焙帧 N / 75」随播放头更新。
8. **1366**：区间滑杆拖动时选离鼠标近的那个滑块；结构树头部固定；时间轴有滚动提示；提示不遮挡下一行。
