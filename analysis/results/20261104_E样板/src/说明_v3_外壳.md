## 设计规范 v3 逐节（外壳部分）

- **第 1 节 字号字重**：产品名 15 / 600；版本号、UE、文件夹、计数、显卡 12（1366 下 11）；命令、页面标签 13；字重只有 400 / 600（当前页标签 600，换字重不挤动顶栏：标签按 600 预留宽度）。数值等宽。
- **第 2 节 网格**：命令点击区 28（版本号、文件夹标签、「设置」「重试」「返回制作」、页面标签）；行高 28；列表条目里的「更新」「重试」上下负边距，点击区 28 不撑高行。两页的左栏 = 制作区左栏 + 72 px（1920 下 372、1366 下 332，变量 `--sh-wl`）：素材包和基础模板一行要并排放名称、副信息和右侧状态，用制作区的 300 / 260 会截断；右栏同制作区（460 / 380）。工具行按下面的栏分段，分段边和栏边对齐。

## 判断与定论

1. 「导入」薄荷实底、「备份 需允许访问」琥珀：规范 v3 已补（3a6f2fda）：薄荷给每页唯一的主操作（资源交付页是「导入」），「需允许访问」会挡住写入，用琥珀。
2. 提示条前缀写动作名「导入：」「制作：」（不写页名「资源交付：」），短，且和按钮「导入」同一个词。
3. 用词跟制作区统一（`text_audit.py` 的用词表）：另存对话框标题「另存」（不写「另存为」），操作处提示「已另存「名称」 hh:mm」；勾选写「同时放进编排」，和导出 ▾ 菜单同一个词（规范第 12 节）。
4. 「样板的 shellAfterExport 被调了两次、第二次不带参数」（A 的 check_main 里看到的 `null`）：不是外壳调的。`check_main.py` 用 `page.evaluate("window.__exp = []; window.shellAfterExport = a => …")` 装记录器，这个表达式的值是那个箭头函数，Playwright 遇到函数会顺手调一次（不带参数），所以记录里多出一个 `undefined`。真导出一次：挂钩只被样板调一次、只切一次页面、屏上只有一条提示条（`check_shell.py`「③-导出一次」两项）。A 那边把那句包成 `(() => { …; })()` 就不会多出来。
