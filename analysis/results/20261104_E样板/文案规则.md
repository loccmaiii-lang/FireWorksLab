# 界面文案规则（E 样板起，三个工作区共用）

> 用户 2026-11-04 23:55：「现在还有很多浮层，字数是超标的，很多描述尽量书面精简化，用词统一风格，这是一个生产力工具，不要做的跟随随便便拼凑的标签书一样」。
> 词汇以 `协作/交互宪章.md` 第 4 节为准：一个概念只用一个词。

## 字数上限

| 位置 | 上限 | 写法 |
| --- | --- | --- |
| 按钮、标签、菜单项 | 2–4 字（专有名词除外） | 动宾或名词：「导出」「设为入点」「打开文件夹」 |
| 选项值 | 1–4 字，不重复参数名 | 「序列方式：单次 / 循环」，不写「单次序列」 |
| 悬停提示 | 一句，≤ 16 字；需要时另起一行写快捷键 | 「缩放这一层的整体大小」，下一行「快捷键 S」 |
| 菜单项的说明行 | 尽量不写；非写不可时 ≤ 10 字，或改成右侧数字 | 「导出全部　3」 |
| 原因（变灰、失效） | ≤ 16 字，写条件，不写建议 | 「湍流强度为 0 时无效」 |
| 提示条 | ≤ 20 字 + 一个操作 | 「已删除「点灭星」　撤销」 |
| 对话框正文 | ≤ 3 句，每句 ≤ 25 字 | 先写会发生什么，再写要用户做什么 |
| 空状态 | 一句说明 + 一个操作 | 「还没有我的模板　新建」 |

## 语气与标点

- 书面陈述。不写「你可以」「会帮你」「请」「哦」，不用问句、感叹号、括号里的补充说明。
- 用中文全角标点；句末的句号只在对话框正文里用，按钮、标签、提示都不加。
- 数字和单位之间空一格（「1.10 倍」「0.35 s」）；范围用「–」（「0.35–3.70 s」）。
- 不用「·」把几件事串在一起；产品名「烟花工坊 · FireWorksLab」除外。
- 状态用名词短语（「需重新导出」「未进 UE」「已保存 21:42」），不写成句子。
- 同一个动作，在按钮、菜单、提示、撤销提示条里用同一个词（例如全屏都用「只看」，不混用「独看」「单独显示」）。
