# E 样板 v2：烟花工坊 5.0 外壳（说明）

> 2026-11-04。按交互宪章 0.9（①–⑧ + 待裁决 11 条，待裁决一律按推荐）和外壳任务单做。只写三份：`part_css_shell.css`、`part_body_shell.html`、`part_js_shell.js`；样板其余文件没动。`build.py` 已接入（构建时打印 `shell: css,html,js`）。

## 文件与接法

| 文件 | 内容 |
| --- | --- |
| `part_css_shell.css` | 外壳顶栏、导入 / 编排工作区、基础模板条目、对话框补充、重新授权气泡、状态栏编排预览、样板开关、全表一节。只用 `part_css1` 的 token；没有新色值（`check_shell.py` 槽位-4 核对） |
| `part_body_shell.html` | `#wsImport`、`#wsWB` 两个工作区的骨架，样板开关 `#shKit`。放在 `#shParts`（hidden）里，脚本启动时搬进槽位 |
| `part_js_shell.js` | 单独一个 `<script>`，不在样板闭包里。菜单、提示条、对话框、操作处提示按样板的 DOM 和类名另写一份；悬停提示直接用样板的 `[data-tip]` |
| `check_shell.py` | Playwright 走查 190 项 + 截图（`--no-shots` 只走查） |

启动时：`#wsImport`、`#wsWB` 插到 `#wsBaker` 后面（`class="ws"`，默认 `hidden`）；`#shKit` 放进 `#sbarShell`；`#shell` 内容由脚本按状态生成；`#sheetShell` 一节在第一次切到组件全表时才生成（同样板的全表正文）。槽位不在时脚本不报错（槽位-5）。

给样板调用的接口：

| 接口 | 作用 |
| --- | --- |
| `window.shellAfterExport({name, pc, mobile, alsoWB, layers})` | 导出写完后：切到「导入」、选中刚导出的包、出提示条；`alsoWB` 为真时接着生成编排预览 |
| `window.openSaveDialog()` | 另存的命名对话框（含「同时放进编排（基础模板）」） |
| `window.shellPickExportFolder()` | 同点顶栏的导出文件夹标签：未选 → 选文件夹；已选 → 标签下面出「换一个文件夹」菜单；要重新授权 → 允许访问 |
| `window.SHELL` | 走查 / 截图用：`set(k, v)` 样板开关、`ws(name)` 切工作区、`speed(k)` 计时倍数、`state()` |

## 宪章 0.9 逐条

### ① 外壳顶栏
- 位置：`#shell`（`barHTML()`），40 px / 1366 下 36 px。从左到右：产品名「烟花工坊 · FireWorksLab 5.0.3」→ 工作区「制作 / 导入 2 / 编排」→ UE 状态 → 导出文件夹 → 备份文件夹 → 更新记录 2 → 显卡「RTX 4070」（最右，悬停全名，待裁决 1）。
- 关于：点产品名出小浮层（`.menu` 样式）：制作 = 烘焙器 4.9.129、导入 = 导入器 v2.31、编排 = 编排工作台 16.0.37，浏览器，显卡全名；可「复制版本信息」。
- 工作区标签：用已有的 `.tabs.tabs-mode`（贴满顶栏高、3 px 薄荷绿下划线、常态次亮字、选中加粗）。效果库大号标签是 `.tabs-lg`（面板里等分、2 px、常态灰字）——同一种风格，层级靠位置、下划线粗细和常态亮度分开。全屏只有这一组 `.tabs-mode`。「导入」后带待导入的包数（待裁决 7）；读不到导出文件夹时不带数。
- 切换只换显示：三个 `.ws` 同一格、用 `hidden` 切换，DOM 不重建，参数、选择、滚动、播放时间都在（走查 ①-36）。在导入 / 编排里，制作区的单键快捷键（空格、R、S、H、F、L、P、[ ]、← →、Ctrl+Z / Y / S）不作用到看不见的制作区；工作区快捷键这一版不加（待裁决 8）。
- UE 状态：连接中（转圈）/ 已连接（实心点）/ 未连接（空心圈）+「重试」+「12 秒后自动重试」（真倒计时，到 0 自动重试）/ 写入中 3 / N（转圈 + 进度，点一下切到「导入」）。悬停写「127.0.0.1:17780　上次连上 22:41」。编排在写 UE 时只写「UE 写入中」，点一下切到「编排」。另加一态「UE 不可用」：Chrome / Edge 以外的浏览器连不上 UE（⑤ 的推论，宪章 ① 没列）。
- 文件夹标签：未选（导出 = 警告色 + 警示图形，点了选文件夹；备份 = 次要灰字，不算错误）/ 已选（中性色，点了出菜单「换一个文件夹…」）/ 需允许访问（警告色，点一下即允许）/ 不可用（其他浏览器，变灰写原因）。名字过长截断加省略号，悬停看全名；1366 下最长组合也放得下（走查 尺寸-1366-1/2）。
- 更新记录：「更新记录 2」，点开列出 2 条，看过后数字消失。
- 三个工具原来的标题栏：样板的工具行已拿掉产品名、资源交付、更新记录、显卡；导入、编排工作区没有自己的标题栏。

### ④「同时放进编排（基础模板）」
- 另存对话框 `openSaveDialog()`：名称（默认「金曜菊-B 副本」，空名、和已有效果同名都就地报错）；名称下面一行勾选 + 小字原文。默认：第一次不勾；已放进编排的效果默认勾上，按效果记住（待裁决 4）。
- 导出 ▾ 面板的勾选由样板画（`#expAlsoWB`），结果经 `shellAfterExport({alsoWB})` 进来。
- 进度：对话框关掉后不挡操作，状态栏 `#sbPreview`「生成编排预览 38%　取消」，约 4 秒（走查 ④-29 实测）。导入、编排工作区的状态栏中间显示同一条，切过去也看得到。编排里这一行同时显示「生成预览中」。
- 成功：「已放进编排：金曜菊-B 副本　去编排看」，10 秒后消失（悬停不消失，同样板提示条）；「去编排看」切到编排、选中并高亮那一行。新效果没配 ResourceFX 行，副信息写英文名、标「未进 UE」。
- 失败：同一位置变错误样式（错误底色 + 警示图形）「编排预览没生成：浏览器存储空间不足　效果已保存　重试　详情　×」，一直留到重试成功或关掉；导出后的写「已导出」。「详情」写原因和能做什么。
- 直接保存（待裁决 3）：点样板的「保存」/ Ctrl+S 时，按这个效果记住的勾选生成新预览；已在编排里的效果生成后标「有新版本」，点「更新」才换。样板初始没有记住的效果，所以平时直接保存不触发。

### ⑤ 首次使用
- 第一次导出、没选导出文件夹：点导出（主按钮、导出菜单各项、交付表「导出勾选的层」）时先弹「选择导出文件夹」，选好后接着按原来那一项导出；取消则不导出，按钮旁说「没导出：还没选导出文件夹」。导出前在捕获阶段先看文件夹，样板的导出逻辑不动；`shellAfterExport` 里另有一道兜底。
- 第一次覆盖 UE 资产、没选备份文件夹：导入写到第一个要覆盖的资产前停下，弹「覆盖前先选备份位置」（原文，「不要选 UE 工程里面的文件夹。」加粗），主「选择备份文件夹…」、次「取消导入」。对话框左下「样板：模拟选到工程里」（虚线框，表示不是产品按钮）显示就地报错，对话框不关。
- 重新授权：标签变「需允许访问」+ 标签下方一次小气泡「重新打开后要再允许一次访问 FWL_Export　允许访问」；导出、导入、刷新时按钮旁出同一句；导入区包列表就地写同一句 +「允许访问」（待裁决 6）。备份文件夹要重新允许时，导入停在覆盖前、「导入」旁出同一句，点允许接着写。
- 其他浏览器：样板开关「浏览器：其他」时弹一次「请用 Chrome 或 Edge 打开」（原文，主「复制本页地址」、次「仍在这个浏览器里看」）；之后文件夹标签写「不可用」，UE 写「不可用」，制作区导出、导入区导入 / 刷新、编排的三个按钮变灰写原因（待裁决 5）。样板的导出按钮会重画，用 MutationObserver 在重画后再变灰一次。

### ⑦ 变灰与互锁
- UE 未连接：导入区内容和预检照常；工具行下面原因条（`.fb.warn`，原文 +「重试」）；「导入」变灰，悬停同一原因（待裁决 11）。UE 连接中时「导入」也变灰写原因。
- 导入写 UE：外壳「UE 写入中 n / N」，逐资产行逐行打勾；编排三个按钮变灰写「导入正在写 UE，写完后可用」。
- 编排写 UE（点灯光等，约 2.4 秒）：导入的「导入」变灰写「编排正在写 UE，写完后可用」（双向，待裁决 9）。
- 变灰一律用 `.is-disabled` + `aria-disabled`（不用 `disabled` 属性，悬停才出得了原因），按钮不隐藏。
