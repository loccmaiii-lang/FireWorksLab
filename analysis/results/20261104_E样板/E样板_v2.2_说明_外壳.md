## 文件与接法

| 文件 | 内容 |
| --- | --- |
| `part_css_shell.css` | 外壳顶栏（含三种工作区切换方案）、导入 / 编排工作区、基础模板条目、对话框补充、重新授权气泡、状态栏编排预览、样板开关、全表一节 |
| `part_body_shell.html` | `#wsImport`、`#wsWB` 两个工作区的骨架，样板开关 `#shKit`。放在 `#shParts`（hidden）里：`#shKit` 启动时搬进 `#sbarShell`；两个工作区切到哪个才搬进 `#app` |
| `part_js_shell.js` | 单独一个 `<script>`，不在样板闭包里。菜单、提示条、对话框、操作处提示按样板的 DOM 和类名另写一份；悬停提示用样板的 `[data-tip]` |
| `check_shell.py` | Playwright 走查 + 截图 + 文案自查表（`--no-shots` 只走查） |

- 启动时：`#shKit` 放进 `#sbarShell`；`#shell` 内容按状态生成；`#sheetShell` 一节第一次切到全表时才生成。槽位不在时不报错。
- 工作区：`#wsImport`、`#wsWB` 是 `class="ws"`，用 `hidden` 切换。切到哪个，才把它搬进 `#app`、放在 `#wsBaker` 后面；没切到的放回 `#shParts`（产品区外、隐藏）。这样 `#app` 里只有制作区和当前工作区，样板按 `#app` 全屏统计的规则（如 W0「全屏只有工作模式用 .modeseg」、W15 悬停提示字数）不会数到藏着的工作区；导入的「烟花导入 / ResourceFX 配表」是导入区自己的工作模式，照样用 `.modeseg`。
- 给样板调用的接口：`window.shellAfterExport({name, pc, mobile, alsoWB, layers})`、`window.openSaveDialog()`、`window.shellPickExportFolder()`（同点顶栏导出文件夹标签，菜单出在标签下面）；走查用 `window.SHELL`（`set`、`ws`、`cmp`、`speed`、`state`、`copy`）。

- 另存对话框：名称（空名、和已有效果同名就地报错）；名称下面一行勾选「放进编排」（`.ckl`），下面另起一段小字（对话框正文，两句）。第一次不勾；已放进编排的效果默认勾上，按效果记住（待裁决 4）。
