# FSQ5 / FSQ6 参数生效审查 · 看法（对话框FanGold，2026-10-13）

审看版本：烘焙器 4.9.75（FSQ5 = ea108a8c 之前的 061a2cef 构建；FSQ6 = ea108a8c 构建）。证据：`FSQ5/参数生效审查/参数生效审查.md`、`FSQ6/全景|放大/*.png` 和 json。状态：执行结束、AI 自检过；不需要用户验收（工具检查，不是效果）。

## 方法

`analysis/scripts/参数生效审查.py`：右栏 486 个参数（数值 / 下拉 / 曲线）。每个参数在所有能看到这一行的场景里（32 个场景：各花型默认 + 一个开了 51 项功能的锦冠 + 分簇 / 自定义 / 子花 / 地面 / 升空），改一个值，固定取景出 4 个时刻（0.12 s、0.3 s、30 %、70 %，有燃烧时间的再加 95 % 燃烧），和改前逐像素比，另比取景 / 帧计划。同参数出两次画面一致（结果可信）。

另把这个键从参数里删掉，和「写缺省」同场景比：一样的，右栏缺了显示缺省就是真的。

21 个复核（FSQ6：384 px 全景 + 放大到星那一圈、修了改值规则）：

- 其实生效（10）：开花闪光半径（-1 = 自动，第一轮改成 -0.6 仍是自动）、开花闪光寿命（加了 0.3 s 时刻）、六边形转角、火花形状 / 不规则 / 翻转（96 px 看不出形状）、自定义 1 / 2 延迟随机（场景里延迟 0，随机是按延迟的百分比）、升空摆动频率（摆动幅度 0）、余烬淡出开始（场景开了「余烬跟随星体」活不到淡出段；单独场景云端验证生效）。
- 本来就不进画面（11）：导出缩放、PC / 手机导出、入点 / 出点、格子装法、单格、裁掉开头空白、建议亮部目标、锁定曝光；节奏（拖滑杆时一次性换算其它时间参数，P.tempo 只是记录）。

顺带查出的真问题：CPU 火花（旧版母版 engine ≠ gpu 才走）把余烬衰减 / 余烬淡出开始 / 余烬寿命随机 / 温度随机 / 继承速度随机写死成缺省数。4.9.76 已改成读参数，缺省逐位不变。

## 缺了 ≠ 缺省（71 个）

全是老参数（星数、初速、燃烧时间、火花生成率、喷口……），代码缺了不回落缺省（NaN 或别的值）。这些在存档里一直都有，真缺了是存档坏了，4.9.76 右栏照旧空着提醒，不显示缺省骗人。`sparkPerM` 例外照显示缺省：缺它的存档没有「生成方式 = 每米」，这一行不出来。其余参数（后加的、默认关的）缺了 = 写缺省，4.9.76 右栏显示缺省（默认关的 = 0）。

## 没做

- 升空尾缀 / 尾缀序列 / 物理尾缀 196 个参数没判（要换成它们自己的渲染路径再跑）；右栏缺了照旧显示存档里的值。
- 曲线（按寿命）缺了显示空 = 不随寿命变，和代码一致；自定义 1 / 2 亮度曲线的缺省是「0:1, 0.7:1, 1:0」，缺了是平的，这两条没改。
