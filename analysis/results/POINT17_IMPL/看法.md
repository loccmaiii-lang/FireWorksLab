# POINT17_IMPL · 4.3.8 光点方案实装

执行完成、AI功能自检通过；不是全库效果重新验收，未改任何效果的用户通过状态。

## 已接入与使用

打开牡丹等花型 → 参数栏「分组定位 → 曝光光晕」：
- 亮核分布选择「渐变亮核」。这是发光体分布，按像素积分，保持相对原均匀圆盘的线性总光量、二阶矩；关闭光晕也保留完整绘制范围。星头、GPU火花、爆裂小闪共用；V5兼容高斯、开花闪光和UE独立软圆点不改。
- 「建议亮部目标」可试0.80–0.85，再点击「建议曝光」。默认0.96兼容原计算；不点击就不改曝光。它只控制采样亮部分位，不是所有像素不过曝的保证。
- 颜色栏「显示强度」扩到20倍，仍写入已有Color Over Life；用于在降低贴图曝光后补显示亮度。降低曝光会改变Ramp取色，不能把同一套数值套给全库，也不会自动保持颜色。
- 小星头优先试1024单格；实时模拟显示当前取景的星头标称纹素直径。0.4米小点可能仍需更高分辨率或独立粒子；超采样不能代替输出分辨率。没有自动修改帧率、格子或默认配方。

默认coreProfile=0，保留原着色程序；可选分布按需编译，模拟公式仍共用。默认输出版本保持；启用新分布的条目指纹包含4.3.8-core1。新参数进入完整配方，存档/导出后可恢复。
