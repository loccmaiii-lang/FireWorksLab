# 光点方案实装计划

目标：把 POINT17 的有效方案接入共用渲染核，默认配方逐像素兼容。

1. 保存4.3.7基线；先检查可选核尚不存在（失败证据）。
2. 通用 coreProfile：默认均匀圆盘；可选像素积分渐变核，保总量和二阶矩，关闭光晕时也不裁尾；兼容专用旧高斯分支。
3. 建议曝光增加亮部目标，默认96%；显示强度沿用已有材质乘数并扩展调节范围，明确不写进贴图。增加星头纹素直径提示，不自动改格子或配方。
4. 对真实WebGL单点、CPU/GPU路径、默认基准画面、导出回放、存档及双平台闭环验证。
5. 升版本、构建、更新命名说明、保留检查入口、记录实际结果和UE未验证边界，提交推送并释放源码。
