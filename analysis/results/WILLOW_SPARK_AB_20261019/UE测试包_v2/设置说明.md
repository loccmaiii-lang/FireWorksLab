# 网格垂柳 B 第 2 版 · 本机 UE 沙盒测试包（2026-10-19，研究总览）

> 由 `analysis/scripts/网格垂柳_AB/gen_b.mjs` 从预览页 `tool/prototypes/mesh-willow-ab/index.html` 的同一份算法导出，数值 = 页面默认值（725 m、竖向 60°、1080p）。所有数字也在 `params.json`。
> **只在沙盒副本里试，不动正式资产**（`P_EFX_FireWorks_GoldKamuro_HD / _M`、`MI_EFX_Fireworks_Hero_FlowFixed_01`、`SM_EFX_FireWork_Hero_*` 都不改）。没经过 UE 实测。

## 包里有什么

| 文件 | 用途 |
|---|---|
| `SM_MW_B_PC.obj` | PC 网格：400 束，10,988 顶点 / 10,188 三角（和 `SM_EFX_FireWork_Hero_PC` 一样）。分段、位置都和正式网格相同，只改了每束的宽细（±28 %）和 U（每束选条带里的一个变体） |

**条带和网格必须配套**：`T_MW_StripB` 只能配 `SM_MW_B_*`。配正式网格会每束显示 8 条细线。

## 1. 网格导入

和正式 `SM_EFX_FireWork_Hero_PC` 同一套设置（坐标已按本机实测 UE = (obj.x, −obj.y, obj.z) 写好，见 `MESH_WILLOW_20261016/UE_v2_verify`）：
- Import Uniform Scale 1，Convert Scene 开，Force Front XAxis 关
- Use Full Precision UVs **开**
- Normal Import Method：**Import Normals**（OBJ 里写了共享法线；不这样导，顶点数会变成接近三角角点数）
- Auto Generate Collision 关，Generate Lightmap UVs 关，Combine Meshes 开

导入后核对：顶点 **10,988 / 1,998**；Approx Size 和正式网格基本一样（位置相同，只是带子宽细不同）。不对就停下告诉我。

## 2. 贴图导入

**T_MW_StripB**（和正式 `T_EFX_FireWorks_Hero_FlowFixed` 同口径，RGB 已写成线性值）
- sRGB **关**；Compression Settings：**VectorDisplacementmap**
- Mip Gen Settings：**NoMipmaps**；Filter：Bilinear
- X-axis Tiling：**Wrap**；Y-axis Tiling：**Clamp**
- Texture Group：**DistantVFX**；**不勾 Never Stream**

**T_MW_SparkNoise**
- sRGB **关**（图里写的是线性值）；Compression Default（或 Grayscale）
- 开 mip（From Texture Group）；X / Y 都 **Wrap**
- Texture Group：**DistantVFX**；**不勾 Never Stream**

## 4. 粒子系统

复制 `P_EFX_FireWorks_GoldKamuro_HD` → `PS_MW_B_HD`，`P_EFX_FireWorks_GoldKamuro_M` → `PS_MW_B_M`。

### 4.1 网格发射器（两套都改）

| 模块 · 字段 | 值 | 原值 |
|---|---|---|
| Required · Material | MI_MW_B | MI_EFX_Fireworks_Hero_FlowFixed_01 |
| TypeData Mesh · Mesh | PC：SM_MW_B_PC；手游：SM_MW_B_Mobile | SM_EFX_FireWork_Hero_* |
| Dynamic Parameter · 0 UVIncrement | 线性曲线 (0, 0.9844) → (1, −0.2427) | (0, 0.9941) → (1, −1.2049) |
| Dynamic Parameter · 1 Param2 | 曲线 (0, 0)、(0.8421, 0)、(0.9825, −0.06)、(1, −0.06) | 常数 1.02 |
| Color Over Life · Scale Color/Life | 常数 (2, 0.8378, 0.2557) | (10, 4.188829, 1.278419) |

其余不变：Lifetime 14–14.5、Initial Size 0.5–0.55、Alpha (0, 1)、(0.9814, 1)、(1, 0)、锁 Z 朝相机、Mesh Rotation、DP2/DP3、Use Emitter Time 关。

数值的来由：UVParam.y + DP0 把条带年龄轴拉到约 11.5 s（垂帘挂更久）；DP0 起点 0.9844 = 星头放在第 1008 行，前面留 16 行让星头前沿是圆的（正式条带只留 4 行，前沿被切平，是「方头」的来源之一）；ColorIntensity 5 让星头和亮肩的透明度顶满、颗粒打不进去，Color Scale 同步 ÷ 5，亮度不变；hardness + Param2 打开颗粒。

| Initial Size | 150–250 cm（XYZ 锁定） | 480–600 |
| Sphere · Surface Only | **开** | 关 |
| Sphere · Velocity / VelocityScale | 开 / Uniform 0.03–0.06 | 开 / 0.1–0.2 |
| Sphere · StartRadius | **Uniform Curve**，见下表 | 16000–16500 |
| Sphere · StartLocation | X、Y 常数 0；Z 用 Curve，见下表 | X/Y ±1000、Z −3000…−3500 |
| Initial Velocity | (0, 0, −1000) – (0, 0, −400) cm/s | (2.4, 0.42, −1034.01) |

| 发射器秒 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7–10 |

## 5. 测试步骤

1. 沙盒关卡放 `P_EFX_FireWorks_GoldKamuro_HD`（A）和 `PS_MW_B_HD`（B），相机按 B09 原机位（约 725 m、仰角约 45°），两个分开放、不重叠。
2. PC 高画质、最低画质各看一遍；`PS_MW_B_M` 在手游预览里看一遍。每个看 2 / 4 / 7 / 9 / 11 s 的截图，再连续播放看闪烁。
3. 逐项看作用（在 MI_MW_B 上临时改，看完改回）：
   - 关颗粒：hardness 0、Param2 常数 1.02
   - 关闪烁：NoiseUVParam.z = 0
   - 关 GPU 亮点：L3_Sparkle 关掉
4. 性能：`stat GPU` 或 ProfileGPU，A、B、B 关 L3 三种同机位记一次；记 L3 的活粒子数（应约 435）。

## 6. 验收看什么

- 近看（拉近或截图放大）：B 的星头前沿是圆的、有泪滴形（头比后面略粗），后面一段亮肩再收成细尾；A 是平头。
- 游戏机位 1080p / 1440p：束和束之间有粗细、亮度、亮肩长短的差别，不再是一排一样的色块。
- 3 s 后尾巴断成一串串亮点，一明一暗；不能看起来像贴图在横着滑。
- 束交叠的地方没有暗边、暗纱（母材质是 Translucent，亮度一直放在透明度里）。
- L3 金点在垂柳里面和边上，跟着外扩、下坠，不像一个单独的球。
- 手游：网格层的变化都有，没有 GPU 点。
- 开销：网格发射器顶点数、贴图尺寸级别不变；只多一张 256² 噪声图和 PC 的 L3。

## 7. 预览里没法确认、要在 UE 里看的

- TAA 对 1–2 px 颗粒和小点的抹平程度（可能变暗、变糊）；必要时调大页面「颗粒屏上大小」重出。
- L2_Dots 读回的颜色是 (4, 0.27, 0.42) × 50，实机你看着是金色：预览按金色画的，L3 颜色照抄 L2，实际以 UE 为准。
- 竖向视角 60° 是推断；颗粒大小（沿轨迹约 1.36 m）是按它和 1080p 算的。
- Sphere 曲线的横轴（见 4.2）。
- 星头 / 亮肩 / 尾巴的亮度比例、Color Scale 和曝光的配合。
