## 0. 先导轴向试件、再核点数（3 分钟，不过就停）

1. 导入 `SM_KKB_AxisTest.obj`（导入设置见第 1 步）：Approx Size 应为 **1000 × 2000 × 3000**，Z 朝上。
2. 导入任一网格后，顶点数必须与上表一致（静态网格编辑器 Vertices）。如果约等于三角数 × 3，说明法线没导入、顶点被拆开了，检查 Normal Import Method。
3. 包围盒（cm）应与 `params.json` → 档位 → UE包围盒 一致（橙引线层 ±8,800 左右、金锦层 ±11,700 左右）。
4. 不对：先停，把读数告诉我。不要在错的网格上继续配粒子。

## 1. 网格导入设置（本机 UE 4.24 实测过的口径）

- Import Uniform Scale 1，Convert Scene 开，Force Front XAxis 关（OBJ 坐标已按「UE = (obj.x, −obj.y, obj.z)」预先换好）
- Use Full Precision UVs **开**（U 到 60 以上）
- Normal Import Method：**Import Normals**（OBJ 里写了显式共享法线；不要选 Compute，会把顶点拆开）
- Auto Generate Collision 关，Generate Lightmap UVs 关，Combine Meshes 开
- 导入后删掉 LOD 1–3（原系统 LOD 距离 0 / 150 / 200 / 250 m，1 km 外会用最后一级）；Distance Field Resolution Scale 设 0

## 2. 贴图导入设置

**T_KKB_Strip_Lyr0 / Lyr1**（RGB 已写成线性值）
- sRGB **关**；Compression：VectorDisplacementmap（RGBA8，不压缩）
- Mip Gen：**NoMipmaps**；X（U）**Wrap**；Y（V）**Clamp**；**Filter 显式选 Bilinear（不要 Default）**；**不勾 Never Stream**、贴图组 DistantVFX（用户 10-18 贴图规范；本说明 10-16 初版写成「Never Stream 开」，10-19 更正）
- 依据（本机 17:25–20:34 排查，`QUALITY_REPEAT_1725/排查结论与修复.md`）：每束用一个整数 U 偏移，U 会到 60 以上，U 方向 Clamp 会把大多数束压到贴图边缘；Filter 用 Default 会随画质档改变采样，最低 / 极高画质下弧尾和白热段显示不一致。把这两项显式写死后，用户 20:16 / 20:34 确认高配和最低配都正常。本包沿用同一分工（U Wrap / V Clamp / Bilinear），但**这包的贴图本身还没在 UE 里实测**
- 如果材质实例报 sampler 类型不匹配，按报错改并告诉我，我改贴图写法

**T_KKB_Grain**
- sRGB 开，Compression Default，开 mip，X / Y 都 Wrap

## 5. 怎么看、怎么验收

1. 机位：1 km 外、地面高度，关自动曝光（Min / Max Brightness 都设 1），三档轮流放同一点。
2. 对照：预览页同取景的截图在 `../对照/`（0.6 / 1.2 / 2.0 / 3.0 / 4.5 s）；UE 里同一秒截图对比。**烘焙器同一秒的图只对了三帧（橙引线层 0.8 / 2.0 s、金锦层 2.0 s）**（云端软件渲染一帧要约 7 分钟，完整对照要排本机 GPU）：外廓一致，带宽按覆盖率定为 2 m；其余时刻的星束疏密、尾巴长短、亮度没有和烘焙器对过。要看的是：星束数量、长短、颜色走向（橙 → 金 → 暗）、整体外廓，不是逐像素。
3. 高配（十字）：绕一圈带子不翻转、不变细；**这是原约束「镜头不转」的版本**。
4. 低配 / 手游（锁 Z）：整朵会随相机方位转，这是锁轴的本性。判断标准是**游戏机位平移几十米时你会不会察觉**；未量化，由你定能不能接受。
5. 星头外面不应有细线（贴图不开 mip）；极高 / 最低画质各看一次：弧尾和白热段应一致（Bloom / 曝光 / AA 的亮度差异仍会有，那不是网格问题，本机排查已说明）。
6. 手游档：只验证渲染顶点数 = 2,000 的预算，**手机上的材质兼容和性能没验证**。

## 6. 未验证 / 已知近似（别当成已确认）

- 全部网格、贴图、材质设置**未经 UE 实测**；本机之前验证的是 v2 的试件，不是这包。
- 尾巴亮度只随「年龄」变化（来自烘焙器火花公式的整体平均）：金锦层火花率随时间上升（sparkRamp 1.01 s）、不同星的火花寿命不同，这两点网格表达不了，同秒图里尾巴的疏密会和烘焙器有差别。
- 每束只有一条轨迹线：烘焙器里一颗星后面是一团粒子云，网格版是一条带，细节（火花流动感）靠颗粒贴图近似。
- 位置误差：高配 p95 约 0.6 m，低配约 1.2 m，手游橙引线层 1.6 m / 金锦层 2.8 m（1 km 处约 1–3 px）。手游金锦层的 2.8 m 是为了卡进 2,000 点的取舍。
- 「单束的序列」没有做成序列贴图：Soft 母材质只有普通 SubUV，没有 RGBA 接力解帧；FireBase 有 RGBA 解帧但没有独立 UV 平移，单个材质实例两样都做不到。现在是「静态条带 + UV 滑动」，滑动已在本机 UE 验证过。
