## 0. 先导轴向试件（1 分钟）

导入设置同第 1 步。打开静态网格编辑器看 Approx Size，应该是 **1000 × 2000 × 3000**（X 10 m、Y 20 m、Z 30 m 朝上）。
- 对了 → 继续。
- 不对 → 先停，把三根杆各沿哪个轴告诉我，我改映射重出（或在导入时填 Import Rotation）。

## 1. 网格导入设置

- Import Uniform Scale 1，Convert Scene 开，Force Front XAxis 关
- Use Full Precision UVs **开**（U 到 64、V 到 1.2，半精度不够）
- Normal Import Method：Compute Normals（OBJ 里没写法线；材质是 Unlit，法线不影响画面）
- Auto Generate Collision 关，Generate Lightmap UVs 关，Combine Meshes 开
- 导入后在网格编辑器里把 Distance Field Resolution Scale 设 0（项目若开了网格距离场）

## 2. 贴图导入设置

**T_MW_Strip**（和原 T_EFX_ShellTrail_02 同口径，RGB 已写成线性值）
- sRGB **关**；Compression Settings：VectorDisplacementmap（不压缩 RGBA8）
- Mip Gen Settings：**NoMipmaps**（细线就是 mip 漏出来的，必须关）
- X-axis Tiling Method：**Wrap**；Y-axis Tiling Method：**Clamp**
- Never Stream 开
- 如果材质实例报 sampler type 不匹配，按报错改 sRGB / 压缩，并告诉我，我改贴图的颜色写法

**T_MW_Grain**（和原噪声 T_EFX_Mask_62 同口径）
- sRGB 开，Compression Default，开 mip，X / Y 都 Wrap

## 4. 粒子系统（两套，只有网格和朝向不同）

复制 `P_EFX_FireWorks_Hero_HD` 到沙盒，叫 `PS_MW_Cross`。**删掉另外 12 个发射器，再删掉 LOD 1–3**：原系统的 LOD 距离是 0 / 150 / 200 / 250 m，1 km 外会用最后一级 LOD，改了 LOD 0 也看不到。

**System**
- System Update Mode：先用 **Real Time**；再切回 FixedTime 10 FPS 看一次有没有一格一格跳（项目统一口径是 FixedTime，这一条最后由你定）
- Use Fixed Relative Bounding Box 开：Min (−60000, −60000, −60000)，Max (60000, 60000, 60000)

**网格发射器（原第 5 个 Particle Emitter）**
- Required：Material = MI_MW_Strip；Screen Alignment = Square（不改）；Emitter Duration 16.1；Emitter Loops 0（循环播放，方便看）
- Spawn：Rate 0；Burst 1 个 @ 0
- Lifetime：16.1
- Initial Size：(1, 1, 1)；**删掉两个 Size By Life**（网格已经是真实大小，不再整体缩放）
- **删掉 Mesh Rotation**（不要随机偏航；锁轴那套有了它会偏）
- Color Over Life / Scale Color Life：颜色 (9, 9, 9) 起步，按游戏里亮度调；Alpha：0 → 1、0.9814 → 1、1.0 → 0
- Dynamic Parameter（Use Emitter Time 都关）：
  - 0 UVIncrement：线性曲线，(0, 0.9941) → (1, −1.2049)
  - 1 Param2：先给常数 1.02（原 2.0 起点，推断是完全可见）；看颗粒时逐步调小（0.8 / 0.6 / 0.4），把看着对的值告诉我
  - 2、3 保持 1
- TypeData Mesh：Mesh = SM_MW_Cross_N400；Override Material 开；Cast Shadows 关；**Camera Facing 关**

再复制一份叫 `PS_MW_LockZ`，只改 TypeData Mesh：
- Mesh = SM_MW_Single_N400_LockZ（手游试件换成 SM_MW_Single_N130_LockZ_Mobile）
- **Camera Facing 开**
- Camera Facing Option = **Locked Axis : Z Axis Facing**
- Axis Lock Option = **Z**
- Apply Particle Rotation as Spin 关，Face Camera Direction Rather Than Position 关

快速判断锁轴设对没有：
- 花是立着的，正面看和十字那套一样 → 对了。
- 花**横躺**（侧着倒下）→ 锁轴没生效（网格本地 X 朝上）。试：Required 的 Screen Alignment 改成 Type Specific 再看；还不行告诉我。
- 立着但薄成一片线 → 朝相机的是 Y 不是 Z：把 Camera Facing Option 改成 Locked Axis : Y Axis Facing。

## 5. 怎么看

1. 放一个 CameraActor 在游戏机位（离花 1000 m 左右、地面高度），两套轮流放在同一个点；关掉自动曝光（后处理里 Min / Max Brightness 都设 1），否则两次亮度没法比。
2. 播放时星头应该从爆点往外走、尾巴留在后面。如果整片不亮、或者星头往回走，说明 UE 导入时 V 的翻转和我预计的相反：先把 MI 的 UVParam 改成 (1, −1, 0, 1) 试，告诉我结果。
3. 十字：编辑器里绕一圈，带子不应变细、不应翻转；斜 45° 时会比正面亮一点（最多约 1.4 倍）。
4. 锁 Z：编辑器里绕一圈会看到整朵跟着转，这是锁轴的本性。要判断的是**游戏里**会不会被看出来：在游戏机位左右平移几十米、慢慢走动，看是否察觉到转动。正下方往上看时它会乱转，这个角度你之前说可以放宽。
5. 星头外面不应有细线（第 2 步贴图不开 mip）。
6. 两套各截 2 / 4 / 6 / 7.5 s 四张，加一段绕圈和平移的录屏。
