# 单光点成像诊断 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用当前烘焙器真实WebGL核查明平顶、方边与光感不足的来源，给出实测方案；本轮不实施生产修复。

**Architecture:** 隔离脚本只读当前HTML，调用实际drawPoints/packCell40/编码及材质显示着色器；改变单一变量并读回像素。小尺寸离屏画布保持等效每米像素数，另用真实牡丹配方核对每格比例。原数据、环境、源码指纹与审看结论一起保存。

**Tech Stack:** Python 3.12、既有Playwright依赖、Chromium WebGL2、Pillow、NumPy。

## Global Constraints

- 不新增UE材质、不写引擎代码；不改tool/src、默认配方、验收状态。
- 标为诊断，不作为标准检查全过的效果候选，也不是UE实测。
- 不用模糊图像伪造改进；视觉来自真实渲染输出。
- 使用已安装依赖，不安装插件；不打开用户正在用的浏览器会话。

### Task 1: 核心与管线采样

**Files:** Create `analysis/scripts/point_light_diagnostic.py`; outputs `analysis/results/POINT17/`。

**Interfaces:** 脚本载入生产HTML，注入诊断函数；返回每组输入、线性光量/峰值、编码峰值/饱和数、实际PNG，JSON记录完整环境和配方。

- [ ] 以独立无头Chromium启动既有HTML，关闭自动播放与自动烘焙，记录真实GPU型号。
- [ ] 静止点直径0.40/0.65/1.4m；相位0/0.25/0.5像素；亮度0.3/1/3；光晕0/.22；在512/1024等效每米像素下读回结果。
- [ ] 同一线性图分别量原值、1-exp(-exposure*x)编码、Ramp合并/分开上色、最终显示；亮度倍数保持可追溯。
- [ ] 测静止与运动（0/20/100m/s），快门0/.2/.6，持帧1/30与1/10秒；量线性总量、峰值与空间扩展。
- [ ] 复用shader绘制等效放大与正常显示，不能用人为后处理当修复。真实配方用defaultsFor('botan')及displayPlan40，保持其余参数一致。

### Task 2: 分析与交付方案

**Files:** Create `analysis/results/POINT17/看法.md`; update `对话记录/对话框17.md` and `交接.md`。

**Interfaces:** 消费Task1的JSON/PNG；产出归因、条件性推荐、回归验收要求。

- [ ] 能量检查：尺寸从.4到.65在同亮度下预期面积比(.65/.4)^2；亮度翻倍预期线性总量翻倍；相位变化不应使总能量大幅变化。
- [ ] 比较同取景的512/1024、同总光量不同显示增益、Ramp/纯色，明确哪些改善经过实测、哪些只是建议。
- [ ] 实际查看对照图，区分诊断图的放大和游戏内真实大小；图与JSON指纹相符。
- [ ] 提交前运行 `python -X utf8 analysis/scripts/标准检查.py --ui-state-only`、`git diff --check`；文档/诊断提交不声称效果验收通过。
