# JM4-40E2 看法（对话框2，2026-10-01）

**结论：可以进「待我验收」。** 回放检查唯一没过的「中心跳变 3.83 px」是测量问题，不是画面在晃。

- 素材：2 张 2048（4×4×RGBA，单格 512），A 64 帧 + B 46 帧，共 3.67 s；30 fps 下 A 显示 63/64、B 45/46，每次最多前进 1 帧，没有回跳。A→B 衔接处（1.83 s / 2.57 s）回放连续，没有空档。
- 裁切 0、过曝像素 ≤ 0.08%、中间 / 末尾空帧 0。
- 中心跳变：3.83 px 只发生在 A 的第 0 → 1 帧。第 0 帧是开花那一瞬，只有 1414 个亮像素，中心是噪声；之后 A 全程 ≤ 1.0 px，B ≤ 2.1 px（512 格）。原因是「亮像素太少不算」的 400 像素门槛是按 256 格定的，没按 512 格的面积换算；已改成按格子面积换算（512 格 = 1600 像素），及格线 3 px 不变。用这次的逐帧中心数据重算：A 最大 1.0、B 最大 2.1，通过。
- 实时模拟和导出效果同一秒对得上（`烘焙回放.jpg`）。和实拍比：形状、颜色、时间和 JM4 一致；火花比 3.7 细、清楚，光晕少一些，亮处偏白一点（见审阅卡）。
