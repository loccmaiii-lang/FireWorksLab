- 柠点星：大小随寿命缩小（FWHM 5.6 / 5.1 / 3.9 / 2.2 px 对实拍 5.5 / 5.1 / 4.3 / 2.9）、拉长比 1.1 都对上了；光晕占比要 coreProfile 1 + 光晕 0.45 才到实拍的 0.05；颜色：丙 / 戊 的柠绿渐变图太绿（色相 75–95°，实拍 49–69°，线性光），甲 / 乙 太白太淡。
- 橙引尾：甲 起火花密 / 粗 / 热以后成串从 0.33 降到 0.15–0.19（实拍 0.12），但**整体变成了黄金色**（看 对照_0.47：实拍是橙、线间透一点天），对比度 0.7–0.9（实拍 0.3–0.4，线之间有一层光）；+0.8 s 实拍线带外端已经退到 0.74 R（火花在 ≈ 0.5 s 停、尾巴还挂 0.4 s），甲 停在 0.7 s 太晚。
- 金菊蕊：+2.0 s 甲 起整团偏亮偏黄（实拍是细密的橙丝），+1.2 s 纯白一块（实拍淡金白、有丝的纹理）；沿线起伏 0.26–0.36（实拍 0.06–0.15）= 丝太稀太断。
- 丁（柠点星层加余烬做青绿细线）没出线：只有 40 粒 / 秒的火花，余烬没起来；下一轮改成柠点星层自己的淡火花（0.9–2.6 s，寿命 1 s，不跟星走）。
