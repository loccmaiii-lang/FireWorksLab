T_Crossette_Willow_A.png（星头、闪光、拖尾合并）
T_Crossette_Willow_B.png（星头、闪光、拖尾合并）
尺寸 2048×2048，灰度（线性），RGBA 接力：先填满 R 的 16 格（第 0–15 帧），再接 G（16–31）、B（32–47）、A（48–63）
格子 4 列 × 4 行，行优先，左上为第 0 帧；单格 512×512 像素；共 64 帧；格子四周留空 2 像素
导入：sRGB 关闭，压缩 BC7；1K 版本在引擎里复制一张，把最大尺寸设为 1024 即可
T_Crossette_Willow_FrameTest.png（帧号测试）：排查用。格子、接力、取景与正式贴图完全相同，内容是帧号 + 以爆点为中心的固定大小圆和网格。
  把材质实例的贴图临时换成它播放：帧号应连续递增不倒退，圆应不动、不胀缩、不变扁。
  帧号乱跳 / 倒退 → 帧号曲线或材质的接力解码不对；圆胀缩、晃动 → Size By Life / 位置曲线不对；圆变扁 → 对齐方式或 Initial Size 不对
T_Crossette_Willow_Ramp.png：渐变图 256×8（sRGB；最右一格黑 = 护栏，4.9.31），灰度从暗到亮依次取：拖尾冷却色 → 拖尾高温色 → 星头高温色

项目现有的 RGBA 序列帧材质；列 = 4，行 = 4；Ramp = T_Crossette_Willow_Ramp

【Cutout：裁掉面片上的空白，减少 overdraw】
段 A：Required → Cutout Texture = T_Crossette_Willow_A_Cutout（512×512，所有帧叠在一起的轮廓）；
  Sub Images Horizontal = 1，Vertical = 1；Bounding Mode = Eight Vertices；Opacity Source Mode = Alpha；Alpha Threshold = 0.1；不加 SubUV 模块。
  面片剩下约 49%（引擎按轮廓外接八边形，会略大一点）。材质照旧用 Dynamic Parameter 帧号通道取帧。
段 B：Required → Cutout Texture = T_Crossette_Willow_B_Cutout（512×512，所有帧叠在一起的轮廓）；
  Sub Images Horizontal = 1，Vertical = 1；Bounding Mode = Eight Vertices；Opacity Source Mode = Alpha；Alpha Threshold = 0.1；不加 SubUV 模块。
  面片剩下约 55%（引擎按轮廓外接八边形，会略大一点）。材质照旧用 Dynamic Parameter 帧号通道取帧。

  段 A：过曝：无
  段 A：边缘渗色：无（留边 2 像素）
  段 A：通道布局：R 有内容，G 有内容，B 有内容，A 有内容
  段 A：近似帧：0 对相邻帧几乎相同
  段 A：每帧最大位移 25.9 像素，开花初期可能跳帧：可增加格子数或调高最低帧率
  段 B：画面占比：平均 83%，最差 10% 的帧 ≥ 81%（紧凑取景已禁用：引擎里会抖；想更满可以减少留边或改随开花放大）
  段 B：过曝：无
  段 B：边缘渗色：无（留边 2 像素）
  段 B：通道布局：R 有内容，G 有内容，B 有内容，A 空；有空通道，可减少帧数或改单通道
  段 B：近似帧：0 对相邻帧几乎相同
  段 B：每帧最大位移 25.9 像素，开花初期可能跳帧：可增加格子数或调高最低帧率

【LOD 建议（1080p、竖直视角 60°）】
LOD 0：0–127 m，全部层，2K 贴图
LOD 1：127–255 m，屏幕上已小于单格像素：1K 贴图即可；粒子数/火花发射率减半；关闭 Light
LOD 2：255 m 以外：只留本层；去掉芯（小缩放的牡丹层）和烟
（Cascade：粒子系统的 LOD Distances 依次填 0、12700、25500，单位 cm）


【说明】
面向相机的精灵用 Initial Location 的 Z 偏移对齐爆点；从很陡的仰角看时会有轻微偏差。
Crossette_Willow.json 保存了全部参数，用烘焙器「导入参数 JSON」即可继续修改。
