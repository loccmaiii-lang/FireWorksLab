# UI8 看法（4.1.2，对话框2）

- 层轨道把手、拖第 2 层入点（7.03 s）、拖入点后的引擎回放、尾迹外形前后（金芒菊 泪滴 0.7 / 粗细随机 0.8 / 亮肩 0.6）都正常。
- 帧间隔：鸿巢实时模拟开花后 1 s 和 8 s 的中位数都是 83.4 ms（p95 133 / 150 ms）——后段不再变慢（以前每帧从 0 重算）。整体约 12 fps，是实时模拟本身重（鸿巢火花多、按导出分辨率），另查。
- 最后一步（升空尾缀查看交付）出错是任务脚本的问题：单层 openEffect 不返回 Promise，`.then` 报错；UI9 改用 Promise.resolve。
