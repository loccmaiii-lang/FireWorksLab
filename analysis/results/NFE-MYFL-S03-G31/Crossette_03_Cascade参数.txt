烟花母版：Crossette_03（分裂（十字））
工具：烟花母版烘焙器 4.9.31（模拟内核：GPU；产物：大面片母版）

【贴图】
T_Crossette_03.png（星头、闪光、拖尾合并）
尺寸 2048×2048，灰度（线性），RGBA 接力：先填满 R 的 16 格（第 0–15 帧），再接 G（16–31）、B（32–47）、A（48–63）
格子 4 列 × 4 行，行优先，左上为第 0 帧；单格 512×512 像素；共 63 帧；格子四周留空 2 像素
导入：sRGB 关闭，压缩 BC7；1K 版本在引擎里复制一张，把最大尺寸设为 1024 即可
T_Crossette_03_FrameTest.png（帧号测试）：排查用。格子、接力、取景与正式贴图完全相同，内容是帧号 + 以爆点为中心的固定大小圆和网格。
  把材质实例的贴图临时换成它播放：帧号应连续递增不倒退，圆应不动、不胀缩、不变扁。
  帧号乱跳 / 倒退 → 帧号曲线或材质的接力解码不对；圆胀缩、晃动 → Size By Life / 位置曲线不对；圆变扁 → 对齐方式或 Initial Size 不对
T_Crossette_03_Ramp.png：渐变图 256×8（sRGB；最右一格黑 = 护栏，4.9.31），灰度从暗到亮依次取：拖尾冷却色 → 拖尾高温色 → 星头高温色

【材质实例】
项目现有的 RGBA 序列帧材质；列 = 4，行 = 4；Ramp = T_Crossette_03_Ramp

【Cutout：裁掉面片上的空白，减少 overdraw】
Required → Cutout Texture = T_Crossette_03_Cutout（512×512，所有帧叠在一起的轮廓）；
  Sub Images Horizontal = 1，Vertical = 1；Bounding Mode = Eight Vertices；Opacity Source Mode = Alpha；Alpha Threshold = 0.1；不加 SubUV 模块。
  面片剩下约 55%（引擎按轮廓外接八边形，会略大一点）。材质照旧用 Dynamic Parameter 帧号通道取帧。

【Cascade 发射器】
Required：Screen Alignment = Rectangle（面向相机，X、Y 尺寸分开生效；不要用 Square——Square 只认 X，Y 方向会按错的比例缩放，画面变形、抖动）；Emitter Duration = 2.10 s；Emitter Loops = 1
所有曲线（Size By Life、Dynamic Parameter 帧号、Color Over Life、Location / Velocity 等）：每个关键点的 Interp Mode = Linear。CurveAuto 会在关键点之间冲过头：尺寸来回抖、帧号倒退一抖一抖。Size By Life 勾选 Multiply X、Multiply Y。
Spawn：Rate = 0；Burst：Count = 1，Time = 0
Lifetime：2.10 s（常量）
Initial Size：X = 6085 cm，Y = 6085 cm（常量）
Initial Location：0；Required → Pivot Offset = (−0.5, -0.4571)（爆点在贴图里的位置：面片中心比爆点高 -261 cm；面片总是面向相机，用 Pivot 对齐仰视时也不错位；未经 UE 验证）
Dynamic Parameter：帧号通道（按导入配置，实测第 0 通道）= 帧号；Use Emitter Time 不勾选；曲线插值 Linear

【帧与流畅度】
平均 30.0 fps，最低 30.0 fps，每帧最大位移 9.4 像素（建议 ≤ 3）
平均面片面积为最大尺寸的 100%（overdraw 按此折算）

【自检】
  画面占比：平均 59%，最差 10% 的帧 ≥ 19%（紧凑取景已禁用：引擎里会抖；想更满可以减少留边或改随开花放大）
  过曝：无
  边缘渗色：无（留边 2 像素）
  通道布局：R 有内容，G 有内容，B 有内容，A 有内容
  近似帧：0 对相邻帧几乎相同
  每帧最大位移 9.4 像素，开花初期可能跳帧：可增加格子数或调高最低帧率

【烟（开花烟，用项目现有烟雾贴图）】
Spawn：Burst Count = 8；Lifetime 4.61–9.61 s
Location → Sphere：Velocity 勾选，速度约 4467 cm/s；Drag = 3.26（烟团很快停在星走过的地方）
Initial Size 600 cm，Size By Life 1 → 3（扩散）
Alpha Over Life：0 → 0.3（在 0.09）→ 0
颜色：前 0.61 s 被火光照亮，乘本母版 Color Over Life 与 Light 曲线；之后转为场景夜空灰

【LOD 建议（1080p、竖直视角 60°）】
LOD 0：0–111 m，全部层，2K 贴图
LOD 1：111–222 m，屏幕上已小于单格像素：1K 贴图即可；粒子数/火花发射率减半；关闭 Light
LOD 2：222 m 以外：只留本层；去掉芯（小缩放的牡丹层）和烟
（Cascade：粒子系统的 LOD Distances 依次填 0、11100、22200，单位 cm）


【说明】
面向相机的精灵用 Initial Location 的 Z 偏移对齐爆点；从很陡的仰角看时会有轻微偏差。
Crossette_03.json 保存了全部参数，用烘焙器「导入参数 JSON」即可继续修改。
