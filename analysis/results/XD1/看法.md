# XD1 看法（对话框2，4.2.12 光点层试导）

素材包打出来了：PC cascade = 主层两张序列 + `L2_Dots`（GPU、soft_dot、没有贴图）；手机 = 主层 + 红点层序列，Cut / Ramp 都在。

三个问题，4.2.13 修：
1. **烘焙回放里红点从开花就亮、9 s 时反而没了**——实时模拟里红点是主层烧完才亮（红点层是「第二段」：主段期间不发光）。光点的寿命和亮度曲线以前只按点火 + 燃烧算。现在直接跑一遍模拟，按每颗星的星头亮度定（`dotVis`）：寿命 = 每颗星最后亮着的时刻，亮度曲线按「时刻 ÷ 寿命」平均（延时点火、星头压暗、第二段、渐隐都在里面）。combo_pack_check 加了「第二段主段期间不亮」。
2. 回放检查出错（`'seq'`）：组合包的回放检查把光点发射器也当序列读。改成只查「一个面片放序列」的发射器，光点 / 单束跳过并记日志。
3. 包根目录多了 `T_Hongchao40Dots_Mobile_L2_FrameTest.png`（手机帧号测试图没被丢掉）。4.2.13 起手机测试图一律丢掉。
