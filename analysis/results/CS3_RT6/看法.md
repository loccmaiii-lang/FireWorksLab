# Comet / Silver 3.0：待用户验收

本次使用4.9.77烘焙器重新模拟，导出（23）的RT6近远合并为底层；原Blender资产只作参考。Comet保留红头独立、金尾合并；Silver合并银白星头、亮肩、细尾和远段余烬。没有替换旧正式库。

## 看到的形态与时序

- Comet：红头紧凑，金尾较细、颗粒分离，少量较亮余烬在尾后漂散。头尾同一90米弹道；约2.1584秒头部熄灭，此后只剩金色余烬，序列到5.9333秒。手机红头使用既有CPU soft_dot，是紧凑红点；PC独立单帧贴图保留短焰。
- Silver：银白头后的亮肩更长、细粒更密；尾端逐渐破碎成散点。约2.2263秒燃尽，余烬持续到6.9333秒。未把Blender原地母动态4.8秒或历史引擎播放2.8秒当成新弹道燃烧时间。
- 两款尾迹均64帧，PC2048²、手机1024²，16×1×RGBA；细长格按面积等效512²/256²检查。Comet PC另有512²单帧星头，位置由同一速度曲线连续推进。

实际图见 `CS3C_PC_回放.jpg` / `CS3S_PC_回放.jpg` 和各自Mobile图；浏览器实时/导出/贴图截图一并保存。按全程30Hz tick核对帧序与寿命，人工审看0.6、1.4、2.1、2.5、3.5、5.2秒，红头燃尽后没有继续随余烬亮着。普通工作台按用户此前约定只显示PC，手机另用实际手机产物及相同渲染函数核对，不能把强制切平台后又回到PC的截图当作手机验证。

## 验证与复现

- `输出检查.json`：真实ZIP中的PC/手机配置、每个贴图引用与SHA256、尺寸、发射器数量、模块数值和回放检查。4个平台组合全部通过；全部序列帧可显示，无空帧/回跳，边界光量为0，最大饱和值占比低于2%。手机CPU红头不适用贴图检查，另核对曲线与合成回放。
- `标准检查快照.json`：当前候选和45项回归条目标准检查通过。`逐像素回归.json`：与4.9.76基准比较六模板及现有主条目共45项，序列/远段/淡出RGBA逐字节一致。
- `入口检查.json`：默认分段、PC合并、手机独立近段/合并、原始GPU参数保留及命名引用检查。`cs3_replay_motion_check.py`验证Absolute VelocityOverLife积分（先失败后修复）。
- `操作走查.json`：真实页面打开、实时/导出/贴图视图、数值控件、保存、刷新重开、ZIP下载，无页面错误。验证用改参包与交付包分开，交付仍用原推荐参数。
- 老版 `bake_state_check.mjs`有两项夹具错误（缺归档base、store未定义），在4.9.76同样出现，详见`旧版界面检查.json`；本次不扩展范围修历史测试。
- 可复现入口：`analysis/scripts/cs3_bake.cjs CS3C CS3S`、`cs3_verify.py`、`cs3_ui_check.cjs`、`rt6_full_pc_check.cjs`、`cs3_regression.cjs`。Windows GPU任务要使用仓库统一GPU锁。完整展开参数在`完整参数.json`，配方在`analysis/原理/条目_CometSilver3.json`。
