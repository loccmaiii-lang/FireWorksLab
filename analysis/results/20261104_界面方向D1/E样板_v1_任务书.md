## 2. 主屏结构（用户 20:17、20:33 定）

- **左栏上：结构树**（当前效果）。整体 → 层 → 发射器（仙女棒嵌套 3 级）、输出、＋ 加层、＋ 加发射器；每行 显示 / 只看 / ⋯（⋯ 只在悬停或选中行出现）。层多时可滚动。
- **分隔条**：可上下拖动；结构树与效果库各自能折叠成一行标题。
- **左栏下：效果库**，照 `参考_编排资源库标签.png` 的模式：
  - 一级大标签：**效果 / 模板**（字号与该参考一致，选中项绿色下划线）；
  - 「模板」下二级标签：**花型模板 / 多层花型模板**；
  - 搜索框（占位写清能搜什么：名字、任务号、花型）；
  - 筛选块（例：全部 / 球花 / 尾缀 / 扇形），选中块用**绿色细框**；
  - 一行：排序或范围下拉（原生下拉）· 数量 · ＋ 新建；
  - 列表：缩略图、名称、副信息、状态文字（新、待验收、制作中、已通过——只是文字，**不分组**）、多档效果写「3 档」；
  - 底部：复制我的意见。
- **时间轴**：行与结构树**当前展开的行一一对应、顺序相同**（结构树折叠，时间轴也折叠），各自可滚动但滚动同步；选中行同步高亮。时间轴只做时间相关操作（拖播放头、拖区间、设入点 / 出点 / 清除、两个选项）。
- **右栏检查器**：只放参数。顶部：当前对象路径（例「仙女棒 › 05 分裂母粒 › 06 一级分叉 › 08 二级碎火星」，路径中的每段可点）；多档效果在标题旁有档位切换（分段选择或下拉）；参数搜索、显示 ▾；参数模块；底部只放保存状态。
- **中间**：保持 E v2 的工具条、视图条、画面（四角裁切标记）、技术信息一行、播放条（播放、重播、速度、循环、时间、时间工具、生成缩略图）、胶片条 + 刻度 + 轨道。
- **顶栏**：产品名、版本、显卡型号（右上角）、资源交付、更新记录。
- **选中态（当前编辑对象）**：**绿色细框**（1 px 薄荷绿描边），结构树、时间轴、效果库同步；不用底色块 + 左侧粗条。
- **主按钮**：一屏只有一个实心主按钮——当前状态「需重新导出」→ 导出 ▾ 为实心；保存为文字按钮。

## 3. 设计规则（参考_RefactoringUI规则.png 摘要，逐条遵守）

1. 个性由字体、颜色、圆角、措辞决定，全界面一致：Noto Sans SC + Inter 等宽数字；颜色只用固定色板；圆角 0–2 px；文案书面、简短。
2. 先用黑白灰把层级做对（间距、字重、对比度），颜色只强调重点。
3. 层级不单靠字号：两三种文字颜色 + 两种字重（400 / 600）。
4. 突出重点靠弱化其他元素。
5. 减少不必要的标签：能靠内容看懂的不加标签。
6. 按钮分级：一屏一个实心主按钮；次要操作浅底；辅助操作文字按钮；危险操作只在确认时用红色。
7. 留白先多后收；不强行填满空间。
8. 组与组的间距大于组内间距。
9. 小屏不照搬大屏比例（1366 下字号、间距单独定）。
10. 大小字按基线对齐。
11. 完整色板：中性色 9–10 档、主色 5 档、警告 / 错误 / 成功各 3 档；正文对比度 ≥ 4.5 : 1。
12. 不单靠颜色传达信息（状态配文字或形状）。
13. 用强调色细边突出重点（选中的导航项、当前对象）——即「绿色细框」。
14. 复杂背景上的文字要保证可读（画面上的技术信息）。
15. 图标尺寸合适，不强行放大；截图 / 缩略图不缩到看不清。
16. 少用分割线，优先用底色差、留白。
17. 设计空状态：我的模板为空、搜索无结果、参数「仅显示已改」为空——都要有说明和一个操作。

## 4. 组件全表

把清单第 2–4 节的每个组件按「变体 × 状态」排成网格，每格都是真组件（同一份样式），交互能用：

- 状态用强制类名画出静态版本（悬停、焦点、按下、停用、错误、加载），旁边放一个能真点的实例。
- 原生下拉：用浏览器原生 `<select>`，样式与自定义菜单一致（截图拍不到原生弹出层，在说明.md 注明）。
- 曲线编辑：至少一条可拖动关键点的曲线（仙女棒「大小曲线」）。
- 交付产物表：每层一行，列 PC / 手机 / 状态（示例值，注明为示例）。
- 编排、导入器专用部件：资源库列表、点位选择组、输入建议列表、连接状态标签、导入范围——各画一个基本形态。
