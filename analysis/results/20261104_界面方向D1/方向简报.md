## 已决原则台账（4 个方向都必须遵守）

| 编号 | 原则 | 来源 |

| P1 | 颜色只用现有蓝灰中性色 + 薄荷绿主色 + 警告 / 错误色；色相不改，用量、比例、位置可大胆调整 | 用户（「不要改我现在所有的主色辅色高亮色」） |

## 明确禁忌（AI 痕迹）
发光 / 光晕、装饰渐变、卡片套卡片、药丸标签、emoji、无意义的徽章、假旋钮等拟物装饰、左右对称的模板化布局（方向 A 的对称是有意为之除外）。

## 方向 A ·「示波器」

- **种子与子模式**（种子 2）：数字中 8 出现 5 次 → 8 格刻度、8 px 基础单位；「00 77 00」成对镜像 → 以画面中轴对称；两段很长的小写字母串 → 大面积安静区域，不填东西。
- **跨界灵感**：实验室示波器的屏幕与读数（刻度格、通道迹线、屏幕边缘的测量读数），不做旋钮拟物。
- **期望感受**：精密、冷静，像在测量一束光。
- **配色**：几乎全是 g0–g2 黑蓝；刻度线 g4；文字 g7 / g8；薄荷绿只当「迹线」用——播放头、当前取值线、选中项的细框或括号；没有实心按钮。
- **布局**：视图就是仪器屏幕，四周是 8 × 10 格刻度，屏幕边缘排读数（当前时间、总长、距离、曝光）；时间轴变成「通道」CH1–CH3，用阶梯迹线表示发射区间，而不是色块；检查器是测量面板：参数以读数为主，取值控件是带刻度的标尺而不是滑杆；左右两栏等宽，围绕中轴。
- **字体**：所有数字与小标签用等宽 Source Code Pro；中文标签 Noto Sans SC 400、12 px；当前时间等大读数用 Inter 200 大字号。
- **质感**：1 px 细线、点状网格、刻度短线；无阴影、无渐变、无发光。
- **参考锚点**（不照抄）：Tektronix MSO 屏幕读数；Teenage Engineering 的克制标注。

## 方向 B ·「点火台」

- **种子与子模式**（种子 1）：「332」→ 主要区域按 3 : 3 : 2 分配；大写字母成 4–5 个一簇 → 按钮按 4–5 个一组成簇；16 个数字 → 底部操作台 16 单位网格。
- **跨界灵感**：专业烟花点火控制系统（FireOne、Cobra 一类）与调音台的通道条：每一层是一条「通道」，有编号、启用、只看、起止读数。
- **期望感受**：有分量、可触摸、一切尽在掌控。
- **配色**：底部操作台用较亮的 g3 / g4 面板（层级反转：控件在亮面板上），按键 g2、刻印文字 g8；薄荷绿只用于「已启用 / 当前」的方形指示灯和当前通道；「需重新导出」用警告色方形指示灯。
- **布局**：上半部分是视图 + 检查器；下半部分是贯通全宽的操作台：每层一行「机架」，左端是通道条（序号、启用、只看、起止读数），右端是时间轨道；播放控制做成一组实体按键；效果库收成左侧窄栏，以缩略图为主。
- **字体**：拉丁标签用 Inter 600 大写小字（如 CH、CUE）；中文 Noto Sans SC 500、12 px；数字放在深色内凹读数窗里，用 Source Code Pro。
- **质感**：平面面板，按键上沿 1 px 亮线、下沿 1 px 暗线表现可按；读数窗内凹；方形指示灯。不做旋钮、不做渐变。
- **参考锚点**（不照抄）：调音台通道条；Teenage Engineering OP-1 / TX-6 的按键分组与刻印。

## 方向 C ·「接触印样」

- **种子与子模式**（种子 3）：以 6 开头、「64」出现两次 → 8 × 8 的帧网格（正是序列贴图的图集）、6 : 4 即 3 : 2 画幅；o、p、Q 等圆形字母最多 → 圆形标记、套准标记；14 个数字 → 胶片条一次显示 14 帧。
- **跨界灵感**：暗房接触印样、剪辑台上的红蜡笔记号、胶片边缘的片号。烘焙结果本来就是一帧帧的序列图，正好贴合。
- **期望感受**：在灯箱前逐帧审片——专注、手作、每一帧都能回看。
- **配色**：底色 g1 / g2；印样「纸面」g3；片边编号 g6；薄荷绿当作蜡笔记号——圈住选中的效果与帧、入点 / 出点、播放头，用得很省。
- **布局**：视图是一格 3 : 2 的胶片画面，边缘有片号；画面下方是烘焙帧的胶片条（14 帧，可用两张烟花图裁出不同时刻）；时间轴做成带帧号的片边；效果库是接触印样式缩略图网格（图为主，名字小字在下）；检查器像场记单：效果名用衬线大字，参数是带横线的记录表。
- **字体**：标题 Noto Serif SC 600；标签 Noto Sans SC；帧号、片边编号用 Source Code Pro。
- **质感**：片边编号、套准标记、细横线；让图片承担视觉重量；不要满屏胶片颗粒。
- **参考锚点**（不照抄）：Magnum 接触印样；剪辑台审片记号。

## 方向 D ·「大字报网格」

- **种子与子模式**（种子 4）：20 个数字、「20」出现两次 → 20 栏网格；「96 96」重复 → 成对的大号数字；z 最多 → Z 字阅读路径（左上 → 右上 → 左下 → 右下）；最长的连续大写 7 个 → 每个区域只有一个超大元素。
- **跨界灵感**：瑞士国际主义版式（Müller-Brockmann）、车站出发牌、博朗产品标注。
- **期望感受**：果断、清楚，一眼看到最重要的数字。
- **配色**：g0 底，几乎不用面板；区域之间靠细线和留白分隔；大字用 g9；薄荷绿只给最重要的一个实时数值（当前时间或选中参数）和选中状态。
- **布局**：严格 20 栏、不对称；按 Z 字路径：左上是超大效果名（Noto Sans SC 900），右上是超大当前时间数字，左下是时间轴，右下是检查器参数；效果库是带编号的文字索引（缩略图很小或不用）；不用卡片、不画框。
- **字体**：极端字号对比：64–96 px 展示字 vs 12 px 标签；数字用 Inter 等宽数字。
- **质感**：只有字、线和烟花图片本身。
- **参考锚点**（不照抄）：Müller-Brockmann 音乐会海报；Experimental Jetset。
