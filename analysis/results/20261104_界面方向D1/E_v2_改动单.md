## A. 用户反馈（必须）

1. **加烘焙帧胶片条**：时间刻度正上方一条胶片条，与刻度、轨道共用同一横轴（0–5.24 s 对齐）。每格是该时刻的烘焙帧缩略图（用两张烟花图裁出：小的初爆 → 满开 → 散落），高约 36–40 px；已烘焙的帧正常亮度，未烘焙的帧压暗；播放头所在帧有细框。不要另加单独的进度条。
2. **左栏可滚动**：左栏整列是一个可滚动列表，右侧画出细滚动条（表示内容超出）。分组可折叠并带数量：待我验收、制作中、我的效果、我的模板、花型模板、多层花型模板（后两者用 3 列小缩略图网格）。
3. **大小档（RT6S / M / L）不是筛选器**：它是某个效果的几个分档（例：「升空尾缀 RT6」有 小 RT6S / 中 RT6M / 大 RT6L；「金芒菊 · 规格」有 3 号 / 5 号 / 尺玉 / 2 尺 / 3 尺 / 4 尺），显示为该效果条目下面的一排小缩略图按钮，点哪档开哪档。从搜索框下面删掉；在列表里放一个带分档的效果条目（不是当前打开的，所以没有档被选中）。
4. **显卡型号放回顶栏右上角**（「资源交付」左侧，安静的灰字）。
5. **「生成缩略图」**：播放条右侧，相机图标 + 文字「生成缩略图」（把当前帧截成这一项的缩略图）。

## C. 第 1 版评委意见（采纳）

1. **强调跟状态走**：当前状态是「已保存、需重新导出」→「保存」为普通文字按钮；「导出」为唯一的实心主按钮（薄荷绿）。
2. **画面**：去掉「框中框」，1024 单格只用四角裁切标记表示；单格尽量放大，减少左右空白；画面下方保留一条安静的技术信息（PC、单格、帧、张、fps、tick），显卡已移到顶栏。
3. **去掉悬浮的「火花」小窗**（不要任何浮在画面上的面板）。
4. **爆后扰动关闭时，下面四项直接隐藏**，不占位。
5. **字号层级**：三级清楚——检查器当前对象标题、模块标题、参数名；折叠模块的摘要右缘与数值列右缘对齐。
6. **开关统一一种**：参数里的开关、时间轴的两个选项用同一种开关控件；分段选择的选中样式只有一种；所有选中态用同一种画法（底色 + 左侧细条，只用在「当前编辑对象」上）。
7. **薄荷绿只用于**：当前编辑对象、播放头、导出（待办）。滑杆、复选框、选中的模式 / 视图选项用中性色。
8. **缩略图不抢画面**：左栏缩略图整体降低亮度（约 70%），悬停恢复。
9. **底部三条操作区**：时间轴的「设为入点 / 设为出点 / 清除」和两个选项移到时间轴标题行右侧；左栏底部只留「新建效果」「复制我的意见」；检查器底部只留保存状态。三处不在同一条线上挤成一排。
10. 文案：搜索框占位只写「搜索」；不用「·」串联信息。
