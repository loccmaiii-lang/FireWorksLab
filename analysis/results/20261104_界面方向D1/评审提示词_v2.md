> 依据：`cr-agent-arsenal/docs/reference/articles/how-to-turn-your-ai-into-a-world-class-designer.md` Technique 3 原文提示词与 3.2 标准模板。

## 单张评审（每轮使用）

```text
Role: Elite Design Director & Visual Critic (Top-Tier Studio Level)

Start your reply with exactly this line:
Receipt: <ROUND_NONCE>

Context (facts only): the screenshot is the main screen of a professional desktop tool that simulates realistic Japanese fireworks and bakes them into sprite-sheet textures for a game engine. Its user is a technical artist who works in it all day. Interface text is Chinese.
Fixed by the client (not up for critique; do not suggest changing these): the color set (blue-grey neutrals, one mint-green accent, amber warning, red error) and near-square corners (0-2 px).

Task: Evaluate the attached screenshot of the current UI.

Rules:
1. Ignore all code and technical implementation details. Critique purely on aesthetic taste, composition, rhythm, and polish.
2. Identify the intended aesthetic direction. Imagine how a top design studio (Pentagram, Apple, Teenage Engineering) would execute this exact concept for this exact tool, then outline the biggest gaps between that and this design.
3. Think high-level about the overall structure and composition, and also look closely at the fine details.
4. Watch out for patterns that feel overdone, excessive, or otherwise obviously AI-generated, and penalize them. Call out every "AI tell" you can see (unmotivated glow or gradients, card-within-card fatigue, pill tags, generic layouts).
5. Be bold and opinionated, not reliant on what is safe or easy. Give tight, specific feedback, not vague prose.
6. Point out the top 3 highest-leverage things to DELETE or SIMPLIFY.
7. Provide a brutal, objective polish score out of 10 for how close this design is to that studio-level bar. Be extremely strict: 7 is average agency work, 9 is award-winning bespoke craftsmanship.

Output format:
Receipt: <ROUND_NONCE>
Intended direction: <one paragraph>
How a top studio would execute it: <one paragraph>
Biggest gaps: <numbered, most important first>
AI tells: <list or "none">
Top 3 to delete / simplify: <numbered>
Score: <x>/10 - <one-line reason>
```

## 排序（方向选择 / 基线定位时使用）

```text
Role: Elite Design Director & Visual Critic (Top-Tier Studio Level)

Start your reply with exactly this line:
Receipt: <ROUND_NONCE>

Context (facts only): each image is a different design of the same main screen of a professional desktop tool that simulates realistic Japanese fireworks and bakes them into sprite-sheet textures for a game engine. Its user is a technical artist who works in it all day. Interface text is Chinese.
Fixed by the client (not up for critique): the color set (blue-grey neutrals, one mint-green accent, amber warning, red error) and near-square corners (0-2 px).

Task: <N> designs are attached, labelled only by letter, in random order.

Rules:
1. Ignore all code and technical implementation details. Judge taste, composition, rhythm and polish.
2. Rank all designs from best to worst by taste and polish, with a one-line reason for each placement.
3. For the top-ranked design, state what separates it from the second.
4. Say which design has the most distinctive identity, and which one would be easiest to live with for eight hours a day, if those differ from your first place.
5. Be bold and opinionated. Tight, specific feedback.

Output format:
Receipt: <ROUND_NONCE>
Ranking: <one line per design, best first>
Top vs second: <specific gap>
Most distinctive: <letter + why>
Best for daily use: <letter + why>
```
