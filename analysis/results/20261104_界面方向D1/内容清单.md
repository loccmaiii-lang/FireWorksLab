# 烘焙器主屏 · 内容清单（4 个方向共用）

> 本文件只规定「屏幕上必须有什么」，不规定样子和位置。样式、布局、字体、质感按各自方向简报决定。
> 内容参考截图：129 整屏截图（云端临时文件）（现行 4.9.129 版，只用来核对内容，不要模仿它的样子）。

## 产品与用户

- 产品：网页「烟花烘焙器」，为 UE 4.24 手游 / PC 游戏制作写实日式烟花特效：在网页里模拟烟花，烘焙成序列贴图，导出素材包给引擎。
- 用户：技术美术，每天长时间使用；深色界面；1920 × 1080 为主，1366 × 768 也要能用。
- 屏幕上的界面文字全部用中文，书面化、简短；不要常驻说明文字（按钮和参数名能看懂的，不再加注释）。

## 固定约束（客户已定，不可改）

1. 颜色只用下面这套（色相不改，用量、比例、用在哪里可以大胆调整）：
   - 中性色（蓝灰）：g0 #0c1518 · g1 #111d21 · g2 #16242a · g3 #1b2a2f · g4 #24373d · g5 #2b4149 · g6 #39515a · g7 #8da3ac · g8 #b4c5cb · g9 #e4edef
   - 主色（薄荷绿）：p1 #062a23 · p2 #173d39 · p3 #1f5b49 · p4 #00d49b · p5 #36e4b0 · 选中文字 #a1ded0
   - 警告：#e0b25a（及其暗色）；错误：#e8735a（及其暗色）
   - 烟花图片本身的颜色不受限制。
2. 接近直角：圆角 0–2 px（滑杆圆点、状态圆点这类本身是圆形的元素除外）。
3. 字体只用以下几种（云端和用户 Windows 都能得到同样字形）：
   - 中文无衬线：`"Noto Sans SC","Noto Sans CJK SC",sans-serif`（字重 100–900 都有）
   - 中文衬线：`"Noto Serif SC","Noto Serif CJK SC",serif`（200–900）
   - 西文 / 数字：`"Inter",sans-serif`（100–900，可用 `font-variant-numeric: tabular-nums`）
   - 等宽：`"Source Code Pro","Noto Sans Mono CJK SC",monospace`
   - 在 `<head>` 里加 Google Fonts 链接（Inter、Noto Sans SC、Noto Serif SC、Source Code Pro）；云端截图时这些链接加载不到，会自动用本机同款字体。
4. 只用浏览器原生能力（HTML / CSS / 少量 JS），不引第三方组件库；单文件。

## 交付物要求
- 一个单文件 HTML，画布固定 1920 × 1080（`body` 无滚动条），图片用 base64 内嵌。
- 不是可交互原型，但所有控件要画出真实状态（选中、当前、关闭、不可用、已改）。
- 不要出现种子串、方向名、设计说明之类的元信息。
