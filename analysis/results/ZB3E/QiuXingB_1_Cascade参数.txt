工具：烟花母版烘焙器 3.7（模拟内核：GPU；产物：大面片母版）

【贴图】
T_QiuXingB_1.png（星头、闪光、拖尾合并）
尺寸 2048×2048，灰度（线性），RGBA 接力：先填满 R 的 64 格（第 0–63 帧），再接 G（64–127）、B（128–191）、A（192–255）
格子 8 列 × 8 行，行优先，左上为第 0 帧；单格 256×256 像素；共 256 帧；格子四周留空 2 像素
导入：sRGB 关闭，压缩 BC7；1K 版本在引擎里复制一张，把最大尺寸设为 1024 即可
T_QiuXingB_1_FrameTest.png（帧号测试）：排查用。格子、接力、取景与正式贴图完全相同，内容是帧号 + 以爆点为中心的固定大小圆和网格。
  把材质实例的贴图临时换成它播放：帧号应连续递增不倒退，圆应不动、不胀缩、不变扁。
  帧号乱跳 / 倒退 → 帧号曲线或材质的接力解码不对；圆胀缩、晃动 → Size By Life / 位置曲线不对；圆变扁 → 对齐方式或 Initial Size 不对
T_QiuXingB_1_Ramp.png：渐变图 256×8（sRGB），灰度从暗到亮依次取：拖尾冷却色 → 拖尾高温色 → 星头高温色

【材质实例】
项目现有的 RGBA 序列帧材质；列 = 8，行 = 8；Ramp = T_QiuXingB_1_Ramp

【Cutout：裁掉面片上的空白，减少 overdraw】
Required → Cutout Texture = T_QiuXingB_1_Cutout（512×512，所有帧叠在一起的轮廓）；
  Sub Images Horizontal = 1，Vertical = 1；Bounding Mode = Eight Vertices；Opacity Source Mode = Alpha；Alpha Threshold = 0.1；不加 SubUV 模块。
  面片剩下约 30%（引擎按轮廓外接八边形，会略大一点）。材质照旧用 Dynamic Parameter 第三通道取帧。

所有曲线（Size By Life、Dynamic Parameter 帧号、Color Over Life、Location / Velocity 等）：每个关键点的 Interp Mode = Linear。CurveAuto 会在关键点之间冲过头：尺寸来回抖、帧号倒退一抖一抖。Size By Life 勾选 Multiply X、Multiply Y。

【帧与流畅度】
平均 128.0 fps，最低 64.6 fps，每帧最大位移 0.8 像素（建议 ≤ 3）
平均面片面积为最大尺寸的 73%（overdraw 按此折算）

【自检】
  画面占比：平均 48%，最差 10% 的帧 ≥ 33%（紧凑取景已禁用：引擎里会抖；想更满可以减少留边或改随开花放大）
  过曝：第 13、14、15、16、17、18、19、20… 帧超过 2% 像素顶到 255，可降低星头亮度或改 Gamma 2.2
  边缘渗色：无（留边 2 像素）
  通道布局：R 有内容，G 有内容，B 有内容，A 有内容
  近似帧：158 对相邻帧几乎相同，可把「取帧」改成「按画面变化」自动合并
  末尾 35 帧接近全黑，可把序列时长缩短到约 1.47 s

【烟（开花烟，用项目现有烟雾贴图）】
Spawn：Burst Count = 48；Lifetime 5.35–10.35 s
Location → Sphere：Velocity 勾选，速度约 2045 cm/s；Drag = 1.48（烟团很快停在星走过的地方）
Initial Size 600 cm，Size By Life 1 → 3（扩散）
Alpha Over Life：0 → 0.3（在 0.18）→ 0
颜色：前 1.35 s 被火光照亮，乘本母版 Color Over Life 与 Light 曲线；之后转为场景夜空灰

【声音节点（相对开花，秒）】
  0.000  开花爆响
  玩家听到的时刻 = 事件时刻 + 距离 ÷ 343 m/s（800 m 约晚 2.3 s）

【LOD 建议（1080p、竖直视角 60°）】
LOD 0：0–224 m，全部层，2K 贴图
LOD 1：224–448 m，屏幕上已小于单格像素：1K 贴图即可；粒子数/火花发射率减半；关闭 Light
LOD 2：448 m 以外：只留本层；去掉芯（小缩放的牡丹层）和烟
（Cascade：粒子系统的 LOD Distances 依次填 0、22400、44800，单位 cm）


【说明】
Size By Life 以精灵中心缩放，爆点就在中心，所以面片放大时爆点位置不变。
QiuXingB_1.json 保存了全部参数，用烘焙器「导入参数 JSON」即可继续修改。
