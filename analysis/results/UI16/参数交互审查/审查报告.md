## 按用户影响排序的发现

1. **P1 · 自动说明打断调参。** 参数行同时绑定 mouseenter / focusin，说明固定在滚动栏底部，内容长度决定占用高度；焦点 / 鼠标频繁移动导致重复改变。改为明确的 `?` / F1，固定独立说明区域，保留内容与曲线高亮。Esc / 关闭退出，继续调参不切换说明。
2. **P2 · 多层折叠的视觉层级不清。** 类别、模块、更多、随机都能折叠，标题与参数字体接近。类别保留原名并作为静态标题；模块为主要折叠入口；更多与随机用具体动作和实际状态文案。
3. **P2 · 更多的状态文案错误。** refreshVisibility 每次都写「更多 N 项」，不区分已展开。关闭时「展开更多参数（N 项）」；打开时「收起更多参数」；筛选自动展开也同步文案。
4. **P2 · 图层管理难发现。** 标题实测 12px，缩小后的图层行与辅助操作不易读。标题 16px、图层名 14px，默认展开，选中态明确，展开 / 收起文字清晰；独看与静音仍只影响观察。
5. **P2 · 字体、控制尺寸与帮助入口不统一。** 当前 11–16px 混用，英文辅助名与模块名、数值与参数标签层级不一致。统一分类16 / 模块15 / 参数14 / 数值13 / 辅助12；使用原字体、色板和控件。窄栏把标签 / 滑杆分两行，不整体缩小。
6. **P2 · 初始「改过」标记可能残留。** 打开效果后的面板先按模板默认值计算，而 wbArm 等烘焙稳定后才记打开时基线，未同步刷新面板标记。草稿只补一次 UI 刷新，不改基线、参数或烘焙时间逻辑。
7. **P3 · 搜索范围不明。** 搜索及只看改过的作用于参数 SCHEMA，颜色、规格及原有操作有独立行为。草稿保留逻辑，显式提示范围；进一步统一搜索语义需单独评审，不能为了视觉悄悄扩大数值或模块含义。

## 名称核实

`Emitter · 发射`、`发射器`、`Appearance · 外观` 等字符串已经存在于 4.3.3（提交 75c9696），不是本次新改名。4.3.7 的分组定位读取同一套分类。当前草稿逐项保留 `PNAMES`、`PMODULES` 与 `P43_GROUPS`；不把「火花」改成「生成」或把「尾缀各层」合并掉。用户看到的重复概念来自外层类别和内部模块层级不清，草稿靠层级解决。

## 保留的行为

- 滑杆、数值框、双击恢复默认、锁定、按号数联动、随机微调。
- 时间参数继续调用原 setTimingParam / timingEdit，不改接力或图层关联。
- 随机继续归属原本体；不起作用的参数仍呈灰色，理由通过主动说明查看；不直接删参数。
- 空白发射器的添加 / 去掉模块规则、各花型的适用条件和隐藏条件。
- 各层的独立参数、整体观察、独看 / 静音只影响观察、各平台输出方案。
- 颜色阶段排序、第一段固定 0、最多五段、原材质 / 输出语义。
- 保存、另存为、素材包、单束、交付清单、显卡、更新记录。
