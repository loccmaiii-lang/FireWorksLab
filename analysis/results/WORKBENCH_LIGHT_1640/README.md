## 发现（影响结果，需知道）

1. **峰值 ≤ 10 是参数，不是编排结果**：强度按全场最亮一帧归一，SkyLight 峰值 = 1800 × 0.003846 = 6.92，换什么编排都一样。B08 的最亮帧光量比 B07 低 7.8 %（S_max 8.275 → 7.632），所以同样峰值下整场天光平均亮约 6 %（1.99 → 2.11）。
2. **低配看到的花不够撑这条光**：序列只有一份。按 B08 修订4 档位，中配光源占高配 87 %、亮帧都有花；低配只占 50 %，约 5.6 s「灯亮着但低配那一刻光源不到 1/4」（修订2 时 44 % / 10.1 s；修订3、4 相同）。未改，等用户定（按中配算 / 维持高配 / 导演能否分档挂序列——未查）。
3. **文件 vs 工作台的结束时刻**：dfshow 里 19 发小平台 V 形彗星（B04_XSV4）effectiveEnd 比工作台实时编排长 1.05 s（文件 2.79 s，工作台按固定子模板 1.74 s）。交付按工作台（和导演表导出同源）；对灯光影响最大 2.6 %（40.1 s）。编译器写的旧值，告诉跨年秀（22）。
4. 查过但不改：SkyLight 复用 SpotLight2 的距离权重 vs 不按距离，两条曲线相关 0.992，各段差 ≤ 15 %，不值得改。
