# NFJV3 看法（对话框新花型，2026-10-08）

候选对比 3（辛 / 子 / 丑 / 寅 / 卯，都是在 4.9.39 模板上改参数，没进模板）。总差距：辛 0.386、子 0.388、丑 0.448、寅 0.381、**卯 0.342**。
审看：差距.md + 对照_0.47 / 1.20 / 1.80 / 3.00（上排整朵、下排放大右上四分之一）。这是实时渲染（mtRenderLayers）对实拍，不是导出包、不是 UE。

**量法的问题（先说，影响读数）**：渲染图的里 / 外分界是渲染自己自动找的，找不到就退回「全部」——红点蕊、柠点星 +3.0 s 的读数因此混进了别的层（卯的红点蕊 FWHM 5.2 / 光晕 0.069 和柠点星一模一样；子 +3.0 s 星晕色相 34° 是芯的金丝混进来）。已改 `候选对比.py`：渲染一律用**实拍同一时刻的分界**（实拍没分界时两边都用「全部」）。NFJV4 起读数和前三轮不完全可比，所以 NFJV4 把卯重量一遍。

看图（和数对得上的部分）：
- 橙引尾：卯的线宽 2.1–2.5 px（实拍 2.3–3.1）、成串 0.12–0.13 对上；颜色还偏黄、偏亮，线尖上的星头太大太亮（+0.47 s 是一圈黄晕；实拍是淡黄白的小点）→ 柠点星起势要更晚、早期星头要小；寅（更红）比子好一点。
- 金菊蕊：**子–卯 +0.47 s 芯是一整块过曝白盘**（底光 0.08 太强；辛 0.06 还看得到丝），实拍是能看清一根根的淡黄白丝；+1.8 s 整团偏黄偏亮（实拍暗橙、丝细密）；+3.0 s 还有丝（实拍 +2.7 s 前收完）。
- 红点蕊：光晕 0.75 / 半径 4 把一圈粉点糊成**连续的洋红光环**；实拍是芯边上一颗颗淡紫白的小点 → 光晕要小、颜色淡紫白、星头小。（拆解卡里红点蕊「光晕占比 0.3–0.55」是在过曝的芯里量的，周围全是亮丝，偏大，不能照着调。）
- 柠点星：个数、大小、拉长比都对上；+3.8 s 星头比实拍小、个数少（末段缩得太狠、太暗）。星晕颜色偏黄（实拍黄绿）。
- 青绿细线：子 / 卯（亮度 0.1）在放大图里看得到，丑（0.2）太多太亮、像星后面拖了一圈黄绿的尾；颜色是黄橄榄色，实拍偏青绿 → 渐变图暗端往绿偏。
