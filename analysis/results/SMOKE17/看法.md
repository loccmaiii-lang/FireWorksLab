# SMOKE17 看法（对话框2，2026-10-03）

4.2.21（预跑只算一次、星轨道共用），本机 RTX 5080，和 SMOKE16 同样的量法。

- 「预跑」一栏全部 0 s（SMOKE16 是 0.07–3.4 s）：打开效果时同一份参数不再重复预跑，这一项达到目的。
- 但实时模拟的帧间隔基本没变：鸿巢烘完 18 / 36 ms，永丰 35 / 160，片贝 53 / 551，七夕 / V3 53 / 89（压子样本后回到 18）。说明剩下的卡顿不在显卡，在 CPU 的实时模拟本身 → 云端把画图换成空操作量了一遍：每帧从快照倒回重走快门窗口（5 倍物理步）+ 每帧深拷贝几百颗星（垃圾回收停顿），4.2.22 改掉，排 SMOKE18 复核。
- 片贝「压子样本后」5.6 s 一帧：千轮层 7220 颗星在主线程上的整段物理，不是显卡；4.2.22 后每帧只走 1/60 s 的物理，预计明显好转，但 7220 颗星 × 每帧 8 步仍是 CPU 的活，暂停中的片贝以后要靠减子星数或把星轨道算进后台线程。
