# UI12 看法（对话框2：新旧对照，3.7 → 4.0 迁移）

引擎回放、适应窗口，按实拍同一秒并排：`对照_QN10_QN11.jpg`、`对照_HK9_HK10.jpg`（每行：实拍 | 旧版 3.7 | 新版 4.0）。

**结论：两朵的 4.0 版和 3.7 版一致，没有退化；鸿巢 4.0 在 7.25 s 更接近实拍。**

- **运动 / 时间**：同一秒新旧两版的花径比是常数（青柠星 ≈ 1.24、鸿巢 ≈ 1.35，各时刻差 < 5%），开花、展开、下垂、熄灭的节奏一样。画面里 4.0 版看起来更大，是 4.0 取景把花放得更满（出图占比，4.2.3–4.2.7），不是花变大了——参数没变、模拟是同一个。
- **颜色**：青柠星 0.36 s 橙、之后淡黄绿星点，两版一样；鸿巢白热 → 金色长尾 → 红点，两版一样。4.0 的星点、尾丝略细一点，亮度比例相同。
- **鸿巢 7.25 s**：3.7 版底边已经冒出几颗红点（实拍此时还没有），4.0 版没有——4.0 更对。
- **两版共同、和迁移无关的差异**（不在这次的范围）：
  - 青柠星实拍里星点之间有淡淡的放射尾丝，两版都很淡；
  - 鸿巢 9.32 s 的红点比实拍小、暗。要调的话改红点层的星头大小 / 亮度，是效果参数，不是迁移问题。

所以 QN11 / HK10 作为「HK9 / QN10 原样迁到 4.0」的候选成立，「待我验收」里不用再等新旧对照。
