# 地面循环火焰第一版 · SGF1 / 4.9.124

已实现、内部导出与 AI 自检通过；等待用户审美验收。未经 UE 实播。

打开烘焙器，左栏「待我验收 → 地面循环火焰」；新建时在花型模板「粒子图 → 地面循环火焰」。它是现有分层粒子图的通用体积形态，任意粒子层的「形态 → 粒子形态」都可以选「体积火焰」。无需另装 WebGPU 项目或新增 UE 材质。

## 这一版包含什么

地面椭圆范围内连续生成火舌，共享三维气流改变其轨迹；沿轨迹重建密度，程序噪声侵蚀/卷曲密度，射线积分得到灰度亮度，再用既有 Ramp 着色。固定 ID、有限寿命、周期出生和年龄驱动细节，使任意 t 与 t+T 相同。第0帧已经是稳定燃烧，不含预热，不重复导出终点帧。

默认地面源横向直径0.6m、纵深范围倍率0.6、竖直范围0；火焰高度随寿命、速度和气流变化。固定取景约1.632×1.754m，循环64/30秒。PC为2048²/单格512，手机1024²/单格256，均为4×4×RGBA、64帧/30fps。交付一个推荐候选，本机素材在同目录 `GroundFlame.zip`，完整参数见 `导出参数.json`。ZIP沿用仓库忽略规则不入Git，换机器可从SGF1或模板重新导出。

## 怎么调

| 想改变 | 参数位置 |
|---|---|
| 整团等比变大，不改变节奏 | 分层粒子图 → 整体调整 → 整体尺寸 |
| 变宽、铺开地面、移动燃烧位置 | 燃烧火舌 → 形状 → 出生半径、三轴范围倍率、源中心 |
| 单根火舌粗细/随机 | 燃烧火舌 → 大小 → 粒子直径、大小倍率、大小随寿命 |
| 高低、燃尽速度 | 初速、寿命、加速度；全局气流的竖直风也影响高度 |
| 横风、卷动、收束、惯性 | 分层粒子图 → 全局气流；每层阻力重力 → 随风强度 |
| 厚实、薄透、破碎、卷曲 | 燃烧火舌 → 形态 → 密度、纵深、侵蚀、细节尺度、卷曲位移 |
| 火苗细节向上流动的速度 | 形态 → 细节上移速度（与轨迹气流独立） |
| 收尖、地面穿透 | 形态 → 尖端半径比例、地面截断与高度 |
| 循环更长/更短 | 分层粒子图 → 生成与运动 → 循环周期；寿命上限必须短于周期，同时核对输出帧率 |
| 换颜色/明暗 | 本层颜色的四点 Ramp、颜色曲线；亮度/曝光；不提供未求解的“温度”旋钮 |

大风或加长火舌后，扩大「输出 → 取景」相应边界并看边缘自检；整体尺寸倍率会同步缩放取景。参数超常用范围可直接输入，但仍受有限数、周期寿命、积分预算等有效性检查约束。细节过小时增加单格分辨率/积分样本，默认48样本，上限64；样本只影响烘焙速度，不增加游戏运行时成本。

## 核验与审看

- 模型9项：周期与负时间、旧图逐位一致、源位置、子火舌位置继承、控场、零密度、无效参数、缺省与旧存档首次写向量。首次写新向量的问题先复现失败，再修到通过，已接入 `标准检查.py --flame-model-only`。
- 实际GPU为 RTX5080/D3D11；17项参数拨动有画面变化；整体尺寸2倍使物理宽高2倍，时间不变；t和t+T PNG完全一致。正式PC/手机导出本机约1秒，不代表别的配方或硬件。
- 统一界面：整体尺寸/密度数值编辑、撤销/重做、保存、刷新恢复；实际“引擎回放”连续播放跨两个循环，并审看3张时刻截图；地面关闭、零密度和镜头不支持状态有提示。
- PC/手机标准、导出回放通过。普通回放检查只自动识别粒子内锯齿帧号，本任务额外检查发射器重生循环：128 tick恰好显示两轮0–63。末首中心变化分别3.32/3.41个512归一化像素，允许上限17.94/17.92；空帧0、边缘裁切0，饱和占比0.14%/0.13%。详见 `回放检查.json` 中 `emitter_restart`，不是用“通过”代替实际接缝测量。
- 旧效果回归67项：9个模板各3帧、现行待验收/已通过的旧效果及组合层各1帧，帧计划与PNG逐位相同。用户窜天猴存档6层的镜头参数体检无新增无效/灰错。门禁覆盖18种代表产物199行、导出JSON及界面8项。
- 审看：根部贴地、火舌连续上升并受场弯折，粗细有层次，PC/手机轮廓保持。仍有少量细长火尖，整体是可控程序火焰的观感；是否要进一步做更厚、更浑浊、更多翻卷，由用户看这一版决定。

## 范围与限制

这是程序体积重建，未移植 procedural-fire 的压力/燃烧求解。火舌内部有消光，火舌之间沿用发光相加；没有完整互相遮挡、烟、热扭曲、地形碰撞或一次性点燃/熄灭段。关闭地面截断可以做离地火源，倾斜/复杂地形需另行建模。

粒子镜头散焦/运动积分暂不支持体积火焰，面板说明且冲突导入报错；通用输出快门采样可用。颜色受当前灰度+单Ramp材质约束，不能独立控制同一贴图中“蓝色火根”和“橙色火尖”的温度场；需要独立配色时拆输出层。

审看建议用“适应窗口”或“1:1”。编辑器沿用4.9.35既有交互，常规引擎回放按PC显示；手机版以独立导出包和本页PC/手机贴图回放对照审看，未新增平台切换界面。原烟花“游戏内大小”按远距标定，燃烧弹近景的材质、Bloom、压缩和实际米数仍需 UE 检验。烘焙后的风向固定在序列里，运行时改变风需换变体或重新烘焙。
