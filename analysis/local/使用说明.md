# 本地跑对照（用你电脑的显卡）

Claude 在云端没有显卡，渲染一次对照要 1–2 分钟；你的电脑上不到 1 秒。所以重活放在你这边跑，通过 git 交换：

```
Claude 写任务 → push → 你 pull、双击跑 → push 结果 → Claude 读结果、改参数或写下一轮任务
```

你的电脑不需要登录 Claude，只要能 `git pull / push` 这个仓库。

## 第一次（只做一次）

1. 装 Python 3.10 或更新版本（安装时勾选 “Add Python to PATH”）。
2. 电脑上要有 Chrome 或 Edge（Windows 自带 Edge 就行，不用另外下载浏览器）。
3. 双击 `analysis/local/首次安装.bat`：装依赖，然后试渲一帧。
   - 最后一行应该显示你的显卡名，试渲一帧在 1–2 秒内。
   - 如果写着「软件渲染」：浏览器没用上显卡，检查显卡驱动，或在 Edge / Chrome 设置里打开「使用硬件加速」。

公司网络不能直接 `pip install` 的话，用公司的 pip 镜像：`pip install -r analysis/local/requirements.txt -i <镜像地址>`。

## 每次跑

双击 `analysis/local/跑任务.bat`，它会依次：

1. `git pull` 拉最新任务；
2. 跑 `analysis/jobs/` 里还没结果的任务。跑的时候会弹出一个浏览器窗口，可以被别的窗口挡住，但不要关掉它。
3. 把 `analysis/results/` 提交并 `git push`。

只跑某几个：在命令行里执行 `analysis\local\跑任务.bat QN1 WC1`。升空尾缀任务（TR1 这类）会校准、导出 2K + 4K 贴图和录视频，结果里多一个 `samples/` 文件夹（约 100 MB）。已经跑过的要重跑：`python analysis/local/run_jobs.py --force QN1`。

跑完在对话里告诉 Claude「跑完了，已推送」。

## 结果放在哪

`analysis/results/<任务id>/`：

| 文件 | 内容 |
| --- | --- |
| `对照.jpg` | 上排实拍、下排模拟，燃烧 10%–90% 五个时刻 |
| `数值.json` | 逐时刻的半径、亮痕细长度、放射一致度等对照，以及总差距 |
| `best.json` | 最终参数（Claude 用它更新烘焙器里的复刻） |
| `variant_*.jpg` | 任务里额外试的几组改动（有的话） |
| `log.txt` / `env.json` | 过程记录；用的显卡和耗时 |
| `error.json` | 出错时的报错（直接推上来，Claude 看） |

你自己也可以先看 `对照.jpg`：像不像由你判断，数字只是辅助。
