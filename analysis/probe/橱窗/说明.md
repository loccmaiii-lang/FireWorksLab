# 4.0 光点对照橱窗 · 工程版本 3.11

这是开工说明阶段 a 的光点、美术方向检查点，不是效果交付或 4.0 完成。没有将条目移入「待我验收」，也没有修改用户的通过标记。

## 查看方式

刷新 `tool/FireworkBaker.html` → 左栏底部「4.0 对照橱窗」。选择菊、牡丹、锦冠、千轮、点灭、JM4 或 V5 三档；同一时钟连续播放，游戏内大小默认 1000 m，可以切 PC / 手机、800–1200 m、适应窗口。F 键放大画布。「保存对照配方」保留两边完整参数和颜色。

左边使用 3.7 原参数和旧光点，右边使用新光点、512 格和固定曝光。V5 三档仍锁 3.7，左右均为旧核，界面明确标注；最终迁移阶段再另做新核版本。JM4 的新核画面只存在于橱窗，不覆盖正式库。

右侧固定曝光：菊 3、牡丹 3、锦冠 4、千轮 4、点灭 3、JM4 0.2。这些值为看过整体和局部后选择的橱窗推荐值，不是自动逐帧归一化，也没有写回正式库。参考截图按开花后 0.05、0.5、1.2 秒和 70% 时长截取，先看游戏内大小，再看局部。

## 观察和检查

RTX 5080 / D3D11 实际烘焙和浏览器回放。新核亮点边缘更清楚，JM4 的尾部颗粒与亮核更容易区分；旧版额外预览光晕保留，新核默认关闭。初次检查发现新核重复使用旧开花闪光的高斯面积倍数，造成过亮；修正强度单位，失败与修复后检查均保留。V5 同一贴图在左右 viewport 显示曾有一个通道的一个像素差 1，关闭输出抖色后仍存在；判断为不同位置采样/量化级差，显示检查容许 1 / 255，原始贴图兼容检查仍严格要求零差。
