# 云端配方提前预览 · 4.0 开发版 / 阶段 3.12

用户明确要求把云端新增配方一起预览，因此先将现有模拟能表达的结构接入。共 22 个可运行配方、11 组缺能力的目录项。来源是 `协作/花型配方总表.md`；完整配方在 `tool/src/js/17_cloudrecipes.js`，图层、颜色、延迟、爆点位置分别描述，不在模拟核按效果名称分支。

## 在哪看

刷新烘焙器 → 左栏底部「云端配方预览 · 22」。下拉框选配方，旁边选整体或单层；使用实际烘焙贴图，30 fps 播放，PC / 手机独立烘焙，游戏大小和距离可调。可保存完整配方 JSON。同一下拉框也能切回 3.7 / 4.0 基准左右对照。

可看：芯入菊、八重芯、三重芯、四重芯、金蕊青柠星、银冠、金冠、金柳、银柳、四色牡丹（混合）、霹雳芯、海上自爆、彩色千轮、红/蓝引先菊、银菊转残光、满天星、三节礼花弹、四色牡丹霹雳蕊、洋红/青绿/柠檬牡丹。

上方可展开全部缺项：变色转冠、交叉环、飞游星/尖叫星、蝶、雷/段雷、虎之尾、降落伞/吊灯、打铁花、白闪蕊/齐闪、速射/地面组合/节目、光露。没有用单环假扮交叉环、用随机点灭假扮齐闪、用普通喷泉假扮打铁花。

## 表达范围

- 多层芯以半径比反求初速，共用爆点和开花时间；亲星不计入芯的层数。
- 四色牡丹用四组独立色星叠在一次爆点，是混合分布，尚未做参考里的扇区分色。彩色千轮是四组小玉，共 20 朵，不包含速射节目。
- 多节礼花弹有各自延迟和偏移爆点，先看开花编排；节间弹体继续飞行尚未表现。
- 引先用已有前段暗头、尾停发和色星变亮能力。残光和满天星暂取低频 2 Hz，不代替后续帧预算和频闪标定。
- 冠/柳和新色是云端参数起点的结构预览，未宣称精确复刻视频。银柳首轮出现白团，仅减曝光未解决展开过小；调整初速、终端速度、质量变化和曝光后，展开/下垂与枝条可辨。正式库未改。

## 检查与未完成标准

`配方检查.json`：22 个 PC 配方；`手机/配方检查.json`：八重芯、四色牡丹、银柳、彩色千轮、多节礼花弹。每个案例保存 0.8 秒、1.6 秒和 70% 时长的实际回放图。整体和局部已看，连续播放、逐层查看、完整配方下载、快速切换、注入失败后的恢复、退出和旧模式恢复均经过浏览器检查。单画面 CSS 曾拉伸圆花，已补显示比例检查并修复。

`旧橱窗/橱窗检查.json`：9 项原橱窗全部可播放。`兼容回归/回归.json`：7 项旧核定帧对 3.7 基线逐像素零差。显卡为 RTX 5080 / D3D11。
