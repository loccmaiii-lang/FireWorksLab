# 4.0 连续播放修复检查（3.13）

本报告只证明源码调用、模拟/计划数据和变换数学正确。没有本轮 GPU 像素、亲眼连续播放或 UE 实测，不能作为艺术验收通过。

用户反馈：清晰度改善，全部新预览顿挫、抖动，后段整个预览缩小。

确认的两个机制：实时预览将当前烘焙取景铺满画布，取景扩大时观看镜头也后退；贴图的帧中心时刻与回放 tick 的 Size By Life 时刻不同，静止世界标记在换帧时会重置尺度，离线复现最大约 3.24%。后者已消除时刻差，前者已改固定世界镜头，静止标记的显示投影误差不超过半个像素。
