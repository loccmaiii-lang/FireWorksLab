# 4.6.0 → 4.7.0 改前改后（开花后同一秒，对话框15 2026-10-05）

每张图三格：左 = 4.6.0（改前），中 = 4.7.0（改后），右 = 差 × 8。

4.7.0 是 5.0 第 2 步，改了三件事：
- 一套物理：火花按实际年龄冷却，老的先暗；
- 结尾等火花自然灭完；
- 固定机位 + 匀速帧。

- **看到的变化**：
  - 尾迹后段先淡掉，线变短、更干净。以前是「一条线上随机灭」，沿线有零碎的亮点。
  - 菊的序列时长 3.2 → 4.4 s，金芒菊 4.56 → 5.5 s，火花自然灭完，不再最后 0.3 s 整体淡出。
- **图**：
  - 菊 `kiku_*.png`、锦冠 `kamuro_*.png`、点灭 `strobe_*.png`：花型模板；
  - 金芒菊 `jinmangju_*.png`：正式库那一版的参数（正式库导进引擎的包不动）。
- 用法：`python3 analysis/scripts/基准回归.py --old 旧.html --new 新.html --at 0.6,1.6,2.6,3.6`（4.7.0 起有 `--at`：序列时长改了时，要按同一秒比）。
