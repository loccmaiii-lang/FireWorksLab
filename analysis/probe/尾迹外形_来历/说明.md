## 代码（`40_gl.js` 火花着色器，从 4.2.8 到现在 4.9.20 一个字没改）

- 位置 a = 这颗火花出生点离星头的距离 ÷ 这条尾迹的长度（星头现在的位置到「一个火花寿命之前」星的位置），0 = 星头、1 = 尾端。**是整条尾迹归一化**，按距离不按年龄（星在减速，按年龄算最粗处会贴到星头）。
  - 4.2.8 的 CHANGELOG 写的是「火花年龄 ÷ 寿命」，同一次提交的代码注释写的是距离，代码按距离——记录写错了，代码没变过。
- 宽度曲线 wq(a)：最粗处之前从 1 − 星头端收尖 升到 1，之后降到 1 − 尾端收尖；W = 粗细 × wq。
- 改的是**火花横向散开那部分位移**（散布速度 × 阻力衰减）和尾迹扩散，所以整条尾迹变粗 / 变细、两头收尖；颗粒大小只 × √粗细 × (0.5 + 0.5 wq)，尾端那半段稍暗。
- **只作用在「火花」**：`c == 0 && !emb`——余烬（`emberFrac` 那部分）、分叉火花都不管；尾迹长度也按火花寿命算。
  - 亮肩 `tailShoulder`、大小随机 `tailJit` 却连余烬一起管（各按自己的年龄）；泪滴形 `headTear` 只管星头（`20_sim.js`，沿运动反方向补几个点）。

## 为什么四尺玉看起来「只改了单颗火花」

四尺玉锦冠层（HK10-1）：余烬占 45%、余烬寿命 6.48 s、余烬大小 0.8；火花寿命 2.03 s、大小 0.22。看到的那一大片长长下垂的金色尾迹主要是**余烬**，这几个旋钮从 4.2.8 起就不管余烬；能变的只有星头附近 2 s 那截火花（白亮的短段）。

对照图 `尾迹外形_对照.png`（云端低画质快速渲染，星数减到 90，只看趋势）：
- 四尺玉：粗细 3 只把星头附近那截白亮火花加粗，金色余烬尾迹不变；把余烬比例调成 0 以后只剩那截短火花——长尾迹就是余烬。
- 引菊 → 锦金锦层（没有余烬）：粗细 3 整条尾迹变粗；两头收尖 1 / 1 两头细、中间粗——整条尾迹归一化照常。
