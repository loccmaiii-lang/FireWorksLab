# 5.0 第 1 / 3 步示例：同一朵菊，开花后 2.8 s（烘焙器 4.8.1，云端软件渲染 384 px）

`菊_加发射器_对照.png` 从左到右四格：

1. **菊（模板原样）**。
2. **＋ 加发射器 → 自定义 1 = 星熄灭时生成光点**：
   - 每颗星 10 个，初速 14 m/s，亮度 2.5，大小 0.9 m，寿命 0.8 s；
   - 闪烁 0.6 / 12 Hz，像熄灭时炸开一小簇碎光。
3. **自定义 1 改成「生成星」**：
   - 每颗星熄灭时开 5 颗小星，带火花（每秒 60），像子花；
   - 以前只有千轮 / 分裂两种花型能做。
4. **火花「大小随寿命」**「0:0.3, 0.25:1.6, 1:0.4」+「亮度随寿命」「0:1, 0.5:1.4, 1:0.3」：
   - 刚喷出细、中段粗亮、尾端收细（梭形的新做法）；
   - 这个时刻火花大多在灭，差别不大，开花后 1 s 左右看得更清楚。

怎么用：右栏发射器标签那一行最后「＋ 加发射器」；曲线在每个发射器的「大小」「亮度」模块里，「随寿命」那一行写几行「时刻:倍数」。
