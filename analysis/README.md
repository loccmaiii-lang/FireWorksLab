# 实拍视频解析

14 段参考视频（`vidio/`）的编号、缩略图总览、测量数据和脚本。完整结论见提示词文档里的「实拍视频解析」。

| 文件 | 内容 |
| --- | --- |
| `视频编号.json` | V01–V14 与原文件名的对应 |
| `sheets/` | 每段视频 24 格缩略图总览 |
| `measure.json` | 燃烧时长、扩张曲线（半径到 50% / 80% / 90% 所用的燃烧进度）、下坠量、上下不对称、消え口、爆点位置 |
| `colors.json` | 按燃烧进度的主色时间线（只统计比开花前变亮、未过曝的像素） |
| `fit.json` | 用工具同款物理模型（二次阻力 + 重力）反推的初速与终端速度 |
| `curves/` | 亮度总览、归一化扩张曲线 |
| `scripts/` | 可复现的分析脚本（Python + OpenCV） |

所有比例都是无量纲的（时间除以燃烧时长、长度除以终态半径），不受慢放倍数和拍摄距离影响。
