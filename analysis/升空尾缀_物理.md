# 升空尾缀：物理原理、实拍印证、新做法（2026-09-29）

> 起因：你看完 TR2 说「所有效果都是一条线周围有一些粒子，头部加一个光点」，化学上就不对——礼花弹飞行中不停燃烧、释放大量火星，有的弹会旋转，火星会被风吹出轻微扰动。
> 这份文档把真实的物理化学查清楚，用参考视频逐条印证，再换成烘焙器 / Cascade 的做法。代码：`analysis/scripts/trail_phys.py`（物理模型 + 对照）、`trail_phys_bake.py`（烘焙引擎素材）。

## 1. 结论先说

你的判断是对的，而且还有两点你没说到、但实拍里看得很清楚：

1. **尾迹是停在空中的火星，不是跟着弹体走的线。** 火星一离开弹体就被空气拦住（小颗粒阻力大，零点几秒就停），停在「弹体走过的路」上原地燃尽、随风慢慢漂。实拍 尾缀B 里，尾迹上的每一段在画面里几乎不动，只有星头往上走。
2. **弹体一直在减速**（出膛 77 m/s → 开花前 17 m/s），所以尾迹的长度和密度一直在变：出膛时火星撒得开、尾迹长而稀；接近开花时撒得密、尾迹短而亮。旧做法是「弹体坐标里匀速循环」，这一点从根上就做不出来。

旧做法错在哪：

| 旧做法（TR1–TR3） | 真实情况 |
|---|---|
| 在随弹体的坐标里、按固定速度做一段循环 | 地面坐标里火星停在原地；弹体在减速，尾迹长度、疏密一直在变 |
| 一条细火花组成的「线」+ 周围一些粗火花 | 同一股喷流：刚喷出的一大团又热又密的火粉 = 连续白热段；木炭火星燃烧期亮度稳定，快烧完才变暗变橙，一颗颗散开 |
| 星头 = 一个圆光点 | 星头 = 泪滴形燃气焰，尖头朝前，后面紧接白热柱 |
| 波浪 = 星头左右甩 | 星头走得很直（尾缀B 摆动 0.18 m）；波浪是**弹体自转**让喷口方向转圈（细碎小波纹）+ 弹体轻微摆动（30–60 m 的大波浪），喷出来就「冻」在空中不动 |
| 没有风 | 整条尾迹以约 1.7 m/s 顺风漂，越老的火星偏得越多 |

## 2. 真实的物理和化学

**曲导（昇り曲導）是什么。** 日式礼花弹外面绑的升空效果件。「竜」（昇り竜）是一节装火药的纸筒，出膛时被发射药点燃，一路燃烧到开花，向后喷出火焰和火星；金色的叫金竜（木炭火星），白色的叫银竜（铝粉火星），还有带小花、分砲、笛音的变体 [1]。它本质上是绑在弹体上的一支小「火箭尾焰」，喷出的东西有三种：

- **燃气焰**：火药燃烧的高温气体，紧贴喷口，是星头那个又尖又亮的泪滴形。
- **火粉**：极细的颗粒，数量极多、温度最高（接近白色）、寿命只有零点几秒——它们挤在星头后面十几米内，相机里连成一根过曝的白热柱。
- **木炭火星**：较粗的木炭颗粒在空气中燃烧，是金色尾迹的主体。木炭颗粒越细燃得越久、越「挂」在空中，越粗越亮但烧得快 [2]。

**火星为什么是金色、怎么变色。** 木炭火星是固体颗粒在空气里燃烧发光，颜色就是它的温度（黑体辐射）：约 2300–2500 K 是黄白色，2000 K 左右是金色，1500 K 以下是橙红。燃烧期颗粒表面温度基本稳定（燃烧速度受氧气扩散限制），所以一颗火星大部分时间都是亮的金色，快烧完时颗粒变小、温度掉下来，才迅速变橙变暗熄灭。

**寿命和粒径。** 颗粒燃烧遵循「d² 定律」：燃尽时间 ∝ 粒径²。粒径大致是对数正态分布，所以寿命也是：多数火星 1–2 秒，少数大颗能烧 3–4 秒，就是尾迹最下面零零星星的几个火点。

**弹体怎么飞。** 竖直方向受重力和二次空气阻力（阻力 ∝ 速度²）：
v(t) = √(g/k) · tan(atan(v₀√(k/g)) − √(gk)·t)，高度 h(t) = ln(cos(a − √(gk)t)/cos a)/k，a = atan(v₀√(k/g))。

**火星出来以后怎么动。** 出生时带着弹体速度，减去向后喷出的速度（十几到二十米每秒），再加一点横向散开。然后受三种力：空气阻力（dv/dt = −k(v − 风速)，小颗粒 k 大，零点几秒就停下）、重力（停下后以终端速度慢慢下坠，不到 1 m/s）、风（整体顺风漂，不同高度风不一样 → 尾迹有冻住的弯曲）。

**旋转。** 礼花弹出膛时会带一点自转，曲导绑在弹体侧面，弹一转、喷口方向就跟着转，火星出膛时多了一个转圈的横向速度——落在空中就是一圈螺旋，从侧面看是尾迹上细碎的小波纹。弹体越快，波纹拉得越长（波长 = 速度 / 转速）。

**相机。** 实拍里白热段是过曝的（像素顶到 255），所以它的「亮度」看不出来，只看得出它有多长、多粗；星头因为移动快，在快门时间内被拖成一小段亮线；近景跟拍时相机在转，停在空中的火星反而被拖成短竖线（尾缀3.0_A 里那些「竖线火星」就是这么来的）。这些都只在对照时加，不烘进贴图。

## 3. 实拍印证（量出来的数）

远景 **尾缀B**（固定机位，2560×1440，0.306 m/像素，逐帧跟踪星头和每一行的尾迹中心）：

| 量 | 实测 | 说明 |
|---|---|---|
| 出膛速度、阻力 | v₀ = 77.5 m/s，k = 0.002 /m | 星头高度逐帧拟合，均方根误差 3.6 像素 |
| 速度 | 1 s 72，2 s 54，3 s 40，4 s 28，开花前 17 m/s | 一直在减速 |
| 开花 | 出膛后 4.46 s，高 188 m | 视频 5.2 s |
| 弹道倾斜 | x = −0.0092·z − 0.00073·z²（m），开花时偏 27 m | 越高越偏，顺风 |
| 星头摆动 | 0.18 m | 星头走得很直 |
| 可见尾迹长度 | 2.5 s 时 89 m，4.5 s 时 81 m，5.1 s 时 62 m | 可见的最老火星约 1.5 s（快时）→ 2.2 s（慢时） |
| 过曝白热段 | 约 35–49 m | 快时约 0.8 s 以内的火星、慢时约 1.4 s 以内 |
| 横向宽度 | 0.56–0.65 m（按行亮度的标准差） | |
| 火星随年龄的横向偏移 | 0.1 s −0.17 m，0.4 s −0.64 m，1.0 s −1.68 m，1.4 s −2.38 m | 顺风漂 **1.7 m/s** |
| 尾迹的弯曲 | 主要波长 30–40 m，幅度 0.2 → 0.5 m（随年龄慢慢变大） | 0.2 s 和 1.4 s 的形状相关系数 0.92：喷出来就冻住 |

远景 **尾缀A**（同一机位、更大的弹）：星头摆动 0.68 m，尾迹弯曲 1.1 m（波长 32–38 m），顺风 1.45 m/s——弹越大、波浪越明显，规律相同。

近景 **尾缀3.0_A**（4K 竖拍，从发射点附近仰拍跟拍，是另一发更大的弹）：尖头火焰 → 很长的连续过曝白热柱 → 往下散开成一颗颗金色火星（带跟拍拖出的短竖线）→ 越往下越稀。
它「往下越来越宽」主要是**透视**：相机在发射点附近往上拍，尾迹越往下离镜头越近、被放大。所以近景只对结构和质感，不对比例。

**十六寸永丰**：同样是长白热段 + 下方金色火星，跟拍，近似竖直，印证同一结构。

## 5. 进引擎：两层（只用 Cascade + 现有材质）

1. **星头白热段**（1 个粒子，Screen Alignment = Velocity）：火焰 + 火粉。在「随弹体、匀速」的坐标里这一段是稳态的，所以烘成一段无缝循环（火粉按周期复制、自转转数取整）。Velocity/Life 按弹道速度曲线走；Size By Life 的 Y 按速度缩放（参考速度 50 m/s 时 18.7 m；出膛约 28 m、到顶约 7 m）。
   贴图：`T_EFX_FireWorks_RiseTrail_Head_16x1_01`（2048，16×1 格，RGBA 接力 64 帧，30 fps 循环）。
2. **金火星簇**（世界坐标，Spawn Rate 约 143/s）：一簇 = 同一瞬间喷出的 14 颗木炭火星（按粒径分位取样：一簇就代表整个分布），贴图里是它们自己的散开、闪烁、大颗后灭。一簇整体怎么动交给 Cascade：
   Initial Location = 弹道位置、Initial Velocity = 弹体速度 − 喷出速度（都是按发射器时间取值的曲线）、Drag = 空气阻力、Acceleration = 重力 + 阻力 × 横风（按高度的曲线）。
   贴图：`T_EFX_FireWorks_RiseTrail_Puff_4x4_01`（2048，4×4 格，RGBA 接力 64 帧 / 3.2 s），逐帧曝光、Color Over Life 乘回。
3. **渐变图**：黑体颜色（1350 / 1750 / 2150 / 2500 K → 暗红 / 橙 / 金 / 黄白），编码值越高越白。

这样尾迹停在空中、随风漂、弹体减速时自然变短变密、有冻住的波浪——这些都不是贴图「画」出来的，而是 Cascade 按物理摆放出来的。参数表：`analysis/results/TP1/RiseTrail_Cascade参数.txt`。

需要在引擎里确认的一点：Initial Location / Initial Velocity 的曲线按发射器时间取值（Cascade CPU 粒子是这样）。GPU 粒子如果不是，改成 CPU 粒子（同屏约 450 个）。

## 6. 新的提示词（以后做尾缀、或让别的模型接手时直接用）

```
任务：做写实日式礼花弹的升空尾缀（昇り竜 / 曲导），用于 UE4.24 Cascade（只用现有材质，帧号走 Dynamic Parameter 第 3 通道，RGBA 接力灰度 2K，颜色来自渐变图 + Color Over Life）。

物理必须满足：
1. 地面坐标：弹体按二次阻力弹道减速上升（v0、k 从实拍星头轨迹拟合），曲导从出膛一直烧到开花。
2. 喷出物三层：星头泪滴形燃气焰；极密极短命（0.1–0.3 s）的火粉 → 连续白热段，长度 ≈ 速度 × 寿命；
   木炭火星（对数正态粒径，寿命 ∝ 粒径²，燃烧期温度稳定、快烧完才变橙变暗，闪烁），少量长寿大颗落火。
3. 火星出生速度 = 弹体速度 − 向后喷出速度 + 横向散开 + 自转造成的旋转横向速度；之后线性阻力（小颗停得快）+ 重力 + 风 + 随高度变化的冻结湍流。
   结果：尾迹停在空中、顺风漂、波浪一喷出就冻住；弹体越慢尾迹越短越密。
4. 颜色按黑体温度（2500 K 黄白 → 2150 K 金 → 1750 K 橙 → 1350 K 暗红）。
5. 相机效果（过曝、快门拖影、镜头光晕）只在和实拍对照时加，不烘进贴图。

验证：远景固定机位视频（如 尾缀B）用同一套量法对：星头轨迹、可见长度、过曝段长度、横向宽度、火星随年龄的横向偏移（风）、尾迹弯曲的波长和持续性；
近景视频（如 尾缀3.0_A）只对结构和质感（仰拍有透视，比例不可比）。

引擎拆法：星头白热段 = 速度朝向单粒子 + 无缝循环序列（长度按速度缩放）；金火星 = 世界坐标的「火星簇」序列粒子，
出生位置 / 初速 / 加速度用按发射器时间取值的曲线落在弹道上。不要做「随弹体匀速循环的一条线」。
```
