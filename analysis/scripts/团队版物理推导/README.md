# 团队版物理推导脚本（2026-10-25）

`analysis/原理/` 下 5 个复杂火星推导（钢命中火星、爆炸分簇火星、短路喷溅、砂轮切割火星、龙息弹）里的数字由这些脚本算出。只用 numpy，在本目录运行：`python3 phys2.py` 等。

- `phys.py`：共用核——空气物性、Schiller–Naumann 阻力、轨迹积分 `traj`、线性 / 平方阻力拟合、Ranz–Marshall 对流 + 辐射冷却 `cool`。
- `phys2.py`–`phys10.py`、`bb.py`、`refine.py`：各模板的分步计算（文件里注明对应哪个模板哪一节）；`refine.py` 是砂轮寿命分布的向量化回代。

这是推导工具，不是烘焙器的一部分；改了烘焙器模型不影响它们。
