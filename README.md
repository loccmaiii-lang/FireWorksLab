# FireWorksLab · 烟花烘焙器

UE 4.24 Cascade 用的写实日式烟花素材：在网页烘焙器里模拟、调参，烘焙成序列贴图，导出素材包（贴图 + Ramp + Cutout + `cascade.json` PC / 手机），再用本机导入工具进引擎。不新增材质，引擎里不写代码。

## 打开

用电脑版 Chrome 或 Edge 直接打开 `tool/FireworkBaker.html`，不用安装。右上角会显示用的显卡；提示「软件渲染」就开启浏览器硬件加速。拉取更新：`git pull` 后刷新页面。

- **左栏**：待我验收 / 制作中 / 已通过 / 我的版本；旧版本在各效果的「历史」里。
- **画面上方资产栏**：版本（AI 版 / 你保存的版本）、保存、导出素材包。
- **右栏**：参数 / 审阅 / 工具。
