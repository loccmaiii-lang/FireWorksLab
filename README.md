# 烟花母版烘焙器

离线模拟写实日式烟花，烘焙成 UE 4.24 Cascade 可直接使用的通道打包序列帧，并导出 Cascade 参数表。不需要新增材质或代码，只用项目现有的序列帧材质、发射器模块和贴图。

## 使用

用电脑版 Chrome 或 Edge 直接打开 `tool/FireworkBaker.html`，不需要安装。右上角会显示当前使用的显卡；如果提示「软件渲染」，请开启浏览器硬件加速，笔记本需把浏览器设为高性能显卡。

三个页签：

- **母版**：点「花型 → 更换」打开花型库（缩略图、分类、搜索、收藏、最近使用）选花型、调参数、看「实时模拟 / 导出效果 / 贴图」，导出 ZIP。贴图视图可切「流转动画」：放大当前格、整张贴图上金框走动、下方帧号曲线。
- **组合**：把几张母版叠成芯、多重芯、四尺玉等组合。
- **迭代**：A/B 分屏、实拍视频或实机截图叠加、与实拍的数值对比、版本回滚、派生配方、显卡测速。

## 花型与产物

| 类别 | 花型 | 默认产物 |
| --- | --- | --- |
| 礼花 | 菊、牡丹（芯）、锦冠、柳、千轮、蜂、椰子、变色菊（5 段） | 大面片母版；锦冠、柳可分段；菊类可出单元序列 |
| 效果星 | 点灭、辉星、爆裂、松叶、分裂（十字）、落叶、时差（延时点火） | 大面片母版 |
| 形状 | 环、土星、型物（心形、笑脸、五角星、文字）、水中花火（含水面倒影） | 大面片母版 |
| 上升 | 金色曲导、银竜、暗升、昇り小花、分砲、笛、螺旋 | 星头循环 + 弹道拟合 + 尾迹火花发射器参数 |
| 地面 · 循环 | 喷泉（可排成扇面）、瀑布、转轮、扇形、连发、仕掛け（文字/图案） | 周期性烘焙的循环序列，首尾无缝 |
| 实拍复刻 | 按你发来的视频逐个复刻，每个都有实拍与模拟的对照图和数值，确认后加入 | 按对应花型 |

四种产物：

- **大面片母版**：整朵花一张序列、一个面片。默认「紧凑取景」：面片中心跟着内容走（Cascade 用 Initial Velocity + Drag + Const Acceleration 复现），横竖 Size By Life 分开，每帧内容占满格子 90% 以上。可选「分段」：开花段与下垂段各一张贴图、一个发射器。可一键导出三个种子变体 V1–V3（共用参数表，只换贴图）。
- **单元序列**：贴图里只有一颗星（一束）的星头和拖尾（沿速度方向），比如松叶只要其中一束就用它，每颗星一个 Cascade 粒子，轨迹由线性阻力 + 恒定加速度拟合，Size By Life 横竖分别缩放。
- **上升星头循环**：弹体随体坐标里的星头与尾迹，按 30 fps 循环；参数表给出弹道、Orbit 曲导、尾迹火花发射器、开花衔接。
- **地面循环**：火花按周期性编号生成，最后一帧直接接回第一帧；Cascade 里 Emitter Loops = 0。

## 导出格式（与项目材质约定）

- 一张贴图、灰度、BC7、只导出 2K（1K 在引擎内复制后设最大尺寸）
- 帧号由 Dynamic Parameter 第三通道给出，材质取整、不做帧间混合
- RGBA 接力：先填满 R 的全部格子再接 G、B、A；格子行优先，左上为第 0 帧；格子四周默认留空 2 像素
- 颜色：渐变图按灰度取色，随时间变色用 Color Over Life（最多 5 段）
- 大面片可随开花放大（Size By Life），爆点在精灵中心
- ZIP 内容：贴图、渐变图、`Cascade参数.txt`（含自检、烟、声音节点、LOD 建议）、曲线 CSV、声音节点 JSON、参数 JSON

## 命令行批量重烘

```
cd tool
npm i playwright
npx playwright install chromium
node batch_bake.mjs <参数JSON、配方库JSON 或 文件夹> [输出文件夹] [--size 2048] [--show]
```

Windows 上无头模式有时用不到独立显卡，慢的话加 `--show`。
