## 背景

用户 2026-10-05 的原话：「没有统一的 UI/UX 与交互逻辑，经常加了功能到处乱放，整个工具当前东拼西凑的感觉明显」「类似的 bug 与功能不完整性很多，希望可以一起筛查出来」。他当天碰到的具体例子（都已核实，照这个颗粒度写）：

- 想删不满意的版本 / 效果 → 「删除这个版本」在左栏最下折叠的「版本记录」菜单里、只对保存过的版本亮；「删除这个效果」在顶栏「⋯」菜单里、只对「我的效果」亮；AI 条目不能删。
- 调好一层想存成模板 / 收藏 → 选择器只有花型模板和 AI 效果的层，没有「我的模板」。
- 打开 AI 做的效果调完保存后想加层 → 加层只在「我的效果」里有，保存成「AI 效果下的我的版本」后层数仍锁着。
- 调模板不满意想一键还原 → 「恢复到打开时」在参数栏最底下（滚过 300 多个参数），双击参数名回默认没人知道。
- 参数说明条点开关不掉 → 4.4 改成了点击切换，没有关闭。
- 时间轴新加的发射器行和曲线视图挤掉笔记本画布。
- 打开效果默认进「引擎回放」（只对待验收候选），用户想要实时模拟。

这些会由对话框15 在「第 1 步快改包」里修。你的任务是把**其余所有**同类问题找全，并给出一张「什么东西该在哪」的图，让以后加功能有地方放。

## 怎么走

1. 构建：`python3 tool/build.py`（会顺带跑静态检查）。打开 `tool/FireworkBaker.html`（本地文件即可；Playwright 用 `analysis/scripts/browser_runtime.py` 的 `launch_async`，参考 `analysis/scripts/界面冒烟.py` 和 `界面状态检查.py` 怎么打开、怎么等空闲、怎么截图）。先跑一遍 `python3 analysis/scripts/界面冒烟.py --sweep --noshot` 看有没有 console error。
2. **对象清单**（行）：花型模板（36 个）、空白发射器、AI 条目（单层 / 多层）、正式库条目、我的效果、我的效果的版本、未保存草稿、导出时自动存的恢复点、层（多层里的一层）、我的模板（现在没有）、收藏、配方文件（.json 导入导出）、素材包（导出结果）、本机任务结果（结果文件夹）。
3. **动作清单**（列）：新建、打开、改参数、保存、另存 / 派生、复制、改名、删除、撤销删除、还原（到打开时 / 到默认 / 到某版本 / 某模块）、收藏、隐藏、排序、导入、导出、分享给 AI（复制改动）、查看历史、搜索。
4. 每个格子填：`有 / 无 / 半`（半 = 有但条件苛刻或藏着）、**入口路径**（例：顶栏 ⋯ → 删除这个效果）、**从看到对象到完成动作要几步**、**和同类动作放的位置一不一致**、**坏没坏**（坏了写复现步骤）。
5. **交互模式一致性**抽查：同一件事在不同地方的做法是否一样——确认对话框 vs 直接做、折叠 details vs 菜单 vs 按钮、悬停 vs 点击、快捷键有没有、Esc 关什么、撤销覆盖哪些操作、错误怎么提示（flash / alert / 静默）、破坏性动作有没有确认和撤销。
6. **布局**：1366×768、1920×1080 两个尺寸截图：画布占多少、左右栏默认宽度、底部占多少、哪些控件在首屏看不到。
7. **文案**：同一个概念有几个叫法（例：「实时模拟 / 渲染模式」「引擎回放 / 回放模式」「版本 / 恢复点 / 草稿」「效果 / 条目 / 配方 / 模板」），列成表。
8. 发现的 bug 一律写复现步骤（打开谁 → 点哪 → 预期 → 实际），能截图就放 `协作/筛查/截图/`。
